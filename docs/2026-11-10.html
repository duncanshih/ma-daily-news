總經 / 地緣政治

Fed理事Waller轉鷹：12月升息「傾向支持」、不排除一次升2碼 — 今晚10月CPI成為決定升息幅度的關鍵

深度解析

發生什麼事

聯準會理事Waller於11月10日表示，他「傾向支持」在12月FOMC升息，並明確說若通膨持續加速，他可以支持一次升息50個基點，這將是2022年以來最大幅度的升息；他並把政策建議直接掛鉤今晚公布的10月CPI。市場共識預期10月CPI月增0.3%、核心CPI月增0.2%；彭博指出利率期貨已將12月升息機率定價在八成以上。背景是10月非農新增16.5萬人、遠超預期，舊金山聯準銀行總裁Daly形容美國人正處於「高通膨跑步機」上、更多升息可能是必要的，里奇蒙聯準銀行總裁Barkin也稱升息在前但步調漸進。另一方面，T. Rowe Price全球固收主管Husain認為美債殖利率要等到美國經濟衰退才會見頂，而高盛則說「各項條件已到位」、全球10年期公債殖利率將出現轉折。美國10年期公債殖利率在Waller談話後小幅走高，交易員同時消化民主黨橫掃期中選舉後的避險買盤。

解讀

這不是單一官員的口風，而是Fed內部從「暫停」轉向「重新緊縮」的集體訊號：Waller過去是鴿派代表，他轉鷹的訊號價值比任何鷹派官員都高。市場反應以基本面為主，因為通膨來源是伊朗戰爭推升的能源與關稅成本，並非短期情緒。真正的分歧在幅度而非方向：1碼已被定價，2碼尚未。

傳導鏈

Waller鷹派談話 → 12月升息機率>80%、2碼機率開始定價 → 美債2年期殖利率上行、美元走強 → 新興市場匯率承壓（新台幣逼近33元、日圓）→ 外資自亞股匯出 → 台股估值壓縮、高本益比AI股首當其衝 → 企業海外籌資成本上升、IPO定價轉趨保守

結構性

週期性：這是通膨週期的第二波（能源+關稅），不是結構性利率中樞上移；但若Fed被迫一次升2碼，將確認「higher for longer」的結構敘事，與2022年情境類似。

矛盾訊號

Fed官員集體喊升息，但高盛卻說「殖利率轉折的條件已到位」、民主黨橫掃後資金轉進美債避險，殖利率曲線前端升、後端卻有買盤。市場同時在定價「升息」與「衰退」，兩者不可能同時正確——若CPI超預期，後端殖利率的避險買盤會被證明是錯的。

分叉情境

如果10月CPI月增≥0.4%、核心≥0.3%：12月升2碼機率升至四成以上，美元指數上測前高，新台幣跌破33元、台股再測4萬點整數關卡；如果CPI月增≤0.2%：市場回到12月升1碼甚至暫停的定價，美債10年期殖利率回落15-20個基點，亞股反彈延續。

展望

短期 · 1M
短期（1個月內）：12月FOMC升息1碼為基準情境（機率約六成），2碼機率約兩成五，不升機率約一成五；美債10年期殖利率在4.3%-4.7%區間震盪，前提是CPI落在共識±0.1個百分點內。
中期 · 3–6M
中期（3-6個月）：若美伊談判有進展、油價維持在80-90美元，通膨壓力在2027年Q1見頂，Fed升息循環止於累計2-3碼；關鍵變數是民主黨國會是否通過新的財政支出或對AI/資料中心課稅，改變通膨與成長組合。

Anthropic定價區間70-78美元、估值上看1.4兆美元、募資640億美元 — 11月19日掛牌將成AI交易的壓力測試

深度解析

發生什麼事

多家媒體於11月10日報導，Anthropic將IPO價格區間訂在每股70至78美元，預計11月19日開始交易，依FT計算估值最高達1.4兆美元，BBC報導本次募資規模約640億美元，將是史上最大IPO之一，距離SpaceX創紀錄的上市僅約5個月。同日Anthropic釋出新一代Mythos與Fable模型，並計畫舉辦執行長Amodei與摩根大通執行長Dimon的直播對談作為路演的一部分。台積電董事會同日核准以不超過5億美元、依IPO價格認購Anthropic普通股，另核准以不超過5億美元認購OpenAI特別股，兩案上限合計10億美元。CNBC的Cramer直言，這檔IPO「可能成就或摧毀AI交易」，因為它是在期中選舉後AI股遭2兆美元拋售、那斯達克進入修正區後登場。

解讀

這是AI資本市場從「私募估值」轉向「公開市場驗證」的分水嶺。Anthropic選在AI股剛修正、Fed轉鷹的時點定價，顯示承銷團判斷機構需求仍足以撐起640億美元的規模，而台積電的5億美元策略投資是供應鏈綁定客戶的訊號，不只是財務投資。但1.4兆美元估值意味市場要相信Anthropic的營收能在3-4年內成長數倍，這個預期差是IPO後股價波動的主因。

傳導鏈

Anthropic定價 → 640億美元新股供給吸走市場流動性 → 其他AI股（Nvidia、CoreWeave等）面臨籌碼排擠 → 若掛牌首日表現強勁，AI融資窗口重開、私募基金續投資料中心 → 台積電/台廠AI供應鏈訂單能見度延長；若破發 → AI估值全面重估、高殖利率AI債（CoreWeave 16%）違約疑慮升高

結構性

結構性：巨型AI公司從私募走向公開市場是不可逆的趨勢，SpaceX、Anthropic之後OpenAI勢必跟進；但定價時點與募資規模受週期影響（AI股修正、利率上行）。

矛盾訊號

一邊是Anthropic敢在AI股修正後以1.4兆美元估值募640億美元，另一邊是英國央行監管官員說銀行正削減AI曝險、CoreWeave債券殖利率突破16%。股權市場與信用市場對AI的定價正在分道揚鑣——通常信用市場先對。

分叉情境

如果11月19日掛牌首日漲幅≥15%且收在區間上緣以上：AI融資窗口重開，預期2027年Q1 OpenAI啟動IPO程序，台積電帳面投資收益立即顯現；如果首日跌破發行價或定價落在區間下緣70美元以下：AI相關債券利差再擴50-100個基點，資料中心新建案延後，台廠AI伺服器2027年訂單下修風險升高。

短期（1個月內）：定價可能落在區間上緣74-78美元，掛牌首週波動區間±20%；前提是CPI未引發Fed升2碼的恐慌。

中期（3-6個月）：Anthropic上市後市值在1-1.6兆美元間波動，成為AI板塊的新定價錨；關鍵變數是2027年Q1財報能否證明營收年增率維持三位數。

中國貿易順差連續第二年突破1兆美元（持續追蹤）

持續追蹤中

發生什麼事

CNBC報導，截至10月中國商品貿易順差已連續第二年超過1兆美元，貿易夥伴對中國低價商品傾銷的不滿升高，呼籲北京再平衡。同日FT報導福斯汽車放棄「在中國、為中國」策略，因中國市場急遽下滑而再度轉向；花旗執行長Fraser則在獲批設立大陸全資證券公司後向對手喊話「小心了」。民主黨橫掃期中選舉後，分析師指出川普維持美中貿易休戰的能力面臨風險。

關鍵數據

順差>1兆美元（截至10月，連續第二年）；福斯在華銷售急跌後策略轉向；花旗取得中國大陸全資券商牌照

解讀

1兆美元順差的本質是中國內需不足與產能過剩的外溢，不是出口競爭力單純提升。這會讓歐洲與新興市場的保護主義在2027年加速，而中國則用金融開放（花旗牌照）換取政治緩衝。

傳導鏈

分叉情境

如果歐盟在2027年Q1對中國產品擴大加徵關稅：台灣機械、鋼鐵出口歐洲受益（經部已取消焊接鋼管輸歐配額管制）；如果中國啟動大規模內需刺激（人民幣2兆以上）：順差縮小，台灣對中出口的傳統產業（石化、紡織）回溫。

展望

短期 · 1M
短期：11月中國出口年增率維持5-8%，順差續創新高；12月歐盟對中國鋼鐵、電動車的新一輪貿易措施是觀察點。
中期 · 3–6M
中期：2027年全球保護主義升級，中國順差可能在1.1-1.2兆美元見頂；若美國民主黨國會推動更強硬的對中貿易立法，美中休戰有破局風險。

不動產 / 私募

金管會拆高雄專區「緊箍咒」：私募基金99人上限鬆綁、銀行准賣海外比特幣ETF、保費可預繳 — 58家業者即日可申請

深度解析

發生什麼事

金管會11月10日宣布修正高雄資產管理專區試辦作業原則，11月11日生效，五大重點包括：未具證券投資信託性質的境外基金與境內私募股權基金，不再受單一基金客戶總數99人的限制；開放銀行銷售海外虛擬資產（比特幣）ETF；可替在台大戶辦理海外開戶；新增預繳保費專戶及OIU（國際保險業務）遠距投保，六家進駐專區的壽險業者即日可遞件。金管會估計合計58家金融業者可望受惠。同日歐洲最大資產管理公司東方匯理宣布在台推出首檔ETF（00993B，20-35年期AAA至A級美元公司債），台灣ETF市場規模已突破11.6兆元；國泰世華銀行則首度獲《PWM & The Banker》「台灣最佳另類投資私人銀行」獎。金融總會同時公布2026年金融科技投資預算將達483.5億元、年增近五成。

解讀

這是亞洲資產管理中心政策從「口號」走向「產品」的第一個實質拆牆：99人上限是私募基金在台灣募資的最大障礙，鬆綁後境外私募股權、私募信貸基金可以直接向台灣高資產客戶募資，等於把過去流向新加坡、香港的資金留在台灣。但開放僅限高雄專區且逐案送審，實際規模要看業者申請速度。

傳導鏈

解讀

長榮航空公布第3季合併營收660.94億元、年增26.0%，稅後純益67.99億元、年增15.7%，EPS 1.26元；10月營收231.82億元、年增22.63%創歷史次高，前10月營收2,175.61億元創同期新高，中央社指出長榮航、華航受惠AI帶動貨運強勁成長，獲利持穩高檔。星宇航空第3季營收162.82億元、稅後淨損2.93億元、EPS -0.1元，前三季淨損6.38億元，燃油成本較去年同期上升61%，貨運營收占比僅一成多、缺乏貨機「護體」；但10月營收58.95億元、年增59%創新高。國際上JetBlue一年內第三次調高行李費、澳航裁員850人移往印度並加速AI轉型，顯示油價正在壓迫全球航空業的成本結構。

關鍵數據

長榮航Q3 EPS 1.26元、淨利67.99億元（+15.7%）；星宇Q3 EPS -0.1元、燃油成本+61%；長榮航10月營收231.82億元（+22.63%）

解讀

同一個油價衝擊，有貨機的航空公司靠AI伺服器空運需求把成本轉嫁出去，沒有貨機的星宇只能硬吃。這是「資產結構決定週期韌性」的經典案例：AI供應鏈的空運需求（伺服器、GPU時效性高）成為航空貨運的結構性需求，而非疫情時的短期紅利。

傳導鏈

伊朗戰爭推升航空燃油 → 航空業燃油成本年增61% → 有貨機的長榮航、華航以AI伺服器空運需求（運價高、時效性強）抵銷 → 星宇客運為主、無貨機，Q3轉虧 → 油價跌破90美元後星宇Q4有望轉盈 → 若AI伺服器出貨放緩，貨運運價回落，長榮航、華航的緩衝消失 → 航空業獲利的決定因素從「油價」變成「油價+AI出貨」

分叉情境

如果油價回落至80美元且AI出貨持續：長榮航2027年EPS上看5元以上，星宇全年轉盈；如果油價回到100美元且AI伺服器出貨放緩：長榮航貨運緩衝消失、EPS下修三成，星宇虧損擴大至全年10億元以上。
