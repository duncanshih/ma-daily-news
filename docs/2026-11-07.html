總經 / 地緣政治

美國10月非農大增16.5萬、失業率降至4.1% — 聯準會從「暫停」轉向「再升息」的討論升溫，民主黨大勝與油價回落是僅有的煞車

深度解析

發生什麼事

11月6日美國勞工部公布10月非農新增16.5萬人，市場預期僅5.9萬；失業率由4.2%降至4.1%，同樣優於預期。舊金山聯準銀行總裁Daly稱就業報告是「美國勞工的好消息」，但美國人正處於「高通膨的跑步機」上，更多升息「有可能」；里奇蒙聯準銀行總裁Barkin 11月5日表示升息在前方但步伐漸進；10月30日Musalem與Logan已率先釋出需重回緊縮的訊號。同日CNBC指出，民主黨期中選舉大勝讓市場重新思考利率路徑：伊朗戰爭若和解、美國成長放緩、新財政政策三者都可能壓制升息，但「沒有一項是確定的」。強勁數據底下藏著隱憂：10月平均失業持續時間突破27週，是十年來疫情期以外最高。數據公布後美元走強、科技股反彈，那斯達克100上漲1.4%。

解讀

這份報告把Fed的兩難推到極限：就業偏熱與通膨黏著支持升息，但AI股3.2兆美元蒸發與民主黨主導的資料中心限制正在為2027年成長蒙上陰影。市場反應（美元強、10年期殖利率未明顯上升）顯示投資人押注Fed「說升但不急著升」。27週的長期失業數字則說明勞動市場是「低聘低解」的僵固狀態，而非全面過熱。

傳導鏈

非農16.5萬遠超預期 → Fed官員升息論述獲得數據背書 → 美元指數反彈、亞幣（新台幣、韓元）承壓 → 美債短端殖利率上行、長端因成長疑慮持平 → 殖利率曲線趨平 → 高估值成長股折現率上升、AI股反彈乏力 → 台灣外資匯出壓力不減

結構性

週期性：這是通膨黏著週期的尾段，Fed在「升息抗通膨」與「AI資本支出放緩拖累成長」之間擺盪，不是結構性轉向。

矛盾訊號

就業強勁（+16.5萬）與長期失業人口達十年高點並存；Fed說要升息，但民主黨大勝後市場反而在討論「升息會被壓制」——數據與政治在拉扯同一條利率路徑。

分叉情境

若11月CPI年增率維持3%以上且12月非農再超過10萬，Fed在12月17日會議升息1碼的機率升至6成以上、美元指數站回102、新台幣再測33元；若伊朗停火落定且油價跌破80美元，通膨預期回落，Fed維持按兵不動、美元回落至98-100，亞幣與AI股同步獲得喘息。

解讀

台灣資金市場「兩樣情」（持續追蹤）— 30天期CP利率1.75%創17年新高、隔拆利率0.811%卻為今年新低；央行減發定存單1.54兆放水、未到期餘額跌破6兆

持續追蹤中

發生什麼事

央行最新統計，10月金融業隔夜拆款加權平均利率0.811%、較9月降0.006個百分點，為今年新低；但30天期商業本票（CP）次級市場平均利率升至1.75%、單月大漲0.23個百分點，續創2008年11月以來近17年新高，銀行間資金市場與企業短期融資市場呈現兩樣情。工商時報指央行今年至10月底減發未到期定存單達1兆5,442億元，未到期餘額跌破6兆元，9月起公開市場操作方向明確轉為積極放錢，以舒緩「錢荒」疑慮。

關鍵數據

30天期CP利率1.75%（月增0.23個百分點、17年新高）；隔拆利率0.811%（今年新低）；央行減發定存單1兆5,442億元、餘額跌破6兆

解讀

銀行間有錢、企業借不到便宜錢，說明資金卡在銀行體系（存放比偏高、信用風險溢酬上升、AI大廠擴產吸走長期資金）。這是股災前就在發生的信用分層：CP與隔拆的利差擴大至約94個基點，中小企業短票成本被推高，而央行放水只到銀行間、傳導不到票券市場。股災與外資匯出會讓這個分層進一步惡化。

傳導鏈

外資匯出＋AI大廠擴產資金需求 → 銀行放款額度緊、存放比上升 → 企業轉向CP市場 → CP利率飆至17年新高 → 央行減發定存單放水 → 隔拆降至新低但未傳導至CP → 信用利差擴大 → 中小企業融資成本上升、營運資金壓力 → 若股災延續、銀行進一步收緊授信，違約率上升

分叉情境

若股市止穩、外資回流，CP利率12月回落至1.5%、利差收斂；若外資續匯出，央行放水效果有限，CP利率站上2%，中小企業與票券公司承壓，2027年第一季企業違約率上升。

展望

短期 · 1M
短期（1個月內）：11月CP利率是否突破1.8%、央行是否進一步減發定存單或啟動其他流動性工具；外資匯出對台幣流動性的衝擊。
中期 · 3–6M
中期（3-6個月）：央行12月理監事會利率決策與信用管制是否微調；若Fed升息，央行面臨「穩匯」與「放水」的政策衝突。

台灣AI供應鏈基本面與政策變數（持續追蹤）— 日月光1,237億元擴產南科高階封測、世芯Q3 EPS 37.7元、10月出口預估年增40-44%，但台廠赴美面臨電力、租稅、勞動三變數

發生什麼事

日月光通過經濟部投資臺灣事務所「歡迎台商回台投資行動方案」審查，規劃投入1,237億元在南科台南園區、高雄園區及楠梓科技園區增設智慧化產線，擴充高階封裝測試產能，台南市長黃偉哲稱將強化台南先進封裝聚落。世芯-KY 11月6日法說公布第三季獲利季增近一倍、EPS 37.7元，前三季EPS 75.94元、年增逾五成，法人估明年業績倍增。財政部預計11月9日公布10月出口，先前預測852-877億美元、年增40-44%；亞太商工總會執行長邱達生指民主黨對AI疑慮較多、台灣出口高度依賴AI，選舉結果需觀察。經濟日報指德州、俄亥俄等共和黨票倉變天，台廠AI供應鏈赴美投資將面臨電力供應、租稅優惠、勞動規範三大變數。

關鍵數據

日月光投資1,237億元；世芯Q3 EPS 37.7元、前三季75.94元；10月出口預估852-877億美元、年增40-44%

解讀

基本面數據全在高檔（出口+40%、世芯EPS翻倍、封測擴產），但這些都是「過去決策」的結果；市場現在定價的是2027年以後的訂單。日月光選擇在台灣而非美國擴產，是對美國政策變數最直接的回答——當美國州級政策不確定性上升，「在台擴產、在美保守」會成為台廠的主流策略。

傳導鏈

AI需求 → 先進封裝產能吃緊 → 日月光台灣擴產1,237億 → 台灣半導體聚落強化、對美投資相對放緩 → 美國州政府政策變數上升（電力、租稅、勞動） → 台廠「在台擴產、在美保守」 → 若美國要求製造在地化加碼，台廠面臨二次投資壓力 → 台灣電力與土地需求同步上升

分叉情境

若美國新任州長維持既有租稅協議，台廠美國投資照舊、台灣擴產與美國投資並行；若德州取消優惠或電價調漲，台廠轉向亞利桑那或回台擴產，台灣半導體投資2027年再增10%以上，但台灣電力供應壓力同步升高。

中期（3-6個月）：2027年台廠美國投資案是否延後、德州電價與租稅優惠變化；台灣南部科學園區的電力與用水配置。
