總經 / 地緣政治

AI 股災全面升級 — 標普、道瓊落入修正，那指抹平全年漲幅，費半單週跌17.1%創25年最慘

深度解析

發生什麼事

美股週五（11/20）全面重挫：標普500單日跌3.7%、那斯達克跌5.3%，標普與道瓊自歷史高點回落逾10%正式進入修正，那斯達克100更進入熊市（高點回落逾20%）。以週線計算，道瓊跌8.02%、標普跌8.61%、那指跌10.0%，是2020年疫情初期以來最慘的一週；那指今年迄今轉為下跌2.7%，單週市值蒸發4兆美元。重災區是半導體：費城半導體指數單週跌17.13%、市值蒸發2.3兆美元，為25年來最慘週線。恐慌指數VIX盤中飆上40、收37.66，單日升32%。引爆點有三：Anthropic史上最大IPO未能提振AI交易（上市第二日跌8.5%）、輝達在黃仁勳去職後再遭SEC調查會計作業、以及Fed官員接連釋出升息訊號。CNBC指出，企業正從庫藏股轉為增發新股（「聰明錢」在賣），Kalshi預測市場對標普年底站上8,000的機率從逾70%崩至極低。

解讀

這是情緒面與基本面同時惡化的「雙殺」，不是單純的技術性回檔。基本面上，AI資本支出能否產生足夠回報的質疑已持續數週；情緒面上，Anthropic IPO原被視為「全村的希望」，結果卻成為供給端壓力（81億美元籌資吸走市場流動性）。更關鍵的是宏觀背景變了：Fed從降息預期轉為升息預期，意味過去三年支撐高估值的「低利率＋AI成長」敘事同時失去一隻腳。VIX接近40在歷史上通常接近賣壓尾聲，但前提是沒有新的基本面利空。

傳導鏈

Anthropic IPO吸走流動性＋輝達SEC調查 → AI龍頭估值重估 → 費半單週-17%、那指100進入熊市 → 融資斷頭與量化基金去槓桿 → 比特幣跌破6萬美元、黃金創最糟單週 → 風險資產全面去槓桿 → 台股、日經等高AI曝險市場週跌17%、5% → 亞洲貨幣貶值壓力 → 各國央行穩匯、監管機關限空

結構性

週期性為主、帶結構性成分：估值修正是週期性去槓桿；但「AI資本支出回報率」與「Fed重回升息」兩個疑慮若確立，會成為結構性的估值天花板下修。

矛盾訊號

Anthropic前三季營收332.4億美元年增12倍、ARR 810億美元，基本面數字極強，卻在上市第二日即跌8.5%；市場說「AI需求無虞」，但同時用腳投票賣出AI供應鏈。另一個矛盾：VIX飆上40歷史上多為底部訊號，但CNBC報導晶片股出現大規模看空選擇權押注，顯示機構仍在加碼空單。

分叉情境

如果下週Fed官員維持鷹派（12月升息1碼機率續升）且輝達SEC調查擴大，那指100可能再跌5-8%、費半測試前低下方10%，VIX維持35以上；如果Anthropic週一掛牌的選擇權引進避險需求、且聯準會釋出「觀望」訊號，則標普可能在修正區（-10%至-12%）築底，VIX回落至25以下，但反彈領頭羊將是Alphabet、Berkshire等「非AI」資產，而非輝達。

Fed 轉鷹 — 10月會議紀要預期「更多升息」，Waller 稱可能需要2碼「震撼市場」

深度解析

發生什麼事

聯準會11/18公布10月會議紀要，當次會議維持基準利率在3.75%-4.00%不變，但多數官員預期後續需要「更多升息」，並首度明確點名AI投資熱潮對通膨的推升效果（資料中心電力、建材與勞工需求）。理事Waller同日表示，若通膨持續高於2%目標，Fed可能需要以半碼（50bp）升息「震撼市場」。背景是美國10月CPI月增0.4%、核心CPI月增0.3%，雙雙高於預期的0.3%與0.2%；英國也因柴油價格創新高，通膨升至3.6%的一年高點。主席Warsh希望官員少發言，但CNBC指出官員反而「搶著上麥克風」。FT同時觀察到，油價與公債殖利率的緊密連動已經斷裂，通膨「病毒」已從能源擴散到服務與資本財，市場目前預估12月至少升息1碼。

解讀

這是本輪股災被低估的真正推手。市場原本以為AI capex是通縮力量（生產力提升），Fed紀要卻把它定義為通膨來源，等於宣告「AI愈熱、利率愈高」的負向回饋。油價與殖利率脫鉤更是結構性訊號：即使荷莫茲情勢緩和、油價回落，殖利率也不會跟著降，因為通膨已由需求面接棒。對台灣而言，美台利差擴大是外資匯出與台幣貶值壓力的根源。

傳導鏈

AI資本支出推升電力、建材、勞工成本 → 核心CPI月增0.3%超預期 → Fed紀要轉鷹、Waller喊2碼 → 2年期殖利率上行、美元走強 → 美台利差擴大 → 外資賣超台股並匯出 → 台幣逼近33元、央行進場 → 台股融資斷頭 → 金管會限空

結構性

結構性：通膨來源從能源（週期性）轉為AI基建需求（結構性），意味本輪升息週期不會因油價回落而結束。

矛盾訊號

Fed說AI推升通膨要升息，但同一週AI股崩跌、資本支出預期下修——若AI capex真的放緩，Fed的通膨理由就消失了。市場正在猜Fed是否會因股災而退縮（Fed put），但Waller的發言顯示這次Fed更在意通膨信譽。

分叉情境

如果11月核心CPI月增再達0.3%以上，12月FOMC升息2碼的機率將從目前的低檔升至40%以上，10年期美債殖利率上看5%，台幣可能失守33元；如果股災造成財富效果收縮、11月CPI月增回到0.2%，Fed可能只升1碼並暗示暫停，風險資產將出現技術性反彈，但「升息週期未結束」的定價不會消失。

展望

短期 · 1M
短期（1個月內）：12月FOMC升息1碼為基本情境，2碼為尾部風險。美元指數維持強勢、2年期殖利率區間4.3%-4.7%。
中期 · 3–6M
中期（3-6個月）：若AI capex放緩與股災財富效果共同壓抑需求，Fed在2027年Q1可能回到觀望；若通膨黏著在3%以上，聯邦基金利率上看4.5%-4.75%，高收益債利差將擴大100bp以上。
長期 · 1Y+
長期（1年以上）：AI基建被定義為通膨源，意味中性利率（r*）可能被永久上修0.5-1個百分點，所有長天期資產（不動產、基建、成長股）的折現率基準都要重新校準。

持續追蹤

11月美國CPI（12月上旬公布）核心月增率12月FOMC點陣圖與Warsh記者會措辭2年期與10年期美債殖利率、美元指數美台利差與外資淨匯出金額

面試角度

國泰CIM債券面：「Fed紀要說AI推升通膨，這對殖利率曲線的含義是什麼？」答：曲線熊平（短端升得比長端快）。開發資本基建投資：「無風險利率上升1個百分點，對一個20年期基建案的IRR門檻有什麼影響？」要能說出折現率與估值的敏感度。中信投資專案：「油價與殖利率脫鉤，對你的宏觀假設有什麼修正？」

口說版

「Fed 10月紀要最讓我注意的不是「更多升息」四個字，而是官員首度把AI投資熱潮列為通膨來源——這代表AI愈熱、利率愈高，和過去「科技等於通縮」的假設完全相反。美國10月核心CPI月增0.3%高於預期，Waller甚至說可能需要2碼。從國泰CIM的角度，我會把這解讀為殖利率曲線熊平，短天期債券殖利率上行壓力最大；對開發資本評估基建案來說，無風險利率每升1個百分點，20年期專案的IRR門檻就要同步上調，這會讓很多原本勉強過關的案子不再可行。」

持續追蹤中

發生什麼事

英國海事貿易行動辦公室（UKMTO）11/21通報阿曼哈薩布（Khasab）附近兩艘油輪遇襲，伊朗則稱一艘船在荷莫茲以東觸雷；伊朗革命衛隊宣稱擊落美國無人機，美國同日制裁4名伊朗「石油受託人」。FT報導通過荷莫茲的原油出貨量隨伊朗攻擊增加而下滑，分析師形容中東原油出口的復甦「愈來愈脆弱」；川普正考慮新一輪對伊打擊，但美軍高層警告長期部署與預算削減正在侵蝕戰備，戰事恐拖至2027年。IEA署長更直言荷莫茲「沒有可信的路徑」回到戰前常態。油價週五小漲，但週線連3黑；中油宣布汽柴油連續第10週凍漲，累計吸收357.3億元。

關鍵數據

美國原油約85美元/桶（11/16）；布蘭特11/10曾跌破90美元；中油累計吸收357.3億元、92無鉛維持31.2元/公升；英國通膨3.6%（柴油創新高）

解讀

傳導鏈

伊朗攻擊油輪、通過荷莫茲油量下滑 → 保險費與運費上升 → 亞洲進口成本上升 → 中油凍漲吸收357億元 → 台灣通膨被壓抑但中油虧損擴大 → 若戰事拖至2027年，油價風險溢價重回，電價、油價調漲壓力集中爆發

分叉情境

如果戰事拖至2027年且美軍戰備持續消耗，川普可能被迫談判，油價回落至80美元以下但航道風險溢價不消失；如果以色列推動美國恢復打擊、伊朗封鎖海峽，油價短線衝破110美元，台灣CPI將在2個月內升破2.5%。

中投尋求以「災難情境」保護條款重返美國私募市場 — 地緣風險正式寫入LP合約

深度解析

發生什麼事

FT報導，中國主權財富基金中投（CIC）正領導一項行動，尋求以特殊條款重返美國私募股權基金：要求GP在合約中加入「災難情境」保護，例如若美國政府強制中資LP退出、凍結資產或限制分配時，中方可獲得退出保障或補償。中資LP自2023年美國對外投資審查收緊後大幅退出美國PE，GP募資因此失去一大資金來源；如今在美中領袖深圳三方會談後，中方試圖以合約條款而非政治保證來重新開門。這與同週另一則新聞形成對照：CVC指控Advent在30億歐元Irca（義大利糕點原料商）交易中操縱會計、誇大財務表現，Advent否認——顯示PE二級交易的盡職調查爭議升溫。

解讀

這是私募市場「地緣風險定價化」的里程碑。過去LP合約只處理商業風險，現在要處理主權對抗風險；GP若接受這類條款，等於承擔政治風險以換取資金，這會反映在管理費、carry分配或其他LP的優先權設計上。對台灣的中信、開發資本這類有海外私募配置的機構而言，意味未來評估基金時要讀懂side letter中的地緣條款，自己的權益可能被稀釋。

傳導鏈

美國對外投資審查收緊 → 中資LP退出美國PE → GP募資缺口擴大、募資週期拉長 → 中投提出「災難情境」條款換取重返 → GP在LPA中加入主權風險條款 → 其他LP要求同等保護或更高優先分配 → 私募基金條款複雜化、法律成本上升 → 二級市場折價擴大

結構性

結構性：美中資本脫鉤不會因一次峰會逆轉，合約化的地緣風險條款會成為跨境私募的新常態。

矛盾訊號

分叉情境

深度解析

發生什麼事

川普11/20結束亞洲行後在白宮表示，將禁止美國企業在海外興建AI資料中心，違者將課「巨額稅金」，理由是防止北京在AI競賽中領先。同日CNBC報導，美國大型資料中心2026年建造成本飆升13%，因AI需求成長超過「有電力的土地」與營建勞工供給；IEA則估計全球資料中心用電量在2030年前可能翻倍，對各國電網形成壓力。配套政策方面，參議院通過獲AI與能源業支持的BAAJA許可改革法案（仍需眾院通過），歐洲央行總裁拉加德呼籲歐盟公共資金應承擔晶片廠與資料中心的「首損」風險；Meta則因AI熱潮重新評估2030年淨零目標。同週美國Fed紀要首度把AI投資列為通膨來源。

AI基建的瓶頸正從「晶片」轉移到「電力、土地、勞工與政策」。建造成本+13%與用電翻倍是結構性供給限制，川普的海外禁令則是政策面的額外約束——若落實，微軟、Google、Amazon在台灣、新加坡、馬來西亞的資料中心擴建都會受影響，但同時會推高美國本土的電力與營建需求，使Fed擔心的「AI通膨」更嚴重。拉加德的「公共首損」提議說明歐洲已承認純民間資本無法承擔AI基建風險，這對基建基金是機會（政府分擔下行風險）。
