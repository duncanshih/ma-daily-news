美國7月零售銷售月減0.6%、CPI降至3.4% — 市場把「Warsh 聯準會」的升息劇本改寫了

發生什麼事

美國7月零售銷售月減0.6%，遠低於經濟學家預期，是今年以來最弱的單月表現；同期CPI年增率自6月水準回落至3.4%，食品與汽油價格是主要降溫來源，住房成本仍是唯一撐住通膨的分項。這組數據的組合很關鍵：物價降溫的同時，需求端也在同步走弱，而不是「軟著陸式」的只降通膨、不傷需求。市場立刻反應——聯邦基金期貨對聯準會9月「升息」的機率定價大幅下修，美元指數承壓，黃金站穩4,400美元、白銀站上65美元。但長端並沒有跟著鬆：10年期公債殖利率反而小幅走高，交易員同時在消化疲弱的零售數據與美國宣稱對伊朗海上封鎖「可無限期持續」的地緣風險。美國財政部本月標售的30年期公債，得標利率創2001年以來最高。標普500週五收跌0.17%、道瓊跌107.58點，但仍締造連續第三週上漲。

📐 解讀：這是基本面訊號，不是情緒面。真正的重點不是「通膨降了」，而是「這一輪聯準會的政策風險方向是升息、不是降息」——在Warsh主政下，市場過去幾個月一直在對「9月升息」定價，7月數據等於把這個尾部風險往後推。但零售銷售月減0.6%同時告訴你：壓下通膨的力量有一部分來自需求毀滅，而不是供給改善。短端利率預期下降、長端因財政與地緣風險黏著，殖利率曲線正在用最不健康的方式陡化——不是因為成長預期改善，而是因為期限溢酬（term premium）在補償赤字與油價風險。
🔗 零售銷售 -0.6% + CPI 3.4% → 9月升息機率定價下修 → 短端殖利率下滑、美元指數走弱 → 新台幣等亞幣升值、外資回補亞股 → 但長端受赤字與油價支撐（30年標售利率2001年來最高）→ 殖利率曲線陡化 → 壽險業海外債投資評價與避險成本重估、銀行NIM先受惠後承壓
🏗️ 結構性 — 週期為主、結構為輔。需求降溫是週期性的（消費者信心、就業鬆動）；但長端殖利率因財政赤字與期限溢酬而黏著，是結構性的——這一段不會因為一次CPI回落就修復。
⚡ 矛盾訊號：矛盾很明顯：股市把「不升息」當利多，連三週上漲、全球股票型基金延續資金淨流入；債市卻用30年期2001年以來最高的得標利率告訴你，長期資金成本並沒有下降。同一組數據，股債給出完全相反的解讀，通常代表其中一方在錯價——歷史上多半是股市晚一步認錯。
🔀 如果8月CPI續降至3.2%以下、且非農新增就業低於10萬人，聯準會9月按兵不動幾乎確定，10年期殖利率有機會回落20-30個基點，美元指數再貶2-3%，新台幣有望挑戰31.8元；如果荷莫茲僵局持續讓布蘭特站上95美元以上、推升8-9月能源分項，CPI反彈回3.7%以上，9月升息重回檯面，美股高估值族群（本益比逾30倍的AI基建股）將面臨第二輪去槓桿，殺傷力會比7月那次更大，因為這次沒有「降息救援」的敘事可用。

13F季報全揭密 — 巴菲特加碼Alphabet 83%、輝達手上有210億美元SpaceX，但機構整體對科技股在減碼

發生什麼事

美國6,371家資產管理規模超過1億美元的機構在45天期限內完成13F申報。最受矚目的是波克夏海瑟威：截至6月底持有約1.06億股Alphabet、市值379億美元，較前一季增加83%，一舉躍升為第三大美國上市股票持倉，僅次於蘋果與美國運通，同時加碼達美航空與房地產相關部位。輝達則首度揭露透過投資xAI而間接持有的SpaceX部位，季末市值約210億美元；Alphabet的SpaceX持股在十年間成長逾100倍至940億美元；馬斯克本人揭露持有SpaceX約48.4%、價值逾9,000億美元。但整體圖像跟明星個股相反：13F彙總顯示機構投資人第2季對半導體、AI基礎設施與大型科技股「略有減碼」，買賣力道呈現拉鋸，對產業前景缺乏共識。同期崩盤的避險基金Situational Awareness，申報揭露其前五大持股為Sandisk、美光、Bloom Energy、台積電與Nebius，這個組合在7月AI回檔中被迫整體出售給Citadel，並讓造市商Jane Street承受高達150億美元的衝擊。

📐 解讀：13F是落後指標（揭露的是6月底部位），但它的價值在於「揭露分歧」而不是「揭露方向」。這一季最重要的訊號是：明星資金（波克夏、輝達）在買，但機構總體在減碼——這不是看多也不是看空，而是「持股高度集中化」的證據。當AI交易的多頭部位越來越集中在少數幾家口袋深的玩家手上，市場的流動性結構就變脆弱了，Situational Awareness被迫平倉、Jane Street虧150億美元就是這個脆弱性的實證。順帶一提，巴菲特買Alphabet不是買AI，是買「有現金流、有壟斷租金、本益比還沒瘋掉」的資產，這是價值投資對AI敘事的一種側面否定。
🔗 AI多頭部位集中化 → 單一基金爆倉（Situational Awareness）→ 被迫在流動性最差的時點整體出售給Citadel → 造市商（Jane Street）承接時價格跳空、虧損150億美元 → 造市商縮減風險預算、報價價差擴大 → AI相關股票的日內波動放大 → 更多槓桿部位觸發追繳 → 正回饋螺旋
🏗️ 結構性 — 結構性。持股集中化與被動化是過去十年的長期趨勢，AI主題只是把它推到極致；這種市場微結構的脆弱性不會隨這一輪回檔結束而消失。
⚡ 矛盾訊號：最大的矛盾是：波克夏加碼83%的Alphabet被媒體解讀成「股神看好AI」，但巴菲特買的是搜尋廣告與雲端的現金流，且Alphabet的本益比在七巨頭裡相對最低。同時輝達揭露210億美元的SpaceX持股，本質上是「晶片商用自己的資產負債表去投資自己的客戶生態系」——這跟1999年電信設備商賣方融資（vendor financing）的結構高度相似，市場卻普遍當成利多在解讀。
🔀 如果第3季13F顯示機構減碼幅度擴大、且被動基金流入放緩，AI集中度風險會轉為系統性風險，標普500前十大權值股佔比若跌破目前水準5個百分點以上，整體指數會出現與基本面脫鉤的下殺；如果第3季財報再度全面超預期、且輝達$500億美元融資計畫順利落地，資金會從減碼轉為追價，集中度進一步上升到歷史極值，屆時風險不是消失而是被推遲，且下一次去槓桿的幅度會更大。

🔄 日銀秋季升息預期升溫 — 美日28年來首度聯手干預日圓後，市場焦點從「何時再干預」轉向「何時升息」

發生什麼事

日本政府與日銀在7月底進場買進日圓，美國罕見加入，這是兩國時隔28年再度聯手阻升日圓匯率。匯率干預暫時壓制了日圓空頭，市場焦點正從「政府何時再度干預」轉向「日銀何時升息」，9月的政策決策會議成為新的關鍵時點。同時，日本7月躉售物價（PPI）年增7.2%，低於路透調查預期的7.4%，也較6月修正後的7.3%微幅回落——這給了日銀「通膨壓力見頂」的空間，但7.2%的絕對水準仍高，並不支持鴿派。日經指數週五漲0.59%、TOPIX再創收盤新高，但外資持續減碼日股，日本投資人反而大買海外股票、金額創今年次高。

關鍵數據

美日28年來首度聯手干預日圓；日本7月PPI年增7.2%（預期7.4%、6月修正後7.3%）；TOPIX創收盤新高、外資續減碼日股

📐 解讀：干預只能買時間，不能改變利差。真正能結構性扭轉日圓的只有兩件事：日銀升息，或美國降息。目前美國在Warsh主政下不降息，所以壓力全落在日銀身上——這也是為什麼市場預期會從「干預」快速轉向「升息」。但這裡有個常被忽略的細節：外資減碼日股、日本人加碼海外股票，代表資金仍在淨流出日本，這是持續性的日圓賣壓來源，光靠一次干預壓不住。日銀如果9月升息，短線日圓會急升，但也會同時衝擊日股與日本國債（JGB）評價，這對台灣壽險業持有的日圓資產與避險部位是雙面刃。
🔗 美日聯手干預 → 日圓空頭短線停損回補 → 但美日利差未變、日本資金持續淨流出 → 干預效果衰減 → 壓力轉向日銀升息 → 若9月升息，JGB殖利率上行 → 日本壽險與銀行回收海外資金（carry trade平倉）→ 美債與亞洲美元債面臨賣壓 → 全球長端殖利率再上行
🔀 如果日銀9月升息且幅度達25個基點以上，日圓一週內可能升值3-5%，全球carry trade平倉將壓抑高息貨幣與新興市場債，台灣壽險的美元資產避險成本反而下降；如果日銀9月按兵不動、且美國因油價反彈重啟升息討論，日圓將再破前低，第二輪干預幾乎確定，屆時日本外匯存底消耗與美國的配合意願將成為市場攻擊的目標。

歐洲乾旱變成能源危機 — 熱浪與缺水迫使核電機組減載停機，羅馬尼亞開始讓唯一運轉中反應爐脫網

發生什麼事

歐洲的高溫與乾旱正在從氣候事件演變為能源供給危機。CNBC報導指出，熱浪與缺水正在全歐範圍內壓抑核電輸出——核電廠依賴河水或海水冷卻，當河川水位下降、水溫上升，機組必須減載甚至停機以符合環境排放溫度的法規限制。羅馬尼亞已開始進行讓其唯一運轉中反應爐脫離電網的程序。同一週，英國因野火而暫時禁用拋棄式烤肉架並出動軍隊協助滅火，法國西南部林火燒毀1,600公頃、650人撤離。英國經濟雖有成長，但專家警告未來數月充滿挑戰，且伊朗戰事可能拖累明年成長。

📐 解讀：這件事的重要性遠超過一則氣候新聞，因為它直接打破了能源轉型的一個核心假設：核電是「穩定基載」。事實是核電對水資源的依賴度極高，在氣候變遷加劇的情境下，它的可用率（availability factor）本身就變成了一個氣候相依變數。這對能源投資的建模是根本性的挑戰——過去核電廠的財務模型用90%以上的容量因數（capacity factor）當基準假設，未來這個假設在南歐與內陸地區可能必須下修。更諷刺的是，熱浪同時推升空調用電需求，供給下降與需求上升同時發生，正是電網最脆弱的組合。
🔗 熱浪與乾旱 → 河川水位下降、水溫上升 → 核電冷卻受限、被迫減載或停機 → 基載電力供給下降 → 同時空調需求上升 → 電力現貨價格飆升 → 工業用電成本上升、部分產能被迫停工 → 歐洲製造業競爭力進一步惡化（德國出口模式已面臨結構性挑戰）→ 歐洲對進口能源與進口工業品的依賴加深

13家金控前七月大賺4,927.81億元、年增78.2%創史上同期新高 — 但富邦金7月單月竟出現稅後淨損17.6億元

發生什麼事

13家金控8月14日全數公布7月獲利：7月單月稅後純益合計518.94億元，是今年單月獲利次低；但累計前七月稅後純益達4,927.81億元、較去年同期成長約78.2%，改寫史上同期新高，其中11家金控的累計獲利都創下史上同期新高。富邦金以前七月稅後純益955.8億元、EPS 6.54元居13家之冠，國泰金以873.4億元、EPS 5.68元居次。但細節值得注意：壓軸公布的富邦金7月單月出現稅後淨損17.6億元的罕見現象，主因是台股7月修正；若加計透過其他綜合損益按公允價值衡量（FVOCI）的股票處分利益，富邦金前七月合計淨利達1,962.5億元、EPS 13.73元，已超越歷年全年獲利表現。六大壽險前七月獲利1,533億元。銀行端也強勁：8家上市銀行前七月獲利飽滿，五大發卡行前七月刷卡金額攀峰、中信銀以7,284億元創新紀錄、年增24%，今年信用卡繳稅金額突破2,700億元創新猷，且1%的大戶包辦超過半數稅額，反映國內所得的K型化。

📐 解讀：78.2%的年增率看起來驚人，但要拆開來看獲利的品質：這一輪金控獲利的主要來源是股利收入與股票處分利益，也就是「資本利得驅動」而非「本業利差驅動」。富邦金7月單月虧損17.6億元就是最好的證據——台股一修正，獲利立刻翻負。真正的核心利差業務（NIM、保險本業）並沒有這麼劇烈的波動。這意味著金控獲利與台股指數的相關性極高，它不是防禦性資產。從投資角度，這改變了「金融股是穩健配置」的傳統假設——在資本利得佔比這麼高的情況下，金控股本質上是槓桿後的台股部位。
🔗 台股上半年大漲 → 金控股利收入與FVOCI股票處分利益暴增 → 前七月獲利年增78.2%、創史上同期新高 → 但7月台股修正 → 富邦金單月由盈轉虧17.6億元 → 顯示獲利對股市的高度敏感性 → 若第3、4季台股震盪，金控獲利成長率將快速收斂 → 明年配息政策面臨高基期壓力
🏗️ 結構性 — 強烈的週期性。獲利成長78.2%主要來自資本市場的評價效應，這不是可持續的結構性改善。
⚡ 矛盾訊號：市場把「13金控前七月大賺4,927億」當成金融股的利多，但同一份資料裡藏著相反訊號：7月單月獲利518.94億元是今年單月次低，且獲利王富邦金在7月是虧損的。前七月的亮眼數字是上半年台股大漲的存量結果，7月的疲弱才是當前的流量訊號。用存量數據推論未來，是最常見的判斷錯誤。
🔀 如果台股第3、4季能在45,000點以上維持震盪，金控全年獲利仍可望創高，但年增率會從78%快速收斂至30-40%；如果台股回落至42,000點以下，FVOCI的未實現利益將轉為評價損失，金控下半年獲利年增率可能跌破10%，屆時明年的配息政策與股價評價都會面臨明顯壓力。

長期（1年以上）：長期（1年以上）：IFRS 17接軌後，壽險獲利的認列方式改變，市場需要重新建立比較基準。富邦金特別揭露加計FVOCI處分利益後的EPS 13.73元，就是為了提供與接軌前更可比的口徑，這個細節在做金融股評價時非常重要。

🔄 新台幣升上32.046元成最強亞幣，但2年期公債利率同時飆上19年新高 — 這兩個訊號互相矛盾

發生什麼事

美國7月通膨符合預期加上就業市場鬆動，市場對聯準會升息的預期大幅降溫，美元指數持續承壓。外資8月14日持續大舉回補台股，盤初瘋狂匯入，新台幣兌美元盤中一舉升破32元整數關卡、最高觸及31.991元，午後部分外資轉為匯出，終場收32.046元、升值1.22角，單週升值0.75%，成為最強亞幣，全日成交量30.7億美元。摩根士丹利認為兩大壓力緩解，建議押注新台幣續升，匯銀預期下週有機會挑戰31.8元。但同一天，央行代財政部標售200億元2年期公債，最高得標利率衝上1.725%、創2007年6月以來逾19年新高；同日標售的250億元2年期定存單，加權平均得標利率也升至1.663%、創2003年2月以來23年半新高。銀行資金調度主管指出，今年資金持續湧入股市，加上外資獲利了結、股利匯出，市場資金仍偏緊。台股當日收45,811點、下跌210點，失守46K，本週仍上漲1,585點、漲幅3.5%，外資本週天天買超、合計買超2,061億元，但外資台指期淨空單仍高掛85,179口。

關鍵數據

新台幣收32.046元、單週升0.75%、盤中最高31.991元；2年期公債得標利率1.725%（19年新高）、2年期定存單1.663%（23年半新高）；台股45,811點、週漲3.5%、外資週買超2,061億元、台指期淨空單85,179口

📐 解讀：這是本週台灣市場最值得深思的矛盾訊號。教科書上，外資大舉匯入應該讓新台幣升值「並且」讓本地資金寬鬆——但台灣現在是新台幣升值的同時，2年期公債利率創19年新高。為什麼？因為外資匯入的錢直接進了股市，並沒有留在銀行體系當存款；同時本地資金也大量從定存搬去股市，加上外資獲利了結與股利匯出造成的資金外流，銀行體系的可貸資金反而是變緊的。換句話說，這是「匯市寬鬆、貨幣市場緊縮」的分裂狀態。而外資一邊現貨買超2,061億元、一邊台指期留8.5萬口淨空單，等於在做多現貨的同時對沖下檔——這不是純多頭，是套利或避險部位。市場的實際風險偏好，比指數週漲3.5%所顯示的要謹慎得多。
🔗 聯準會升息預期降溫 → 美元走弱 → 外資匯入買台股（週買超2,061億元）→ 新台幣升破32元 → 但資金直接進股市而非留在銀行體系 → 加上本地資金從定存搬去股市、外資獲利了結與股利匯出 → 銀行可貸資金收緊 → 公債與定存單標售利率創19年、23年半新高 → 企業融資成本上升 → 高槓桿產業（營建、租賃）財務壓力浮現
🔀 如果聯準會9月確定不升息、美元續弱，新台幣有機會挑戰31.5-31.8元，出口商的匯損壓力將明顯浮現，電子代工業的毛利率可能因此下滑0.5-1個百分點；如果荷莫茲油價再漲、美國通膨反彈導致升息預期重啟，美元反彈，新台幣可能快速回貶至32.5元以上，外資反手匯出，屆時台股與債市會同時承壓——這是最糟的情境組合。

短期（1個月內）：短期（1個月內）：新台幣若站穩31元價位，下一步挑戰31.8元。但要提防8月19日台指期結算的壓低風險，以及外資8.5萬口淨空單的實際意圖。

中期（3-6個月）：中期（3-6個月）：資金面偏緊會持續。這對銀行的存放利差是正面（放款利率上升快於存款），但對高槓桿的營建與租賃業是負面。若央行9月理監事會有任何緊縮訊號，債市會再有一波修正。

🔄 立院三讀442億元無人機6年計畫、國防預算破紀錄延宕後過關 — 但美國同時對無人機課最高100%關稅

發生什麼事

立法院8月14日三讀通過6年新台幣442億元的「無人載具產業發展統籌型計畫」預算案；Al Jazeera報導台灣國會在破紀錄的延宕後通過國防預算，並保留了關鍵的無人機計畫經費。外貿協會董事長黃志芳表示預算通過是為產業注入強心針，「無人機產業馬上就要起飛」，貿協將透過國際展覽、論壇與全球駐外據點協助業者拓展海外市場。但同一週美國白宮8月13日宣布，將對重量超過25公斤或具備特定功能的無人機及其零組件課徵232條款關稅、最高達100%，目標是加速無人機供應鏈與中國脫鉤，台灣、歐盟、日本、韓國適用15%的稅率。美股無人機類股在川普宣布後大漲。另一則相關訊號是：美國智庫傳統基金會統計，川普第二任內美軍艦艇通過台灣海峽的公開通報次數大幅下降（川普第一任28次、拜登任內32次），學者警告可能讓盟友甚至北京誤判華府承諾。

關鍵數據

442億元、6年期無人載具產業發展統籌型計畫三讀通過；美國無人機232關稅最高100%，台灣、歐盟、日、韓適用15%；美艦通過台海公開通報次數在川普第二任大幅下降

📐 解讀：442億元的產業政策與15%的美國關稅要合起來看，這其實是一個對台灣相當有利的組合。原因是：100%的最高稅率主要打的是中國製無人機（大疆等），而台灣被歸在15%這一檔——這是明確的相對優勢，等於美國用關稅幫台灣無人機產業清出了一塊市場。真正的挑戰不在關稅而在供應鏈：台灣無人機產業目前規模小、零組件（馬達、電池、飛控晶片）仍有中國依賴，442億元的政策資金能否在6年內建立起真正的非紅供應鏈，才是決定這個機會能不能兌現的關鍵。至於美艦通過台海通報次數下降，這是地緣風險溢價的長期變數，短期不會反映在資產價格，但對評估台灣長期投資案的國家風險溢酬是必須納入的因素。
🔗 美國對中國無人機課最高100%關稅 → 美國市場出現非中國無人機的供給缺口 → 台灣適用15%稅率取得相對優勢 → 442億元政策資金投入建立非紅供應鏈 → 台廠無人機與零組件廠訂單能見度提升 → 但關鍵零組件（飛控晶片、馬達、電池）需先完成去中化 → 短期成本上升、中期市佔擴大
🔀 如果台廠能在1-2年內完成關鍵零組件的非紅化並取得美國市場訂單，442億元政策加上15%關稅優勢可望催生一個新的出口產業，規模有機會達到數百億元台幣；如果零組件去中化進度落後、或美國轉而扶植本土供應鏈（100%關稅的真正目的可能是扶植美國製造而非讓台灣受惠），台灣可能只吃到短暫的轉單，長期市場仍被美國本土業者拿走。

🔭 展望

短期（1個月內）：短期（1個月內）：無人機概念股的題材面反應，但要注意442億元是6年期預算，年均僅約74億元，短期對個別公司的營收貢獻有限。

中期（3-6個月）：中期（3-6個月）：觀察政策資金的實際招標與撥付進度，以及台廠能否取得美國政府或企業的實際訂單。訂單能見度才是驗證點。

💬 口說版：「我會把兩件事合起來看：立法院三讀通過442億元、6年期的無人載具產業計畫，同一週美國對無人機課最高100%關稅、台灣跟歐日韓適用15%。這個組合對台灣其實相當有利——100%主要打的是中國無人機，等於美國用關稅幫台灣清出了一塊市場。但我認為真正的挑戰不在關稅而在供應鏈：台灣無人機產業規模還小，飛控晶片、馬達、電池仍有中國依賴，442億元分6年只有年均約74億元，能不能建立起真正的非紅供應鏈才是關鍵。而且要留意一個風險——美國課100%關稅的真正目的可能是扶植本土製造，台灣拿到的可能只是過渡期的轉單。如果我在開發資本評估這類產業投資案，我會把驗證點放在台廠實際取得的美國訂單金額，而不是政策預算的規模。」
