總經 / 地緣政治

美國10月CPI月增0.4%超預期 — 10年期美債殖利率重返5%、高盛改口明年3月再升息，Fed「升息循環12月結束」的劇本被推翻

深度解析

發生什麼事

美國勞工部11月10日公布10月CPI月增0.4%，高於市場共識的0.3%，推升項目集中在房租、食品與能源；雖較9月放緩，但經濟學家仍稱「高到令人不安」。數據公布後美債遭拋售，10年期殖利率重新站上5%，2年期殖利率單日升幅為2024年以來最大；Fed理事Waller同日重申傾向12月升息，並表示若通膨續升可支持一次升2碼。高盛據此修改預測，從「升息循環在今年12月結束」改為2027年3月再升1碼；德銀更新增明年1月升1碼，預期12月、1月、3月連三升。美元指數站上102，美國30年期房貸利率在連續4週下滑後急升，國際金價前一日重挫近3%後在4,026至4,052美元間徘徊、距五日高點4,145美元回落逾100美元。經濟日報引述彭博指出，近期美債市場累積的大量多頭部位「被殺個措手不及」。

解讀

市場反應是基本面而非情緒面：通膨來源是伊朗戰爭推升的能源成本與關稅傳導，兩者都不是一兩個月會消失的變數。關鍵變化不在12月升不升（已被定價），而在升息循環的「長度」被拉長到2027年Q1，這改變了整條殖利率曲線的定價基礎。10年期回到5%意味著無風險利率已足以與股票風險溢酬競爭，高本益比成長股的估值天花板實質下移。

傳導鏈

10月CPI月增0.4% → 高盛／德銀把升息終點從12月延到2027年3月 → 2年期殖利率急升、10年期重返5% → 美元指數破102、金價跌回4,000美元 → 美國房貸利率反彈、房市交易再凍結 → 新興市場匯率承壓（新台幣盤中32.968）→ 外資續自亞股匯出 → 台股高本益比AI股估值壓縮、企業海外發債成本上升

結構性

週期為主、結構為輔：通膨第二波來自能源與關稅，屬週期性；但若Fed連升三次把政策利率推高，市場將重新接受3.5%至4%的中性利率，這部分是結構性的利率中樞上移。

矛盾訊號

Fed官員集體鷹派、高盛預期升到明年3月，但同一天美國汽油價格跌破4美元、零售銷售增速為近一年最慢、信用卡債創1.29兆美元新高——通膨數據與消費體質正在背離。市場同時定價「升息」與「消費衰退」，兩者只能對一個；若消費先斷，Fed升到3月的劇本不會實現。

分叉情境

如果11月CPI月增仍在0.3%以上、核心CPI月增0.3%：12月升2碼機率升破四成，10年期殖利率測5.2%至5.3%，美元指數上看104、新台幣破33元；如果11月CPI月增回落到0.2%以下、同時油價守在85美元以下：市場回到12月升1碼即結束的定價，10年期殖利率回落至4.7%至4.8%，亞股資金回流。

發生什麼事

傳導鏈

物價高、實質薪資被侵蝕 → 家庭轉向信用卡與HELOC借貸 → 利息負擔隨Fed升息同步上升 → 零售銷售增速放緩、車貸期限拉長 → 若失業率上升則信用卡與車貸違約率跳升 → 銀行消金壞帳提列增加、消費類股獲利下修 → Fed被迫在通膨未達標前停止升息

發生什麼事

解讀

這是AI資本市場的「壓力測試日」：Anthropic能在輝達風波與Fed鷹派的最糟時點拿到超額認購，證明股權市場對前沿模型公司仍然開放，與債市對neocloud關門形成鮮明對比。但場外轉售配額收5%費用、創辦人同步套現、估值臨時上調，都是2021年IPO泡沫期的典型特徵。真正的風險不在首日，而在180天禁售期屆滿時——屆時若輝達財報與Fed路徑已確認AI capex放緩，將出現Selby所說的連鎖回調。

解讀

油價跌破90美元交易的是「川普不想打」，而非「伊朗願意談」——兩者有本質差異。荷莫茲仍封閉、船隻仍在觸雷，實體供給並未恢復，只是市場相信美國不會升級。這種「單邊降溫」的油價回落很脆弱：只要伊朗對美國本土或官員（Bessent）的威脅升級成實際攻擊，川普的政治空間會被迫收窄。我判斷油價在85至95美元區間的機率最高，100美元以上的尾部風險仍在兩成。

結構性

週期性為主：油價回落是地緣預期的擺盪；但荷莫茲封鎖已持續數月，全球油運航線與煉油布局（亞洲轉向美洲與非洲原油）的改變是結構性的，即使停火也不會完全逆轉。

矛盾訊號

川普說「伊朗軍事上已經完了」、油價跌破90，但同一天美國財長因伊朗威脅躲進軍事基地、IRGC宣稱船隻觸雷、Rubio說談判沒進展——華府內部對伊朗的評估明顯分歧。油價相信的是川普的政治意願，而不是地面上的實體風險。

深度解析

發生什麼事

台股11月11日在台積電、聯發科等高價股帶動下終場大漲1,545.23點、收44,257.15點，為史上第6大收盤，連續3個交易日上漲、重返44,000點與十日線，三日累計反彈約6,000點；台指期夜盤再漲265點至44,401點。反彈的起點是國安基金上週五宣布第10次進場，財政部長莊翠雲11日在立法院表示退場須經委員會共識決議、「從來不會在進場時就說何時退場」。但外資面並未轉向：LSEG數據顯示外資10月自七個亞洲市場淨撤出497.7億美元，台灣占306億美元、為18年來單月最大賣超；新台幣受美國CPI超預期與美元指數站上102影響，早盤一度貶至32.968元逼近33元，隨台股反彈與外資匯出趨緩、央行尾盤調節，終場收32.86元微升0.5分，台北與元太外匯市場成交量縮至23.52億美元。同日財政部公布10月全國稅收5,669億元、年增35.8%創歷年同月新高，前10月4兆1,383億元年增25.8%、已達全年預算91.4%，證交稅、營所稅、營業稅為主力，財政部估全年超出預算1,100億至1,600億元；主計總處公布前9月經常性薪資年增2.93%為26年同期次高、實質總薪資年增2.6%為11年同期最大。亞股同步走強：日經收61,248.59點漲1.31%，日本11月製造業信心升至27為2021年8月以來新高；韓股KOSPI收5,375.36點漲2.6%、外資買超6,552.6億韓元。

解讀

解讀

亞太呈現「半導體強、傳統製造弱」的K型分化：日本製造業信心靠晶片需求創五年新高，但日產在中國被本土電動車擊潰，說明AI以外的製造業正承受中國產能外溢的結構性壓力。日本散戶搶購2.39%的國債是另一個訊號——日本家庭正從「零利率存款」轉向「有息資產」，這會逐步抽走海外（含美債與台股）的日資。韓國重罰公債一級交易商則顯示亞洲監管機關對債市操縱的容忍度下降，對台灣公債市場做市制度有參考意義。
