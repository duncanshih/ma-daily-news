總經 / 地緣政治

全球風險資產同步重挫 — 油價破112美元、美以傳選後打伊朗、AI獲利了結三線交會

深度解析

發生什麼事

10月22日布蘭特原油期貨大漲2.94%至每桶112.02美元、創5個月新高，WTI漲2.69%至99.76美元，導火線是伊朗支持的胡塞組織加大對沙烏地阿拉伯的攻擊、波斯灣與荷姆茲海峽船隻再度遇襲，美國國務院下令非緊急人員及眷屬撤離駐沙烏地館處，紐約時報並披露美國與以色列已制定在11月3日期中選舉後再度對伊朗動武、迫其讓步的具體計畫。亞股首當其衝：日經225收62,907.84點、跌1,713.4點（-2.65%），7月以來首度收在63,000點下方；韓國KOSPI收5,533.77點、跌201.89點（-3.52%），KOSDAQ跌3.62%；台股跌846.34點收46,041.43點（-1.8%）失守季線；中國滬深300自6月高點回落20%、正式進入技術性熊市，為連續第10週下跌。歐股Stoxx 600早盤跌0.98%至638.16點，美股期指那斯達克100期貨跌1.83%、標普500期貨跌1.02%，Meta、SpaceX、德州儀器財報優於預期也無法扭轉賣壓。CNBC民調顯示8成美國人認為經濟「普通或差」，川普經濟支持率創歷史新低。

解讀

這不是單一事件的情緒性殺盤，而是三條獨立壓力線在同一天交會：(1) 油價重返110美元以上令市場重新定價「通膨再起、央行無法降息」；(2) AI資本開支能否轉化為利潤的疑慮使半導體與AI基建股成為獲利了結的提款機，費半指數已連八跌；(3) 法國公債殖利率破5%引發的歐洲主權債壓力。基本面上Meta、SpaceX、TI的財報都不差，但市場選擇賣出，顯示現在主導定價的變數是「折現率」而非「盈餘」，這是典型的估值重估階段而非盈餘衰退階段。

傳導鏈

胡塞攻擊沙烏地+美撤館 → 布蘭特破112美元 → 通膨預期上修、Fed 10/28降息預期消失 → 美債殖利率上行壓力（BMO稱有突破風險）→ 高本益比AI/半導體股折現率上升 → 亞洲出口導向股市（日、韓、台）首當其衝 → 外資撤出新興亞洲、新台幣貶至32.5、韓元承壓 → 亞洲央行穩匯壓力升高、政策空間壓縮

結構性

週期為主：油價衝高與AI獲利了結屬短期週期性修正；但中東衝突導致的能源運輸路線重組與歐洲財政壓力具結構性成分，若美以真的在11月再動武，將從週期轉為結構。

矛盾訊號

中東衝突升溫、油價創5個月新高，但FT數據顯示波灣產油國日出口量已回升到2,460萬桶、高於戰前的2,330萬桶（透過替代航線），實體供給並未減少，油價溢價反映的是運輸風險與保費（CNBC估實體交割溢價達每桶38美元）而非供給缺口。另一矛盾：主權基金對中國與香港的投資暴增190%，同一天滬深300卻跌入熊市。

分叉情境

若美以在11月3日後一週內對伊朗動武且荷姆茲航運中斷超過2週，布蘭特可能挑戰120-130美元，亞股再跌5-8%，Fed 2026年內升息機率升至五成以上；若俄方中介的美伊談判在期中選舉前取得停火框架，布蘭特回落至95-100美元，風險資產11月出現反彈，但AI估值重估仍會獨立持續。

法國10年期殖利率破5%、挪威主權基金Q3虧2,780億克朗 — 歐洲主權債壓力進入「實質虧損」階段

深度解析

發生什麼事

法國10年期公債殖利率10月22日升破5%，為2002年以來首見、24年新高，從2月底的3.2%攀升180個基點，背景是上週末全國示威演變為街頭暴力、里昂已禁止10月24日所有抗議活動，加上公共財政與政治穩定疑慮；馬克宏公開批評川普等人對法國抗議的「愚蠢」評論。同日全球最大主權基金挪威主權基金公布第3季虧損2,780億挪威克朗（約新台幣9,700億元、約300億美元），主因各國利率升高造成債券部位損失，基金總規模約2.3兆美元。英國9月CPI升至3.5%（前值3.1%），政府借款創一年新高，財政大臣John Healey將於10月28日公布預算、已排除調高資本利得稅；FT評論直指G7中法國與美國是「揮霍海報男孩」、正走向財政牆。倫敦信用對沖基金Arini 10月再虧約7%、年內跌逾21%。日本本土銀行領軍的投資人連續5週賣出外國債券、為4年來最長拋售潮，日本10年期公債殖利率年內升逾80個基點、10月一度觸及3年高點。

解讀

法國殖利率破5%是歐洲主權債市場「債券義警」回歸的訊號，市場不再相信歐洲可以靠美債殖利率下降來緩解自身借貸成本。挪威基金的300億美元虧損證明高利率已從「債券價格下跌」實質轉化為大型機構的帳面損失，接下來會傳到保險公司、退休基金的資產負債表與償付能力比率。本質是全球「高利率持續更久」的現實被重新定價，而非法國單一政治事件；日資回流本土更是把全球長債買盤抽走的結構性力量。

傳導鏈

法國示威+財政疑慮 → OAT 10年期殖利率破5% → 義、西周邊利差跟隨擴大 → 歐洲銀行持有主權債部位減值、Stoxx 600銀行股承壓 → 全球長債殖利率同步上行、挪威基金等長期資金帳面虧損 → 保險/退休基金資產配置從長債移向短債與現金 → 企業發債成本上升、IPO與併購退出延後（Blackstone已點名）→ 台灣壽險業歐美長債部位評價損失、避險成本上升

結構性

結構性：歐洲高債務（法國債務佔GDP約115%）、低成長、人口老化加上社會抗爭的組合不是一次預算案能解決；但殖利率短期衝上5%有恐慌成分，有回落至4.5%的週期性空間。

矛盾訊號

英國通膨升至3.5%、借款創新高，但財政大臣仍拒絕調高資本利得稅並規劃免除中型企業審計（省下12億英鎊費用），政治選擇與財政紀律方向相反。另一方面日本投資人連5週賣出外債、資金回流日本，顯示全球資本不是「無處可去」而是正在重新分配，受害的是歐美長債。

分叉情境

若法國政府在11月預算案未能提出可信的赤字削減（赤字降至GDP 5%以下），10年期殖利率可能上探5.5%、法德利差擴至100個基點以上，ECB被迫啟動TPI（傳導保護工具）討論；若示威降溫且預算案通過，殖利率回落至4.5-4.7%，但不會回到3.2%的起點，歐洲長債的「新常態」已上移。

不動產 / 私募

Blackstone下調不動產估值、IPO退出停滯 — 私募轉向「公轉私」折價進場

深度解析

發生什麼事

Blackstone總裁Jonathan Gray 10月22日表示，高利率已侵蝕不動產投資報酬，集團下調旗下不動產資產估值，並坦言市場波動升高使透過IPO快速返還現金給投資人的計畫停滯。同一週歐洲出現兩筆大型「公轉私」交易：瑞典私募EQT以108億歐元收購德國診斷公司Qiagen，為今年歐洲最大私有化交易之一；CVC則在瑞典上市的保全公司Verisure掛牌僅一年、股價較IPO價低30%的情況下探詢收購。FT另報導大型私募出資人（LP）聯合呼籲加強審查有潛在利益衝突的「甜心交易」（sweetheart deals），擔心投資人準備不足、無法有效挑戰收購基金。Blackstone AI主管Jas Khaira同日受訪認為市場對AI基建債務的擔憂「過度」。倫敦信用對沖基金Arini 10月虧約7%、年內跌逾21%；FT報導Highland Spring億萬富豪家族的英國房地產帝國因貸款違約遭債權人追討、被迫出售核心資產。

解讀

這是私募市場在高利率下的三段式調整：(1) 既有資產減值（Blackstone不動產）；(2) 退出管道從IPO轉為二級買賣或再私有化（Verisure股價低於IPO價30%反而成為收購標的）；(3) LP與GP關係緊張（甜心交易審查）。核心本質是「資本成本上升+退出窗口關閉」，使私募必須透過更低的進場價格而非更高的退出乘數來創造報酬，這與2021年零利率時代的模式完全相反。英國房地產帝國違約是「高槓桿持有實體資產」在高利率下的第一批受害者。

傳導鏈

法國殖利率破5%、美債高檔 → 不動產資本化率（cap rate）上升、估值下修 → Blackstone等減記資產、IPO退出停滯 → LP現金回流變慢、新基金募資困難 → GP轉向「公轉私」尋找折價標的（Qiagen、Verisure）→ 上市中型股估值折價成為私募獵物 → 歐洲中型股市場流動性進一步萎縮 → 高槓桿房地產持有者（Highland Spring家族）違約、資產拋售壓低成交價

結構性

結構性為主：私募過去15年的報酬有相當比例來自利率下行帶動的乘數擴張，這個順風已經結束；但估值下修的幅度與速度屬週期性，若2027年利率回落仍可能部分回補。

矛盾訊號

Blackstone一邊下調不動產估值、承認IPO退出停滯，一邊其AI主管說AI基建債務的擔憂「過度」——同一家公司對傳統實體資產保守、對AI資料中心（本質也是實體資產加高槓桿）樂觀，兩者估值邏輯的差距值得追問。另一矛盾：LP呼籲審查甜心交易，但同時持續把資金投入最大型的GP，集中度反而上升。

分叉情境

若美債10年期殖利率在Q4站穩4.5%以上，私募不動產基金NAV在2026年底前再下修5-10%，LP贖回壓力迫使更多非上市REIT啟動贖回閘門；若Fed在2027年Q1轉向降息，在低點完成公轉私交易的基金將在2028-2029年取得25%以上IRR，形成新一輪私募超額報酬週期。

展望

短期 · 1M
短期（1個月內）：關注Blackstone BREIT與其他非上市REIT的10月贖回請求數字，以及EQT/Qiagen交易的融資條件（槓桿倍數、利差）。
中期 · 3–6M
中期（3-6個月）：歐洲公轉私交易量將創2022年以來新高，股價低於IPO價20%以上的近年IPO公司都是潛在標的；私募二級市場（secondaries）折價從10-15%擴大到20%。
長期 · 1Y+
長期（1年以上）：私募產業從「乘數擴張」轉向「營運改善+低價進場」模式，LP將要求更高的透明度與共同投資權利；對台灣壽險業與退休基金的另類投資配置意味著更嚴格的GP篩選與更長的鎖定期。

持續追蹤

Blackstone BREIT月度贖回請求EQT-Qiagen融資槓桿倍數與利差Verisure股價對CVC出價的反應歐洲高收益債利差全球私募secondaries折價幅度

面試角度

持續追蹤中

發生什麼事

中央銀行10月22日公布，9月五大銀行新承做購屋貸款697.83億元，較8月增加126.18億元，主因農曆鬼月季節性因素消退，但仍遠低於去年同期水準；週轉金貸款升至3年半高點，顯示企業資金需求升溫。財政部同日公布今年地價稅11月1日開徵、11月30日截止，開徵戶數約939萬戶（年增1.64%），稅額1,046億元（年增6.91%），主因全國公告地價調漲5.24%。對照美國，NPR引述新分析指平均租屋家庭需16年才能存夠頭期款與交割費用，為2019年的兩倍。

關鍵數據

9月五大銀行新承做房貸697.83億元（月增126.18億）；地價稅1,046億元（年增6.91%、939萬戶）；公告地價+5.24%；美國存頭期款需16年（2019年的2倍）

解讀

房貸金額回升是季節性而非趨勢反轉，央行第七波信用管制與銀行不動產放款集中度上限仍壓著市場；地價稅年增6.91%、超過通膨與薪資成長，反映持有成本在政策引導下持續上升，與交易量低迷形成「量縮、持有成本升」的組合，對多屋族與囤地建商的現金流壓力正在累積。週轉金貸款創3年半高點則是另一面：企業端（尤其AI供應鏈擴產）的資金需求正在吸走銀行額度，房貸的相對優先順序被排擠。

傳導鏈

公告地價+5.24% → 地價稅+6.91% → 多屋族與建商持有成本上升 → 餘屋去化壓力、讓價意願提高 → 房價溫和修正（非崩跌）→ 銀行不動產放款集中度下降、放貸額度釋出 → 2027年房貸利率與限貸鬆綁成為政策選項 → 但全球利率不降，台灣央行12月鬆綁空間有限

分叉情境

若央行12月維持管制且美債殖利率續升，2027年Q1六都房價年減3-5%、交易量維持低檔；若Fed 2027年轉向降息且央行鬆綁限貸，壓抑一年半的換屋需求釋出，交易量反彈20%以上但房價僅持平。

短期 · 1M
短期：看10月房貸數字能否維持650億元以上、地價稅繳納期間對多屋族拋售壓力的影響，以及新台幣貶至32.5對外資置產的吸引力。
中期 · 3–6M
中期（3-6個月）：若全球利率維持高檔，台灣央行12月不會鬆綁信用管制；2027年Q1新青安到期後的政策接續是房市轉折點。

AI / 半導體

AI融資鏈壓力測試 — 黃仁勳「需求爆表但資本稀缺」、CoreWeave CDS走闊、NextDC電力延遲股價-40%

深度解析

發生什麼事

輝達執行長黃仁勳10月22日在柏林GTC接受CNBC專訪時表示，neocloud（新型AI雲端業者）的需求「爆表」，但「資本稀缺」正限制其成長。市場數據印證：CoreWeave股價10月以來下跌29%、信用違約交換（CDS）利差走闊；澳洲資料中心業者NextDC因墨爾本廠區電力供應延遲（社區與利害關係人反對）下修財測，股價單日暴跌40%；HSBC執行長警告「AI熱潮不會讓每座資料中心都是好投資」。Nebius則反駁說AI算力價格正在上漲。Meta宣布將透過新創設的無投票權股份類別為AI建置籌資；川普呼籲資料中心向社區支付「分紅」換取支持；FT專欄直指「誰在為AI建置付錢？可能就是你」——已開發國家所有大型資本池都在為資料中心融資。《大賣空》貝瑞放空4檔AI股，但美光股價近乎翻倍；Anthropic被視為今年最後一個大型AI IPO希望，並與neocloud Nscale洽談第二筆數十億美元資料中心交易。

解讀

AI基建的融資結構正從「超級雲端商自有現金流」擴展到「neocloud高槓桿債務+ABS證券化+新股類別+社區分紅」，每多一層融資就多一個脆弱點。黃仁勳說「資本稀缺」是極重要的訊號——GPU需求方（neocloud）的資金成本已上升到限制訂單的程度，這意味輝達的下游需求不再只受技術限制，而開始受信用市場限制。CoreWeave的CDS走闊是信用市場對AI基建債務的第一次明確定價；NextDC的案例則說明電力取得而非GPU才是資料中心的真正瓶頸。

傳導鏈

美債殖利率高檔+法國殖利率破5% → 高收益債與私募信貸成本上升 → neocloud（CoreWeave、Nebius、Nscale）發債成本上升、CDS走闊 → GPU採購速度放緩（黃仁勳「資本稀缺」）→ 輝達下游訂單能見度下降 → 台灣AI供應鏈（伺服器組裝、散熱、PCB、CCL）訂單波動 → 費半連八跌、台股電子組件跌3.64% → 資料中心選址轉向電力確定性高的地區（NextDC反例）

結構性

結構+週期疊加：AI算力需求是結構性成長（Nebius說價格在漲是真的），但融資端的槓桿擴張是週期性的，現在進入「需求結構性強、融資週期性緊」的錯配階段，這正是2000年電信光纖建置潮的翻版——需求是真的，但融資結構撐不住。

矛盾訊號

黃仁勳說需求爆表、Nebius說算力價格上漲 vs. CoreWeave股價-29%、CDS走闊、NextDC-40%：實體需求與金融定價明顯背離。另一矛盾：貝瑞放空AI股，但美光近乎翻倍；Blackstone AI主管說債務擔憂過度，但Blackstone自己在下調不動產估值。

分叉情境

若CoreWeave或任一neocloud在2026年Q4出現債務再融資困難（CDS升破800bp或債券殖利率突破12%），AI基建信用事件觸發連鎖拋售，台灣AI伺服器供應鏈股價修正20-30%，輝達FY2027訂單能見度被質疑；若超級雲端商（微軟、Google、Meta、Amazon）10月底財報維持2027年資本支出上修且自有現金流覆蓋率高於70%，AI週期由「信用驅動」回到「現金流驅動」，neocloud問題被視為個案而非系統風險。

台電電價與電網韌性（持續追蹤）— 711億撥補未過則12月工業大戶恐漲、漢翔9MW/54MWh電力島啟用

持續追蹤中

發生什麼事

台電10月22日表示，10月電價暫時凍漲，若無法取得711億元撥補預算將影響12月電價走勢；台電目前已吸收民生用電成本逾760億元，若非得調整，前景較好、產值攀升且為用電大戶的外銷產業「被討論的機會相對較高」。同日漢翔在台中水湳廠區啟用全台最大工業級表後儲能微電網「電力島」（9MW/54MWh），整合風力、太陽光電、緊急發電機與電池儲能，具孤島運轉、智慧調度能力，可提供全廠區最高6小時備援、每年節省能源成本近40%，上銀、矽品、寶成等高用電大廠到場觀摩，未來鎖定大型工業用戶、AI資料中心與大型醫院。外貿協會董事長黃志芳同日呼籲補齊主權基金拼圖，助台灣掌握半導體、AI、能源三大關鍵產業主導權。

關鍵數據

台電待撥補711億元、已吸收民生用電成本逾760億元；漢翔電力島9MW/54MWh、年省能源成本近40%、6小時備援

解讀

油價110美元以上直接惡化台電燃料成本，而撥補預算在政治上不確定，使「12月對外銷用電大戶漲電價」成為基準情境。這會把能源成本從台電資產負債表轉移到AI供應鏈與半導體廠的損益表，而漢翔電力島展示的「表後儲能+微電網」正是企業自保的解方——年省40%能源成本與6小時備援在電價上漲與供電不確定下，投資回收期將從目前估計的7-8年縮短至5年以內，澳洲NextDC因電力延遲財測砍到股價-40%則是反面教材。

傳導鏈

布蘭特112美元 → 台電燃料成本上升、虧損擴大 → 711億撥補若未過 → 12月對外銷用電大戶漲電價（半導體、AI伺服器廠）→ 企業能源成本上升、表後儲能與微電網投資回收期縮短 → 儲能系統整合商（漢翔、雲豹、台達電）訂單增加 → 電網韌性成為資料中心選址核心變數 → 台灣AI資料中心投資案的電力確定性成為外資評估重點

分叉情境

若撥補通過且油價回落至100美元以下，12月電價全面凍漲、台電虧損由政府承擔；若撥補未過且油價維持110美元，12月工業大戶電價漲10%以上、民生仍凍漲，表後儲能案場2027年新增量年增50%以上。

展望

短期 · 1M
短期：關注立法院對711億撥補的審議、電價費率審議會召開時間、颱風薔琵對電網的衝擊與復電速度。
中期 · 3–6M
中期（3-6個月）：若12月對工業大戶漲電價10-15%，台灣AI伺服器組裝與半導體廠的電費佔成本比重上升0.5-1個百分點，儲能需求爆發；台電2027年再虧損將迫使電價結構性改革。

深度解析

發生什麼事

台股10月22日開高走低，加權指數開盤46,942.75點、盤中最高47,332.18點，午盤後因中東緊張、日韓股市分別重挫2.65%與3.52%、光復節連假與強颱薔琵（23日可能停班）的不確定性，恐慌性賣壓湧現，從高點下殺1,290點，終場收在當日最低46,041.43點，跌846.34點（-1.8%）、失守季線，成交值擴大至8,792.3億元，上市股票上漲257家、下跌844家。三大法人賣超1,001.59億元，其中外資賣超816.57億元（以ETF為提款主力）、投信買超88.75億元。台積電收2,385元跌35元（-1.44%），半導體類股跌1.9%、電子組件跌3.64%、電腦週邊跌2.28%，金融股相對抗跌撐盤，聯電13天跌近24%；費半指數連八跌。新台幣收32.508元、貶2分，盤中一度貶破32.6、創18個月低點，仰賴央行尾盤穩匯，成交27.71億美元。台指期跌741點收46,262點，期現貨轉為正價差230.57點，夜盤小漲25點。另證交所公布全體券商前9月稅後淨利2,012.54億元、年增170.62%創歷史新高，但9月單月187.81億元、月減31.51%；國泰證券前三季複委託交易額2.85兆元、市占逾20%。

解讀

這是「連假前避險+颱風假不確定+外部三重利空」的流動性驅動賣壓，不是基本面轉折：台灣外銷訂單持續成長、券商獲利創高、AI供應鏈財報（信邦前三季EPS 11.16元、欣銓Q3創高、南亞9月EPS 4.42元）仍佳。但外資單日賣超816億元且以ETF為提款方式、新台幣貶至18個月低點，說明是外資整體減碼台灣部位而非個股換股，與費半連八跌同步，背後是全球AI估值重估。期現貨轉正價差、夜盤反彈，顯示空方並未追殺，連假後的方向取決於美股超級財報週。

傳導鏈

油價破112+美以傳選後打伊朗 → 日韓股市重挫2.65-3.52% → 外資撤出亞洲、台股賣超816億 → 新台幣貶破32.6、央行尾盤穩匯 → 連假前+颱風假不確定放大賣壓、失守季線 → 融資斷頭與ETF贖回壓力 → 下週開盤看美股超級財報週（微軟、Google、Amazon）與Fed 10/28決定方向 → 券商Q4經紀與自營收入隨成交量降溫下滑

結構性

週期性：季線失守與外資賣超是流動性與事件驅動；但新台幣貶至18個月低點與外資持續賣超ETF，反映台灣在全球AI估值重估中的高beta位置是結構性的。

矛盾訊號

外資賣超816億、三大法人賣超破千億，但投信連續買超、券商前9月獲利創高年增170%；南亞9月自結EPS 4.42元、年增9倍，盤中卻因「M9遭AWS驗證不合格」謠言跌破300元、需發重訊澄清——基本面與價格行為嚴重脫鉤。另一矛盾：費半連八跌，但Lam Research、BESI、德州儀器財報都創新高或超預期，市場在懲罰「好但不夠好」的財測。

若連假期間美股超級財報週（微軟、Google、Amazon）資本支出指引上修且Fed 10/28未釋放升息訊號，台股10/27開盤收復季線、外資回補300億元以上；若任一超級雲端商下修資本支出或Fed暗示升息，台股測試45,000點、新台幣貶向33，外資賣超延續至11月。

公股投信四合一拍板 — 第一金投信存續、第一金控持股50.3%、AUM約5,000億衝前八、2028年元旦合併；同日TISA 2.4萬免稅定案

深度解析

發生什麼事

第一金控、兆豐金控、合庫金控及華南金控四家公股金控董事會與旗下第一金投信、兆豐國際投信、合作金庫投信、華南永昌投信四家董事會10月22日同步通過整併案，為首件由財政部主導的跨公股金控子公司合併案，由資產管理規模最大、經營績效較佳的第一金投信擔任存續公司。合併全數以普通股換股：第一金投信每1股分別換發兆豐國際投信1.4532股、合作金庫投信2.7321股；合併後第一金控持股50.3%、兆豐金30.4%、合庫金9.8%、華南金9.5%，董事會7席中第一金取得4席、其餘各1席，董事長與總經理由第一金主導。合併後公募基金規模約4,000億元、排名約第12名，加計代操後AUM約5,000億元（金管會稱資產規模可達4,848億元），目標進入前十甚至前八，設定公募基金年成長15%、代操年成長10%，產品鎖定TISA、REITs等。約370名員工全數留任、工作權保障3年，另有留任獎金與優退優離；第一金投信客戶約5萬戶、兆豐投信約3萬戶。預計10月底向金管會銀行局、證期局與公平會送件，暫定2028年1月1日為合併基準日，金管會表示將盯3大審查重點。同日行政院拍板TISA租稅優惠：本人、配偶及受撫養未成年子女每年提撥2.4萬元內可自綜合所得總額減除（四口之家最多省稅3.84萬元），以修正證券投資信託及顧問法方式納入，最快2027年修法完成、2028年報稅適用。

解讀

這是台灣資產管理業「規模經濟」邏輯的制度化：四家公股投信各自排名15名以外、產品重疊、系統各自投資，合併後排名第12仍不算大，真正的價值在於(1) 配合TISA第二階段租稅優惠帶來的長期定期定額資金；(2) 配合亞洲資產管理中心政策，公股需要一個有規模的「國家隊」承接REITs、基礎建設基金等政策性產品。但換股比例（1:1.4532、1:2.7321）反映各家獲利能力與AUM差異，兆豐金以30.4%持股僅得1席董事，治理安排是財政部主導的政治結果而非純商業談判。最大挑戰在整合期長達14個月（2028年才合併），期間人才流失與客戶重疊是綜效的最大敵人。

傳導鏈

財政部主導公股投信整併 → 第一金投信存續、AUM 5,000億、排名12 → TISA 2.4萬免稅（2028適用）帶來定期定額長期資金 → 公募基金年增15%目標 → 產品鎖定TISA級別基金、REITs → 公股「資產管理國家隊」承接基礎建設基金、亞資中心政策產品 → 民營投信（元大、國泰、富邦）在ETF以外的主動型與退休型產品面臨公股競爭 → 2028年後台灣投信業進一步整併、公股證券與租賃可能複製此模式

結構性

結構性：台灣資產管理業從「金控各自為政」轉向「規模整併+政策導向」是不可逆的制度變革，TISA免稅額是20年來最重要的退休儲蓄制度改革，兩者疊加將改變散戶資金的長期流向。

矛盾訊號

目標「前八強」vs. 合併後排名僅第12、AUM 5,000億，與第一名元大投信（AUM逾2兆）差距仍達4倍；公股強調「綜效」，但保障370名員工全數留任3年、系統各自整合，短期內成本綜效幾乎為零，綜效只能來自營收端（TISA、代操）。另一矛盾：同一天台股重挫846點、外資以ETF提款816億，資產管理業的「規模」在市場下跌時反而是風險。

分叉情境

若TISA修法在2027年如期完成且2028年報稅適用，定期定額資金每年流入投信業500億元以上，合併後公股投信AUM在2029年達8,000億元、進入前十；若TISA修法延宕或金管會/公平會審查拖過2027年Q2，整併期間人才流失、客戶轉向民營ETF，合併後AUM不增反減。

台積電探尋「無稀土」設備方案（持續追蹤）— 供應鏈韌性從晶片材料延伸到廠務設備；經濟部新增343個出口管制實體

持續追蹤中

發生什麼事

路透社10月22日獨家報導，3名知情人士透露台積電正針對工廠自動化設備中使用「無稀土馬達」一事對設備供應商展開調查，評估替代方案以降低中國稀土出口管制干擾先進晶圓廠營運的風險，討論仍處初步階段、尚未促成大規模採購。同日經濟部國際貿易署公告更新「戰略性高科技貨品」出口實體管理名單，新增納管343個實體，涵蓋伊朗、俄羅斯、墨西哥、阿拉伯聯合大公國等。上週中國向歐盟表示稀土將持續供應歐洲、不受美中貿易協議到期影響；中國9月出口強勁超預期。

關鍵數據

台積電調查供應商無稀土馬達方案（初步階段）；經濟部新增343個出口管制實體；中國對歐稀土續供

解讀

台積電主動「去稀土化」是供應鏈韌性從「晶片材料」延伸到「廠務設備」層面的訊號：先進晶圓廠的自動化物料搬運系統、真空泵、機械手臂大量使用稀土永磁馬達，若中國以稀土出口管制作為對台籌碼，影響的不是晶片本身而是整座廠的運轉。這是結構性的供應鏈重組，成本上升（無稀土馬達效率較低、體積較大）將由設備商與台積電分攤。經濟部同日新增343個管制實體，顯示台灣在美中科技戰中正從「被管制方」轉為「執行管制方」，合規成本與地緣定位同時改變。

傳導鏈

中國稀土出口管制威脅 → 台積電調查無稀土馬達替代 → 設備供應商（ASML、應材、東京威力、台灣廠務設備商）開發無稀土方案 → 無稀土馬達、鐵氧體磁鐵、稀土回收商需求上升 → 台灣廠務設備與自動化供應鏈（宇田控制、旭誼工程等）訂單結構改變 → 先進製程建廠成本上升1-2% → 美日歐稀土供應鏈（MP Materials、Lynas）投資加速

分叉情境

若中國在2027年Q1前擴大稀土管制至台灣半導體設備，台積電加速無稀土採購、建廠成本上升2-3%，稀土替代供應鏈股價上漲30%以上；若美中達成稀土協議延長，無稀土方案停留在備援層級、影響有限，但台積電的供應鏈韌性溢價已反映在估值。

展望

短期 · 1M
短期：關注設備供應商是否公開無稀土產品路線圖、中國對台稀土出口是否有異動、經濟部出口管制清單對台灣中小企業合規成本的影響。
中期 · 3–6M
中期（3-6個月）：若中國在美中談判中動用稀土管制，台積電供應鏈的無稀土替代將從調查進入採購，相關台灣自動化與馬達廠商（東元、士電）受惠；中國9月出口強勁與對歐續供顯示其暫無全面管制意圖。

創新板「亞洲那斯達克」兩年40家目標與IPO管線（持續追蹤）— 超秦上市審議通過、7家上櫃公司赴星引資、湧盛掛牌

持續追蹤中

發生什麼事

證交所10月22日舉行創新板年度品牌發布會，呼應賴清德總統「亞洲那斯達克」戰略，董事長林修銘設定未來兩年新增40家企業登上創新板，並強調「市值」成為新認知變革中心、更在意建立創新生態系而非家數。同日證交所上市審議委員會通過超秦（8345）初次上市案（資本額6億元、電宰家禽100%內銷、輔導承銷商為國泰證券）；櫃買中心宣布10月29日攜手台新證券、集保率7家上櫃公司赴新加坡辦理今年首場海外引資說明會；旭誼工程（7849，高科技廠房機電無塵室統包，2025年EPS 2.62元）與益材科技（7879）送件申請上櫃；湧盛電機（2249）以承銷價66元上櫃掛牌、收68.2元（+3.3%）；宇田控制（7962）23日以42.5元登錄興櫃、半導體訂單已看到明年Q2；瑩碩生技（6677）預計明年Q2送件上櫃。

關鍵數據

創新板目標2年40家；超秦上市審議通過（國泰證券輔導）；7家上櫃公司10/29赴星引資；湧盛掛牌首日+3.3%

解讀

在台股重挫846點、失守季線的同一天，IPO管線仍在正常推進，說明台灣一級市場的供給端尚未受二級市場波動影響——但這是滯後指標，承銷定價與掛牌時點將在未來一季反映波動。創新板「兩年40家」目標與「市值」導向，是試圖讓非獲利新創（AI、生技）用市值而非獲利門檻上市，這是台灣資本市場向那斯達克模式的制度轉向，但流動性能否跟上（創新板過去成交清淡）是關鍵；櫃買赴星引資則是從需求端補流動性。

傳導鏈

總統「亞洲那斯達克」政策 → 創新板放寬、2年40家目標 → 承銷商（國泰、富邦、元大、台新）IPO輔導案件增加 → 台股重挫、季線失守 → Q4掛牌案承銷價下修、超額認購倍數下降 → 新創籌資轉向私募/可轉債 → 若2027年Q1市場回穩，壓抑的IPO管線集中釋出 → 承銷商投行收入呈「延後但不消失」

分叉情境

若台股在11月收復季線且費半止跌，Q4與2027年Q1 IPO案集中掛牌、承銷商投行收入年增20%以上；若台股續跌至45,000點以下，IPO案延後至2027年Q2、承銷價平均下修15%，承銷商改以SPO與可轉債維持收入。

展望

短期 · 1M
短期：關注連假後市場是否回穩、超秦與旭誼的承銷時程、創新板11月是否有新案掛牌；台股波動對Q4 IPO定價的折價幅度。
中期 · 3–6M
中期（3-6個月）：創新板能否在2027年Q1前達到10家新掛牌是「兩年40家」可信度的檢驗；海外引資（新加坡）對上櫃中小型股外資持股比重的效果。
