發生什麼事

中秋連假期間全球債市持續失血。FT報導，隨著美伊協議希望破滅、布蘭特原油上漲，美國10年期公債殖利率週一升破5.2%，CNBC指出這已是近19年高點，推升因素包括黏性通膨、大量發債與AI投資熱潮。歐洲同步承壓：德國10年期公債殖利率觸及3.6383%，為2009年6月以來最高，已連續七週走揚、9月單月可望上升逾30個基點，市場開始定價ECB升息。避險資產未能倖免：金價28日盤中最低4,191.41美元，自近五日約4,360美元高點回落，距今年近5,600美元高點已跌約25%，白銀單日重挫約5%。美股方面，道瓊開盤跌逾300點，四大指數齊跌，僅輝達因庫藏股消息逆勢上漲約3%；亞股日經跌486點、韓股跌2.7%、中國創業板跌逾4.5%，印度股市開盤即暴跌。

國銀房貸逾放升至97億元、72-2比率創16年低 — 房市信用「存量變差、增量受限」

發生什麼事

金管會統計，8月底國銀房貸逾放餘額97.13億元，月增2.88億元，終結連二降，並已連續17個月站穩90億元以上；工商時報指出，因個別銀行自2016年起申報錯誤，金管會已「校正回歸」，近期可能看到破百億元的數字。同時，國銀依《銀行法》72-2條計算的不動產放款比率降至23.97%，月減0.22個百分點、年減1.92個百分點，創2010年11月以來近16年新低，主因是存款總額增加稀釋分母。房仲業者反映資金偏緊、部分房貸重現排撥，金管會則否認，並強調首購、自住與已承諾案件須優先承作。另一方面，壽險業上半年新增房貸789.7億元、年增1倍，壽險業者表示這是降低幣別錯配、尋找國內投資管道的選項。

📐 解讀：逾放上升的主因不是房價崩跌，而是高利率下的借款人償債壓力（首購利率已上探3%）與過去寬鬆期承作的案件開始「熟成」。72-2比率創新低看似空間充裕，但銀行實際上是在「總量寬、分配緊」的環境下主動挑案，資金被AI企業授信與新南向吸走——房市信用正從被動管制轉為銀行主動風控。
🔗 全球升息＋國內利率高檔 → 房貸戶月付金上升 → 逾放連17個月站穩90億元以上、可能破百億 → 銀行提高風險定價、選案趨嚴（排撥傳聞） → 非首購與投資客資金取得困難 → 成交量萎縮、建商去化變慢 → 壽險以房貸承接部分需求、分散幣別錯配
🏗️ 結構性 — 週期為主：逾放上升反映利率週期與信用管制；但壽險增加國內房貸以降低匯率錯配，是IFRS 17與TW-ICS上路後的結構性資產配置調整。
⚡ 矛盾訊號：房仲說「排撥重現」、金管會說「沒有排撥」；72-2比率創新低顯示放款空間充足，但市場實際感受是「借不到、借很貴」——官方看總量、業者看邊際，兩者都對。
🔀 若央行12月理監事會維持利率不變且逾放在年底前突破100億元，銀行將進一步提高非自住房貸利率至3.2%以上，2027年上半年房市交易量可能再萎縮10%-15%；若Fed在年底前停止升息、國內利率見頂，逾放可望穩定在95-100億元區間，首購需求在2027年回溫。

私募市場流動性卡關 — 富人跟進NAV融資、Odido放棄IPO改私下轉手、私募信貸贖回潮趨緩

發生什麼事

FT報導，因私募基金分配款放緩，高資產個人正跟隨退休基金與機構投資人，以私募股權持分為擔保借款（NAV lending）以取得流動性。同時，私募股權業者擱置荷蘭電信商Odido的上市計畫，Apax正接近以交易方式買下Warburg Pincus在這家估值65億歐元電信集團的持股，原因是市場不穩定使IPO窗口關閉。私募信貸方面，FT指出散戶贖回申請減少、動盪趨緩，但業內認為「現在喊底部還太早」。另據報導，高盛正領先競標規模約370億美元的CLO管理業者Palmer Square。

📐 解讀：這三件事指向同一個問題：私募資產的「退場管道」堵塞。IPO窗口在殖利率5%以上時難以打開，LP拿不到分配款只好借錢（NAV融資），GP則靠GP-led接續基金或私下轉手（如Odido）來提供流動性。這是在延後而非解決估值重定價，槓桿其實是往上疊。
🔗 長端利率破5% → IPO窗口關閉、併購融資成本上升 → 私募退場延遲、分配款放緩 → LP與富人以NAV融資取得流動性 → 私募部位槓桿上升 → 若估值下修，NAV貸款觸發追繳、形成二次拋售 → 次級市場（secondaries）折價擴大、買方獲得入場機會
🏗️ 結構性 — 週期為主：利率高檔造成退場延遲；但私募產品散戶化（常青基金、半流動基金）與NAV融資普及是結構性變化，使私募市場對利率與流動性衝擊更敏感。
⚡ 矛盾訊號：私募信貸贖回減緩被解讀為「最壞已過」，但同時富人卻在借錢維持流動性——表面平靜可能只是把壓力從贖回轉成槓桿。
