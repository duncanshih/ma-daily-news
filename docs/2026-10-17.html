美國2026財年赤字1.99兆美元、年增12% — 「2兆赤字＋5%殖利率」成為美國最大總經挑戰

發生什麼事

美國財政部16日公布，截至9月的2026財政年度聯邦預算赤字達1.99兆美元（約新台幣64.55兆元），較上一財年擴大12%，創2021年以來新高，川普政府削減支出的承諾並未反映在數字上。CNBC分析指出，10年期美債殖利率站上5%，正同時推高家庭房貸、企業融資與聯邦政府本身的利息成本，形成「赤字→發債→殖利率→利息支出→更大赤字」的自我強化循環。全球債市同步承壓，ECB總裁拉加德表示近期公債拋售將有助於降溫通膨，其中高負債的法國受創最重。本週稍早美國9月CPI年增3.7%高於預期，主因燃油價格上漲，交易員押注Fed 12月升息機率約90%。不過本週後段AI股重挫觸發避險買盤，FT指出美債數月來的拋售暫告中止。

📐 解讀：這是結構性的「財政主導」(fiscal dominance)風險，而非單週的債市波動：當赤字率約6-7% GDP、通膨3.7%、Fed仍在升息時，期限溢價(term premium)沒有理由回到2010年代的低水位。本週美債反彈是AI恐慌帶來的避險需求，是情緒面支撐，不改變供給過剩的基本面。
🔗 赤字1.99兆美元 → 財政部加大發債（特別是長債） → 期限溢價上升、10年債維持5%上下 → 美元資產殖利率吸引力上升、台美利差擴大 → 亞洲貨幣（新台幣本週貶1.45%）承壓、壽險海外債券評價損益波動 → 高槓桿企業與AI基建融資成本上升
🏗️ 結構性 — 結構性：赤字擴大來自利息支出與國防/社福剛性支出，不隨景氣自然收斂；10年債5%是新常態的中樞而非頂點。
⚡ 矛盾訊號：Fed在升息抗通膨（緊縮），財政部卻以1.99兆美元赤字持續擴張（寬鬆），貨幣與財政政策方向相反；同時本週美債因AI恐慌上漲，掩蓋了供給面惡化的訊號。
🔀 如果10月27日FOMC再升1碼且11月財政部再擴大長債發行規模，10年債可能上攻5.3%-5.5%，股債同跌風險上升；如果AI股修正演變成信用事件（如CoreWeave違約），避險買盤可能把10年債壓回4.6%-4.8%，但這是以風險資產重挫為代價的「壞的下跌」。

中期（3-6個月）：3-6個月：若2027財年赤字維持2兆美元以上，期限溢價持續墊高，30年債可能測試5.5%；評等機構對美國主權評等的展望調整是關鍵變數。

川普豁免《葛蘭姆法案》對俄制裁與100%二級關稅 — 用地緣籌碼換柴油供給

發生什麼事

美國總統川普16日深夜簽署行政命令，以「符合國家利益」為由，暫緩執行9月才簽署成法的《葛蘭姆法案》對俄大規模新制裁，並豁免對大量採購俄國石油買家課徵的100%關稅。FT指出這是川普與莫斯科達成柴油釋出協議後給普丁的「緩刑」。CNBC先前估算，該柴油協議的量不到美國兩週需求，對油價實質幫助有限，但期中選舉在11月3日、美國柴油價格9月創歷史新高，白宮面臨強烈選舉壓力。烏克蘭總統澤倫斯基批評此舉「獎勵且鼓舞普丁」；同一週美國邀請俄羅斯重返曼谷G20會議，引發歐洲不滿，IMFC會議上多國代表在俄國官員發言時離席。共和黨內也有多名參議員公開反對。

📐 解讀：這是以地緣政治讓步換取短期能源價格的交易，本質是選舉週期驅動的政策，而非戰略轉向。市場意義在於：俄國油品重新被允許流入全球市場，二級關稅威脅解除，印度、土耳其等買家風險下降；但對歐洲而言，美國承諾的可信度再打折扣，歐洲國防與能源自主的資本支出會加速。
🔗 豁免對俄制裁與100%二級關稅 → 印度/土耳其等買家放心增購俄油 → 柴油與原油供給邊際增加、選前汽柴油價格壓力略緩 → 歐洲對美國安全承諾信任下降 → 歐洲國防預算與能源自主投資加速 → 歐洲國防/電網/儲能資產需求上升
🏗️ 結構性 — 政策面屬週期性（選舉驅動、可隨時撤回），但對歐美同盟信任的侵蝕是結構性的。
⚡ 矛盾訊號：財政部8日才制裁17艘伊朗影子船隊油輪，16日卻豁免俄國制裁；一邊施壓伊朗、一邊放寬俄羅斯，顯示能源政策以油價為優先而非一致的制裁邏輯。
🔀 如果期中選舉後共和黨保住參議院，豁免可能延長、俄油出口量回升，布蘭特油價在伊朗風險不變下有5-8美元/桶下修空間；如果國會兩黨聯手以立法推翻豁免（需2/3多數），制裁恢復，柴油緊缺延續至2027年的IEA預測將更確定。

中期（3-6個月）：3-6個月：若俄烏「能源停火」破局（烏克蘭誓言續打俄國煉油廠），豁免帶來的增量供給會被抵銷；觀察俄國海運原油出口量是否回到每日350萬桶以上。

台灣人壽600億元簽下台中「台灣超巨蛋」BOT — 保險資金轉向長天期實體資產

發生什麼事

台中市政府16日與中信金旗下台灣人壽完成「台中市運動產業園區新建營運移轉（BOT）案」簽約，台灣人壽將投資約600億元興建，園區定名為「台灣超巨蛋」。台灣人壽董事長許舒博表示，中信集團長期深耕體育公益，並連結辜家與台中的淵源。這是繼新光人壽南港轉運站BOT之後，又一件壽險資金參與大型公共建設的案例。資金面上，七大壽險前九月新契約保費達8,534.3億元、年增72.2%，其中國泰人壽2,859.3億元、年增111.1%，大量新增保費需要長天期、穩定現金流的資產去匹配。另一方面，台北市長蔣萬安提出松山機場遷建，鄉林集團董事長賴正鎰估計可釋出約300公頃土地，民間開發商同步卡位公私合作商機。

📐 解讀：這不只是一座運動場館，而是壽險業資產負債管理(ALM)的結構性選擇：在美債5%但新台幣避險成本與匯率波動加劇的環境下，以新台幣計價、30-50年特許期的BOT資產，可以同時降低匯率風險、提供長天期收益，並在IFRS 17/ICS下改善資產負債存續期間缺口。風險在於場館營運收入（賽事、商場、停車）的需求假設與建造成本上升。
🔗 壽險新契約保費年增72% → 新增負債需要長天期新台幣資產匹配 → 投入BOT/PPP等公共建設 → 降低海外投資比重與匯率避險成本 → 營建、場館營運、周邊商業開發受惠 → 地方政府以民間資金替代財政支出
🏗️ 結構性 — 結構性：ICS接軌與匯率波動讓壽險持續增加國內實體資產配置，且公共建設PPP化是地方政府財政的長期趨勢。
⚡ 矛盾訊號：壽險一方面大舉投入600億元低流動性資產，另一方面金管會正推動強化金融韌性；當新台幣急貶、外資匯出、銀行LCR降至新低時，大型非流動性資產的集中度是否過高值得追問。
🔀 如果場館年營收能達到預估並在特許期內帶來5%-6%的專案IRR，將成為壽險PPP投資的範本，帶動高雄、台南等地類似案件；如果營建成本超支20%以上或賽事營運不如預期，IRR可能壓縮至3%以下，低於10年期美債避險後收益，引發監理對保險業不動產投資比重的檢視。

🔭 展望

短期（1個月內）：1個月內：關注台灣人壽公布的融資結構（自有資金/聯貸比例）與統包工程發包時程。

中期（3-6個月）：3-6個月：其他壽險可能跟進地方政府的運動、轉運、醫療園區BOT案；金管會對保險業公共建設投資的資本計提優惠是關鍵變數。

長期（1年以上）：1年以上：壽險將成為台灣基礎建設的主要長期資金提供者，與開發資本等基建投資機構形成共同投資/接手的生態系。
