總經 / 地緣政治

美國2026財年赤字1.99兆美元、年增12% — 「2兆赤字＋5%殖利率」成為美國最大總經挑戰

深度解析

發生什麼事

美國財政部16日公布，截至9月的2026財政年度聯邦預算赤字達1.99兆美元（約新台幣64.55兆元），較上一財年擴大12%，創2021年以來新高，川普政府削減支出的承諾並未反映在數字上。CNBC分析指出，10年期美債殖利率站上5%，正同時推高家庭房貸、企業融資與聯邦政府本身的利息成本，形成「赤字→發債→殖利率→利息支出→更大赤字」的自我強化循環。全球債市同步承壓，ECB總裁拉加德表示近期公債拋售將有助於降溫通膨，其中高負債的法國受創最重。本週稍早美國9月CPI年增3.7%高於預期，主因燃油價格上漲，交易員押注Fed 12月升息機率約90%。不過本週後段AI股重挫觸發避險買盤，FT指出美債數月來的拋售暫告中止。

解讀

這是結構性的「財政主導」(fiscal dominance)風險，而非單週的債市波動：當赤字率約6-7% GDP、通膨3.7%、Fed仍在升息時，期限溢價(term premium)沒有理由回到2010年代的低水位。本週美債反彈是AI恐慌帶來的避險需求，是情緒面支撐，不改變供給過剩的基本面。

傳導鏈

赤字1.99兆美元 → 財政部加大發債（特別是長債） → 期限溢價上升、10年債維持5%上下 → 美元資產殖利率吸引力上升、台美利差擴大 → 亞洲貨幣（新台幣本週貶1.45%）承壓、壽險海外債券評價損益波動 → 高槓桿企業與AI基建融資成本上升

結構性

結構性：赤字擴大來自利息支出與國防/社福剛性支出，不隨景氣自然收斂；10年債5%是新常態的中樞而非頂點。

矛盾訊號

Fed在升息抗通膨（緊縮），財政部卻以1.99兆美元赤字持續擴張（寬鬆），貨幣與財政政策方向相反；同時本週美債因AI恐慌上漲，掩蓋了供給面惡化的訊號。

分叉情境

如果10月27日FOMC再升1碼且11月財政部再擴大長債發行規模，10年債可能上攻5.3%-5.5%，股債同跌風險上升；如果AI股修正演變成信用事件（如CoreWeave違約），避險買盤可能把10年債壓回4.6%-4.8%，但這是以風險資產重挫為代價的「壞的下跌」。

展望

短期 · 1M
1個月內：10年債在4.8%-5.2%區間震盪，關鍵看10/27 FOMC與11/3期中選舉後的財政方向；選前川普可能以釋油、豁免制裁壓油價，短期通膨預期略降。
中期 · 3–6M
3-6個月：若2027財年赤字維持2兆美元以上，期限溢價持續墊高，30年債可能測試5.5%；評等機構對美國主權評等的展望調整是關鍵變數。
長期 · 1Y+
1年以上：全球資產配置的無風險利率中樞從2%-3%上移至4%-5%，長天期資產（基建、不動產、成長股）的折現率永久性上調，負債端長天期的壽險反而受惠於再投資收益率提高。

持續追蹤

10/27 FOMC利率決策與點陣圖美國財政部11月季度再融資公告(QRA)長債比重10年期美債期限溢價(ACM模型)法國OAT-德國Bund利差

面試角度

國泰CIM會問：殖利率5%時壽險該如何調整海外債券存續期間與避險比率？開發資本會問：無風險利率上移100bp，基建專案IRR門檻該怎麼調？中信投資專案會問：不動產Cap rate會不會跟著擴張？

口說版

「美國2026財年赤字1.99兆美元、年增12%，加上10年債站上5%，我認為這是財政主導的結構性問題，不是短期波動。對國泰CIM這類壽險資金來說，5%的美債是鎖住長期收益的機會，但要同時處理新台幣本週貶1.45%帶來的避險成本；對基建和不動產投資而言，折現率上移代表估值要重新校準。」

川普豁免《葛蘭姆法案》對俄制裁與100%二級關稅 — 用地緣籌碼換柴油供給

深度解析

發生什麼事

美國總統川普16日深夜簽署行政命令，以「符合國家利益」為由，暫緩執行9月才簽署成法的《葛蘭姆法案》對俄大規模新制裁，並豁免對大量採購俄國石油買家課徵的100%關稅。FT指出這是川普與莫斯科達成柴油釋出協議後給普丁的「緩刑」。CNBC先前估算，該柴油協議的量不到美國兩週需求，對油價實質幫助有限，但期中選舉在11月3日、美國柴油價格9月創歷史新高，白宮面臨強烈選舉壓力。烏克蘭總統澤倫斯基批評此舉「獎勵且鼓舞普丁」；同一週美國邀請俄羅斯重返曼谷G20會議，引發歐洲不滿，IMFC會議上多國代表在俄國官員發言時離席。共和黨內也有多名參議員公開反對。

解讀

這是以地緣政治讓步換取短期能源價格的交易，本質是選舉週期驅動的政策，而非戰略轉向。市場意義在於：俄國油品重新被允許流入全球市場，二級關稅威脅解除，印度、土耳其等買家風險下降；但對歐洲而言，美國承諾的可信度再打折扣，歐洲國防與能源自主的資本支出會加速。

傳導鏈

豁免對俄制裁與100%二級關稅 → 印度/土耳其等買家放心增購俄油 → 柴油與原油供給邊際增加、選前汽柴油價格壓力略緩 → 歐洲對美國安全承諾信任下降 → 歐洲國防預算與能源自主投資加速 → 歐洲國防/電網/儲能資產需求上升

結構性

政策面屬週期性（選舉驅動、可隨時撤回），但對歐美同盟信任的侵蝕是結構性的。

矛盾訊號

財政部8日才制裁17艘伊朗影子船隊油輪，16日卻豁免俄國制裁；一邊施壓伊朗、一邊放寬俄羅斯，顯示能源政策以油價為優先而非一致的制裁邏輯。

分叉情境

如果期中選舉後共和黨保住參議院，豁免可能延長、俄油出口量回升，布蘭特油價在伊朗風險不變下有5-8美元/桶下修空間；如果國會兩黨聯手以立法推翻豁免（需2/3多數），制裁恢復，柴油緊缺延續至2027年的IEA預測將更確定。

展望

短期 · 1M
1個月內：選前白宮傾向持續釋油、豁免制裁，對柴油裂解價差有限度壓抑；歐洲股市國防類股可能因同盟疑慮而走強。
中期 · 3–6M
3-6個月：若俄烏「能源停火」破局（烏克蘭誓言續打俄國煉油廠），豁免帶來的增量供給會被抵銷；觀察俄國海運原油出口量是否回到每日350萬桶以上。
長期 · 1Y+
1年以上：美國對盟友的安全承諾變成可交易籌碼，推動歐洲、日本、台灣提高自主國防與能源韌性預算，是國防供應鏈與能源基建長期的需求來源。

持續追蹤

俄國海運原油/柴油出口量國會是否提出推翻豁免的聯合決議歐盟12月對中/對俄貿易措施俄烏能源停火執行情況

面試角度

元大投行法金可能問：二級關稅解除對有俄油交易往來的企業客戶授信風險有何改變？開發資本會問：歐洲國防與能源自主預算擴大，對台灣無人機、電網設備供應鏈的投資機會？

口說版

「川普豁免對俄制裁，本質是用地緣籌碼換選前油價，但協議柴油量不到美國兩週需求，實際降價效果有限。我更關注的是第二層效應：盟友對美國承諾的信任下降，會加速歐洲和亞洲的國防與能源自主投資，這是開發資本這類基建投資人可以提前布局的長期需求。」

美國9月CPI年增3.7%；12月升息機率約90%；黃金4,165.12美元/盎司

中期 · 3–6M
2027上半年政策利率可能在高檔停留，降息需等油價回落至90美元以下且核心通膨連3個月下行。

台灣人壽600億元簽下台中「台灣超巨蛋」BOT — 保險資金轉向長天期實體資產

深度解析

發生什麼事

台中市政府16日與中信金旗下台灣人壽完成「台中市運動產業園區新建營運移轉（BOT）案」簽約，台灣人壽將投資約600億元興建，園區定名為「台灣超巨蛋」。台灣人壽董事長許舒博表示，中信集團長期深耕體育公益，並連結辜家與台中的淵源。這是繼新光人壽南港轉運站BOT之後，又一件壽險資金參與大型公共建設的案例。資金面上，七大壽險前九月新契約保費達8,534.3億元、年增72.2%，其中國泰人壽2,859.3億元、年增111.1%，大量新增保費需要長天期、穩定現金流的資產去匹配。另一方面，台北市長蔣萬安提出松山機場遷建，鄉林集團董事長賴正鎰估計可釋出約300公頃土地，民間開發商同步卡位公私合作商機。

解讀

這不只是一座運動場館，而是壽險業資產負債管理(ALM)的結構性選擇：在美債5%但新台幣避險成本與匯率波動加劇的環境下，以新台幣計價、30-50年特許期的BOT資產，可以同時降低匯率風險、提供長天期收益，並在IFRS 17/ICS下改善資產負債存續期間缺口。風險在於場館營運收入（賽事、商場、停車）的需求假設與建造成本上升。

傳導鏈

壽險新契約保費年增72% → 新增負債需要長天期新台幣資產匹配 → 投入BOT/PPP等公共建設 → 降低海外投資比重與匯率避險成本 → 營建、場館營運、周邊商業開發受惠 → 地方政府以民間資金替代財政支出

結構性

結構性：ICS接軌與匯率波動讓壽險持續增加國內實體資產配置，且公共建設PPP化是地方政府財政的長期趨勢。

矛盾訊號

壽險一方面大舉投入600億元低流動性資產，另一方面金管會正推動強化金融韌性；當新台幣急貶、外資匯出、銀行LCR降至新低時，大型非流動性資產的集中度是否過高值得追問。

分叉情境

如果場館年營收能達到預估並在特許期內帶來5%-6%的專案IRR，將成為壽險PPP投資的範本，帶動高雄、台南等地類似案件；如果營建成本超支20%以上或賽事營運不如預期，IRR可能壓縮至3%以下，低於10年期美債避險後收益，引發監理對保險業不動產投資比重的檢視。

展望

短期 · 1M
1個月內：關注台灣人壽公布的融資結構（自有資金/聯貸比例）與統包工程發包時程。
中期 · 3–6M
3-6個月：其他壽險可能跟進地方政府的運動、轉運、醫療園區BOT案；金管會對保險業公共建設投資的資本計提優惠是關鍵變數。
長期 · 1Y+
1年以上：壽險將成為台灣基礎建設的主要長期資金提供者，與開發資本等基建投資機構形成共同投資/接手的生態系。

持續追蹤

台灣人壽BOT融資與工程發包金管會保險業公共建設投資規範壽險前十月新契約保費松山機場遷建與台北都更政策進度

面試角度

中信MA投資專案最可能問（這就是中信集團的案子）：600億BOT的關鍵風險怎麼拆？營收假設怎麼驗證？開發資本會問：運動場館屬於經濟型還是社會型基建？IRR怎麼估？

口說版

「台灣人壽600億元投資台灣超巨蛋BOT，我認為它的核心邏輯是資產負債管理：壽險前九月新契約保費年增72%，需要長天期、新台幣計價的資產來匹配負債，同時降低匯率避險成本。如果我是中信投資專案團隊，我會先把營收拆成賽事、商場、停車三塊做敏感度分析，確認在營建成本超支20%時IRR仍高於資金成本。」

IPO窗口再關：Klook撤回美國IPO、私募改靠舉債分紅（持續追蹤）

持續追蹤中

發生什麼事

深度解析

發生什麼事

經濟日報報導，近期國內大型離岸風電廠爆雷黯然下市，其子公司債務危機讓銀行圈想起2021年國內電子大廠子公司破產案。當年同樣由母公司出具支持函(letter of support)，債權銀行集體發存證信函要求母公司履行承諾，最終母公司負起責任；但這次離岸風電案母公司的處理方式「完全不同」，讓銀行重新評估最上層母公司的信用與支持函的法律效力。結果是銀行對離岸風電專案融資(project finance)明顯縮手。同時，MoneyDJ指出AI融資疑慮升溫，Bloom Energy、GE Vernova等能源設備股也同步承壓，能源轉型資產的資金成本全面上升。

解讀

支持函是一種「軟性信用增強」，不是保證，本質上依賴母公司的商譽與往來關係；這次事件讓銀行意識到支持函在壓力情境下可能毫無作用，等於專案融資的信用結構要重新定價。這不是風電技術或需求問題，而是融資結構（追索權、信用增強）的問題，將推高後續區塊開發的資金成本。

傳導鏈

離岸風電開發商爆雷下市 → 母公司未履行支持函 → 銀行重新評估支持函效力、收緊專案融資條件 → 要求母公司正式保證或提高股本比例 → 開發商資金成本上升、專案IRR下降 → 區塊開發延宕、2030年再生能源目標與綠電供給承壓

結構性

結構性：專案融資市場的風險定價機制改變（由軟性支持轉向硬性保證），且發生在利率高檔，影響會持續數年。

布蘭特觸及110美元、荷姆茲攻擊創新高（持續追蹤）

持續追蹤中

發生什麼事

布蘭特原油16日自5月以來首次觸及每桶110美元，美油單週漲逾10%。FT指出沙烏地領導的聯軍攔截並摧毀飛向關鍵能源設施的飛彈；BBC Verify統計一週內有12艘船遭攻擊創新高，一艘新加坡貨櫃輪在荷姆茲沉沒；葉門青年運動包圍第三大城塔伊茲，烏克蘭誓言持續攻擊俄國煉油廠。17日又有一艘油輪在沙烏地外海波斯灣遇襲失去動力。

關鍵數據

布蘭特110美元/桶（5個月新高）；一週12艘船遇襲；美油單週漲逾10%

解讀

油價上漲由三個供給面風險疊加（荷姆茲、沙烏地設施、俄國煉油），屬於地緣風險溢價而非需求拉動；但實體市場運費與保險成本使實際交付價高出期貨30-40美元，期貨價格低估了真實的能源成本。

傳導鏈

荷姆茲與沙烏地設施遇襲 → 原油運費與保費飆升 → 布蘭特110美元 → 美國CPI燃油分項上升、Fed升息預期升溫 → 航空、運輸、石化利潤受壓 → 亞洲進口國貿易條件惡化、貨幣貶值

分叉情境

如果美國對伊朗展開大規模轟炸（川普已排除核武與地面部隊），短線可能衝上120-130美元；如果美伊透過俄國斡旋達成停火，風險溢價可能在數週內回吐15-20美元。

展望

短期 · 1M
1個月內：布蘭特在100-120美元區間高檔震盪，美國選前釋油與俄油豁免可抵銷約5美元。
中期 · 3–6M
若荷姆茲攻擊頻率不降，2027年上半年均價可能維持100美元以上，航空業已預警多年的票價與需求壓力。

口說版

「布蘭特觸及110美元，但實體交付成本比期貨高出30到40美元，所以真實的能源衝擊比報價更大。對國泰CIM而言，這代表通膨與升息壓力延續，債券存續期間應該偏短；對開發資本來說，高油價反而強化了能源自主與再生能源投資的經濟性。」

柴油短缺延續至2027、中油凍漲累計吸收289.9億元（持續追蹤）

持續追蹤中

發生什麼事

IEA將儘快釋出逾2,000萬桶柴油，並警告柴油短缺將延續至2027年。國內方面，中油宣布10月19日至25日汽柴油價格不調整，92無鉛維持每公升31.2元、95無鉛32.7元；自2月28日執行美伊戰爭專案平穩機制以來，汽柴油累計擴大吸收約289.9億元。桶裝瓦斯方面，台塑拒絕再吸收，與中油維持每公斤1.8元價差，市場供應恐在冬季吃緊。

關鍵數據

IEA釋出逾2,000萬桶柴油；中油累計吸收289.9億元；92無鉛31.2元/公升

解讀

凍漲是把通膨從CPI移轉到國營事業資產負債表，最終仍由財政或電價/油價回補承擔；中油與台塑的價格脫鉤顯示民營業者已無力共同吸收，市場扭曲開始出現。

傳導鏈

國際柴油短缺 → 中油凍漲吸收 → 中油虧損擴大、需政府增資或未來補漲 → 台塑價格脫鉤、桶裝瓦斯市占重分配 → 冬季供應吃緊風險

分叉情境

如果布蘭特維持110美元以上至年底，中油累計吸收可能達350億元以上，政府需以預算增資；如果油價回落至90美元，凍漲機制可平順退場。

展望

短期 · 1M
選後與年底前凍漲機制可能持續，但累計吸收可能突破300億元。
中期 · 3–6M
2027年若油價回落，中油將以緩降方式回收虧損，國內油價下調速度慢於國際。

口說版

「中油凍漲已累計吸收289.9億元，本質是把通膨從物價移到國營事業資產負債表上，壓低了台灣CPI，但也延後了央行感受到的通膨壓力。這是我在看台灣利率政策時會特別留意的扭曲。」

銀行不缺錢的時代結束？LCR降至122.97%寫史上同期新低 — 搶存款、外資匯出與央行注資

深度解析

發生什麼事

經濟日報報導，今年6月底本國銀行平均流動性覆蓋率(LCR)降至122.97%，寫下史上同期新低，有6家銀行甚至不到110%（法定最低100%）。銀行間出現搶存款現象，但央行並未急著拉警報，反而擔心銀行因流動性壓力而不敢放款。近期外資股利匯出、本週外資賣超台股5,862億元並大量匯出，使市場一度出現「錢荒」；央行持續注入資金，16日標售250億元2年期定存單，投標倍數回升至3.31倍、加權平均得標利率降至1.58%，較9月大幅下降5.8個基本點、創近四期新低，工商時報形容錢荒疑慮暫告段落。另一方面，13家上市金控前九月稅後獲利6,318.8億元，已超越2024年全年歷史紀錄。

解讀

這是存款結構性流失與短期資金外流的疊加：存款流向投資型保單（七大壽險前九月新契約保費年增72%）、股市與外幣，加上外資匯出，銀行的穩定資金來源下降；同時AI相關授信需求旺盛，資產端擴張。金控獲利創高與流動性指標創低同時出現，說明獲利來自資產端擴張與市場行情，而流動性緩衝正在被消耗。

傳導鏈

股市熱絡、投資型保單熱賣 → 活存轉出、銀行存款成長放緩 → 外資匯出與股利匯出加劇資金缺口 → LCR降至122.97%、銀行搶存款墊高資金成本 → 銀行放款趨保守、淨利差受壓 → 央行注資、定存單利率降至1.58%以穩定短率

結構性

兩者兼具：外資匯出與股利季屬週期性；存款轉向投資型產品、AI授信需求擴大則是結構性，LCR難回到過去140%以上水準。

矛盾訊號

學者主張央行應升息以縮小台美利差、穩定新台幣，但央行本週實際操作卻是注入資金、讓定存單利率下降；穩匯（需要緊）與穩流動性（需要鬆）兩個目標正在打架。

分叉情境

如果外資在11月期中選舉後回流、新台幣回升至32元以下，銀行流動性壓力自然緩解，LCR可望於年底回升至125%-130%；如果外資持續匯出且央行12月升息半碼，短率上升將推高銀行資金成本，LCR低於110%的銀行可能被迫減少授信或發行金融債，中小型銀行壓力最大。

展望

短期 · 1M
1個月內：央行持續以公開市場操作維持銀行間拆款利率穩定，觀察10月底銀行LCR與存款成長率。
中期 · 3–6M
3-6個月：銀行將提高定存利率或推出優惠專案搶穩定存款，淨利差可能收窄2-5個基本點；金管會可能要求LCR偏低銀行提出改善計畫。
長期 · 1Y+
1年以上：台灣銀行業從「資金過剩、放款難」轉向「資金需競爭」的新常態，存款定價能力、財富管理與支付生態圈（帶來活存）成為核心競爭力。

持續追蹤

本國銀行LCR與NSFR季度數據央行12月理監事會利率決策銀行間隔夜拆款利率活期存款年增率

面試角度

國泰CIM會問：銀行搶存款、短率上升，對金控旗下銀行與壽險資金調度有何影響？元大投行法金會問：銀行流動性收緊時，企業金融如何協助客戶轉向資本市場融資？中信MA會問：金控獲利創高但流動性下降，你怎麼看？

口說版

「本國銀行LCR降到122.97%、寫史上同期新低，同時金控前九月獲利6,318.8億元創紀錄，這說明獲利來自資產擴張與市場行情，流動性緩衝卻在下降。央行現在面臨穩匯要緊、穩流動性要鬆的兩難；對金控來說，能夠帶來穩定活存的財富管理與支付生態圈，會是接下來的核心競爭力。」

新台幣單週貶1.45%、央行該升息嗎？（持續追蹤）

持續追蹤中

發生什麼事

新台幣16日盤中貶破32.5元、低點32.52元，央行進場調節後收32.338元，單週貶4.63角、貶幅1.45%為亞幣最弱，兩大匯市成交量46.12億美元為史上第五大。中經院等學者指出，台美利差擴大是外資撤出的根本原因，若台灣12月不升息，利差擴大將加深貶值壓力；外銀則指出1個月期NDF報價32.35-32.38元，與現貨相當，短線有機會趨穩，但中長期仍偏貶。匯銀人士點名下週觀察32.6元關卡。

關鍵數據

收盤32.338元；單週貶1.45%；成交量46.12億美元（史上第五大）

解讀

這波貶值以資本帳（外資股市匯出）為主，經常帳仍是大幅順差，因此貶值的持續性取決於外資對AI股的態度，而非基本面；央行可能以「阻貶不升息」策略撐過選舉前的波動期。

傳導鏈

外資賣超台股 → 匯出美元需求 → 新台幣貶值 → 壽險海外資產新台幣計價評價改善、但進口通膨上升 → 央行升息壓力上升

分叉情境

如果Fed 12月升息而台灣不動，台美利差擴大可能推動新台幣測試33元；如果台灣跟進升息半碼，新台幣可望回到32元附近，但房市與中小企業融資成本上升。

展望

短期 · 1M
下週32.3-32.6元區間，32.6元是關鍵關卡；若費半止跌，新台幣可能回升。
中期 · 3–6M
12月央行理監事會是否升息半碼是中期最大變數。

口說版

「新台幣單週貶1.45%，主要是外資賣股匯出的資本帳因素，經常帳仍是大幅順差，所以我認為趨勢性貶值的條件不成立，但12月台美利差是否擴大是關鍵。對國泰CIM來說，新台幣貶值短期改善海外資產評價，但也提醒避險比率不能隨匯率追漲殺跌。」

台股週跌4.47%、外資賣超5,862億 vs. 亞洲基金淨加碼台灣50%（持續追蹤）

持續追蹤中

發生什麼事

台股本週跌4.47%，15日單日暴跌1,655點、外資單日賣超3,025.55億元創史上紀錄，單週外資賣超5,862.2億元、三大法人合計賣超約7,100億元。16日投信與八大公股行庫護盤，指數漲141點收47,111點；但16日夜盤台指期大跌1,144點，下週一面臨季線保衛戰。美銀10月亞洲基金經理人調查卻顯示，淨加碼台灣比率達50%、領先日韓。永豐投顧提醒融資餘額未明顯下降、維持率持續下滑，可能出現槓桿去化的急殺。

關鍵數據

週跌4.47%；外資週賣超5,862.2億元；夜盤台指期跌1,144點

解讀

外資賣超與亞洲基金調查的淨加碼並不矛盾：前者多是全球型與量化基金的風險預算調整，後者反映區域型基金的中長期偏好；真正的短線風險是內資融資槓桿尚未去化。

傳導鏈

費半連8黑 → 外資調節台積電等權值股 → 融資維持率下滑 → 斷頭賣壓風險 → 指數測試季線

分叉情境

如果融資餘額在下週下降逾5%並出現量縮止跌，可視為健康修正；如果跌破季線且融資未減，可能出現2,000點以上的槓桿去化急殺。

展望

短期 · 1M
下週一可能補跌，季線為關鍵；法人點出費半站回季線、外資翻多、帶量收復月線、台積電收復2,500元、融資減肥為五大反攻訊號。
中期 · 3–6M
期中選舉後不確定性消除，加上Q4財報與AI訂單，有機會回到5萬點挑戰。

口說版

「台股週跌4.47%、外資賣超5,862億元，但美銀調查顯示亞洲基金對台灣淨加碼仍有50%，代表中長期配置沒有改變。我更擔心的是融資餘額還沒有去化，所以短線我會等融資減肥、台積電收復2,500元再分批進場。」

金管會六大施政：亞資中心、TISA稅惠、金融業大語言模型（持續追蹤）

持續追蹤中

發生什麼事

金管會主委彭金隆19日將赴立法院報告，書面報告顯示前八月銀行、證券期貨、保險三業稅前盈餘1兆1,702億元、年增5,662億元。六大方向包括強化金融韌性、健全市場與公司治理、消費者保護、發展具台灣特色的亞洲資產管理中心、金融科技與永續金融。TISA（台灣個人投資儲蓄帳戶）已有約26萬人等待稅惠，市場呼籲免稅額2.4萬元，初步共識是修投信投顧法、細節由財政部定案；首版金融業大語言模型預計2027年第1季發布。

關鍵數據

三業前八月稅前盈餘1兆1,702億元；TISA約26萬人；金融LLM 2027Q1

解讀

金管會施政從「防弊」轉向「發展」，亞資中心與TISA的目標是把高儲蓄率轉成長期資本市場資金；但同一時間銀行LCR下降、存款流向投資產品，TISA會進一步加速存款搬家。

傳導鏈

TISA稅惠 → 定期定額投資ETF/基金增加 → 投信資產規模擴大 → 銀行存款進一步轉出 → 金控內部資產管理與銀行業務重新分配

分叉情境

如果TISA免稅額定為每年2.4萬元以上，有望吸引百萬人開戶；如果只有象徵性優惠，參與人數將停留在數十萬人。

展望

短期 · 1M
19日立法院報告後，TISA修法時程與免稅額度是市場焦點。
中期 · 3–6M
若TISA稅惠於2027年上路，金控投信與證券將迎來長期資金流入。

口說版

「金管會把亞資中心和TISA列為重點，目標是把台灣的高儲蓄轉成長期資本市場資金。對國泰、中信這類金控來說，關鍵是怎麼在集團內做好存款流向投資產品的轉換，把銀行流失的存款留在自家投信與保險。」
