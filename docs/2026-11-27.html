總經 / 地緣政治

Fed 12月升息機率逾9成、華許「家庭之爭」三面作戰 — 川普要求調查Q3 GDP「創紀錄錯誤」，數據公信力成市場新變數

深度解析

發生什麼事

美國商務部26日公布第三季GDP大幅上修（CNBC稱「massive revision higher」），川普隨即在Truth Social將其定性為「創紀錄的錯誤」並要求「立即調查」。同日FT報導Fed官員將通膨列為首要關切，即便科技股拋售引發經濟疑慮，12月仍傾向升息；工商時報引瑞銀投信估12月升息1碼機率逾9成，市場並預期2027年第一季至少再升1碼，目前聯邦資金利率區間為3.75%～4.00%。褐皮書顯示12個聯準銀行轄區中8個溫和成長、4個持平，能源、運輸、保險與關稅相關支出持續墊高成本。FT專欄形容華許主持的FOMC正陷入「通膨、AI、前瞻指引」三維拉扯：紐約Fed威廉斯稱「長期來看利率需要更高」，理事華勒甚至拋出「半碼震撼升息」；而華許本人主張少說話、多讀市場訊號，卻遇上輝達一週內暴跌暴漲的極端噪音。10月PCE年增3.8%、英國央行三位官員同樣暗示12月升息，全球主要央行正同步轉鷹。

解讀

這是「基本面主導」而非情緒面：Fed把通膨放在股市之前，表示其判斷AI拋售是估值重定價而非系統性風險。但川普攻擊GDP數據是新的政治變數，若統計機構公信力受損，市場將失去定錨，風險溢酬會以「不確定性」而非「數字」的形式上升。華許想壓低溝通噪音，但同事們「搶麥克風」反而讓前瞻指引失效，這對債市波動是結構性利空。

傳導鏈

Fed 12月升息1碼至4.00%～4.25% → 美債2年期殖利率上行、美元走強 → 新興市場資金外流、新台幣與韓元承壓 → AI資本支出的融資成本上升（高收債、CDS擴大） → 高槓桿AI基建（CoreWeave、Oracle、軟銀）債務展延壓力 → 台灣AI供應鏈訂單能見度下修風險 → 台股外資賣壓延續

結構性

週期（升息週期延長）疊加結構（央行與行政部門關係惡化、統計數據政治化），後者的影響更持久

矛盾訊號

Fed官員說「通膨優先、不理股市」vs. 期指週五反彈600點、市場押注「升息不等於科技牛市終點」；川普一邊要求調查「GDP上修太多」（暗示經濟沒那麼強），一邊政府又對14國加關稅（推升通膨）——白宮想要的是低利率，Fed給的是高利率

分叉情境

如果12月17日FOMC升息1碼且點陣圖顯示2027年再升1～2碼，10年期美債殖利率上看4.8%～5.0%，S&P 500修正幅度擴大至15%，新台幣測試33.5；如果12月僅升1碼但華許以「觀望」措辭終結升息預期，殖利率回落至4.3%～4.5%，科技股在12月底前收復11月跌幅的一半以上

深度解析

發生什麼事

27日中國官媒罕見在盤中發布高層會議紀要，承諾提供市場流動性支持，滬深300指數創下兩年來最大單日漲幅，中國晶片股更寫下史上最大單日漲幅。同日韓國KOSPI收漲204.47點或4.34%至4,915.68點，KOSDAQ大漲8.13%至708.99點，主因市場預期金融監管機關即將推出穩市措施，散戶在指數接近10個月低點附近逢低承接；日經225指數上漲1,211.95點或2.11%至58,711.11點，AI與半導體買盤回流。基本面訊號分歧：CNBC指出中國10月工業利潤重回成長，但是「AI製造與出口」單引擎拉動，消費與房地產投資持續落後；FT則報導中國家庭持續削減消費貸款，房貸三年連降的趨勢已擴散到消費信貸。韓國11月出口預估年增96.8%（10月為93.9%），將創1974年1月以來最大增幅、連續18個月成長，全靠AI記憶體需求。香港同日宣布以稅務優惠吸引主權基金，因部分國際投資人已縮編在港團隊。

解讀

亞洲這波反彈是「政策底」而非「基本面底」：中韓兩國都在同一天釋出穩市訊號，說明官方對AI拋售外溢到本地市場的容忍度已到極限。但中國的兩速經濟（AI出口 vs. 內需去槓桿）沒有改變，韓國出口+96.8%高度集中於記憶體，這類數據的脆弱性在於單一產業週期一旦反轉，沒有第二支柱。對台灣而言，日韓中同步反彈但台股僅漲0.39%、外資續賣，顯示台灣的「去槓桿」還沒結束。

傳導鏈

北京盤中喊話＋韓國穩市預期 → 亞洲AI供應鏈股票空頭回補 → 區域風險情緒改善、韓元與人民幣短線走強 → 外資在亞洲內部「換股」（賣台灣、買韓國低基期） → 台股相對弱勢、新台幣受壓 → 若中國家庭繼續去槓桿，內需型台商（食品、零售、汽車零組件）營收下修

如果中國12月中央經濟工作會議提出具體財政刺激（規模超過2兆人民幣）且韓國金融委推出股市穩定基金，MSCI亞洲（日本除外）指數在Q1前反彈10%～15%，外資回流台灣機率升高；如果穩市只有口頭承諾、12月出口與工業利潤數據顯示AI以外部門持續萎縮，滬深300在兩週內回吐全部漲幅，區域資金繼續集中在少數AI龍頭

發生什麼事

301條款關稅細節進一步浮現：中國與越南20%、孟加拉、柬埔寨、泰國、馬來西亞18%，且美方表態「若簽貿易協議可享較低稅率」，將關稅直接轉化為談判籌碣。CNBC分析指出印度因未被列入而取得相對亞洲對手的競爭優勢。馬來西亞首相安華呼籲美方考量美企在馬投資，泰國前財長高恩批評政府談判不透明；路透指這一輪關稅實質上「劍指北京」，透過施壓其他國家懲罰中國這座世界工廠。BBC經濟編輯Faisal Islam則認為威脅已不如2025年第一輪：各國已重新導向貿易路線，並開始「看向川普任期之後」。

關鍵數據

14個經濟體；中國/越南20%、孟加拉/柬埔寨/泰國/馬來西亞18%、台灣15%（不疊加）；耶魯估美國平均關稅由11.4%升至13.9%

解讀

這一輪關稅的本質是「談判槓桿」而非「收入工具」——美方明說簽協議可降稅。市場反應（亞股普遍反彈）也證明已把它當成可談判的起點。對台灣來說，15%且不疊加是相對有利的結果，但轉口貿易（台灣→東南亞→美國）的供應鏈重組成本會上升。

傳導鏈

14國關稅公告 → 東南亞各國加速與美談判、承諾採購與投資 → 供應鏈從越南/泰國部分轉向印度、墨西哥 → 台商在東南亞的擴產計畫重新評估 → 美國進口物價上升0.3～0.5個百分點 → 強化Fed升息理由

FT報導全球最大PE律所Kirkland & Ellis遭私募基金出資人（LP）砲轟，因其為「續存基金（continuation vehicle）」撰寫的合約條款，在GP「自己賣給自己」的交易中剝奪了LP在爭議時的訴訟權。同日FT揭露退休基金與大學捐贈基金正以「大幅折價」在次級市場拋售老舊VC基金份額，目的是騰出現金追逐下一代AI新創。CNBC則有兩篇相關報導：PwC警告散戶進入私募市場的管道前所未有地多，但教育落後、贖回限制使流動性風險浮上檯面；主權基金（SWF）越來越像PE巨頭——自行發起交易、取得控股權、建立自有投資平台，也因此繼承了PE的風險。香港同日宣布以稅務優惠吸引主權基金進駐，因部分全球投資人已撤出或縮編在港團隊。FT另一篇評論質疑私募信貸的「alpha」是否真實存在，認為直接放貸的報酬可以在公開市場複製。

解讀

這些新聞指向同一個結構問題：私募市場在低利率時代膨脹到流動性無法支撐的規模，現在資金想退場，卻發現出口被GP掌控的治理結構堵住。續存基金本質是GP用新LP的錢買舊LP的資產、自己定價、自己收費，在估值下行期這是利益衝突的放大器。散戶化（PwC）與主權基金PE化（CNBC）則意味風險正從專業LP擴散到更廣的資金池。這不是週期性的次級市場折價，而是私募治理模式的信任危機。

台股年初至10月大漲 → 壽險逢高實現FVOCI處分利益（國壽1,140億） → 金控獲利創高、保留盈餘暴增 → 股利政策承諾「不讓投資人失望」 → 外資回補高股利金融股、金融股成護盤主力 → 壽險減持台股（國壽9、10月減碼）本身是台股賣壓來源之一 → 2027年若台股盤整，壽險處分利益大減、金控獲利年減20%以上 → 股利配發率承諾成為資本比率壓力

分叉情境

如果台股在2027年Q1回到42,000以上且金管會接軌IFRS 17後允許較高股利配發，國泰金股利達5元以上、金融股再漲10%；如果台股盤整在38,000～40,000且央行跟進升息導致壽險債券評價損失，國泰金股利落在3.5～4元、金融股轉為區間震盪

中期（3-6個月）：2027年Q1金控獲利年減壓力浮現（高基期＋股市盤整），壽險系金控EPS預估年減15%～25%；台新新光銀行合併綜效在2027年H1開始顯現，成本收入比下降2～3個百分點
