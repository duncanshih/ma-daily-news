全球公債同步殺盤 — 日債30年來首破3%、美10年期升抵4.78%，「利率不會再回到過去」開始被市場定價

發生什麼事

9月1日全球主要公債殖利率同步跳升至數十年高點。日本10年期公債殖利率自1996年9月以來首次向上突破3%大關；作為全球資產定價基準的美國10年期公債殖利率突破4.75%阻力區、來到4.78%，創2025年初以來新高；英國30年期公債殖利率觸及1998年以來最高，長天期借貸成本則是2008年金融海嘯以來最貴。導火線有二：一是美伊停火一個月後於8月31日重啟軍事衝突，布蘭特原油衝上92美元，能源通膨預期迅速回補；二是歐元區8月通膨率重回3%以上、德國通膨加速升溫，市場已將歐洲央行9月升息視為主要情境。同時，美國30年期公債殖利率今年維持在5%以上的天數創2006年以來之最，反映的不只是通膨，還有聯邦赤字擴張與企業發債潮對資金的競逐。法國與德國公債期貨賣壓同步湧現，這已不是單一國家的財政事件，而是全球期限溢酬（term premium）的系統性重評價。

📐 解讀：這一輪不是「經濟太強所以殖利率升」的良性升息，而是「供給面通膨＋財政赤字＋央行政策可信度」三重折價同時發生的期限溢酬重估。真正的訊號在於：股債同時被壓，代表市場不再把公債當避險資產，而是當成另一種風險資產在賣。當無風險利率的地板整體抬高，所有以現金流折現定價的資產——成長股、長天期債、私募基金的估值模型、房地產的cap rate——都必須重新算一次。
🔗 美伊衝突升級 → 布蘭特突破92美元 → 歐美通膨預期回補（歐元區CPI重回3%以上） → 央行升息路徑重新定價（ECB 9月升息、Fed 9月成擲銅板） → 全球長天期公債殖利率跳升（日3%、美4.78%、英1998年來高） → 期限溢酬與折現率同步上移 → 高評價成長股、長天期債、私募資產估值承壓 → 新興市場資金回流成熟市場、carry trade 部位面臨平倉
🏗️ 結構性 — 結構性為主。日本結束30年低利率環境、美國赤字驅動的發債潮、能源供給的地緣脆弱化，這三件事都不是庫存循環可以解釋的；週期成分只在於原油的短期風險溢價。判斷依據：美30年期殖利率維持5%以上的天數創2006年來最多，代表這是長期的資金定價轉移而非單一事件跳動。
⚡ 矛盾訊號：同一天台股卻大漲820點、AI權值股領軍創波段新高。市場一邊為「升息重啟」賣債，一邊為「AI資本支出無上限」買股，等於同時假設「折現率上升」與「分子端成長更快」。歷史上這兩件事很少長期並存——FT直指真正該問的問題不是AI需求有多大，而是這波AI榮景是「用什麼錢」融資的。
🔀 如果9月ECB確定升息、且Fed在9月會議跟進升息1碼，美10年期殖利率有機會測試5%、日10年期上看3.3%，全球股市估值須下修10-15%，資金將明顯從長天期成長股轉向現金流前置的價值股與能源股；如果美伊在9月內回到6月協議框架、布蘭特回落至80美元以下，通膨預期快速鬆動，美10年期可能回落至4.3-4.5%，這一輪的殖利率飆升會被事後定義為「地緣事件溢價」而非結構轉折。

貝森特公開施壓日銀升息、日圓貶至160 — 匯豐首席經濟學家：這和1997年亞洲金融危機前夕「驚人相似」

發生什麼事

美國財政部長貝森特在G20財長會議期間分別與日本財務省官員會談後公開表示，日本「下一步應該升息」，並暗示東京可能出手干預匯市支撐日圓。日圓當日貶至160兌1美元，日本10年期公債殖利率同步突破3%、創1996年來新高。隔夜指數交換（OIS）顯示，市場定價日銀本月升息機率已飆至92%，但分析師認為，日圓貶勢太重，單次升息不足以扭轉，需要連續多次升息才有效力。值得注意的是，日本財務大臣片山皋月會後表示，美日財長會談「未談到升息議題」，與貝森特的公開說法出現落差。另一方面，匯豐首席經濟學家指出，當前「美債殖利率上升＋日圓疲軟＋科技市場樂觀情緒」的組合，與1997年亞洲金融危機爆發前的環境驚人相似——而1997年最終導致整個亞洲區域的經濟衰退。

📐 解讀：這是典型的「政策三難」現場：日本要同時處理通膨、匯率與30年來最高的公債殖利率，而美國財長在旁邊公開加壓，等於把日銀的政策獨立性攤在陽光下。我的判斷是，1997年的類比要小心使用——當年亞洲的問題是短期外債＋固定匯率，今天亞洲多數國家是浮動匯率＋高外匯存底，結構韌性完全不同。真正該擔心的不是1997式的貨幣危機，而是「日圓carry trade平倉」帶來的全球流動性瞬間收縮，那才是2024年8月台股單日重挫的劇本。
🔗 貝森特公開施壓＋日本通膨壓力 → 日銀9月升息機率升至92% → 日本10年期殖利率破3% → 日本壽險／退休基金的海外資產（美債、歐債）相對吸引力下降 → 資金回流日債 → 美債長端失去邊際買盤、殖利率再上行 → 日圓carry trade（借日圓買高息資產）融資成本上升 → 新興市場與高beta股票面臨平倉賣壓 → 台股等外資高持股市場首當其衝
🏗️ 結構性 — 結構性。日本正在退出維持了30年的超低利率環境，這是貨幣體制的轉換而非週期波動；日本市場的長期定價邏輯（低利率、日圓作為全球融資貨幣）正在被重塑。
⚡ 矛盾訊號：市場OIS定價日銀9月升息機率92%，但日本財務大臣片山皋月明講「未談到升息議題」；同時日圓仍貶至160，代表匯市根本不相信升息能改變利差結構。若真的92%要升息，日圓不該還這麼弱——不是市場在騙人，就是市場認為「升息一次沒用」。

8月六都移轉15,723棟創10年同期新低 — 土銀董座：信用管制「不會更緊，但鬆綁也很難」，9/17理監事會成全年轉折點

發生什麼事

六都地政局公布8月建物買賣移轉棟數合計15,723棟，創近10年同期新低，月減23.3%、年減5.6%；前8月累計133,665棟、年減1.5%。減幅放大的直接原因是7月民眾搶搭「青安2.0」末班車衝出一波買氣，8月退潮後又適逢暑假與農曆民俗月雙淡季，加上8月工作天數比7月少約9%。土地銀行1日舉行80週年行慶，董事長何英明受訪明確表示，央行選擇性信用管制「短期應不會更緊縮，但放寬難度也很高」，而建商目前最希望鬆綁的是「購地貸款須於18個月內動工」的規定，理由是強迫動工反而會增加爛尾樓風險。何英明並透露，建商購地態度已明顯轉保守，土建融餘額已從高峰近5,000億元降至4,000多億元，但房貸餘額仍持續成長。央行將於9月17日召開第三季理監事會議。

📐 解讀：這是一個「量先價後」的典型收縮期訊號，而且收縮的源頭是政策（信用管制）而非需求崩壊——房貸餘額還在成長，代表自住需求仍在，被壓抑的是投資性與建商端的資金循環。我的判斷是，土建融餘額從5,000億降到4,000多億這個數字比移轉棟數更關鍵：它代表建商的土地儲備正在去化而非累積，未來2-3年的新增供給會結構性下降，這對長期房價其實是支撐而非壓力。
🔗 央行選擇性信用管制（購地貸款成數5成＋18個月動工令） → 建商購地態度轉保守、土建融餘額由近5,000億降至4,000多億 → 土地取得減少 → 未來2-3年推案量下滑 → 新增供給收縮 → 中長期房價下檔支撐加大 → 但短期成交量續萎縮，代銷／房仲／建材產業鏈營收承壓 → 銀行不動產授信成長趨緩、須尋找新的放款成長引擎
🏗️ 結構性 — 週期性為主、但帶有政策造成的結構扭曲。判斷依據：房貸餘額持續成長代表自住剛性需求未消失，衰退集中在建商端與投資端，這是政策工具精準打擊的結果，一旦9月理監事會鬆綁18個月動工令，量能可望回補。
⚡ 矛盾訊號：土銀董座說「不會更緊」，但同時說「鬆綁也很難」——等於明示央行會維持現狀。可是市場（建商）卻仍在期待9月鬆綁，塗料龍頭永記造漆甚至靠「半導體建廠潮」補上住宅市場的缺口、挑戰百億營收。這代表營建產業鏈的分化已經開始：接得到半導體與AI資料中心工程的，跟純住宅的，是兩個完全不同的景氣循環。
🔀 如果9月17日央行理監事會鬆綁18個月動工限制（例如延長至24個月），建商資金壓力立即緩解、爛尾樓風險下降，Q4推案量可望回升15-20%，全年移轉棟數有機會由負轉正；如果央行維持現狀不動，全年六都移轉棟數確定年減，土建融餘額可能進一步降至3,500億以下，中小型建商的財務違約風險（參考兆基案例）將在Q4集中浮現。

發生什麼事

9月1日台灣金控業出現兩件結構性事件。其一，玉山金（2884）完成與三商美邦人壽的股權交割，三商壽即日起正式成為玉山金子公司。本案於2026年7月7日取得金管會核准、採股份轉換方式完成合意併購。隨著銀行、人壽、證券及投信版圖到位，玉山金正式進入「金控2.0」階段，資產規模逾6.6兆元、躍升為國內資產規模第5大上市金控。其二，台新新光金（2887）召開第二季法說會，上半年稅後淨利438億元、較去年同期大增329%，EPS 1.69元，年化ROE 15.36%；法說會前夕股價收在40.3元創新高、總市值正式突破兆元，成為第四家「兆元金控」（合併時股價為16.3元）。法說會同時揭露，新光人壽截至6月底金融資產未實現利益近900億元，其中約九成來自股票，股票投資占比從年初不到一成提高至6月底的13.9%。總經理林維俊表示「非常有信心」明年股利優於今年，形式將傾向以現金股利為主，但保留搭配股票股利的彈性。

📐 解讀：這兩件事放在一起看，說明台灣金控業的競爭邏輯已經從「規模」轉向「業務組合完整度」——玉山補的是壽險這塊拼圖，台新新光證明的是併購綜效可以在18個月內反映在EPS上。我的判斷是，新壽把股票部位從不到10%拉到13.9%、並累積近900億元未實現利益，是這波獲利暴增的主因，但這也意味著金控的獲利波動度大幅提高：股票部位的未實現利益在多頭時是獲利引擎，在空頭時就是資本適足率的壓力來源。台股今天大漲820點固然好，但這種獲利結構在全球殖利率飆升的環境下，下檔風險被低估了。
🔗 金管會核准併購（玉山／三商壽、台新／新光） → 金控取得完整的銀行＋壽險＋證券＋投信業務組合 → 壽險資金部位擴大並提高股票配置（新壽從<10%升至13.9%） → 台股多頭下未實現利益快速累積（新壽近900億、九成來自股票） → 稅後淨利與EPS大幅跳升（台新新光H1 +329%、EPS 1.69元） → 股價與市值同步創高、進入兆元金控行列 → 但獲利對股市的beta顯著提高 → 若台股回檔15-20%，未實現利益反轉將直接衝擊淨值與RBC比率
🏗️ 結構性 — 併購整合是結構性（業務版圖與資產規模不可逆），但獲利成長是週期性（來自台股多頭下的未實現利益）。判斷依據：台新新光H1獲利年增329%的主要動能是投資收益而非核心利差或手續費收入，這種成長率不具可持續性。
⚡ 矛盾訊號：林維俊「非常有信心」明年股利優於今年，但獲利來源有相當比重是股票未實現利益——而未實現利益要變成可分配盈餘，必須真的賣出實現。同時全球公債殖利率正創數十年新高，壽險的債券部位帳面價值會受壓。一邊是股票部位的未實現利益，一邊是債券部位的未實現虧損，兩者的淨效果才是真正的資本狀況，但市場只看到前者。
