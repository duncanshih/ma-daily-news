川普對荷莫茲海峽課20%通行費、重啟封鎖伊朗 — 地緣溢價重新定價全球利率

發生什麼事

川普宣布美國將成為荷莫茲海峽的『守護者』，重啟對伊朗船隻的海上封鎖，並對經此水道運送的貨物收取相當於貨值20%的『維安補償費』，美伊在停火備忘錄破局後連續第三輪互相以飛彈、無人機攻擊。荷莫茲海峽承載全球約2成海運原油與3分之1的LNG，消息一出美國WTI原油單日跳上75美元、本週累漲逾7%，Kalshi交易員押注海峽運量要到2027年才會恢復正常。實際數據顯示，攻擊後單日僅6艘船秘密通過荷莫茲，創5週最少。杜拜已規劃在阿聯東岸新建港口以繞過荷莫茲，反映企業把地緣風險視為結構性而非一次性事件。

📐 解讀：這不是單純的油價事件，而是一次『地緣溢價重新定價』：市場原本把美伊停火當成基準情境（price in 降息路徑），如今被迫把中東戰爭風險重新加回利率曲線。20%通行費本質是一種變相關稅，會被轉嫁到全球運費與能源成本，對通膨的傷害是持續性的、而非一次性的。
🔗 荷莫茲封鎖/課費 → 油價與LNG運費上行 → 全球運輸與製造成本升 → 各國CPI二次上行（印度6月已達4.38%） → 央行降息延後甚至轉向升息 → 美2年期公債殖利率創16個月新高 → 風險資產折現率上調、股市承壓
🏗️ 結構性 — 偏結構性：杜拜建替代港口、Kalshi押注2027年才恢復，顯示市場把荷莫茲風險視為長期化的能源安全議題，而非短期軍事衝突的週期波動。
⚡ 矛盾訊號：矛盾訊號：同一時間IEA說全球原油需求2026年將年減、油價理應走弱，但供給端的荷莫茲封鎖卻讓油價逆勢漲7%——需求面與供給面訊號完全相反，油價短線由地緣（供給）主導、中期則看需求。

關鍵數據

美2年期殖利率：16個月新高；印度6月CPI：4.38%（連8月上行）；美10年期殖利率在停火破裂後維持高檔。

📐 解讀：這是典型的『預期差』行情——年初市場一致預期2026年是降息年，如今地緣+通膨黏性讓這個共識瓦解。短端殖利率飆升代表市場對聯準會政策路徑的重新定價，對成長股與高本益比資產最不利。
🔗 能源通膨+糧食通膨 → 各國CPI上行 → 央行降息延後/轉鷹 → 短端殖利率飆升 → 股債同步承壓、殖利率曲線倒掛壓力再現
🔀 若通膨數據低於預期，殖利率回落、股市喘息；若連續兩個月超預期，市場將完全定價『2026不降息』，成長股評價全面下修。

🔭 展望

短期（1個月內）：短期：市場高度關注即將公布的美國通膨數據，若核心CPI超預期，2年期殖利率恐續彈、風險資產回檔。

中期（3-6個月）：中期：若油價回落、通膨降溫，聯準會仍有1-2碼降息空間；反之則全年按兵不動，金融股受惠淨利差擴大。

🔄 私募基金Apollo臨門搶親easyJet（PE併購溢價戰）

發生什麼事

美國私募巨頭Apollo以更高報價『橫刀奪愛』，超越Castlelake原先對英國廉航easyJet的收購提案，easyJet傾向接受Apollo的收購。FT以『一切都是為了那個數字』形容這場PE溢價戰，凸顯在利率高檔、優質資產稀缺的環境下，私募基金仍願為現金流穩定的實體資產（航空）付出溢價。

關鍵數據

Apollo報價超越Castlelake（具體金額未公開）；easyJet董事會態度轉向接受Apollo。

📐 解讀：在高利率環境下，PE併購案的競標仍如此激烈，說明市場上『乾火藥』（dry powder）充沛，且投資人對具穩定現金流、可槓桿收購的實體資產需求強勁。這是判讀私募市場風險偏好的重要溫度計。
🔗 PE乾火藥充沛 → 對穩定現金流資產競標 → 併購溢價擴大 → 標的估值墊高 → 帶動同業重評價
🔀 若Castlelake再加碼反擊，溢價戰升溫、easyJet股價再漲；若Apollo順利拿下，市場將重估其他歐洲廉航的併購價值。

🔭 展望

短期（1個月內）：短期：關注最終成交價與槓桿結構，以及是否有第三方加入競標。

中期（3-6個月）：中期：若利率維持高檔，PE將更聚焦現金流穩定、可產生穩定EBITDA的實體資產。

💬 口說版：「easyJet的併購案很適合拿來談私募思維——Apollo用更高的價格橫刀奪愛，FT說『一切都是為了那個數字』。這說明即使在高利率環境，PE的乾火藥還是很充沛，願意為航空這種穩定現金流的實體資產付溢價。對中信投資專案或開發資本這種要評估私募與實體資產投資的職位，重點是要看標的的EBITDA穩定度與可承受的槓桿倍數，才能判斷這個溢價付得合不合理。」

發生什麼事
