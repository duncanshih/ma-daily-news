總經 / 地緣政治

美國期中選舉投票日：民主黨兩院全拿機率三分之二、史上最燒錢119億美元、道瓊期貨跌300點 — 市場真正在定價的是「分裂政府 × 不降息」

深度解析

發生什麼事

美國期中選舉11月3日投票，近6,000萬張選票已提前投出，第一批結果預計23:00 GMT開票、最終結果可能拖數天。預測市場給民主黨同時拿下眾參兩院約三分之二的機率，Open Secrets估計本屆總支出達119億美元，較2022年的89億美元增逾三成，馬斯克砸近5億美元成為最大金主。川普在選前最後公開談話承認民主黨佔優，並向《紐約郵報》表示若民主黨掌眾院就考慮「預先特赦」馬斯克與白宮幕僚。市場面：道瓊期貨投票日早盤跌300點、S&P 500與Nasdaq以下跌開啟11月，但CNBC指出S&P 500在期中選舉後一年歷史上「必漲」的76年紀錄仍未被打破；汽油均價在川普任內創歷任總統新高，「負擔能力」成選民首要議題。加密產業為本屆砸下逾2億美元遊說，Kalshi估值一年內從50億飆至400億美元，預測市場本身已成為選舉基礎設施。

解讀

這場選舉對市場的意義不在誰贏，而在「誰贏 × Fed接下來做什麼」的組合。民主黨若全拿，川普剩下兩年只能靠否決權與行政命令，財政擴張（減稅延長）與對大科技的監管風向都會反轉；但這些都是慢變數。快變數是Fed：10月會議已有2票主張升息，Musalem與Logan公開說「需要回頭升息」，I bonds利率升到5.51%，說明通膨預期並未被壓下。CNBC點名VIX「無反應」，FT提醒股市波動率風險上升 — 市場用低波動定價了一個高度不確定的夜晚，這本身就是預期差。

傳導鏈

民主黨全拿 → 減稅延長與去監管受阻、國防/加密/AI政策不確定性升高 → 財政赤字預期略降但成長預期下修 → 長端殖利率短線下行、美元走弱 → 若Fed同時暗示升息，則短端升、長端降 = 曲線平坦化 → 銀行NIM承壓、台韓等出口市場匯率短線反而獲得喘息

結構性

週期性事件，但疊加在一個結構性轉折上：Fed從降息週期轉向「暫停甚至升息」，這個轉折比選舉結果更持久。

矛盾訊號

歷史統計說期中選舉後一年S&P 500必漲（76年紀錄），但這些年份幾乎都伴隨Fed寬鬆；今年Fed官員談的是升息、I bonds給5.51%、垃圾債上週「血洗」。統計規律與利率環境互相矛盾，VIX「無反應」則說明市場選擇相信統計。

分叉情境

如果民主黨兩院全拿且Fed 12月維持不變：美元指數回落1-2%、10年期美債殖利率下行10-20bp、科技股反彈但銀行與國防股承壓，台股可望收復44,000。如果共和黨保住參院且Fed 12月升息機率升破50%：短端殖利率再升、美元走強、新台幣測33元整數關卡、外資賣壓延續至12月FOMC前。

AI 融資結構大辯論：黑石總裁喊「要更多股權」、Apollo 單季放貸1,140億美元創紀錄、大摩估10年15兆美元 — 同一天 Elliott 警告大熊市、前高盛首席經濟學家看到2008訊號

深度解析

發生什麼事

香港金管局投資峰會上，黑石總裁Jon Gray表示AI基礎建設需要更多股權而非債務，因為債券投資人正面臨集中度風險；同場華爾街大行掌門人仍看好大型AI交易的融資需求，摩根士丹利估未來10年AI相關累計支出可能達15兆美元，今年AI支出估逾7,300億美元（去年約7,000億）。FT報導Apollo第三季放貸1,140億美元創紀錄，資金流向Anthropic與Nvidia；Anthropic修訂S-1揭露第三季營收170億美元、採購承諾高達8,954億美元。反面：辛格的Elliott（管理800億美元）10月致投資人信警告AI泡沫與投機交易恐引爆大熊市；前高盛首席經濟學家Jim O'Neill說利率升高「總會暴露最脆弱的群體」，若通膨不緩解、靠大量舉債的AI支出將重演2008式警訊。工商時報另指出美國科技公司湧向歐元債市，Alphabet繼5月90億歐元後本週再發歐元債，推升歐洲企業借貸成本；FT則觀察到AI讓信用違約交換（CDS）市場「重新偉大」；Aon執行長上週已警告資料中心集中風險恐限制保險容量並改變融資結構；10月對沖基金Marshall Wace在AI修正中受創。

解讀

這是本波AI週期最重要的轉折訊號：資金提供者開始公開分歧。黑石要「更多股權」的真正意思是：債權人已經吃到飽、不想再承擔集中度風險，接下來AI capex的邊際資金要從股東口袋出，而股東正好在10月經歷Nasdaq一年多來最差月份。Apollo的1,140億美元紀錄與Elliott的熊市警告並不矛盾，它們是同一件事的兩面：私募信貸在銀行與公開債市縮手處填補缺口，而這正是週期晚期的典型特徵。市場已price in「AI capex會持續」，還沒price in的是「用什麼資本、什麼成本持續」。

傳導鏈

AI capex 7,300億→債市集中度飽和（CDS利差擴大、歐元債供給壓力）→ 融資轉向私募信貸（Apollo 1,140億）與股權 → 科技巨頭自由現金流轉負、增發或減少回購 → 本益比壓縮、10月Nasdaq最差月 → 台韓AI供應鏈外資賣壓（台股單日外資賣1,073億、韓股外資賣1.5兆韓元）→ 若Fed再升息，私募信貸的浮動利率結構放大違約風險

結構性

矛盾訊號

摩根士丹利說10年15兆美元、Apollo單季放貸創紀錄 vs. 黑石說債務風險升高要更多股權、Elliott與O'Neill警告崩盤。放貸最多的人與最警惕的人是同一群私募巨頭，這說明他們在「繼續放貸」的同時正在「調整放貸形式」（更多結構化、更多股權連結）。

分叉情境

如果Fed維持不變且10年期美債殖利率守在4.5%以下：AI債券與私募信貸發行續創紀錄，Anthropic等IPO順利，2027年AI capex再增10-15%。如果Fed於2027Q1升息且垃圾債利差擴大100bp以上：AI相關發債停擺、超大型雲端商被迫減少回購或增發、資料中心施工延遲進一步擴大（FT已指出延遲「越來越尷尬」），私募信貸基金出現贖回潮。

澳洲央行今年第5次升息至18年高點；Fed 10月2票主張升息、I bonds 5.51%；金價3,876.4美元（10/30單日-3.63%）；央行Q3購金321噸、中國+63噸

解讀

這不是單一央行的問題，而是油價110美元環境下全球通膨預期的重新定錨。澳洲是先行指標：資源出口國在油價高檔時通膨最頑固，它已經升了5次；Fed從「暫停降息」走到「討論升息」只用了兩次會議。金價的矛盾最有意思：短線被美元與短端利率壓著跌，但央行以近兩年最快速度買進，代表官方部門正在為「美元信用 × 地緣風險」的長期情境避險，而私人部門在為「利率 × 機會成本」的短期情境減碼 — 兩者看的時間軸不同，不是誰對誰錯。

油價110美元 → 澳洲/美國通膨黏著 → RBA升息至18年高、Fed官員談升息 → 美國短端利率破4%、美元強勢 → 金價跌破4,000、新興市場匯率承壓（新台幣32.76、韓元） → 亞洲出口國央行被迫在「跟進升息」與「匯率貶值輸入通膨」間抉擇 → 台灣央行NCD操作成為觀察重點

深度解析

發生什麼事

永慶房產集團調查各大銀行房貸收件與撥款情況發現，銀行資金緊俏導致首購族也難貸：公股銀行多數仍有承貸額度但由總行統一調控，整體首購房貸資金調度偏緊，撥款時程多落在今年12月底至明年1月，首購利率至少2.5-2.6%起跳，非首購房貸利率已突破3%，部分業者甚至暫停受理。同日中央銀行標售364天期定期存單，額度由1,200億元降為1,100億元，吸引2,731.7億元資金投標、投標倍數回升至2.48倍，加權平均得標利率降至1.577%、連續兩個月下行。背景是央行10月已鬆綁部分信用管制、10月六都移轉17,566棟月減2.1%年增3.4%（昨日資料），房仲看「倒吃甘蔗」；但銀行端受限於不動產放款集中度（銀行法72-2條）與存款成長趨緩，實際放款能力並未跟上政策鬆綁。另一面，金管會同日預告穩定幣子法、保誠人壽白皮書指出逾九成高資產族群有財富傳承需求但僅3.7%完成規劃。

解讀

這是典型的「政策鬆綁、資金不鬆」錯配：央行解除信用管制是價格訊號，但銀行放款額度是數量約束，而數量約束才是現在的瓶頸。央行把NCD額度從1,200億降到1,100億、得標利率連二降，說明央行有意在市場資金趨緊時「少收一點」，是在對沖外資匯出造成的流動性抽離（今天匯市爆52.755億美元量）。對房市的含義是：成交量可以回溫，但價格缺乏槓桿支撐，首購利率2.5-2.6%起跳、非首購破3%，實質房貸成本已回到2008年以來最高區間。

傳導鏈

結構性

週期性資金緊縮（外資匯出＋銀行額度）疊加結構性約束（72-2條不動產放款上限），結構性約束不會因央行解除管制而消失。

矛盾訊號

央行10月鬆綁信用管制說「房市可以放」，但銀行說「沒額度」；央行NCD利率連二降說「我在放水」，但房貸利率破3%說「水沒流到房市」。兩個訊號都是真的，差別在於傳導管道被72-2條與存款成長卡住。

解讀

這是「記憶體從成本項變成策略資產」的完整證據鏈。蘋果囤了145億美元存貨（+154%）說明買方已經在用資產負債表對抗漲價，而不是等價格回落；華邦電70.6%毛利率與731億擴產、美光用5億美元可轉債鎖環球晶10年供應，說明賣方在用資本支出與長約鎖定週期。市場的矛盾在於：10月記憶體股（鎧俠-15%）被當成AI泡沫的一部分殺，但蘋果這種非AI終端的毛利率被記憶體壓縮2-3個百分點，說明需求是真實且跨產業的。預期差在「2027更緊」— 市場price in的是2026缺貨、2027緩解，而華邦電、環球晶、旺宏三家供應商都說2027更緊。

深度解析

發生什麼事

FT引述5名知情人士獨家報導，輝達近幾個月已要求全球雲端運算服務供應商，未來簽訂新合約時至少51%的服務必須銷售給非中國企業，形同要求雲端業者降低對中國客戶依賴；新規只適用新合約、不影響現有合約。輝達聲明稱是基於美國晶片出口規定。這是過去從未實施過的規定，把管制從「晶片直接出口」延伸到「海外算力租用」，MoneyDJ報導新加坡業者反彈最大（新加坡是中國企業租用海外算力的主要中轉站）。同日OpenAI宣布延攬前美國陸軍部長Dan Driscoll出任新設的「國家安全現代化」資深顧問；Palantir第三季美國商業營收年增148%至9.84億美元、首度超越政府營收9.53億，但股價因估值過高跌6%；帕蘭泰爾執行長表態有意供應日本自衛隊AI系統；Anthropic警告「非常接近」遞迴自我改進（RSI）能力。中央社另報導CNBC指出輝達人形機器人系統依賴中國製機械手。

解讀

51%規則是管制邏輯的質變：以前管「賣什麼晶片給誰」，現在管「誰可以用算力」，等於把輝達變成美國出口管制的執行機構。這對中國的影響不是直接斷供（現有合約不受影響），而是封住「租海外算力」這條繞道 — 新加坡、馬來西亞的資料中心商業模式會首當其衝。OpenAI、Palantir、Anthropic的動作則說明AI公司主動擁抱國安身分：Palantir商業營收超越政府是「軍轉民」的里程碑，OpenAI挖陸軍部長是「民轉軍」的里程碑，兩個方向同時發生，代表AI產業的資本結構會越來越像國防產業（高政府採購依賴、高進入門檻、高監管溢價）。

傳導鏈

輝達51%規則 → 新加坡/馬來西亞資料中心的中國客戶合約無法續簽 → 東南亞資料中心需求結構重組、部分產能轉向印度與中東（OpenAI阿布達比四項協議）→ 中國企業被迫自建算力（華為昇騰需求上升）→ 中國AI成本上升、進度放慢 → 美國AI公司國安化（OpenAI、Palantir）→ 美國國防採購成為AI營收的穩定來源 → 台灣伺服器供應鏈的客戶結構向美國政府與軍工傾斜（融程電、合勤控已見國防訂單）

結構性：美中科技脫鉤從硬體延伸到算力服務，這不會因選舉或APEC川習會而逆轉，判斷依據是規則由企業而非政府執行、且只適用新合約（可持續擴大）。

矛盾訊號

川普兩週後赴深圳APEC、暫緩對台140億美元軍售、美俄中討論三方會談 — 政治層面在緩和；但輝達51%規則、OpenAI國安化、英國NCSC點名中國AI網攻 — 產業層面在加速脫鉤。政治緩和與產業脫鉤同時發生，說明脫鉤已經「去政治化」、由企業合規自動執行。

財政部11月3日公布今年1-9月全國稅收較去年同期增加7,004億元，但受新版財劃法影響，中央政府僅增加2,553億元、地方政府增加4,527億元，營業稅劃分至中央的比率下降使中央獲配營業稅年減2,748億元（證交稅、營所稅、營業稅本身均年增）。關務署同日指出前10月快遞貨物報單5,953萬筆年增4.2%，但稅額暴增至586億元、遠高於往年300-400億、創歷年新高，主因AI商機帶動企業戶進口高單價高科技商品。支出端：台電工會籲立院盡速通過追加預算、民生電價低於20年前；財政部上週預告修法將AI算力設施營運所得納入重大公建免營所稅（昨日資料）。地方選舉背景：台北市長蔣萬安以輝達落腳北士科為主要政績、但被挖出2017年杯葛前瞻基礎建設計畫。

關鍵數據

全國稅收+7,004億、中央僅+2,553億、地方+4,527億；中央營業稅-2,748億；快遞貨物稅收586億創高；報單5,953萬筆

解讀

財劃法的效果比預期更劇烈：全國稅收增7,004億但中央只拿到三分之一，而中央要負擔的台電撥補、國防、AI基建免稅卻在增加 — 這是「收入地方化、支出中央化」的結構性錯配，2027年中央預算的赤字壓力會比市場想像的大。快遞貨物稅收586億創高則是AI投資的另一個側影：台灣企業正以前所未有的速度進口高單價AI設備（伺服器、GPU、測試設備），這與台股AI供應鏈的營收年增4成是同一件事。兩者結合的含義：台灣的AI紅利正在透過稅收流向地方政府，而中央負擔的AI基建（電力、免稅）卻在增加，這個錯配會在2027年預算審議時爆發。

傳導鏈

財劃法上路 → 中央營業稅-2,748億、地方+4,527億 → 中央預算赤字壓力上升、台電撥補與國防支出排擠 → 立院對台電追加預算與AI免稅更謹慎 → 台電電網投資與電價凍漲難以兩全 → 2027年電價調漲機率上升 → 地方政府稅收充裕但基建執行能力不足（前瞻計畫爭議）→ 中央地方在AI基建（資料中心用地、供電）的協調成本上升

分叉情境

如果2027年中央以特別預算補足台電與國防缺口：公債發行增加、台灣公債殖利率上升10-20bp、壽險資金配置受影響。如果立院擱置台電追加預算：台電2027年電價調漲10-15%成為唯一出路、工業用電成本上升、AI資料中心選址條件惡化。

展望

短期 · 1M
短期（1個月內）：立院對台電追加預算的審議是中央財政壓力的第一個觀察點；11月底地方選舉前，財劃法分配爭議會成為選戰議題。
中期 · 3–6M
中期（3-6個月）：2027年中央總預算編列將面臨財劃法後的首次完整年度，國防、台電撥補、AI免稅三者的排擠效應浮現；財政部可能提出財劃法修正或特別預算因應。

韓國市場（持續追蹤）：KOSPI 重挫3.59%收5,648.79、外資賣超1.5兆韓元、KOSDAQ 跌4.08%；韓媒直指網路洩密頻傳重創數位經濟、3家金融業者通報資料外洩 — 台韓「AI雙生子」同日同幅度下跌

持續追蹤中

發生什麼事

韓股11月3日開低走低、盤中最低5,615.8點、終場收5,648.79點跌210.29點（-3.59%），KOSDAQ收704.39點跌4.08%，外資大幅賣超1.5兆韓元；分析師歸因於AI巨額支出疑慮加劇、美國晶片股重挫、以及期中選舉對川普共和黨國會多數的不確定性。資安面：韓媒報導銀行、電信與政府機關持續遭網攻、3家金融業者通報資料外洩，威脅已從個資竊取擴及金融服務與製造供應鏈。背景（昨日）：南韓2027年預算增12.8%至820.9兆韓元創紀錄、21.3兆韓元投資半導體與實體AI、目標「全球最高性能主權AI模型」；奧特曼週末突訪三星與SK；韓國10月出口暴增94%。

關鍵數據

KOSPI 5,648.79（-3.59%）；KOSDAQ -4.08%；外資賣超1.5兆韓元；台股同日-3.59%

解讀

台韓同日同幅度（-3.59%）下跌不是巧合，是全球資金把台韓當作同一個「AI硬體beta」在交易：外資賣台股1,073億、賣韓股1.5兆韓元，比例與兩市市值大致相當。差別在於韓國的AI曝險更集中在記憶體（三星、SK海力士），而記憶體正是本週同時出現「蘋果喊成本史無前例」與「華邦電毛利率70%」的產業 — 韓股跌得深但基本面其實更強。韓國金融業資安事件頻傳與台灣永豐銀事故同日發生，則提醒「AI雙生子」在數位基礎設施的脆弱性上也是雙生子。

傳導鏈

美股AI去槓桿 → 台韓作為「AI硬體beta」同步被賣（各-3.59%）→ 外資匯出推貶韓元與新台幣 → 兩國央行同時面臨匯率壓力 → 韓國以820.9兆韓元預算與主權AI投資對沖、台灣以台灣週與亞資中心對沖 → 若記憶體漲價延續至2027（華邦、環球晶判斷），韓股基本面比台股更早反彈；若AI capex下修，韓國財政豪賭的風險暴露更大

分叉情境

如果記憶體合約價2027Q1再漲15%以上：三星、SK海力士獲利上修、KOSPI回到6,000、韓元反彈。如果AI capex下修且記憶體價格見頂：韓國820.9兆預算的AI投資面臨「投在高點」質疑、KOSPI跌破5,500、韓元貶破1,500。

展望

短期 · 1M
短期（1個月內）：KOSPI在5,500-5,800區間震盪，外資賣超是否收斂與三星、SK海力士Q4記憶體價格指引是關鍵。
中期 · 3–6M
中期（3-6個月）：若記憶體合約價續漲，韓股2027Q1領先台股反彈；韓國主權AI預算的執行進度與奧特曼-三星/SK合作案落地是結構性觀察點。

口說版

「我會說台韓同日各跌3.59%說明全球資金把兩國當同一個AI硬體beta在交易，外資賣台股1,073億、賣韓股1.5兆韓元，比例與市值相當。差別是韓國的AI曝險更集中在記憶體，而記憶體這週同時出現蘋果喊成本史無前例與華邦電毛利率70%，韓股跌得深但基本面其實更強，如果記憶體合約價2027年續漲，韓股會比台股早反彈。韓國同日金融業資安事件頻傳、台灣永豐銀系統出包，提醒AI雙生子在數位基礎設施脆弱性上也是雙生子。對國泰CIM來說，台韓配置要看記憶體與邏輯晶片的相對週期位置。」
