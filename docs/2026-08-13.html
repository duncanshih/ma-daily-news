發生什麼事

美國勞工部公布7月生產者物價指數（PPI）月增0%，低於道瓊調查的0.2%預期，年增率4.7%、較6月放緩；7月CPI年增3.4%，低於5、6月，主因能源與食品價格回落。降溫的關鍵在於中東戰爭推升的能源價格在7月出現月減——布蘭特原油從高點回落，帶動運輸與加工成本鏈條同步鬆動。市場對Fed 9月「升息」（注意：目前循環是升息風險而非降息）的定價明顯降溫，美股三大指數續揚、公債殖利率下滑。但住房分項仍在推高整體物價，克魯曼直言下月通膨數據將回升。同時CNBC指出，AI資料中心建置本身正在推升電價與工業用電需求，成為Fed抗通膨的新阻力。

美國30年期公債以2001年來最高成本標售 — 期限溢價回歸，5%可能是10年期的地板而非天花板

發生什麼事

美國財政部標售30年期公債，得標殖利率創2001年以來最高借款成本；前一日標售的420億美元10年期公債，得標殖利率則衝上2007年來最高。背景是美國7月預算赤字飆至歷來同期新高，長債供給持續放量。彭博分析師直言，5%可能是明年美國10年期公債殖利率的「地板」，而非「天花板」。Jefferies同步警告，偏高的實質殖利率意味著未來股市報酬率將疲弱。值得注意的是，這波長端走高發生在CPI與PPI雙雙降溫的同一週——顯示驅動力不是通膨預期，而是期限溢價（term premium）與財政信用溢價的重估。

📐 解讀：這是2020年代最重要的定價轉變：美國公債正在從「無風險資產」被重新定價為「有財政風險的資產」。當通膨數據轉好、長債殖利率卻不跌反升，代表買方要求的補償來自赤字與供給，而不是通膨。這對所有以美債為錨的資產定價都是系統性的重設，而且它是慢變數，不會有戲劇性的崩盤時刻，只會持續侵蝕長天期資產的估值。
🔗 美國7月赤字創同期新高 → 長債發行量放大 → 期限溢價上升、10年期標售利率創2007年來新高 → 全球長端無風險利率上移 → 保險公司與退休基金的折現率被動調升（負債面改善、資產面受壓）→ 長天期資產（基建、商辦、成長股）估值下修 → 股債相關性由負轉正，60/40組合的避險效果失效
🏗️ 結構性 — 結構性。期限溢價回歸反映的是全球央行退出QE後、美債買方結構永久改變（外國央行占比下降、價格敏感的私人部門占比上升），這不是一兩季的財政週期問題。

發生什麼事

中國指標性房地產開發商萬科公布鉅額虧損，成為房地產困境持續擴散的訊號。萬科的特殊性在於它是深圳地鐵集團（國資）持股的混合所有制企業，長期被市場視為「不會倒的那一家」——當恒大、碧桂園等民營開發商相繼出事時，萬科被當成中國房市的最後防線與國家意志的體現。如今萬科出現鉅額虧損，直接引發兩個問題：房地產危機是否會繼續擴散？中國政府究竟會不會、以及以什麼形式出手介入？華爾街日報指出，這動搖了「即使是中國房市中流砥柱也難以倖免」的認知。

📐 解讀：萬科的問題不在於一家公司的財報，而在於它摧毀了市場最後一個心理支柱——「有國資背景就不會倒」。一旦這個信念破裂，中國房地產與地方政府融資平台（LGFV）的信用定價邏輯就必須全面重寫，因為兩者依賴的是同一套隱性擔保假設。這也是為什麼萬科的虧損比恒大當年更值得關注：恒大破壞的是民企信用，萬科動搖的是國家信用的延伸。

發生什麼事

倫敦金絲雀碼頭集團（Canary Wharf Group）以6.25億英鎊出售1-5 Bank Street（法國興業銀行的辦公樓），買方是它自己的股東——加拿大資產管理巨頭Brookfield與卡達主權基金（QIA）。這筆交易的特殊之處在於，賣方與買方實質上是同一組控制人，交易的功能與其說是價格發現，不如說是把資產從營運公司的資產負債表移到股東層級，以改善營運公司的流動性。同時FT報導，英國零售不動產的重心正從傳統的高街（high street）轉向零售園區（retail parks），超市、賣場與折扣連鎖正在爭搶空間；辦公空間市場則持續分化。美國方面，聯邦銀行監理機關新規可能終結部分屋主的房貸代管帳戶利息，多州提告阻擋；Mizuho本月則點名看好一檔辦公室REIT與一檔零售型REIT，並強調其具吸引力的殖利率。

關鍵數據

1-5 Bank Street成交價6.25億英鎊，買方為賣方自身股東Brookfield與QIA；英國零售不動產重心轉向零售園區；Mizuho 8月推薦辦公室與零售REIT並主打殖利率

📐 解讀：當一個資產只能賣給自己的股東，代表公開市場的買方深度不足，也代表這個價格不是真正的市場價格。這是全球商辦市場目前最誠實的訊號：交易量在恢復，但流動性是「內部循環」而不是新資金進場。要判斷商辦是否真正落底，看的不是成交價，而是買方是否為新的第三方資金。同時，Mizuho此時推薦辦公室REIT並強調殖利率，正好呼應長端利率走高環境下「不再賭資本利得、改吃現金收益」的策略轉向。
🔗 長端殖利率創2007年來新高 → 不動產資本化率（cap rate）被迫上移 → 商辦估值下修、公開市場買方觀望 → 交易只能在關聯方之間完成（Canary Wharf賣給自家股東Brookfield與QIA）→ 價格發現機制失能，帳面估值與可實現價值出現落差 → 銀行對商辦放款的擔保品估值難以驗證 → 商辦相關貸款展期條件收緊 → 資金持續從商辦流向有結構性成長的類別（零售園區、資料中心、物流）
🔀 如果2027年前出現三筆以上由非關聯第三方買方完成的大型商辦交易、且成交價高於帳面估值九折，則可確認商辦市場落底，REITs評價修復；如果交易持續由關聯方主導、或成交價低於帳面估值八折，則銀行體系的商辦擔保品必須重新估值，歐美中小型銀行的商辦曝險將成為2027年的信用風險焦點。

發生什麼事

輝達與華爾街資產管理業者敲定高達5,000億美元的融資安排，資金將用於興建新的資料中心。執行長黃仁勳向CNBC表示，因為輝達硬體被廣泛採用、具備彈性與可轉移性，放款人可以把「運算力」視為能產生收入的資產來承作，晶片是「可投資的資產」。市場的質疑隨即出現：投資人對資料中心貸款的估值方法提出疑問，指出資料中心貸款遠比房貸與車貸複雜；「大賣空」原型人物麥可・貝瑞再度砲轟這筆融資案，直指GPU折舊假設站不住腳；CNBC另指出這個計畫面臨來自中國的重大風險——若中國低價算力供給放大，GPU的殘值假設將崩解。同一時間，芝商所（CME）宣布將於10月5日推出兩檔運算力期貨合約，AI算力正式成為可交易的資產類別；貝萊德等機構亦質疑資料中心建設熱潮的最大風險所在。

📐 解讀：這是AI週期最重要的結構轉變：融資模式從「股權」轉向「債權」。股權融資的風險由願賭服輸的股東承擔，債權融資的風險會透過信用市場傳染給所有人。整件事的成立與否只押在一個假設上——GPU的殘值。而GPU殘值取決於技術迭代速度（輝達自己每年推新架構）與中國供給（低價算力），這兩個變數輝達都無法控制。貝瑞攻擊的正是這一點，而且他攻擊得有道理。

歐洲乾旱把核電變成能源危機 — 氣候風險正式進入「基載電力」的定價模型

發生什麼事

歐洲的極端高溫與乾旱正在壓縮核電出力，羅馬尼亞已啟動將其唯一運轉中的反應爐脫離電網的程序。核電機組依賴河川與湖泊冷卻，水溫過高或水位過低時，機組必須降載甚至停機，否則排放的溫水會危害下游生態並違反環保法規。同一時間，歐洲逾1.35億人面臨破35度高溫、熱浪加劇，尖峰用電需求正在創高。這形成一個惡性循環：越熱→冷氣用電越多→越需要基載電力→但基載核電因為太熱而必須降載。這與過去被視為「氣候韌性最高」的核電形象完全相反。

📐 解讀：這件事的意義遠超過一則氣候新聞：它證明了核電的「可用率（availability factor）」不再是一個可以放進財務模型的固定假設。過去核電被當成90%以上可用率的準確定收益資產，現在必須加上一個與氣候相關的隨機折減項。對所有正在把核電當成AI資料中心解方的市場（包含台灣的重啟核電討論、SMR題材）來說，這是一個被嚴重低估的風險因子。
🔗 歐洲熱浪＋乾旱 → 河川水溫升高、水位下降 → 核電機組被迫降載或脫離電網（羅馬尼亞唯一反應爐） → 尖峰時段基載電力缺口擴大 → 天然氣調峰機組出力增加 → 歐洲天然氣需求上升、TTF價格走高 → 同時碳排放上升、碳權價格走高 → 歐洲工業用電成本結構性上升 → 能源密集產業（鋁、化工、水泥）競爭力進一步流失，這正是Rio Tinto需要澳洲政府18億美元紓困鋁廠的同一個劇本
🏗️ 結構性 — 結構性。氣候變遷導致的水文條件改變是不可逆趨勢，這不是「今年比較熱」的週期問題。核電廠的選址（內陸河冷卻 vs. 沿海冷卻）將成為未來估值的關鍵分野。
⚡ 矛盾訊號：全球都在把核電（尤其是SMR）當成AI資料中心用電的萬靈丹——台灣的世紀風電也在布局SMR設備、看好2030年商業化——但歐洲的實際運轉數據顯示，核電在最需要電的時候（熱浪尖峰）反而最不可靠。市場在定價SMR的成長故事，卻沒有定價它的氣候可用率風險。
