總經 / 地緣政治

法國騷亂擴大、法債與歐元同跌 — 「債市暴動 vs. 人民暴動」的歐洲財政困局

深度解析

發生什麼事

法國週末爆發逾50萬人參與的示威並演變為暴力衝突，總理提議部分城市實施宵禁，馬克宏拒絕內政部長請辭並承認預判疏失。週一巴黎股市領跌歐股，米蘭也傳出街頭衝突，法國公債價格下跌、歐元走弱。CNBC引述分析師說法：「不是債市暴動，就是人民暴動，或兩者皆是」，點出法國政府在財政緊縮與社會承受度之間進退兩難。瑞士財長Keller-Sutter在IMF/世銀年會期間警告，歐洲公共債務攀升加上能源價格高漲，可能引發歐元危機。同時英國即將公布預算，市場預期銀行稅將上調，歐洲主權信用成為本週主軸。

解讀

這不是單純的社會事件，而是「財政空間耗盡」的政治表徵：法國赤字已高、又遇上伊朗戰爭推升的能源成本，政府無法同時滿足債市（要緊縮）與選民（要補貼）。市場目前把它當成法國局部風險，但真正的尾部風險是傳染到義大利等高債國，讓ECB被迫在通膨與金融穩定間選邊。

傳導鏈

法國騷亂升溫 → 財政改革（緊縮）政治上不可行 → OAT-Bund利差擴大 → 義大利BTP跟漲、歐元走弱 → ECB面臨啟動TPI的壓力 → 歐洲銀行持有主權債的評價損失 → 歐系銀行對亞洲放款與聯貸胃口收縮

結構性

結構性：歐洲高齡化福利支出＋國防支出上升＋能源轉型成本，財政壓力不會隨景氣循環自動消失；騷亂只是把結構問題提早引爆。

矛盾訊號

Lagarde先前稱債市賣壓會壓低通膨（緊縮效果），但法國情勢顯示債市賣壓同時在製造政治不穩定，反而可能迫使政府擴大支出——「債市自動穩定器」可能失靈。

分叉情境

如果法國政府在11月前推出讓步方案（凍結改革、加發能源補貼），OAT-Bund利差可能再擴大20-30bp、評等機構啟動負向展望；如果ECB口頭暗示TPI可用、示威在2週內降溫，利差回落10-15bp，歐元止跌。

展望

短期 · 1M
1個月內：法債利差維持高檔震盪，歐股金融股承壓；若騷亂延燒至第二個週末，歐元兌美元可能再跌1-2%。
中期 · 3–6M
3-6個月：關鍵變數是2027年預算案能否過關與評等動作；若遭降評，被動型債券基金調整將帶來實質賣壓。
長期 · 1Y+
1年以上：歐洲主權債的「無風險」屬性進一步折價，資金分散至美債、日債與亞洲投資級債，歐洲國防與基建支出更依賴共同發債（EU bonds）。

中國Q3 GDP年增4.5%優於預期 — AI出口撐起成長，內需仍是缺口

深度解析

發生什麼事

中國第三季GDP年增4.5%，較第二季加速並優於市場預期，主因外需對中國科技產品的強勁需求抵銷了疲弱的消費。先前公布的9月進出口雙雙大幅超越預期，BBC指出AI熱潮帶動的出口是成長主引擎。不過同日長鑫存儲（CXMT）雖公布前9月獲利轉正，股價仍重挫近8%，反映市場擔憂2029年記憶體供過於求。另外，國票金子公司在中國的國旺租賃逾放比飆破25%，顯示中國實體經濟的信用壓力仍在。

解讀

數字好看但結構單一：成長靠「AI硬體出口」而不是內需，等於中國把全球AI capex的循環性直接吃進GDP。若全球AI投資因融資成本放緩，中國最強的成長引擎反而最脆弱。

傳導鏈

全球AI資料中心建置 → 中國伺服器零組件、電力設備、成熟製程晶片出口增加 → Q3 GDP 4.5% → 政策刺激急迫性下降 → 人民幣相對穩定 → 但內需與地產信用壓力未解（租賃逾放上升） → 台灣在中國的金融曝險持續提列

結構性

出口面偏週期（跟著AI capex走），內需疲弱與地產去槓桿是結構性，兩者疊加使中國成長高度依賴外部需求。

矛盾訊號

GDP加速 vs. CXMT獲利轉正股價卻跌8%、國旺租賃逾放破25%——總體數字與企業／信用層面的訊號背離。

分叉情境

如果Q4全球AI capex指引（Meta、微軟財報）維持成長，中國全年成長可守在4.5-5.0%區間；如果大型雲端商下修資本支出10%以上，中國出口動能將在Q1 2027明顯放緩，北京需重啟消費刺激。

展望

短期 · 1M
1個月內：本週Meta、特斯拉財報與美中曼谷談判（Mastercard、花旗市場准入）是關鍵，人民幣維持區間。

長期 · 1Y+
1年以上：中國在AI供應鏈的中低階環節市占持續提高，與台灣在伺服器、被動元件的競爭加劇。

持續追蹤中

發生什麼事

週一美債殖利率走低，彭博指出AI交易動盪讓美債初步重拾避險角色，使今年押注債市續跌的空頭部位面臨考驗。FT則分析，伊朗戰爭與中國政策轉變正在收緊國際市場的美元供給，使美國升息效果在全球被放大。上週英國央行副總裁才警告避險基金基差交易可能放大債市衝擊，Fed官員Hammack則表示可能需要更高利率防止通膨心理形成。

關鍵數據

S&P 500上週跌近2%、那斯達克跌4.5%；新台幣盤中觸32.572元；金價每盎司4,175美元

解讀

美債短線因避險買盤走強，但通膨（9月CPI升溫）與財政赤字讓長端殖利率的下行空間有限。真正要看的是「美元荒」——亞洲貨幣同步走弱代表全球美元流動性收緊，這比殖利率本身更影響台灣資金流向。

傳導鏈

AI股修正＋地緣風險 → 資金回流美債 → 殖利率短線下行 → 但美元需求上升、離岸美元供給收緊 → 亞幣（台幣、韓元、印尼盾）同步貶值 → 外資匯出加速 → 壽險避險成本上升

分叉情境

如果AI股賣壓延續、美國經濟數據轉弱，美債可望成為有效避險，10年期殖利率下探；如果10月CPI續熱，則出現股債雙殺，避險基金基差交易被迫拆倉。

展望

短期 · 1M
1個月內：10年期美債殖利率可能在避險與通膨之間拉鋸；美元指數若續強，新台幣測試32.8元。
中期 · 3–6M
3-6個月：若Fed在2027年真的需要升息（市場與Williams看法分歧），長端殖利率重回上行，股債同跌風險升高。

不動產 / 私募

債券殖利率飆升讓商用不動產復甦脫軌 — 買方重議數月前談好的價格

深度解析

發生什麼事

FT報導，商用不動產產業氣氛轉為「嚴峻」，因債券殖利率急升，使幾個月前已談定的交易被買方要求重新議價（recut deals）。市場原本預期2026年是降息帶動的不動產復甦年，但伊朗戰爭推升油價與通膨、Fed官員釋出可能升息的訊號，讓融資成本反向上升。同時英國房屋賣家每天下修約3,000筆物件的開價，住宅市場同步降溫。在台灣，台北豪宅「台北之星」的三圓建設持有戶改由大師房屋代銷，成交價較實價登錄下修約15%，建商以降價加速回收資金。

解讀

這是典型的「cap rate跟著無風險利率重新定價」：不動產估值對利率最敏感，殖利率每升50bp，在租金不變下資產價值就要往下修。市場先前price in的是降息復甦，現在正被迫回補「利率維持高檔更久」的風險溢酬。

傳導鏈

通膨升溫＋地緣風險 → 長天期公債殖利率上升 → 不動產資本化率（cap rate）上調 → 資產估值下修、LTV升高 → 買方重議價格、交易延宕 → 再融資壓力浮現 → 私募信貸與銀行不動產放款品質承壓

結構性

以週期為主（利率循環），但辦公室需求因混合辦公結構性下滑，使利率衝擊在辦公類資產上被放大。

矛盾訊號

股市才剛把「AI清算」當成風險，資金逃向美債壓低短線殖利率；但不動產市場面對的是長端殖利率的通膨溢酬，兩者對利率方向的判讀並不一致。

分叉情境

如果10年期美債殖利率在年底前回落至4%以下，被延宕的交易可望在Q1 2027恢復，物流與資料中心類資產優先回溫；如果殖利率站穩更高水準並出現Fed升息，商辦估值需再下修10-15%，再融資違約案例將在2027上半年集中出現。

展望

短期 · 1M
1個月內：交易量持續萎縮，買方議價能力上升；觀察英國預算案與Fed 11月會議。
中期 · 3–6M
3-6個月：2027年到期的商用不動產貸款再融資牆是關鍵，壓力最大在歐美辦公室資產。
長期 · 1Y+
1年以上：資產分化加劇——資料中心、物流、銀髮住宅等具結構需求的資產維持溢價，傳統辦公室持續折價。

持續追蹤

美國10年期公債殖利率歐美商辦cap rate與交易量CMBS違約率台北豪宅實價登錄成交價

深度解析

發生什麼事

解讀
