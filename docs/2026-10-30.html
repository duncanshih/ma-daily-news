總經 / 地緣政治

AI資本支出恐慌引爆全球科技股崩跌 — 從「誰在花錢」變成「錢從哪裡來」

深度解析

發生什麼事

美國科技巨頭Q3財報連環引爆AI投資回報疑慮。Alphabet公布自由現金流為負90.7億美元、遠遜市場預期，但仍維持全年資本支出指引，週四股價收跌12.6%、創史上最差單日、市值一夕蒸發約5,000億美元；FT統計Google、Amazon、Meta三家合計市值蒸發近9,000億美元。Amazon隨後公布「雙重miss」（營收、獲利皆低於預期），AWS雖年增39%並簽下Meta與OpenAI訂單，但自由現金流轉負（CNBC報導-424億美元、TechCrunch報導-24億美元，口徑不一，需核對原始財報），2026年資本支出維持不變，週五盤前跌7%。Intel因PC業務放緩與製造瓶頸，Q4財測大幅不如預期，盤前暴跌25%。Microsoft與Alphabet的資本支出數字低於預期，反而被解讀為基礎設施夥伴交付延遲，CoreWeave、Nebius等neocloud股同步下挫；Microsoft則宣布發債250億美元支應AI建置，是四大雲端中唯一維持正自由現金流者。資金湧向美國10年期公債避險，估將創近三年最大單月漲幅；亞股全面重挫，日經-2.12%、KOSPI-3.48%、台股-2.49%。

解讀

這波賣壓的本質不是「AI需求消失」，而是市場對AI資本支出的融資結構定價重估：當AWS還能年增39%、Foxconn與東京威力科創都說需求強勁，股價卻崩跌，說明市場懲罰的是「自由現金流轉負＋舉債擴張」這個組合，而不是營收。這是情緒面放大的基本面訊號，Alphabet同時面臨AI Mode侵蝕搜尋廣告，等於「花更多錢、核心現金牛卻在縮」，是四巨頭中最脆弱的敘事。

傳導鏈

超大規模雲端商FCF轉負 → 被迫發債（Microsoft 250億美元）或削減回購 → 市場對AI資本支出要求更高的資本成本 → neocloud與資料中心融資條件收緊（HSBC CEO警告非每座資料中心都是好標的）→ 台韓AI供應鏈訂單能見度受質疑 → 外資撤出台股、韓股（外資單日賣超台股1,124億元）→ 新台幣、韓元承壓 → 亞洲央行干預

結構性

結構性：AI建置從「用現金流自我融資」進入「靠債務與外部資本融資」階段，這改變了科技股的風險屬性，不是單季財報波動。

矛盾訊號

矛盾訊號：(1) AWS年增39%、Oracle給出2030年營收2,250億美元指引、Foxconn說AI需求仍強 vs. 股價以「AI泡沫」定價；(2) Microsoft資本支出低於預期本應是「紀律」，市場卻解讀為「產能交付不出來」；(3) Amazon自由現金流的負數在不同媒體間差了一個數量級（-424億 vs -24億美元），顯示市場連基本數字都還沒對齊，恐慌成分高。

分叉情境

如果下週Apple（11/2）、AMD、Supermicro財報再度出現「營收達標但現金流惡化」，Nasdaq 100可能再回檔5-8%，台股測試44,000點；如果Nvidia 11月中財報維持資料中心營收季增15%以上且給出強勁指引，市場會回到「需求面」敘事，科技股在期中選舉後（11/3）有機會反彈，歷史上選後半年S&P 500平均漲12%。

日銀宣告「2%通膨目標達成」 — 13年量化寬鬆的歷史轉折點，12月升息箭在弦上

深度解析

發生什麼事

日本銀行10月30日決議維持政策利率1.25%左右不變，符合市場預期，但總裁植田和男宣布，排除暫時性因素的「基礎通膨率」已達到與2%物價目標大致相符的水準，這是2013年設定目標以來首次正式宣告，被視為13年超寬鬆政策的里程碑。日銀同時將ETF年出售金額提高至8,600億日圓、加速退出資產購買，並上調2027年通膨預測；一位政策委員提案立即升息。東京10月CPI仍遠高於2%，顯示價格壓力持續。日圓對美元在157.5區間震盪、反應平淡，因為12月升息已基本反映在市場定價；明治安田總研指出日銀更關注通膨與經濟上行風險，升息節奏可能從每六個月一次改為每三個月一次。

解讀

這是結構性宣告而非單次決策：日銀用「目標達成」替未來連續升息取得正當性，同時用加速賣ETF釋放「退出非常規政策」訊號。日圓沒有大漲，說明市場早已price in 12月升息一碼，真正的預期差在於2027年的升息次數——若從兩次變四次，日債殖利率曲線和carry trade的拆解規模會大不相同。

傳導鏈

日銀宣告目標達成 → 12月升息至1.5%確定性提高、2027年升息節奏加快 → 日本10年期公債殖利率上行 → 日圓carry trade部分平倉 → 日本壽險與退休基金資金回流本土債市 → 美債、澳債、台灣美元債需求邊際減弱 → 亞幣對美元出現「日圓強、其他亞幣弱」的分化 → 台灣壽險業避險成本與日圓曝險重新定價

結構性

結構性：日本從通縮經濟轉為「2%通膨常態」，意味日本資金從淨輸出轉為部分回流，這是過去30年全球資金流向的根本逆轉。

矛盾訊號

矛盾訊號：日銀說通膨達標、委員提案升息，但實際行動是「按兵不動」；市場定價12月升息，日圓卻仍弱在157——若通膨真的「可持續」，日圓應該更強，說明市場對日銀「敢不敢連續升」仍存疑。

分叉情境

如果12月升息一碼且2027年指引為每季一次，日圓可能升至145-150、日本10年期殖利率突破2.0%，carry trade拆解衝擊美股科技股與新興市場；如果12月升息後油價回落、通膨回到2%以下，日銀改回「每半年一次」，日圓維持150-158區間，衝擊有限。

幣安遭史上最大駭客攻擊63億美元（持續追蹤）

持續追蹤中

發生什麼事

全球最大加密貨幣交易所幣安證實遭遇涉及多個入侵點的「複雜攻擊」，影響資金約63億美元（約新台幣2,053億元），創加密史上最大盜竊案；FT報導起因是一名工程師的筆電遭入侵。幣安已暫停提領，並與Circle、Tether等合作夥伴凍結約30億美元資產，共同創辦人何一承諾公司承擔所有損失。TRM Labs等兩家鏈上分析公司將攻擊歸因於北韓駭客組織TraderTraitor；Ballet創辦人Bobby Lee認為被竊比特幣已不可能追回。幣圈連鎖反應劇烈，台灣「麻吉大哥」黃立成在Hyperliquid 6小時爆倉8次。同日Coinbase公布Q3淨利年增66%，但盤後反跌5%。

關鍵數據

被竊63億美元、已凍結約30億美元（回收率約48%）、新台幣約2,053億元；Coinbase Q3淨利+66%但股價-5%

解讀

這是「交易所信用風險」而非「比特幣本身風險」的事件：幣安有能力自掏腰包補63億美元，反而證明大型交易所的資本厚度，但也暴露中心化交易所是地緣政治（北韓）攻擊的單點故障。對傳統金融的含義是：穩定幣發行商（Circle、Tether）能即時凍結30億美元，說明它們已是事實上的「鏈上清算機構」，監管會以此為由加速納管。

傳導鏈

幣安遭駭 → 暫停提領引發擠兌恐慌 → 比特幣、山寨幣槓桿多單爆倉 → 加密做市商與對沖基金去槓桿 → 與加密高相關的科技股、Coinbase等受壓 → 各國監管以「北韓資金來源」為由強化交易所資安與穩定幣凍結權規範 → 台灣VASP專法與銀行合作（如第一銀行粉獅幣換USDT）審查趨嚴

分叉情境

如果幣安在一週內全額恢復提領且無其他交易所連鎖事件，市場視為「孤立事件」，比特幣回到事件前水準；如果凍結資產追回率低於50%且引發其他交易所提領潮，加密市場可能再跌20-30%並拖累Coinbase等股票。

展望

短期 · 1M
短期（1個月內）：幣安提領恢復後若無二次擠兌，比特幣在事件前價位±15%區間；美國財政部可能對北韓相關地址追加制裁。
中期 · 3–6M
中期（3-6個月）：各國加速要求交易所持有「客戶資產隔離＋保險準備金」，台灣金管會VASP專法細則可能納入資安險強制投保；資安險需求上升（台灣2026上半年資安險保費已達3.19億元）。

解讀

這是「煉油毛利暴利週期」而非「原油牛市」：煉油廠被炸掉的產能是中段瓶頸，所以煉油商（BP、Exxon、Chevron的下游）賺的是柴油與原油價差，而非油價本身。BP用暴利償債是重要訊號——管理層自己也判斷這是一次性暴利而非新常態。Brent較戰前高60%但供給已回升，說明60%中可能有一半是地緣風險溢酬，一旦美伊達成協議會快速消失。

煉油廠遭轟炸 → 柴油供給短缺、裂解價差擴大 → 煉油商暴利、運輸與航運成本飆升（郵輪公司重組、環球郵輪中止）→ 歐美CPI黏著 → Fed、ECB 12月升息 → 全球長債殖利率上行 → 另一方面高油價推升中東主權基金收入但沙烏地因胡塞攻擊延後投資大會至2027 → 美國LNG出口商受惠（卡達買美國天然氣）→ 台灣進口燃料成本上升、中油台電虧損擴大、電價調漲壓力

央行今天的操作是「守關卡不守趨勢」：盤中容忍貶到32.676，尾盤才出手拉回32.5以內，目的是避免單日貶幅過大引發恐慌性匯出，而非逆轉貶勢。真正的壓力來自外資股市撤離（10月近1兆）與美元強勢（Fed 12月升息預期）的雙重夾擊，在Fed、ECB、BOJ同步鷹派下，台灣央行12月若不跟升，台美利差擴大會加速匯出。

傳導鏈

外資賣超台股匯出 → 新台幣貶破32.6 → 央行尾盤調節守32.5 → 出口商逢高拋匯（台積電等美元收入）提供自然買盤 → 匯價短線穩住但趨勢仍弱 → 壽險業海外資產匯兌收益增加、但避險成本上升 → 進口物價（原油、天然氣）上揚推升CPI → 央行12月面臨跟隨Fed升息的壓力

分叉情境

如果Fed 12月升息且台灣央行按兵不動，新台幣貶破33.0，壽險業避險成本上升但匯兌收益增加、出口商獲利受惠；如果美伊停火、油價回落、Fed暫停升息，美元走弱、外資回補台股，新台幣回升至32.0以下。

展望

短期 · 1M
短期（1個月內）：新台幣在32.3-32.8區間，11月測試32.7前低；若外資賣超收斂，匯價回到32.3-32.5。
中期 · 3–6M
中期（3-6個月）：Fed 12月升息、台灣央行是否跟進決定方向；若台美利差擴大，新台幣可能測試33.0；壽險業匯兌利益與避險成本成為Q4財報焦點。

兆豐銀統籌創意電子400億元聯貸超額認購1.2倍、11家銀行搶參貸 — 全球AI資金荒下「國銀貸放有利賣方」（持續追蹤）

持續追蹤中

發生什麼事

兆豐銀行統籌主辦創意電子（3443）新台幣400億元聯合授信案10月30日簽約，吸引11家金融機構參與、認參金額達目標1.2倍，用途支應AI、雲端與高效能運算客製化晶片設計服務的營運擴張。MoneyDJ《DJ在線》指出全球AI資金荒下，國銀對AI供應鏈的貸放條件「有利賣方」（借款人），銀行搶案導致利差壓縮。同日川湖宣布197.12億元資本支出、投資台灣事務所通過7家企業擴大投資；金管會「2026臺灣週」11月3日登場，45場活動聚焦亞洲資產管理、創新籌資、虛擬資產等七大議題，報名已達2,378人次。

關鍵數據

聯貸400億元、超額認購1.2倍、11家銀行；川湖資本支出197.12億元；臺灣週45場活動、2,378人次報名

解讀

創意電子這類ASIC設計服務商營收規模相對有限，卻能拿到400億元聯貸且超額認購，說明國銀在不動產放款集中度降至34%、房貸受限後，正把資金大量轉向AI供應鏈企業金融——這是台灣銀行業資產配置的結構性轉移。但「有利賣方」意味利差被壓縮、授信集中於AI單一產業，若AI資本支出放緩，國銀的企金資產品質將面臨集中度風險，與今天全球市場懲罰AI舉債的邏輯是同一件事。

傳導鏈

央行房市信用管制 → 國銀不動產放款集中度降至34.02% → 資金轉向AI供應鏈企金聯貸 → 11家銀行搶創意400億案、利差壓縮 → AI供應鏈融資成本低於海外同業（相對CoreWeave等neocloud高息債）→ 台廠資本支出擴張（川湖197億）→ 但國銀授信集中於AI產業 → 若AI週期反轉，企金壞帳與房貸壞帳的相關性上升

分叉情境

如果AI訂單能見度延伸至2027下半年，國銀AI企金放款年增20%以上、利差維持但資產品質穩定；如果2027年AI資本支出放緩，創意等ASIC服務商營收下滑、聯貸案面臨covenant壓力，國銀企金逾放率從0.2%升至0.5%以上。

展望

短期 · 1M
短期（1個月內）：更多AI供應鏈聯貸案（伺服器、散熱、電源）陸續簽約，公股行庫為主辦主力；臺灣週（11/3）釋出資產管理與籌資新政。
中期 · 3–6M
中期（3-6個月）：金管會可能關注銀行對AI產業授信集中度並要求壓力測試；若台股續跌，部分擴產計畫可能延後。
