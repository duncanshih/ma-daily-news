總經 / 地緣政治

Meta引爆AI信用疑慮 — 那斯達克跌2.6%、費半重挫7%、10年期美債殖利率跌破5%，股債翹翹板重啟

深度解析

發生什麼事

10月22日美股遭遇數月來最慘烈拋售：Meta在第三季財報會議上表示AI資本支出已使自由現金流轉為負數，且未來數年將募資「數千億美元」，股價重挫6.98%、市值一日蒸發1,240億美元，5年期信用違約交換（CDS）價格升至歷史新高；那斯達克綜合指數下跌2.6%、寫下三個月來最大單日跌幅，費城半導體指數重挫近7%、距年線不到1%，台積電ADR跌4.52%、亞馬遜跌4.57%。資金湧入公債避險，美國10年期殖利率單日下跌超過17個基點至4.972%，為9月23日以來首次跌破5%，並寫下2023年3月10日以來最大單日跌幅，市場對聯準會12月升息的機率預期降至85%。加州公務員退休系統（Calpers）同日被揭露在2026年上半年削減26%的科技七巨頭直接持股、轉增私募股權配置。亞股23日跟進：韓股KOSPI盤中暴跌4.11%至5,300點保衛戰，隨SK海力士翻紅收斂至跌2%以內，日經盤中狂瀉逾千點；台股因颱風假休市暫時躲過。

解讀

這一天的關鍵不是Meta財報數字（營收其實優於預期），而是市場第一次把AI資本支出從「估值問題」升級為「信用問題」：當一家年度自由現金流曾達數百億美元的公司宣告現金流轉負、要靠發債撐資本支出，CDS創新高就是債市在對AI基建的ROI投下反對票。股債翹翹板重啟（股跌債漲）說明市場的主導敘事從9月以來的「通膨與升息」切換回「成長與信用」，這是典型的「從估值重估進入信用重估」階段。

傳導鏈

Meta宣告FCF轉負+募資數千億 → 5年期CDS創新高、AI債務融資成本上升 → 超大規模雲端商資本支出的「可融資性」被質疑 → 輝達/記憶體/台積電供應鏈的訂單能見度折價 → 費半-7%、台積電ADR-4.5% → 資金湧入美債、10年期殖利率跌破5% → 聯準會12月升息機率從接近確定降至85% → 亞洲出口導向股市（韓、日、台）27日補跌壓力

結構性

結構性轉折的起點：AI資本支出週期從「股權融資、現金流充沛」階段進入「債務融資、現金流轉負」階段，這不是一季的波動，而是融資結構的永久改變；但單日7%的費半跌幅本身屬於週期性的擁擠部位出清。

矛盾訊號

最大的矛盾在債市：如果AI資本支出真的放緩，那是通膨下行的好消息、公債該漲；但如果Meta等公司真的要募資數千億美元，那是公司債供給暴增、信用利差該走闊——22日是「公債漲、公司債CDS走闊」同時發生，說明市場正在定價「AI公司會借到錢但借得很貴」。另一矛盾：黃仁勳同日說neocloud需求「爆表」，但Calpers砍26%七巨頭持股——需求方與資金方正在反向而行。

分叉情境

若Meta在11月中旬前公布具體債務融資計畫（例如超過500億美元的多年期公司債或與私募信貸合作），且發行利差高於同評等公司債100個基點以上，AI基建股將再修正10-15%，費半跌破年線；若微軟、Google、亞馬遜本週及下週財報顯示自由現金流仍為正且資本支出指引未再上修，市場將重新區分「現金流AI」與「舉債AI」，費半在年線附近築底、10年期殖利率回到5.0-5.2%區間。

OpenAI主動砍價1,500億美元是一級市場的風向標：在Meta CDS創新高、Calpers砍七巨頭持股的同一週，連最頂級的AI資產都無法再「開價即成交」，定價權正從發行方移回投資人。但同時哈佛靠SpaceX賺27%、Calpers增配私募股權，說明機構資金並未退出AI，而是從「公開市場的集中曝險」轉向「私募市場的精選曝險」。SK海力士放棄Solidigm IPO則是另一面鏡子：在市場劇烈波動時，母公司股東寧可保留子公司價值也不願在低估值下分拆。

若AI需求維持且超大規模雲端商第4季資本支出指引穩定，台灣2026年工業生產全年成長22%達標、2027年第1季仍維持年增10-15%，失業率維持3.3-3.4%；若美國AI信用疑慮在第4季擴散至資本支出削減，2027年第1季工業生產年增率將降至5%以下、電子業加班時數與年終獎金縮減，失業率在2027年中回升至3.6-3.8%。

展望

短期 · 1M
短期（1個月內）：10月工業生產受颱風假影響略降但仍維持年增15%以上；第4季為iPhone Duo與AI伺服器出貨旺季，電子業產能利用率維持高檔；台經院三大風險中，中東油價是最先衝擊傳產成本的變數。
中期 · 3–6M
中期（3-6個月）：2026年全年工業生產+22%為高基期，2027年上半年增速將因基期效應自然回落至10%以下；關注主計總處11月是否上修2026年GDP、以及2027年預測是否反映AI資本支出放緩。
長期 · 1Y+
長期（1年以上）：台灣經濟對AI電子業的集中度已達歷史高點，分散風險的結構性解方是將AI應用延伸至傳產（智慧製造、機器人）與服務業；否則下一次AI週期下行時，台灣的失業率與內需波動將大於過去任何一次電子業週期。

台灣資產管理制度改革（持續追蹤）— 公股投信四合一細節出爐：第一金持股50.3%、近100檔基金待整合、2028元旦合併；TISA 2.0每人2.4萬免稅、第一階段已27.7萬戶

持續追蹤中

發生什麼事

公股投信四合一22日由第一金、兆豐金、合庫金、華南金四家金控及旗下投信董事會分別通過，第一金投信為存續公司，第一金控持股50.3%並掌握董事會過半席次，預計10月底前向金管會送件，暫定2028年1月1日為合併基準日。合併後公募基金規模約4,000億元、排名約第12，加計代操後AUM約5,000億元，目標進入前十甚至挑戰第八名；四家旗下近100檔基金的整合方案待定。金管會證期局列出三大審查重點：員工權益保障、合併後基金整合規劃、基金受益人權益保障。TISA方面，行政院長卓榮泰指示儘速研擬第二階段優惠，本人、配偶及受撫養未成年子女每人每年可提撥2.4萬元自綜合所得額中扣除（一家三口7.2萬元），需修正《證券投資信託及顧問法》，最快2027年完成修法、2028年報稅適用；第一階段截至10月16日開戶數27.7萬戶、申購128億元、帳戶資產240億元。租稅優惠附三大限制：不回溯、專戶不得任意提領、提前解鎖則歷年提撥一次併入當年所得課稅。

關鍵數據

第一金控持股50.3%；合併後AUM約5,000億（公募4,000億排名第12）；合併基準日2028/1/1；TISA每人每年2.4萬免稅、第一階段27.7萬戶/240億元

解讀

兩項政策是同一個戰略的供需兩端：TISA 2.0在需求端用租稅優惠把散戶的短線資金轉為長期定期定額，公股投信四合一在供給端打造能承接這些資金的「國家隊」。但執行上有三個結構性問題：第一，AUM 5,000億在台灣投信業只排第12名、連前十都進不去，規模效益有限；第二，近100檔基金整合必然涉及績效差的基金清算，受益人權益與員工去留是最大摩擦點；第三，TISA第一階段9個月只吸引27.7萬戶、240億元，相對台股1,400萬開戶數滲透率不到2%，2.4萬元的免稅額度能否改變行為仍待驗證。

傳導鏈

TISA 2.0租稅優惠（2.4萬/人） → 定期定額長期資金流入台股ETF與基金 → 散戶籌碼從融資短線轉為長期持有、降低「多殺多」踩踏風險 → 公股投信四合一承接政策性資金、AUM 5,000億 → 投信業規模排名重組、中小型投信併購壓力上升 → 台股籌碼結構長期穩定、本益比波動收斂 → 但若國家隊基金績效不佳，TISA資金將流向市值型ETF而非主動基金，政策目標落空

分叉情境

若合併順利且TISA 2.0在2027年完成修法，2028年起國家隊AUM可望在三年內從5,000億成長至8,000億、進入前八名，台股散戶長期資金占比提升；若基金整合引發大規模贖回或TISA修法延宕至2028年後，國家隊將淪為「規模相加」而非「綜效相乘」，中小型投信反而因客戶流失獲得併購機會。

展望

短期 · 1M
短期（1個月內）：觀察合併計畫書送件後金管會的審查意見，特別是近100檔基金的整合方案與員工安置；TISA修法草案是否在年底前送立法院。
中期 · 3–6M
中期（3-6個月）：合併案若在2027年上半年獲准，2027下半年將進入基金整併實作期，績效差的基金清算可能引發受益人贖回；TISA 2.0若2027年完成修法，2028年起每年可望帶來200-400億元新增長期資金。

「公股投信四合一細節出爐，第一金控持股50.3%、合併後AUM約5,000億元、暫定2028年元旦合併，同時行政院拍板TISA 2.0每人每年2.4萬元免稅。我認為這是同一個戰略的供需兩端，TISA在需求端把散戶短線資金變成長期定期定額，國家隊在供給端承接這些資金。但有三個問題：AUM 5,000億在台灣只排第12名、規模效益有限；近100檔基金整合必然有清算與員工去留的摩擦；TISA第一階段9個月只有27.7萬戶、240億元，滲透率不到2%。對國泰CIM或富邦投行組來說，這個整併案本身就是一個併購估值與換股比例的實戰案例。」
