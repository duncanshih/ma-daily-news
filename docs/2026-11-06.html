總經 / 地緣政治

民主黨期中選舉大勝引爆AI重新定價 — 華爾街單日蒸發3.2兆美元，那指100跌6.4%、費半崩12.3%，亞股全面跟跌

深度解析

發生什麼事

11月5日美股「黑色星期四」：S&P 500單日下跌4.4%、500檔成分股中430檔收黑；那斯達克綜合指數重挫5.5%，創2025年4月「解放日」以來最大單日跌幅，正式進入修正區；那斯達克100指數暴跌6.4%，單日市值蒸發2.5兆美元（約新台幣82兆元）；費城半導體指數暴跌12.3%；道瓊跌逾1,800點或3.4%。輝達、高通跌逾9%，科技七巨頭單日蒸發1兆美元，特斯拉與SpaceX選後合計蒸發4,200億美元。導火線是民主黨同時拿下參眾兩院與德州州長，進步派議員喊出「全國資料中心暫停令」，德州準州長Hinojosa承諾立法保護居民，而期中選舉的資料中心公投幾乎全數否決。避險資金湧向美債，10年期殖利率單日下滑5個基點。摩根大通估計量化策略與槓桿ETF已拋售逾700億美元部位，未來數日仍有約500億美元被動賣壓。11月6日亞股接棒：日經225跌5.96%收57,434.77點、5月以來首度跌破6萬點；KOSPI跌6.02%收5,059.69點、盤中一度暴跌8%、外資賣超3.4兆韓元；台股收跌4.51%。歐股Stoxx 600早盤跌1.42%，FT指出歐股今年績效已超越S&P 500。週五美股期貨盤前反彈，台積電ADR盤前漲逾7%。

解讀

這次重新定價的本質是「政策風險溢酬」突然被塞進AI基建的折現率：市場重新計價的是建置速度、成本與投資回報時程，而不是全面否定AI需求（凱基投信的解讀）。但賣壓中機械成分極高——量化、槓桿ETF、多策略基金的VaR風控同步觸發，使單日12%的費半跌幅遠超政策面實際變化。短線超賣與中期估值重估混在一起，是這波最難判斷的地方。

傳導鏈

民主黨掌國會與德州州長 → 資料中心電力、水資源、環評審批門檻升高 → 2027-2028年hyperscaler capex時程遞延 → neocloud、記憶體、光通訊訂單能見度下降 → 高本益比AI股forward估值壓縮 → 槓桿ETF與量化基金被迫減碼放大跌幅 → 跨市場拋售蔓延至日韓台 → 亞幣貶值、公債買盤、黃金反而下跌

結構性

結構與週期並存：監管轉向是結構性變化（至少持續到2028年總統選舉），但費半單日12%跌幅屬週期性去槓桿，兩者必須分開定價。

矛盾訊號

超大型雲端商（蘋果、亞馬遜、Google、Meta、微軟）選後週三反而上漲，理由是「監管不確定性消除」；同一時間資料中心供應鏈崩跌——市場實際在說「AI需求在，但新建產能稀缺」，這是K型AI交易的雛形。另一組矛盾：台積電零股交易金額247億元激增1.32倍（散戶抄底），美股散戶卻賣超創疫情以來新高。

分叉情境

若國會在2027年第一季前只推動「社區參與、電費保護」等軟性規範（即OpenAI主動提出的版本），費半3個月內收復一半跌幅、那指脫離修正區；若聯邦層級資料中心暫停令進入立法程序或德州先行凍結新案，hyperscaler 2027年capex預估下修10-15%，那指再跌10%進入熊市，台日韓AI供應鏈同步下修。

全球央行走到再升息拐點 — 英央行三年來首升息至4%、Fed官員Barkin預告漸進升息，黃金在股災中反而下跌

深度解析

發生什麼事

英格蘭銀行11月5日升息25個基點，基準利率從3.75%升至4.0%，是2023年以來首度升息，市場預期12月可能再升一碼；英鎊兌一籃子貨幣升至脫歐公投以來最高。美國方面，里奇蒙Fed總裁Barkin接受CNBC訪問時表示憂心通膨、貨幣政策需要調整，預期升息但步調漸進；10月28日FOMC雖按兵不動，但12位投票委員中有2位反對、主張升息一碼，此前Musalem與Logan已公開表示需回到升息。另一方面CNBC指出，民主黨大勝給市場重新思考利率路徑的理由：伊朗戰爭若結束、美國成長放緩、新財政政策都可能抑制升息，10年期美債殖利率選後下滑。黃金從1月近5,600美元高點回落，高盛大幅調降目標價，理由是Fed轉鷹、高利率壓抑避險需求、格局宛如2022年重演；花旗則指中東局勢是金價上看5,000或回落至3,500美元的分水嶺。

解讀

全球央行從「降息週期」轉為「再升息」的拐點已經出現，驅動力是能源推升的通膨（伊朗戰爭→油價→CPI），而非需求過熱。美國的特殊性在於選舉結果本身可能壓低油價通膨（川普有政治動機在2028年前結束戰爭），給Fed不升息的空間。黃金在史詩級股災中下跌而非上漲，是最誠實的訊號：市場現在交易的是流動性與實質利率，不是恐慌。

傳導鏈

油價高檔 → 英美CPI黏著 → 英央行升息、Fed官員轉鷹 → 實質利率上升 → 黃金、長天期公債、高估值成長股同步承壓 → 美元相對英鎊走弱 → 新興市場資金流向分化（印度受惠、東亞AI曝險市場受害）

結構性

週期為主：這輪通膨是能源供給衝擊驅動，若美伊和解油價回落，升息預期可在數週內逆轉；但「利率中樞不再回到零」是結構性背景。

矛盾訊號

公債殖利率在股災中下滑（避險買盤）vs Fed官員談升息；黃金在「史詩級股災」中下跌而非上漲——說明這波不是信用恐慌，而是估值重估加去槓桿。

分叉情境

若美伊在年底前達成臨時協議、Brent回到75-80美元，Fed 2027年上半年不升息，10年期殖利率回落至4.0%以下，黃金重返5,000美元；若談判破局、Brent突破100美元，Fed 2027年第一季升息一碼，10年期殖利率升至4.6%以上，黃金續跌測試3,500美元。

短期（1個月內）：11月6日的10月非農決定Fed 12月會議基調；若新增就業低於10萬且失業率上升，升息預期延後；英鎊維持強勢、英國長債殖利率續升。
中期 · 3–6M
中期（3-6個月）：英央行12月再升一碼機率過半；Fed在明年第一季前維持不動，但點陣圖可能首度出現2027年升息路徑；黃金在實質利率上升下區間震盪。
長期 · 1Y+
長期（1年以上）：全球利率中樞上移至「higher for longer 2.0」，對債券久期策略與保險業資產負債配置是結構性利多（再投資收益率上升），但對私募、不動產等長久期資產是估值逆風。

避險基金去槓桿加劇市場踩踏（持續追蹤）— Walleye返還資本、思柏10月虧16%、摩根大通估再有500億美元被動賣壓

持續追蹤中

發生什麼事

FT報導管理170億美元的多策略基金Walleye在經歷疫情以來最差月份後返還部分資本、縮減股票業務；彭博報導亞洲大型避險基金思柏投資10月費前虧損16%，為公司史上罕見；Samlyn Capital出清金融股以外所有部位並裁撤高級分析師。彭博總結：10月避險基金先遭AI股重挫、再遇總經衝擊、最後信貸市場恐慌，「無處可躲」。摩根大通估計量化與槓桿ETF已拋售逾700億美元，未來數日仍有約500億美元被動賣壓；美股散戶賣超創疫情股災以來新高；麥可貝瑞將25%半導體ETF空單獲利了結，但仍押注AI續跌。

關鍵數據

Walleye管理資產170億美元；思柏10月虧損16%；摩根大通估已拋售逾700億美元、再有500億美元賣壓

解讀

去槓桿是這波跌勢的放大器而非起因：多策略基金的VaR風控在波動率跳升時自動減碼，賣的是流動性最好的大型AI股，使指數跌勢自我強化。思柏這類亞洲基金受傷最重，反映亞洲資金對AI硬體的曝險集中度遠高於美國同業。

傳導鏈

波動率跳升 → 多策略基金VaR超限 → 強制減碼流動性最好的AI大型股 → 指數下跌 → 槓桿ETF收盤再平衡賣出 → 波動率再升 → 散戶跟進賣超 → 直到被動賣壓耗盡

分叉情境

若波動率一週內回落，被動賣壓止於500億美元，那指在修正區築底；若再出現單日3%以上跌幅，新一輪VaR觸發，可能再有同等規模賣壓，市場進入熊市。

展望

短期 · 1M
短期：摩根大通估計的500億美元賣壓若在一週內消化完畢，市場可出現技術性反彈；觀察VIX是否回落至25以下。
中期 · 3–6M
中期：多策略基金縮減股票曝險、轉向宏觀與信貸，將使AI股的邊際買盤減少，反彈力道受限；亞洲避險基金可能面臨年底贖回潮。

深度解析

發生什麼事

彭博與CNBC報導，荷蘭國際集團（ING）正一次性出售約5億美元、共12筆資料中心貸款組合，其中包含與OpenAI Stargate新墨西哥站點相關的債務，時點恰逢民主黨期中選舉大勝引發市場對此類專案前景的疑慮。同週，黑石總裁Jon Gray公開呼籲AI基建需要更多股權資金，因為債權投資人正面臨集中風險；Aon執行長Greg Case警告資料中心的保險集中風險可能限制承保能量、改變新案融資結構。承租端也出現鬆動：neocloud IREN表示約40億美元年化營收因客戶（微軟）要求延後至明年初，股價重挫，但同時宣布另一項150億美元投資計畫；路透報導微軟不行使與英國Nscale德州資料中心算力租用合約擴大一倍的選擇權。Equinix指出小型資料中心較不受美國限制影響；澳洲NextDC則因Goodman與Digital Realty擬收購至多9.9%股權，單日飆漲近51%。Meta警告選後反對聲浪恐讓AI擴張更困難。

解讀

央行9月起放錢 → 隔拆利率降至0.811% → 銀行資金成本下降 → 股災中融資斷頭與補繳需求升（金管會放寬抵繳擔保品）→ 銀行信用交易風險升、但淨利差改善 → 財管手收因AUM縮水下滑 → 金控獲利結構從財管手收轉回利差與放款 → 壽險股債評價損失拖累金控淨值

分叉情境

若台股1個月內穩定，財管AUM年底回升、金控全年獲利仍可創高；若續跌10%，壽險業淨值比承壓、部分金控2027年股利政策受影響，資本島政策的「財富效果」敘事暫時失色。

展望

短期 · 1M
短期：11月金控自結將反映財管手收下滑與壽險評價損失；證券子公司經紀收入因爆量反而增加，但融資違約風險上升。
中期 · 3–6M
中期（3-6個月）：亞資中心政策推進（高雄專區、家族辦公室、私募與另類投資產品）在波動市場更需要避險產品線；台新新光合併後的法金與財管整合成效浮現。

持續追蹤中

發生什麼事

台塑四寶10月營收年增逾6成，南亞創55個月新高。四寶第四季展望出現分歧：南亞指電子材料與載板需求暢旺、價量齊揚，11月與第四季營收將續攀，並擴大高階材料比重；台塑預期年底旺季推升需求、原料價格仍在高檔，第四季開工率與銷售率均優於第三季；台化則因美國期中選舉後美伊和談傳出進展、國際油價11月明顯回落，憂心庫存跌價損失。中鋼第三季稅後純益11.21億元、EPS 0.07元，連續兩季獲利，前三季轉虧為盈，月盤連三個月開漲，全年有望虧轉盈；董事會同時通過投資10億7,921萬元推動固態氧化物燃料電池（SOFC）與碳捕捉利用（CCU），因應製程電氣化與碳中和。華新麗華則指AI帶動HVDC電纜與不銹鋼需求，第四季看旺。

關鍵數據

南亞10月營收創55個月新高；中鋼第三季EPS 0.07元、連2季獲利；中鋼SOFC與CCU投資10.79億元

解讀

傳產正在被AI切成兩半：有電子材料、載板、電纜曝險的（南亞、華新、聯茂）跟著AI週期走，純石化的跟著油價走。油價回落對台化是「短痛長利」——第四季先認庫存跌價，2027年原料成本改善；對台塑化則是煉油利差收斂。中鋼在獲利剛轉正時就投入10億元做燃料電池與碳捕捉，說明碳費與製程電氣化已是鋼鐵業的生存成本而非選項。

傳導鏈

油價回落 → 石化原料成本降、但既有庫存跌價 → 台化第四季一次性損失、2027年毛利改善；AI資料中心建置 → CCL、載板、HVDC電纜需求 → 南亞、華新、聯茂營收創高 → 傳產內部估值分化 → 投資人以「AI曝險比重」重新分類傳產

分叉情境

若美伊協議成形、油價續跌至70美元，台化2027年原料成本改善但第四季損失擴大，台塑化煉油利差收斂；若AI capex遞延，南亞電子材料成長放緩、傳產AI受惠者的溢價收斂。

展望

短期 · 1M
短期：台化第四季認列庫存跌價損失、南亞營收續創高，四寶股價走勢分歧擴大；中鋼第四季月盤開漲支撐獲利。
中期 · 3–6M
中期（3-6個月）：若油價中樞降至70-80美元，石化毛利率2027年上半年改善；南亞電子材料能否延續取決於hyperscaler capex是否遞延。
