總經 / 地緣政治

Fed決策日撞上油價飆破114美元 — 鮑爾的「滯脹兩難」正式攤牌

深度解析

發生什麼事

美東時間4/29晚間Fed將公布利率決策，市場與聯邦基金期貨幾乎100%預期維持利率不變（目標區間4.00–4.25%）。但今早WTI收94.5美元、Brent盤中觸及114.20美元，較6月伊朗戰爭爆發前累計上漲58%。CNBC以「就看這80秒」形容鮑爾記者會，因鮑爾任期將於2027年5月屆滿，川普數次表達不滿；同時Jamie Dimon週二警告全球公私部門總債務已逾GDP的110%，「某種型式的債券危機」恐隨時引爆。S&P 500期貨平盤、10年期美債殖利率自4.31%升至4.46%，金價自4周高點回落。

解讀

這次會議的看點完全不是利率本身，而是Fed怎麼描述「能源衝擊是暫時還是結構」。若鮑爾措辭偏向「look through energy」，等於默認2026下半年通膨可能維持3%以上仍不升息，將被市場解讀為政治壓力下的鴿派漂移；反之若強調通膨警戒，等於變相收緊金融條件。在政治續任不確定下，鮑爾大機率走中性偏鷹，預期殖利率曲線走陡。

傳導鏈

油價飆漲 → 4–6個月後CPI能源項+運輸+食品傳導 → 核心PCE自2.8%回升至3.3% → Fed延後降息＋長端發債壓力 → 10年殖利率突破4.5% → 高收債利差擴大、新興市場資金外流

結構性

結構性：能源溢價不是季節性而是Hormuz地緣裂痕的常態化，加上Fed獨立性受質疑屬制度性風險，兩者都不會在3-6個月內消退

矛盾訊號

市場一面交易「Fed今年不降息」（短端利率上行），一面交易「衰退避險」（長債殖利率反向走低），兩個訊號邏輯衝突，預示可能即將出現一輪劇烈再定價

分叉情境

情境一：若鮑爾明示「通膨疑慮升溫、降息延後至2027」，10Y美債衝4.55%、新台幣貶破31.7、台股科技股回調5–8%；情境二：若鮑爾被川普於Q3前撤換並由親近派接任，美元指數短線下殺3%、金價衝3,200美元/盎司、台股金融股受惠

短期（1個月內）：Fed維持利率4.00–4.25%機率>95%，10Y殖利率區間4.30–4.55%，S&P 500震盪區間6,250–6,520，VIX回升至20以上
中期 · 3–6M
中期（3-6個月）：若油價維持90–110美元區間，Fed降息點陣圖將自2026年75bp下修至25–50bp；若鮑爾任期問題未明朗，殖利率曲線陡峭化將持續
長期 · 1Y+
長期（1年以上）：Fed獨立性議題若延燒至2027年5月鮑爾任期屆滿，恐使長端期限溢酬永久墊高30–50bp，影響全球債券訂價基準

Jamie Dimon警告「某種債券危機正在路上」 — 全球債務佔GDP破110%的引信

深度解析

發生什麼事

JPMorgan執行長Dimon於週二投資人會議直言「我擔心的不是股市，是債券市場」。他點名美國聯邦債務8月已突破36兆美元（年化利息支出超越國防預算）、日本債務佔GDP 250%、歐元區法義雙雙破130%。他指市場仍把長端利率當「無風險殖利率」交易，但2026年Q3全球國債到期再融資規模高達3.4兆美元，與Fed縮表、日銀升息、ECB QT三股力道疊加，「流動性事件可能在任何一場拍賣中突發」。同日Bill Ackman第二次SPAC IPO定價落在範圍下緣，凸顯一級市場吸金力下滑。

解讀

Dimon這話不是首次，但時點關鍵——全球央行從QE-buyer轉為QT-seller、能源通膨拉抬名目殖利率、川普政府赤字計畫加碼，三條曲線同時往上。這不是單一危機而是「期限溢酬重定價」的累積效應。當市場真正意識到長債不是無風險，影響會比2022年英國Truss迷你預算危機更深更廣。

傳導鏈

央行QT＋赤字擴張＋通膨黏性 → 期限溢酬從負值升至+80bp → 30Y殖利率衝5% → 美壽險與退休基金資產負債缺口擴大 → 強迫拋售風險資產 → 信用利差擴大、流動性溢價爆發

分叉情境

情境一：若日銀年內升息至0.75%以上，日本投資人撤回海外美債部位約1,500億美元，美10Y殖利率短線衝5%、台幣連動貶破32元；情境二：若美財政部主動拉長發債天期占比，下半年30Y拍賣得標利率衝5.2%以上，引發Pension fund強制rebalance

展望

短期 · 1M
短期（1個月內）：10Y殖利率在4.30–4.60%區間震盪，30Y拍賣需求倍數（bid-to-cover）若跌破2.3X將是預警訊號
中期 · 3–6M
中期（3-6個月）：若日銀於7月升息且美財政部公布增發長債計畫，10Y有機會挑戰5%整數關卡，債券基金總報酬轉負
長期 · 1Y+
長期（1年以上）：全球期限溢酬中樞自2010年代-50bp上移至2027年+50bp，所有股債估值模型的折現率假設都要全面調升

持續追蹤

美國30Y國債每月拍賣bid-to-cover倍數日本JGB 10Y殖利率是否突破1.8%美國高收債OAS利差是否突破350bp黃金/白銀比美國公債波動率MOVE指數

面試角度

國泰CIM必考：固定收益部位怎麼防衛duration風險？答題切入floating rate notes、TIPS、短天期投資級債、CDS hedge。中信投資專案：在長端利率重定價情境下，併購標的WACC要怎麼回填，IRR門檻是否從12%上修到15%。元大投行法金：法金客戶在利率風險上的avoidance hedging商機。

口說版

「Dimon這次點到的不是利率高低，而是『誰來買這些債』——當全球央行從buyer變seller，期限溢酬就會從負值翻正，30年期美債殖利率有機會挑戰5%。我面試國泰CIM如果被問固定收益策略，我會說現在不是carry trade的時點，而是縮短duration、加碼TIPS和短天期投資級債的防守期，這也直接影響中信投資專案在做併購WACC假設時要不要把折現率上修到10%以上。」

持續追蹤中

發生什麼事

標普4/29公告維持台灣長期外幣評等AA+、本國貨幣評等AAA、展望「穩定」。報告指出三個正向支柱：（1）央行貨幣政策表現穩健；（2）AI驅動半導體出口推升經常帳順差至GDP的15%；（3）能源衝擊『有限』因台電已建立7月底前瀝青與燃油庫存。負面段落點名「兩岸關係不可能在民進黨政府執政下改善」，並警示2027年大選為地緣關鍵窗口。

關鍵數據

AA+穩定（全球僅10個經濟體擁有此評級）、台灣經常帳順差/GDP 15%（亞洲第一）、外匯存底5,990億美元

解讀

AA+守住代表海外發債利差優勢延續，台灣金融機構發行歐元/美元次順位債的spread有望維持在swap+150bp以內。但兩岸風險被首次以白紙黑字寫進主權報告，下次評鑑（10月）若加入「中國海警封鎖」情境（經濟日報今日學者已警示），展望可能降為「負向」。

傳導鏈

AA+評等維持 → 台灣公債利差優勢保持 → 壽險海外債券部位匯損可控 → 人壽資本適足率穩定 → 金融股獲利能見度延續

展望

短期 · 1M
短期（1個月內）：新台幣兌美元預期區間31.40–31.80，10Y公債殖利率1.42–1.55%，金融股股價有支撐

不動產 / 私募

Kone砸344億美元併德國TK Elevator — 全球電梯產業集中度衝歷史新高

深度解析

發生什麼事

芬蘭Kone（科恩）週三宣布以344億美元（含負債）收購德國蒂森克虜伯旗下TK Elevator，創歐洲基建產業近10年最大併購。交易結構為現金70%＋股權30%，由摩根大通與摩根士丹利擔任財務顧問。合併後新公司年營收約220億歐元、全球市占將從Kone 15%躍升至28%，與Otis（22%）、Schindler（18%）形成三強鼎立。CVC於2020年以171億歐元自蒂森買下TKE，本次出脫IRR約9.8%（5年期）。歐盟反壟斷審批為交易最大不確定因素，預計2026Q4結案。

解讀

這筆交易表面是電梯整合，實質是「老齡化都市基建週期」的重壓注。全球60歲以上人口2030年將達14.2億，垂直交通成為都市更新核心，Kone賭的是『電梯即服務』（Maintenance-as-a-Service）的recurring revenue倍數溢價。CVC的退出價＝1.5x EV/Sales，比2020年進場的1.1x僅小幅提升，反映過去5年歐洲基建PE資產的估值天花板已現。

傳導鏈

Kone併TKE → 歐盟反壟斷審查 → 拆分部分業務出售 → 私募基金（KKR、CVC、EQT）排隊接手分拆資產 → 電梯後市場服務（佔營收60%）成為新賽道 → 拉抬亞洲日立電梯、永大機電（台灣）併購溢價

結構性

結構性：人口老化＋都更＋ESG建築改造是三十年趨勢，後市場服務（保養、智慧化升級）的cash yield特性吸引長期資本；非週期性

分叉情境

情境一：若歐盟要求Kone分拆TKE在義大利與西班牙的業務（合計營收18億歐元），KKR、Brookfield為主要競購對手，預期成交EV/EBITDA 11–13x；情境二：若交易破局，Kone股價短線回吐15%、CVC尋求二次出售路徑，可能轉向中東主權基金

展望

短期 · 1M
短期（1個月內）：Kone股價短期下挫3–6%反映稀釋與整合風險，TKE債券評等可望升等
中期 · 3–6M
中期（3-6個月）：歐盟與英、美反壟斷三方審查並進，預期最終要求分拆20%資產換取通過
長期 · 1Y+
長期（1年以上）：全球電梯產業形成Otis-Kone+TKE-Schindler三強寡頭，後市場服務AI化滲透率自30%升至60%，台灣永大機電（中聯資源旗下）可能成為亞洲整併標的

持續追蹤

歐盟反壟斷審查時程與分拆要求Kone股價對營收/EBITDA倍數變化TKE未上市債券利差亞太區資產分拆是否波及永大機電

面試角度

中信MA投資專案經典題：這個併購案的協同綜效（Synergy）怎麼量化？要回答cost synergy約占目標公司營收5–7%（採購、IT整合）、revenue synergy約占2–4%（cross-sell服務合約）。開發資本基礎建設投資組：這類老齡化基建後市場現金流的IRR如何定價？回答用DCF分10年穩定現金流＋perpetual growth 1.5%的雙階段模型。富邦投行組：M&A顧問費約交易金額1.0–1.5%（兩家加總約4億美元）

口說版

「Kone併TKE 344億美元這個案子很值得拆解——表面是電梯產業整合，骨子裡是賭老齡化都市基建recurring revenue的高倍數估值。我面試開發資本基建組會說，這類資產IRR模型要拆兩段，前10年合約現金流DCF 8%、永續成長1.5%，這跟台灣永大機電未來可能被亞太整併的估值邏輯是一致的。中信投資專案問協同效益，cost synergy 5–7%、revenue synergy 2–4%是市場標準。」

中投CIC考慮出售希思羅機場持股 — 第三跑道工程成本壓垮主權基金耐心

持續追蹤中

發生什麼事

FT報導中國投資有限責任公司（CIC）正研究出脫倫敦希思羅機場10%持股，主因第三跑道工程預算自2024年的140億英鎊膨脹至210億英鎊（+50%），且完工日從2030延至2033。希思羅其餘股東（Ferrovial 25%、Qatar Investment Authority 20%、Universities Superannuation Scheme 10%）也承壓，加拿大養老金CDPQ預估持有IRR已從原10%下修至6.8%。

關鍵數據

希思羅企業價值約180億英鎊，第三跑道資本支出超支70億英鎊，CIC潛在出脫金額約18億英鎊

解讀

這顯示「核心基建PE」的退出機制正面臨估值倍數壓縮。希思羅是全球機場資產標竿，其EV/EBITDA倍數從2022年的18x降至14x，反映建設期資本支出超支＋ESG碳中和支出雙重壓力。CIC作為主權基金開始cycle out核心基建資產，是長期資本配置思維的重大轉向。

傳導鏈

深度解析

發生什麼事

聯電（2303）4/29法說會公布2026Q1每股純益1.29元、稅後純益161億元、毛利率33.5%，優於市場預期31%。共同總經理王石明確指出Q2「8吋及12吋出貨將顯著成長、平均售價（ASP）升3%」，全年產能利用率自Q1的82%升至Q2的88%。先進封裝（22nm特殊製程＋部分3D IC）已獲10家客戶導入、今年開始挹注收益。同時預告嘉晶（3016）8吋矽磊晶需求超預期、Q2營收將年增逾20%，反映特殊製程與功率半導體景氣回溫。

解讀

聯電是成熟製程的indicator stock，3% ASP升幅是2022年以來首見，意味全球fabless客戶對8吋/12吋特殊製程的議價能力正在轉向供方。配合台達電、嘉晶同日法說的擴產訊號，成熟製程進入「真正供需平衡」（不再是價格戰）。對中國SMIC、華虹的競爭壓力短期會強化—但長期反而確認「中美晶圓產能脫鉤」帶來區域市佔重劃。

傳導鏈

成熟製程ASP+3% → 聯電、世界先進、力積電毛利率上修 → 全球fabless（聯發科、瑞昱）成本壓力 → 終端CIS/Driver IC/PMIC售價跟進調漲 → 台積電車用、工控、消費性業務搭順風

結構性

週期回升＋結構轉向：8吋/12吋特殊製程屬「結構性受惠（地緣供應鏈分流）」，AI伺服器電源管理IC的高速成長則屬中期週期

台達電Q1 EPS 7.91元獲利倍增 砸141億擴產 — AI電源王者進入「不擴產不行」階段

深度解析

發生什麼事

台達電（2308）4/29公布2026Q1每股純益7.91元、稅後純益204億元，皆創歷史單季新高，年增108%。董事會通過141億元資本支出擴產案，包括桃園、南科與墨西哥三地AI Server電源（PSU）與液冷散熱模組產能擴增。預估2026年AI相關營收佔比自Q1的28%升至全年35%。同日日月光（3711）法說會表示先進封測成長優於預期、上修資本支出逾20%；台積電竹科20廠第3廠Q4投產。三家供應鏈龍頭同日宣布擴產，密集程度為近年罕見。

解讀

台達電的擴產訊號比SK Hynix的高毛利更值得關注——前者是看到「未來12個月訂單必須加產能才接得了」，後者是「過去訂單已經實現」。141億擴產案配合日月光、台積電同步擴張，等於台灣AI供應鏈在「OpenAI營收不達標」的雜訊中，仍堅守『下游應用會慢，但中游建設不能停』的判斷。台達電股價反映預期，但中長期擴產帶來的折舊壓力會在2027年Q1開始體現。

傳導鏈

台達電擴產141億 → 桃園/南科/墨西哥三地 → AI server電源（PSU/液冷）市佔自35%升至42% → 上游IGBT、磁性元件（康舒、敦泰）訂單能見度延長 → 全球AI server出貨量2026年600萬台、每台台達電拿走4,500美元電源解決方案

結構性

結構性：液冷與AI高功率電源是10年滲透率提升的趨勢；CapEx增20%但折舊延後3-4季出現，Q1–Q3財報視覺仍亮眼

矛盾訊號

OpenAI Q1營收不達標 vs 台達電擴產141億；雲端商capex指引下修風險 vs 中游廠擴產動作。誰判斷對？我傾向台達電的訊號比較領先，因為實質訂單可見性，但風險是2027年產能利用率若未達計畫，折舊壓力擠壓毛利

分叉情境

情境一：若AI server出貨2026年達600萬台目標，台達電全年EPS上修至32元、股價挑戰450元；情境二：若雲端商Q3 capex下修10%，台達電Q4訂單能見度縮短，全年EPS下修至28元、股價回測350元
