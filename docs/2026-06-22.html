美銀大轉向：預測Fed今年連3次升息至4.25-4.50%，稱通膨「明確惡化」

發生什麼事

美國銀行（BofA）首席美國經濟學家Aditya Bhave團隊22日發布報告，將原先「按兵不動」甚至降息的預期，大幅翻轉為預測聯準會將於2026年9月、10月、12月各升息1碼（25bp），累計75bp，把聯邦基金利率目標區間從目前3.5%-3.75%推升至4.25%-4.50%，理由是通膨「unambiguously worse（明確惡化）」、就業市場仍具韌性。這呼應了新任主席Kevin Warsh首次FOMC會議（按兵不動但釋鷹訊號、並要檢討Fed運作）的偏鷹基調。美國公債殖利率因此走高，直接引爆週一大型科技股輪動賣壓，Alphabet、亞馬遜、微軟、SpaceX重挫，標普與那指收黑。

📐 解讀：這是基本面驅動而非情緒面：油價（伊朗戰爭遺留的高基期）與服務業通膨黏著，讓Fed的政策路徑從『何時降息』整個翻轉成『要升幾次』。市場原本price in的是寬鬆，現在被迫重定價，殖利率上行是所有高評價資產（科技、黃金、長天期債）的共同壓力源。BofA從鴿轉鷹的『打臉自己』本身就是訊號——華爾街共識正在崩解。
🔗 伊朗戰爭高基期油價 → 美國CPI/服務業通膨黏著 → Fed從降息轉向升息預期（BofA估+75bp）→ 美債殖利率走高 → 高評價科技股折現率上升、估值承壓 → megacap輪動賣壓（Alphabet、SpaceX重挫）→ 美元走強、壓抑亞幣與黃金
🏗️ 結構性 — 週期性為主（通膨與升息循環的重定價），但疊加結構性的『高利率常態化』——若4.5%成為新平台，等同推翻過去十年低利率對成長股估值的支撐邏輯。
⚡ 矛盾訊號：Fundstrat等同時喊Magnificent 7回檔是『買點』、美股近期趨勢仍偏多；BofA卻喊升息3次。多頭看基本面（獲利上修），空頭看殖利率（折現率）——兩個訊號正面對撞。
🔀 若9月CPI年增續站3.5%以上且非農仍穩 → Fed升息劇本成真、10年期美債上看4.8-5.0%、科技股再殺一段；若油價因Hormuz復航持續回落、核心CPI回落至3%以下 → Fed維持不動、殖利率回落、megacap估值修復、台股科技權值同步受惠。

日圓貶破161創40年新低，美日財長傳緊急視訊，市場高度戒備「閃電干預」

發生什麼事

日圓22日再重挫0.71%、成最弱亞幣，匯價貶破161關卡，逼近40年新低。值得注意的是，日本央行上週才升息1碼將政策利率調升至1%，但市場反應冷淡、未能扭轉弱勢；同時傳出日本財務大臣片山皋月與美國財政部長貝森特進行緊急線上會議，日本財務省一改過去『口頭干預』作風、在急貶時異常沉默，引發市場揣測官方正醞釀『突襲式閃電干預』。臺銀牌告日圓現鈔賣出價一度出現0.199元，為史上最甜換匯價。

📐 解讀：BOJ升息卻擋不住日圓貶，說明問題不在利差絕對值，而在美日利差『方向』——當美國從降息轉向升息預期（見Fed主題），日圓的carry trade套利誘因被重新點燃。財長緊急通話與『沉默』，是在累積干預的突襲效果，真正的彈藥是時機而非言語。
🔗 Fed轉鷹、美元走強 → 美日利差擴大 → 日圓carry trade重啟、資金借日圓買美元資產 → 日圓貶破161 → 進口通膨惡化、BOJ升息壓力 → 官方醞釀閃電干預 → 干預若出手將短暫拉升日圓、衝擊套利部位
🏗️ 結構性 — 週期性（利差驅動的匯率波動），但日本『升息1碼仍止不住貶值』暴露結構性問題——長年超寬鬆累積的龐大套利部位與財政負擔，讓BOJ正常化空間受限。
🔀 若官方在162-163附近閃電干預且Fed同步轉鴿 → 日圓可能急升至155甚至150、套利平倉引發全球風險資產短線震盪；若無干預且美債殖利率續升 → 日圓恐測試165、台幣等亞幣同步承壓。

關鍵數據

金價自約5,400美元高點回落、跌幅逾20%；目前保衛4,200美元；2月底地緣衝突為前波高點起點。

🔗 美伊停火 → 地緣避險溢價消退 → 黃金賣壓 ＋ Fed轉鷹、實質利率上行 → 持有黃金機會成本升高 → 金價自5,400回落保衛4,200
🔀 若4,200失守且Fed升息確立 → 下測4,000-3,800；若地緣風險重燃或Fed意外轉鴿 → 反彈挑戰4,800。
