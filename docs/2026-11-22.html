總經 / 地緣政治

美股修正進入第二階段 — 標普週跌8.6%、連7黑，距「逼Fed轉向」門檻僅65點

深度解析

發生什麼事

美股20日再度重挫：道瓊-1.93%、標普500 -3.7%、那斯達克-5.28%，費城半導體指數單日暴跌10.73%、台積電ADR跌9.48%。標普500連續第7個交易日收黑，創2020年2月以來最長連跌，單週下跌8.6%是「解放日」以來最差單週；標普與道瓊自歷史高點回落超過10%正式落入修正，那斯達克100進入熊市，那指今年漲幅全數吐回。美銀首席策略師Hartnett在《Flow Show》指出，只要標普回吐2026年全部漲幅、跌回6,845點，就可能迫使Fed重新評估緊縮，而上週五收盤6,910點距該門檻僅65點。高盛交易部門的「恐慌指數」升至9分（滿分10分），估算CTA等動量交易者過去一個月已大舉拋售，且賣壓蔓延到系統性投資人，警告未來一週恐出現「拋售引發更多拋售」的惡性循環；高盛同時提出三個觸底訊號供觀察。另一結構性訊號是「聰明錢在賣」：企業正從庫藏股轉為增發新股，Anthropic的810億美元IPO考驗市場承接新供給的能力。

解讀

這波下跌已從「AI估值修正」演變成「流動性與部位去槓桿」：CTA、槓桿ETF、融資斷頭的機械式賣壓與基本面脫鉤，這是情緒面主導的第二階段，但觸發它的根源（Fed升息預期＋AI資本支出回報疑慮＋輝達治理風暴）都是基本面議題，所以不能用「超跌必反彈」一句話帶過。市場正在賭一件事：股市跌夠深，Fed就會放棄升息。這是2018年Q4「Powell pivot」的劇本，但這次通膨在2%以上、Fed官員還在談升息2碼，Fed put的履約價比市場想像的低很多。

傳導鏈

AI資本支出回報疑慮 → 輝達、Anthropic領跌、費半單日-10.7% → CTA/動量策略觸發停損、槓桿ETF再平衡賣壓 → 流動性惡化蔓延至非科技股與比特幣（跌破6萬美元） → 財富效應收縮、企業發債/IPO窗口收窄 → 市場開始押注Fed因金融條件緊縮而停止升息 → 若Fed不買單（通膨>2%、Waller談2碼）則估值失去最後支撐

結構性

週期（部位去槓桿是典型的週期性現象，通常4-8週結束），但疊加結構性的AI投資回報重估，所以反彈後的高點很可能低於10月高點

矛盾訊號

Hartnett說「股市跌回6,845就能逼Fed停手」，但Fed會議紀要說要「更多升息」、Waller談「用2碼嚇市場」；市場在賭Fed put，Fed在賭通膨黏性。兩者只有一個是對的。另一個矛盾：高盛恐慌指數9/10通常是逆向買點，但高盛自己也警告系統性賣壓還沒清完。

分叉情境

如果標普跌破6,845點且VIX站上40超過3個交易日，Fed官員講話將在一週內轉為「金融條件已足夠緊縮」，12月升息機率從目前約70%降到30%以下，市場反彈5-8%；如果標普在6,845-7,000守住、且12月初非農仍強（>15萬），Fed照升1碼，股市將進入第二波下跌測試6,500點（較高點-15%），時間拉長到2027年1月

口說版

「我認為這波美股修正已進入第二階段：第一階段是AI估值修正，第二階段是CTA和融資部位的機械式去槓桿，高盛恐慌指數到9分、標普週跌8.6%都是這個特徵。市場現在在賭標普跌破6,845點會逼Fed停止升息，但Fed會議紀要和Waller的發言顯示Fed put的履約價比市場想的低，因為核心通膨還在2%以上。從國泰CIM投資組合的角度，我會在6,500-6,800區間分批布局有現金流的軟體與防禦股，而不是去接刀AI硬體，因為資本支出成長率從+50%降到+15-20%是結構性的。」

美國房貸利率重回7%以上 — 川普「3%房貸」承諾破功，房屋可負擔性回到1980年代水準

深度解析

發生什麼事

解讀

深度解析

發生什麼事

CNBC報導，極地渦旋（polar vortex）提前崩解將為歐洲帶來更冷的天氣與低風速，而歐洲天然氣儲存在入冬時已處於十多年來最低水準；低風速同時壓低風電出力，使天然氣發電需求在寒流期間雙重上升。英國能源監管機構預測典型家庭能源帳單自1月起將年增443英鎊（+26%），英國10月通膨因創紀錄的柴油價格升至3.6%、創一年新高；歐洲多國爆發學生主導的生活成本抗議（法國連續第六個週末、數萬人上街）。同時COP31在貝倫談判進入第二天延長，EU拒絕「漂綠化石燃料」的協議草案與沙烏地直接對撞，最終文本刪除化石燃料退場、轉向碳捕捉，並首度承認全球暖化將突破1.5°C門檻。荷莫茲海峽通油量因伊朗攻擊下滑亦推升歐洲LNG進口的替代需求。

解讀

歐洲正面臨2022年以來最危險的能源冬季，但市場幾乎沒有定價：TTF天然氣價格並未因庫存十年最低而飆升，因為市場假設美國與卡達LNG供給充足。這個假設的風險在於荷莫茲——卡達LNG必須經過海峽，若伊朗攻擊升級到LNG船，歐洲將同時失去「庫存緩衝」與「進口替代」兩道防線。能源帳單+26%對英國的政治效應更直接：工黨政府面臨選民怒火、歐洲各國抗議擴散，這會推動更多價格管制與暴利稅，對能源企業與基建投資的政策風險上升。COP31刪除化石燃料退場則確認「能源安全優先於氣候」已是全球政策主軸。

極地渦旋提前崩解 → 歐洲氣溫驟降、風速降低（風電出力減） → 天然氣發電需求激增、庫存從十年最低加速消耗 → TTF價格在寒流期間單週飆升30-50% → 英國/歐陸零售電價上調（+26%） → 通膨再升、ECB與BoE被迫維持緊縮 → 生活成本抗議擴散、政府祭出價格管制與暴利稅 → 能源基建投資的政策風險溢價上升

台灣AI供應鏈重估（持續追蹤）— 台達電跌停900元（自高點-65%）、國巨跌破300元（-7成）；華邦電兩年砸1,127億擴產、LED廠45億卡位CPO，資本支出與股價背離

持續追蹤中

發生什麼事

AI供應鏈權值股成為本波殺盤重災區：台達電20日以跌停價900元作收，較今年高點2,585元回檔約65%；國巨跌破300元整數關卡收296元，較7月高點跌逾7成；謝金河直言黃仁勳卸任後台灣「如斷腳」、新機櫃訂單添變數。但產業端的資本支出並未放緩：華邦電兩年擬砸1,127億元擴產並推約360億元併購案；鼎元、立碁、惠特等LED廠啟動擴產卡位2027-2028年CPO（共同封裝光學）商機，合計規模逾45億元；輝達與台積電等6家台廠擴大結盟宣示AI訂單無虞；景順亞洲區首席投資總監對2027年亞洲股市維持正向、偏好台灣半導體與AI硬體；MoneyDJ報導Google在Intel獲微軟封裝合作後重新回頭找台積電。經濟部喊話AI長期趨勢「不因個別公司影響」，國發會定調科技股重挫為「短暫調節」。

關鍵數據

台達電900元（高點2,585元、-65%）；國巨296元（-7成）；華邦電擴產1,127億＋併購360億；LED廠CPO擴產45億；台股自高點-28.4%

解讀

股價與資本支出的背離是本波修正最值得追蹤的訊號：台達電-65%、國巨-7成反映的是市場對「2027年AI資本支出成長率驟降」的定價（而非需求消失），但產業端仍在為2027-2028年的Vera Rubin世代與CPO世代擴產。這種背離有兩種解讀：一是股價超跌、資本支出代表產業內部人看到的訂單能見度，是買點；二是資本支出是過去18個月訂單的慣性，將在2027年形成產能過剩。歷史經驗（2018年記憶體、2022年面板）偏向後者——資本支出高峰通常滯後股價高點2-3季。台達電與國巨跌幅遠超台積電（約-25%），說明市場在懲罰「高beta、高本益比、低議價權」的零組件廠，而非整個供應鏈。

傳導鏈

輝達風暴＋AI資本支出回報疑慮 → 市場對2027年AI硬體成長率預期從+40%降至+15% → 高本益比零組件廠（台達電、國巨）遭殺估值而非殺獲利 → 但產業端仍為Vera Rubin/CPO擴產（華邦電1,127億、LED廠45億） → 2027年H2若需求成長率真的降至15%，擴產將形成產能過剩與價格戰 → 零組件廠毛利率從2026年高點下滑5-8個百分點 → 股價第二波修正或築底取決於四大雲端商1月資本支出指引

分叉情境

如果輝達Vera Rubin世代如期在2027年H1放量且四大雲端商資本支出指引年增30%以上，台達電回到1,300-1,500元、國巨回到400元以上，台灣AI供應鏈在2027年Q2重新領漲；如果資本支出指引年增低於20%，華邦電、LED廠的擴產將在2027年H2形成供給過剩，零組件價格年跌10-15%，台達電測試700元、國巨測試250元

展望

短期 · 1M
短期：台達電、國巨等超跌股在禁空令下反彈幅度可達15-20%（空方回補），但不代表趨勢反轉；關注Q4法說對2027年Q1訂單的指引
中期 · 3–6M
中期（3-6個月）：四大雲端商1月底2027年資本支出指引是分水嶺；若年增30%以上，零組件廠本益比修復至15-18倍；若低於20%，2027年Q2將出現擴產後的產能過剩、價格戰與第二波下修
