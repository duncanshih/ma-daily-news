總經 / 地緣政治

美10年期公債殖利率破5%創19年新高 — 全球同步進入「再升息」而非「降息」週期

深度解析

發生什麼事

根據Tradeweb數據，美國10年期公債殖利率9月23日盤中攀升逾8個基點至5.048%，創2007年7月以來最高；2年期殖利率同步升至4.798%，創2024年6月以來27個月高點。觸發點是標普全球當天公布的美國9月製造業PMI初值由8月的53.9躥升至57，創52個月新高，綜合PMI更勁升至58.4、創62個月新高，顯示中東戰爭推高能源成本的同時，實體需求並未降溫。Fed已於9月16日啟動2023年以來首次升息，並在點陣圖暗示年內還有一次；波士頓聯準銀行總裁Collins進一步警告通膨「顯著」高於2%目標的機率上升。歐債同步遭拋售，德國10年期升至3.5288%、法國4.6136%、義大利4.4647%。匯豐私人銀行預估Fed將於12月再升息1碼。

解讀

這不是情緒面的殖利率跳動，而是市場正在重新定價「終端利率比原先想像更高、更久」。關鍵在於PMI 57這個數字：它告訴你能源成本上升目前是透過「企業投入成本」而非「需求破壞」在運作，也就是說通膨有黏性但經濟沒有衰退——這正是央行最有理由繼續升息的組合。真正該擔心的不是升息本身，而是5%的無風險利率會重新設定所有資產的折現率門檻。

傳導鏈

中東戰爭推升能源成本 → 企業投入成本上升但終端需求維持強勁（PMI 57）→ 通膨預期上修、Fed從降息轉為升息 → 10年期殖利率破5%、全球無風險利率重設 → 高本益比科技股估值承壓、房貸利率破7%壓抑房市 → 高槓桿的私募信貸與商用不動產再融資成本跳升

結構性

結構性。這波殖利率上行不只反映景氣循環，更反映供給面（能源、關稅、去全球化）推升的通膨中樞，以及OECD點名的主權債務利息負擔問題——後者是不會隨景氣回落而消失的。

矛盾訊號

最大矛盾訊號是「殖利率破5%」與「那斯達克100創歷史新高」同時發生。傳統上實質利率上行會壓縮高成長股估值，但AI盈餘成長率目前跑贏折現率上升的速度。這個平衡點很脆弱：一旦AI資本支出成長率出現放緩跡象，5%的折現率會讓估值修正幅度遠大於2021年的情境。

分叉情境

如果11月CPI年增率仍在3.5%以上且非農就業維持月增15萬人以上，Fed 12月升息1碼是基本情境，10年期殖利率有機會測試5.3%-5.5%，那斯達克100可能出現10-15%的估值修正；如果荷姆茲海峽在10月底前重新開放、布蘭特原油回落至85美元以下，通膨預期快速下修，Fed可能在12月按兵不動，10年期殖利率回落至4.5%-4.7%區間，成長股與REITs同步反彈。

展望

短期 · 1M
短期（1個月內）：10年期殖利率在4.9%-5.3%區間高檔震盪，主要變數是10月中公布的9月CPI。若核心CPI月增率超過0.3%，殖利率直接測試5.3%。期間美元指數偏強，新台幣32元價位將是重要心理關卡。
中期 · 3–6M
中期（3-6個月）：若Fed如匯豐預期12月再升息1碼至終端利率，2027年上半年的關鍵變數轉為「財政」而非「貨幣」——美國在5%殖利率下的年度利息支出將突破1.3兆美元，OECD已就此提出警告。殖利率曲線可能在高檔轉為熊市陡化（bear steepening）。
長期 · 1Y+
長期（1年以上）：過去15年「零利率+低通膨」的資產配置範式正式結束。60/40組合需要重新設計，優質投資等級債在5%以上殖利率具備真實的配置價值，而依賴低折現率的成長股、無現金流的私募資產、以及高槓桿基建專案的IRR假設都必須整體下修200-300個基點。

持續追蹤

10月中公布的9月CPI核心年增率（關鍵門檻3.0%）12月FOMC點陣圖中2027年終端利率中位數美國2年/10年期利差是否由陡化轉為倒掛30年期公債標售的投標倍數（主權債需求真實壓力測試）

面試角度

這題五個職位都會問，但切角不同。國泰CIM最可能問：「10年期破5%，你的債券部位怎麼調整存續期間？」——答案要提到在升息末段逐步拉長存續期間、但要先確認Fed點陣圖見頂。開發資本基礎建設投資會問：「無風險利率從3%升到5%，你原本評估的基建案IRR門檻要怎麼調？」——這是折現率與WACC的直接應用。富邦證券投行組則會問：「殖利率5%對IPO定價與企業籌資窗口的影響？」——高利率環境下企業更傾向股權籌資，其實對ECM是結構性利多。

「我認為今天最關鍵的訊號不是殖利率破5%本身，而是它和9月製造業PMI初值57同時出現。這代表能源成本上升目前是透過企業投入成本而非需求破壞在運作，通膨有黏性但經濟沒衰退，這是Fed最有理由繼續升息的組合，匯豐也預估12月再升1碼。以開發資本的基建投資角度來看，無風險利率從3%升到5%，意味著我們過去用的WACC假設要整體上修200到300個基點，很多原本IRR算得過的專案現在都過不了門檻，這才是真正需要重新盤點的地方。」

深度解析

發生什麼事

川普與習近平將於9月24日舉行睽違四個月的第二次會面，川普準備以隆重儀式親自迎接。但回顧過去四個月，美中關係表面和緩、檯面下反制措施不斷。CNBC分析指出，中國對美出口的持續成長正幫助其消化國內經濟壓力，自給率提升改變了美方施壓的計算方式；貿易休戰的三項具體承諾——大豆、飛機、稀土——履約進度不一，顯示休戰基礎脆弱。Politico揭露美中所謂的AI安全「通報機制」，實質上只是財長貝森特與國務院副總理何立峰之間的直接熱線。分析師普遍認為此次會談可能擱置科技競爭、貿易轉運、台灣等棘手議題，僅在AI與伊朗戰爭上達成範圍狹隘的粗略共識。出席國宴的科技巨頭身價合計達2.2兆美元（約70兆台幣），其中馬斯克一人就佔40%以上。

解讀

我的判斷是：這場會談的實質意義在「風險管理」而非「協議達成」。過去美方的槓桿建立在中國對美國技術與市場的依賴上，但當中國的AI晶片（阿里真武V900）、太陽能、稀土自給率都在快速提升時，關稅的邊際嚇阻力正在遞減。真正值得注意的是韓亞證券的觀察——太陽能因攸關國安戰略，美方鬆綁中國產品限制的機率渺茫，這暗示「戰略產業」與「一般貿易」正在脫鉤成兩條獨立軌道。

傳導鏈

中國自給率提升（AI晶片、太陽能、稀土）→ 美方關稅與出口管制的邊際嚇阻力下降 → 談判焦點從「全面協議」退守至「風險通報機制」（貝森特-何立峰熱線）→ 戰略產業（半導體、太陽能、稀土）與一般貿易脫鉤為兩條軌道 → 台灣供應鏈在「非中」與「非美」訂單之間被迫二選一，地緣溢價擴大

結構性。自給率一旦建立就不會逆轉，這是產能與技術路徑依賴的問題，不隨關稅稅率或政治週期改變。

矛盾訊號

市場的矛盾在於：一邊說「貿易休戰維持、風險下降」，一邊卻有大豆、飛機、稀土三項承諾履約進度不一的事實。而Al Jazeera的分析更直接——貿易戰並未削減美國貿易赤字，中國反而錄得順差。也就是說，市場對「休戰有效」的定價，可能建立在一個從未被實現的前提上。

OECD與IMF雙雙示警主權債務利息負擔（持續追蹤）

持續追蹤中

發生什麼事

OECD今天同步發布兩則訊息：一方面小幅上調2026年全球經濟成長預測至2.9%（較6月上修0.1個百分點），認為各國在中東戰爭下仍具「韌性」；另一方面卻對政府公債殖利率飆升提出警告，指出各國債務利息支出正對公共財政形成壓力。IMF總裁Georgieva在BBC專訪中點名英美兩國必須對失控的債務成本採取行動，形容經濟衝擊已把債務水準推高得「像樓梯而不是通往天堂」。英國8月公債發行量意外超出預期，在預算案前夕進一步加重財政大臣壓力，英國8月CPI年增率已因能源成本躍升至3.1%。

關鍵數據

OECD 2026年全球成長預測2.9%（上修0.1pp）；英國8月CPI 3.1%；美國10年期公債殖利率5.048%，法國4.6136%、義大利4.4647%

解讀

「成長上修」與「債務示警」同時出現不是矛盾，而是同一枚硬幣的兩面——名目成長被通膨墊高，但名目利率上升得更快。當r（利率）持續高於g（成長率），債務動態就會自我惡化。這正是1970年代以來第一次，已開發國家同時面臨高債務存量與高實質利率。

傳導鏈

能源價格推升通膨 → 央行升息、公債殖利率破5% → 政府年度利息支出跳增 → 財政空間壓縮、被迫加稅或刪減支出 → 財政緊縮拖累成長，同時主權債信評等承壓 → 主權債殖利率再上行的自我強化循環（法國、義大利利差已明顯擴大）

分叉情境

如果英國預算案端出具體的財政整頓路徑且獲市場接受，英國10年期殖利率可望回落30-50個基點；如果預算案以擴大借貸為主軸，重演2022年迷你預算案的情境並非不可能，英鎊與英國公債將同步承壓。

短期（1個月內）：英國預算案（11月）與法國財政案是兩大引爆點。法國10年期4.6136%對德國3.5288%的利差已達110個基點，若擴大至150個基點以上，歐洲主權債風險將重回市場焦點。

深度解析

發生什麼事

凱基金（2883）代子公司凱基人壽於9月23日公告，董事會通過以新台幣206億元向潤泰創新開發購入台北市南港區不動產，為凱基人壽今年度最大筆不動產投資案。標的包括土地及地上27層、地下5層建物，總樓地板面積約20,580.51坪，建物主要作商辦使用，地下室規劃為停車場。凱基人壽表示該不動產將全棟出租，預計過戶後開始貢獻租金收益，收益率約3%。該案最受矚目之處在於輝達（NVIDIA）先前已在此一口氣簽下10年租約，等於「輝達換房東」。賣方潤泰新公告，交易金額含稅206億元，預計處分利益99.19億元，扣除截至今年6月底已認列約64億元公允價值評價利益後，預計明年初點交後再認列約35億元。此案寫下台灣史上整棟辦公室交易金額紀錄。

解讀

3%的租金收益率在美國10年期公債殖利率破5%的當下看起來毫無吸引力——但這正是理解台灣壽險業資產配置困境的關鍵。台灣央行利率連10凍、本地長債殖利率遠低於美債，壽險業面臨的是「新台幣計價的長天期收益資產嚴重不足」，而海外債券又受匯兌避險成本侵蝕。在這個約束條件下，一棟有輝達10年租約背書、位於南港AI廊帶的甲級商辦，其真正價值不在3%的當期收益率，而在租金的抗通膨特性與承租人信用品質。這是一筆負債驅動投資（LDI）決策，不是純粹的報酬率決策。

傳導鏈

台灣利率連10凍、新台幣長債殖利率偏低 → 壽險業面臨長天期收益資產荒、海外債避險成本高 → 資金轉向有穩定現金流的實體資產 → 甲級商辦成交價創新高、資本化率壓縮至3% → 南港AI產業聚落租金因輝達等外商進駐再上行 → 賣方（潤泰新）一次性認列99.19億元處分利益、帳面價值重估效應外溢至其他持有商辦的資產股

結構性

結構性。台灣壽險業的資產負債錯配是制度性問題，不會隨景氣循環消失；而南港因輝達等AI外商進駐形成的辦公室聚落，也是一個十年以上的產業地理重構。

矛盾訊號

矛盾在於：全球商用不動產正因利率上行而承壓（FT報導私募信貸出現「軟性違約」、私募股權陷入流動性僵局），但台北A辦卻創下歷史成交紀錄。原因是台灣商辦的槓桿率遠低於歐美（壽險以自有資金購置、幾乎不用貸款），所以利率上行對台北A辦的衝擊路徑是「機會成本」而非「再融資風險」——這兩者的殺傷力差距極大。

分叉情境

如果央行在2027年跟進升息且新台幣10年期公債殖利率升破2.5%，3%的資本化率將面臨重新定價，台北A辦交易量會先縮、價格後修；如果輝達等AI外商持續擴大南港據點、租金年漲幅維持3%以上，實質收益率會隨租金調升而改善，這筆交易在第5年就會從「收益率偏低」變成「進場時點精準」。

深度解析

發生什麼事

亞洲開發銀行（ADB）9月23日發布《亞洲發展展望》報告，將今年開發中亞洲和太平洋國家經濟成長預估上調至5%（較7月上修0.1個百分點，但低於2025年的5.5%），其中台灣被上修至11%，居亞太50個經濟體之冠。總統賴清德當晚出席世界台商會聯合總會年會惜別晚宴時強調，今年台灣經濟成長率預估可達11.05%，創39年新高。官方數據同步印證：經濟部統計處公布8月工業生產指數145.97、年增23.47%，製造業生產指數148.42、年增24.61%，雙雙創下歷史新高且為連續30個月正成長、連續4個月創新高。統計處副處長陳玉芳指出，傳統產業生產自今年3月起呈現穩定成長，主要受到AI供應鏈及資訊電子產品需求的外溢效應影響。8月批發業營業額達1兆8501億元、年增65.4%創歷史新高，9月可望首度突破2兆元。

解讀

11%的GDP成長率對一個人均GDP已達已開發國家水準的經濟體而言是極不尋常的數字，它反映的不是內需擴張，而是AI算力這個單一外部需求的爆發性拉動。真正值得注意的是統計處提到的「外溢效應」——傳產自3月起穩定復甦，代表AI紅利已經從電子業擴散到非電子產業，這是這輪景氣與2021年缺貨潮最大的不同。但也必須誠實面對：11%的成長率建立在一個極高的外部需求集中度上，這個結構的脆弱性和它的爆發力是同一件事的兩面。

傳導鏈

全球AI資本支出爆發（Dimon估明年達1兆美元）→ 台灣半導體與伺服器供應鏈訂單滿載 → 8月製造業生產指數年增24.61%創新高 → 外溢至傳產（金屬、化工、塑膠自3月起穩定復甦）→ 批發業營收年增65.4%、9月估破2兆元 → 企業資金需求升溫帶動銀行放款年增10.49%創21年新高 → GDP成長率衝上11%、亞太之冠，但外部需求集中度風險同步升高

結構性

混合。AI算力供應鏈的地位是結構性的，但11%這個絕對成長率高度依賴當前的資本支出週期，明年在高基期下必然大幅回落——這是週期性的。投資判斷上必須區分「台灣的產業地位」（結構性、可持續）與「今年的成長率」（週期性、不可持續）。

矛盾訊號

GDP成長11%的同時，央行公布8月M1B與M2年增率分別降至6.65%及6.79%，M2下降主因是外匯存款及活期儲蓄存款成長減緩。實體經濟火熱但貨幣總計數成長減速，這個背離值得追蹤——它可能意味著資金正從存款流向股市（證券劃撥存款單月爆增3,889億元創最大增速），也可能意味著企業獲利留在海外而未匯回。

分叉情境

如果AI資本支出在2027年維持年增20%以上，台灣2027年GDP成長率可望維持在5-6%的高檔（高基期下的正常回落）；如果超大規模業者2027年資本支出指引出現持平或下修，台灣GDP成長率可能急速回落至2-3%，屆時外資對台股的評價溢價也會同步收斂，這個轉折的訊號會先出現在出口訂單年增率而非GDP數據上。

如果M1B年增率在第4季回升至8%以上且證券劃撥存款持續增加，代表資金持續流入且有新增量，台股高檔結構穩固；如果M1B續降至5%以下而放款年增率同步收斂，代表信用擴張週期見頂，屆時即使指數維持高檔，也要警戒量縮後的補跌風險。

展望

短期 · 1M
短期（1個月內）：9月證券劃撥存款餘額能否續創新高是散戶信心的直接驗證。若在台股48K高檔出現餘額下滑，代表散戶開始獲利了結。
中期 · 3–6M
中期（3-6個月）：銀行放款年增10.49%的水準難以持續，觀察它是否在第4季開始收斂。放款成長率的轉折通常領先企業資本支出週期轉折約2個季度。

「央行8月數據裡有一個很值得挖的背離：銀行放款年增10.49%創21年新高，但M1B年增率卻降到6.65%。教科書上信用擴張應該推升貨幣總計數，現在卻背離，我的解讀是資金在高速周轉而不是沉澱——企業借來的錢直接投入資本支出和供應鏈付款，散戶的活存則搬進證券劃撥帳戶追股票，單月就爆增3,889億元創最大增速。這是典型的景氣擴張中後段特徵：錢的速度在加快，但存量成長在放緩。以元大法金業務的角度，放款年增10.49%代表現在是承作企業聯貸的黃金期，但放款成長率的轉折通常領先資本支出週期約兩個季度，所以我會把它當成最重要的領先指標來盯。」
