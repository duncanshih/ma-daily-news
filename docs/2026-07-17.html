01

總經 / 地緣政治

全球AI去槓桿撞上美伊戰火 — 從『台積電利多出盡』看風險偏好逆轉的傳導鏈

深度解析

發生什麼事

7月17日全球風險資產同步重挫，起點是美股費城半導體指數前一晚下跌逾4%、Nasdaq跌1.47%，接著亞股接棒：日本軟銀單日崩逾9%、台股加權指數暴跌2,953.71點（-6.47%）收42,671.27點，寫下史上最大單日跌點，南韓因休市暫避。三大法人單日賣超2,617億元新台幣、外資與自營商賣超雙創紀錄，成交值放大到約1.2兆元。矛盾的是，台積電16日法說會才把全年美元營收成長上調到40%、再宣布加碼1,000億美元擴建亞利桑那，基本面利多明明還在，股價卻不漲反跌並拖累聯電、世界先進等成熟製程股。這是一場『心理面帶動技術面』的無差別多殺多，本質是槓桿部位在AI估值偏高（6月底台股本益比31.78倍）與地緣風險升溫下被迫平倉。

解讀

這不是基本面崩壞，而是估值與槓桿的均值回歸，疊加美伊戰火提供了平倉的催化劑。當一個市場對『好消息不漲、壞消息大跌』時，代表利多已充分price in、邊際買盤耗盡，剩下的是擁擠交易的退場。真正該擔心的不是台積電的訂單，而是這波下殺暴露了多少融資槓桿與ETF被動資金的連動性。

傳導鏈

費半重挫 → 全球AI擁擠部位觸發風控平倉 → 外資調節亞洲高beta市場(台/日) → 台股融資追繳與被動ETF贖回 → 無差別賣壓擴散至成熟製程與非AI權值 → 新台幣同步走貶、央行進場阻貶

結構性

週期性為主：AI資本支出的結構性趨勢未變（台積電上調財測即為證），但股價位階與槓桿是週期性過熱，屬於漲多回檔的去槓桿階段，而非結構性衰退。

矛盾訊號

台積電基本面全面上修（全年營收+40%、Q2獲利+77%）vs. 股價利多出盡下殺；南非470億美元基金Coronation與《大賣空》貝瑞同時在減碼AI晶片、加碼印度與香港廉價股，暗示聰明錢已在輪動。

分叉情境

情境X（技術性修正）：若下週美股費半止穩、VIX回落至20以下，台股在42,000點附近量縮打底，本波定位為健康回檔，2-4週內收復月線；情境Y（去槓桿螺旋）：若美伊衝突再升級推油價站上90美元、或有大型基金爆倉消息，融資追繳連鎖引發第二隻腳，加權指數恐測試40,000點整數關與年線支撐。

展望

短期 · 1M
短期（1個月內）：高波動延續，加權指數在40,000–44,000點間寬幅震盪，關鍵在外資是否停止賣超；本益比若壓回28倍以下（約38,000點）才進入長線價值區。
中期 · 3–6M
中期（3-6個月）：只要台積電先進製程與CoWoS產能利用率維持滿載、全年營收+40%達標，指數應回歸基本面驅動，重回45,000點以上；變數是Fed利率路徑與美伊停火進度。
長期 · 1Y+
長期（1年以上）：AI資本支出仍是台股結構性主軸，但市場會從『雞犬升天』轉為『看真獲利』（Cramer要求AI付費的cold hard proof），台股將出現AI供應鏈內部的強弱分化，本次急殺是體質篩選的起點。

中國Q2 GDP +4.3%（持續追蹤：出口熱、內需冷的失衡復甦）

持續追蹤中

發生什麼事

中國Q2 GDP年增4.3%，為2022年底以來最慢增速。表面看『出口引擎過熱』——受惠AI帶動的科技產品出口強勁，但消費支出與企業投資明顯落後，就業市場疲弱正回頭擠壓內需。專家警告『Beijing會有麻煩』，因為靠外需撐GDP在美國關稅威脅與各國反傾銷下難以為繼。

關鍵數據

GDP +4.3%（2022Q4以來最慢）；出口為主要貢獻、內需與投資落後；就業疲弱壓抑消費。

解讀

這是一個『數字達標、結構失衡』的復甦。中國正把通縮壓力透過廉價出口輸出到全世界，這也是美國6月進口物價中國商品創2008年以來新高的另一面——關稅還沒完全轉嫁，一旦轉嫁完，通膨與貿易摩擦會同時升溫。

傳導鏈

中國內需疲弱+產能過剩 → 廉價商品出口 → 壓低全球製造業通膨但推升貿易對抗 → 美國關稅加碼 → 進口物價上行 → Fed降息空間受限

分叉情境

若北京推大規模刺激且房市止穩，港股（貝瑞看多的廉價股）有補漲空間；若刺激低於預期，資金持續由中國流向印度（南非470億基金已在加碼印度）。

展望

短期 · 1M
短期：北京可能加碼財政與消費刺激（以舊換新、消費券），但力度受地方財政與房市拖累而有限。
中期 · 3–6M
中期：全年『保5』難度升高，人民幣有貶值壓力，恐引發亞洲貨幣競貶與資金外流至印度、日本等替代市場。

口說版

「中國Q2 GDP 4.3%是2022年底以來最慢，關鍵不是數字本身，而是『出口熱、內需冷』的失衡——它靠廉價出口把通縮輸出全球，這也解釋了美國進口物價創2008年新高。對中信做跨產業投資評估來說，這代表押注中國內需消費要非常謹慎，反而中國廉價商品衝擊到的歐美傳產、以及承接資金轉移的印度資產，才是我會重點研究的方向。」

不動產 / 私募

地緣風險回頭咬房市 — 中東戰火推升英國房貸利率、美國房屋負擔連五月惡化

深度解析

發生什麼事

美伊衝突升溫透過油價這條線直接傳導到不動產融資成本：多家英國大型放款機構在中東戰事重啟後，把固定房貸利率一口氣調高最多0.35個百分點；美國方面，房價與房貸利率同步自年初走高，房屋可負擔指數連續第五個月惡化。這條傳導鏈的核心是『油價→通膨預期→長天期公債殖利率→房貸利率』，戰爭風險溢價正把剛要降溫的房市重新推回高利率環境。同時瑞銀資管的Kevin Zhao計劃做空美債，押注美國經濟強勁削弱公債避險吸引力，等於從另一端推升殖利率與房貸成本。

解讀

房市這次的壓力不是來自需求崩壞，而是『融資成本被地緣政治綁架』。只要荷莫茲海峽風險存在，長端殖利率就有支撐，房貸利率就難鬆——這讓央行的降息劇本被迫延後，房市進入『價格僵、成交縮』的膠著。

傳導鏈

美伊戰火 → 油價週線+11% → 通膨預期上修 → 長天期公債殖利率上行 → 房貸固定利率調升0.35個百分點 → 購屋負擔惡化、成交量縮 → 建商推案與REITs估值承壓

結構性

週期性衝擊（戰爭風險溢價）疊加結構性問題（英美長期供給不足），短期由前者主導，一旦停火利率有望回落。

矛盾訊號

市場一方面預期主要央行進入降息循環（ECB反而被傳9月還要最後升息一次），另一方面戰火又把房貸利率往上推，貨幣政策與市場利率出現方向背離。

分叉情境

情境X（停火）：若美伊數週內重回停火、布蘭特回落至75美元下方，英美房貸利率回softening、遞延買盤回籠，房市Q4觸底；情境Y（戰事延長）：若衝突延燒使油價站穩90美元，房貸利率再升20-35個基點，房市成交量續探低、營建與REIT評價下修。

展望

短期 · 1M
短期：房貸利率跟著油價與長債殖利率高檔震盪，成交量續縮，賣方讓價空間擴大。
中期 · 3–6M
中期：若戰火降溫且央行如期降息，2026下半年房市有機會落底，但反彈力道受制於負擔能力已被高利率消耗。

口說版

「我會用一條傳導鏈回答：美伊戰火讓油價週線漲超過11%，推升通膨預期與長債殖利率，英國房貸固定利率因此一口氣調高0.35個百分點，美國房屋負擔連五個月惡化。這對開發資本評估基建與實體資產投資很關鍵——當融資成本被地緣政治綁架，我在做IRR假設時就要把利率情境從單點改成分叉，並在停火與戰事延長兩種路徑下分別壓力測試專案的資金成本。」

來源FT CompaniesCNBC

中國萬科單季巨虧（持續追蹤：房市危機向績優生蔓延）

持續追蹤中

發生什麼事

被視為中國房地產『穩定股』的萬科（Vanke）公布巨額虧損，市場擔憂房市危機正從高槓桿民企擴散到過去體質相對穩健的龍頭，並再度質疑中國國家隊是否、何時出手托底。這與中國Q2內需與投資疲弱、就業落後的宏觀圖像相互印證。

關鍵數據

萬科單季巨虧（WSJ以『huge loss』形容）；市場關注國家是否介入；房市為Q2內需疲弱主因之一。

解讀

當連萬科都撐不住，代表這不是個別公司問題，而是整個商業模式（高周轉、預售、土地財政）的結構性瓦解。中國房市對GDP、地方財政、家庭資產負債表是三位一體，這也是內需起不來的根源。

傳導鏈

房企現金流斷裂 → 停工/爛尾 → 購屋信心崩壞 → 房價下跌 → 家庭財富縮水+地方賣地收入銳減 → 內需與基建投資雙弱 → GDP靠出口硬撐

分叉情境

若中央推全國性收儲與保交樓大規模撥款，房市有望止穩、帶動港股地產股修復；若僅零星紓困，危機沿供應鏈（建材、家電、金融壞帳）持續擴散。

展望

短期 · 1M
短期：國家隊可能對個別龍頭定向紓困，但難逆轉全行業去槓桿趨勢。
中期 · 3–6M
中期：房市L型築底延續，拖累人民幣與內需，資金持續外溢到印度、日本與港股廉價標的。

口說版

「萬科是中國房市過去的『優等生』，它都出現單季巨虧，說明危機已從高槓桿民企蔓延到龍頭，是商業模式的結構性瓦解。對中信投資專案評估來說，我會特別警惕任何營收或供應鏈高度依賴中國房地產鏈的標的，因為房市、地方財政、家庭資產是三位一體，這條風險線的定價還沒完全反映。」

AI / 半導體

半導體交易崩盤 — 費半寫『解放日』以來最慘週，中國AI模型加速把AI溢價往下拉

深度解析

發生什麼事

美國半導體股本週遭遇去年『解放日（liberation day）』關稅風暴以來最慘一週，費半指數在數個交易日內重挫，並拖累全球AI交易反轉。兩股力量同時發酵：一是估值面，AI龍頭漲多、槓桿部位擁擠，Jim Cramer公開要求看到AI付費的『cold hard proof』；二是競爭面，中國新創Moonshot AI推出Kimi K3宣稱對標OpenAI與Anthropic，DeepSeek更以較弱晶片、極低成本訓練出高效模型，NPR報導部分美國新創已改用便宜的中國模型省成本。Nvidia投資的Fireworks估值升至175億美元，靠的正是幫企業跑『更便宜的AI模型』。這意味著AI的『稀缺性溢價』正被開源與中國低成本模型侵蝕。

解讀

市場正從『AI無腦買』切換到『AI要看單位經濟學』。當推論成本被中國與開源模型打下來，最大受害者是靠賣最貴晶片與最貴token的環節，最大受益者是應用端與推論優化商。這次下殺不是AI敘事終結，而是AI利潤分配的重新洗牌。

傳導鏈

中國低成本模型(Kimi/DeepSeek) → 推論成本與token定價下行 → 市場質疑高階GPU的獨占溢價 → 費半估值修正 → AI擁擠部位平倉 → 全球高beta科技股補跌

結構性

結構性轉折（AI從稀缺走向普及、成本快速下降）疊加週期性去槓桿，長期看是AI商業化深化的必經之路，對整體算力需求反而是放大而非縮小。

矛盾訊號

台股17日『黑色星期五』，外資單日賣超創歷史紀錄、三大法人賣超2,617億元，成交值放大到約1.2兆元（史上第九大量）。新台幣兌美元同步走貶，盤中一度貶破32.3元、午盤暫收32.326元（貶7.7分），終場收32.288元（貶3.9分），央行全力阻貶下跌幅仍相對其他亞幣穩健。金管會晚間回應台股主要反映國際情勢、暫不祭救市措施，並提供基本面數據：6月底本益比31.78倍、現金殖利率1.56%（加計股票股利1.59%）。央行17日標售250億元2年期定存單，得標利率降至1.615%、為今年首次下跌，顯示資金環境在監管趨嚴後略為鬆動。

關鍵數據

三大法人賣超2,617億元、外資賣超創紀錄；成交約1.2兆元（史上第九大量）；新台幣收32.288元；本益比31.78倍、殖利率1.56%。

解讀

股匯雙殺反映的是外資的風險偏好逆轉與去槓桿，而非台灣基本面惡化。新台幣跌幅相對克制、央行阻貶得宜，加上定存單利率首度回落，代表系統性流動性風險目前可控，尚未出現失序的資本外逃。金管會不救市是正確的——這波是估值修正，行政干預只會延後出清。

傳導鏈

全球AI去槓桿 → 外資調節台股高beta部位 → 賣股換匯匯出 → 新台幣貶值壓力 → 央行進場阻貶 → 匯率波動可控但外資賣壓續存

分叉情境

情境X：外資賣壓數週內收斂、新台幣守穩，台股量縮打底；情境Y：美伊戰火升溫或AI財報不如預期，外資延續賣超，新台幣挑戰更弱價位、台股測試年線。

展望

短期 · 1M
短期：外資買賣超是台股能否止穩的最關鍵訊號，新台幣在央行調節下區間震盪，關注是否守穩32.5元。
中期 · 3–6M
中期：若美股與費半回穩、AI基本面續強，外資回補可期，新台幣與台股同步修復；反之股匯續弱。

「台股17日股匯雙殺，外資賣超創紀錄、三大法人賣超2,617億，但新台幣只收在32.288元、跌幅在央行阻貶下相對其他亞幣克制，加上2年期定存單利率首度回落到1.615%，代表系統性流動性風險目前可控。我認同金管會不救市——這波是31.78倍本益比的估值修正，行政干預只會延後出清。做配置我會緊盯外資單日買賣超這個訊號，它才是台股能不能止穩的關鍵。」

國泰世華銀行陳祖培回鍋董座（持續追蹤：鐵拳/獨董事件後的公司治理重整）

持續追蹤中

發生什麼事

國泰金控17日代子公司公告，經董事會共同推舉，由集團資深顧問、現年84歲的陳祖培回鍋出任國泰世華銀行董事長、即日生效，接替因『兼任外部獨董事件』請辭的郭明鑑。陳祖培在集團服務逾30年、曾任國泰金控副董事長與國泰世華銀董事長，他受訪強調上任首要任務是加強內稽內控與風險控管，並回應近期『鐵拳事件』等風波稱『一切都已過去、要重新出發』，要讓大家知道國泰世華是一家『了不起的銀行』。

關鍵數據

陳祖培回鍋、即日生效；集團年資逾30年；前任郭明鑑因獨董事件請辭；施政重點為內稽內控與風控。

解讀

這是金控在治理爭議後的『安定牌』人事——用資深老將穩定軍心、重建內控信任。對國泰集團而言，銀行是獲利核心，治理與風控的市場信任度直接影響估值與監理彈性。人事安定短期是利多，但真正考驗是能否把內控制度化、避免類似事件重演。

傳導鏈

獨董/鐵拳治理爭議 → 市場與監理信任受損 → 董事會請資深老將回鍋穩定 → 強化內稽內控 → 重建監理與市場信任 → 支撐金控估值

分叉情境

若內控改革落實且無新爭議，治理折價收斂、估值修復；若治理問題再現，恐引發監理加強檢查與商譽風險。

展望

短期 · 1M
短期：人事底定消除不確定性，對國泰金股價與監理關係為安定利多。
中期 · 3–6M
中期：觀察內控改革是否制度化、以及84歲董座的接班梯隊安排。

口說版

「這題正好切國泰CIM。國泰世華銀行在獨董與鐵拳等治理風波後，17日請84歲的資深老將陳祖培回鍋當董座、主打加強內稽內控，是一張穩定軍心的『安定牌』。我會點出：對金控來說，銀行是獲利核心，公司治理與風控的市場信任直接影響估值與監理彈性；人事安定是短期利多，但真正的考驗是能不能把內控制度化、避免重蹈覆轍——這也是我如果進國泰、最想參與貢獻的地方。」
