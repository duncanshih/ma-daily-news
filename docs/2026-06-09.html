伊朗戰爭滿100天、Hormuz通航回升 — 油價單日重挫近4%，但庫存風險仍懸頂

發生什麼事

美國能源部長表示Hormuz海峽商船通航量正在回升，加上川普重申與德黑蘭的協議「只差幾天」，國際油價單日重挫近4%，Brent本月創下6年來最大單月跌幅、自2026年高點回落約20%。然而局勢並未真正落地：以色列空襲黎巴嫩南部港市泰爾造成至少8死，內唐亞胡稱與伊朗、真主黨的戰事尚未結束，伊朗仍在海峽佈雷。供給端，中國自開戰以來削減原油進口，替全球油價在100美元下方築頂；但Exxon高層Neil Chapman警告，實體Brent庫存數週內將觸及歷史低點，屆時現貨價恐飆至150-160美元。CNBC估算，戰爭已讓美國家庭平均多付450美元的汽油與能源支出。

📐 解讀：這是典型的「地緣風險溢價退潮、但結構性供給隱憂未解」格局。市場目前把油價往下押，押的是「停火＋Hormuz復通」的樂觀情境；但這個情境的前提（伊朗停止佈雷、以伊真正止戰）至今未兌現。油價的下跌更多是『預期』在交易，而非『現實』已改善——這正是預期差最大的地方。
🔗 Hormuz通航回升 → 原油供給預期改善、油價跌4% → 通膨預期降溫、市場押聯準會仍有降息空間 → 風險資產（股、高收債）回補 → 但若庫存如Exxon所言見底、現貨彈至150美元 → CPI再上行 → 降息延後 → 估值修正
🏗️ 結構性 — 短期是地緣週期波動（停火預期帶動的均值回歸），但Hormuz的長期通航能力與『能源安全重新定價』是結構性轉變——CNBC指出Hormuz出口量可能回不到開戰前水準。
⚡ 矛盾訊號：市場一邊押油價跌（停火樂觀），Exxon卻警告庫存見底要噴到150-160美元；中國『撐住』油價在100以下，但分析師同時警告『這撐不久』。同一個油價，多空兩套劇本同時在跑。
🔀 情境X（停火落地）：若未來1個月Hormuz通航量恢復至開戰前8成、伊朗停止佈雷，Brent有機會在70-80美元區間打底，美國核心CPI回落至3%以下，聯準會9月前重啟降息討論。情境Y（庫存見底）：若停火破局、實體庫存如Exxon警告觸及低點，現貨Brent數週內衝150-160美元，美國家庭能源支出再增、核心CPI重回4%上方，降息全年無望。

📐 解讀：這是『經濟韌性』與『降息夢碎』的拉鋸。就業數據表面強勁，但薪資放緩＋服務業獨撐，顯示成長動能其實偏弱質。市場原本押的降息劇本被推遲，這對長存續期資產（成長股、長債）是逆風，對金融股、價值股相對有利。
🔗 5月非農+17.2萬、失業率4.3% → 聯準會降息預期被排除 → 美債長端殖利率維持高檔 → 美元相對強勢 → 新興市場貨幣承壓（印尼盾、印度盧比）→ EM央行被迫升息護盤 → 全球流動性收緊

🔀 情境X（黏性通膨）：若6月核心CPI因能源延遲效應重回4%上方，聯準會全年按兵不動，10年期殖利率挑戰4.5%以上，成長股估值再修正。情境Y（就業轉弱）：若後續非農跌破10萬、失業率升破4.5%，市場重新押年底降息1碼，長債與成長股反彈。

🔄 黃金恐再跌20%（花旗）— 伊朗戰爭下的「避險神話」破功

發生什麼事

花旗警告黃金到9月前可能再跌20%；自2月28日美伊戰爭爆發以來，黃金作為『避險資產』的聲譽反而承壓——戰時不漲反跌。Comex金價近期收低，銀價同步走弱。背後邏輯是：若伊朗停火、地緣風險退潮，避險買盤撤離，加上實質殖利率維持高檔（降息延後），無息資產黃金的持有成本上升。

關鍵數據

花旗預估9月前黃金恐再跌20%；金價自2月美伊開戰以來表現弱於預期；Comex金價單日曾跌1.4%、銀跌2.5%。

📐 解讀：這顛覆了『戰爭＝買黃金』的直覺。當戰爭推升的是通膨與實質殖利率、而非系統性金融恐慌時，黃金的避險功能會失靈。這是教科書級的『矛盾訊號』案例：地緣風險高，但黃金跌——因為驅動價格的是實質利率，不是新聞標題。
🔗 降息延後 → 實質殖利率維持高檔 → 持有無息黃金的機會成本上升 → 法人減碼黃金 → 若同時停火、避險買盤撤離 → 金價雙重承壓
🔀 若停火＋降息延後同時發生，金價恐如花旗所言再跌20%；若戰事升級轉為系統性金融恐慌（而非單純通膨），黃金避險功能才會重新啟動。

🔭 展望

短期（1個月內）：短期（1個月內）：金價走勢與實質殖利率、停火進度高度連動；若停火落地，3個月內回測前低不意外。

中期（3-6個月）：中期（3-6個月）：若聯準會年底前重啟降息、實質殖利率下行，黃金有機會止跌；但結構性的去美元化、央行購金仍是長線支撐。

💬 口說版：「黃金這題很適合考『避險資產的定價邏輯』。重點是：戰時黃金不漲反跌，因為驅動價格的是實質殖利率不是新聞標題——降息延後讓持有無息黃金的機會成本變高，花旗才看9月前再跌20%。面試若被問避險配置，我會強調黃金的避險功能要區分『通膨型衝擊』與『系統性恐慌』，前者其實不利黃金。」

🔄 美國5月成屋銷售創半年新高、但「先租後付」貸款興起 — 房市的K型分化

發生什麼事

美國5月成屋銷售反彈至去年12月以來最高水準，因4月房貸利率小幅回落，但房價仍在上漲、買方負擔未減。同時FT報導，『先租後付』（Rent now, pay later）短期融資正瞄準被住房成本擠壓的美國消費者，需求擴張至租屋市場；CNBC調查更顯示51%美國成年人認為『美國夢』已遙不可及、81%指生活成本是最大障礙。房市呈現『買得起的人照買、買不起的人靠借』的K型分化。
