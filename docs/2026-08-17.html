日本10年債殖利率觸及2.93%創30年新高 — 日銀9月升息機率衝上80%，全球利率之錨最後一塊鬆動

發生什麼事

指標10年期日本公債殖利率8月17日一度觸及2.93%，創1996年9月以來的30年新高，並已連續六個交易日走升，是一年多來最長連漲紀錄。對政策最敏感的2年期殖利率上升4個基點至1.69%，5年期一度升至2.17%的歷史新高，30年期上升5個基點至4.06%，逼近5月的歷史高點。推動力來自兩層：一是美日罕見聯手干預匯市支撐日圓後，美財長貝森特公開呼籲日銀盡早升息，路透報導日銀考慮最快9月動作，隔夜指數交換（OIS）反映的9月升息機率已達80%；二是日本財政前景惡化，長天期發行壓力持續累積。同日公布的日本第二季GDP年化成長僅1.1%，遠低於市場預估的2%，而7月批發物價（PPI）年增7.2%雖略降但仍在極高水位。日銀副總裁冰見野良三下周演說被視為確認升息時點的關鍵訊號。

📐 解讀：這是基本面驅動，不是情緒面。真正的訊號是「日銀被通膨與匯率逼著升息，而不是被成長邀請著升息」——GDP年化1.1%對上PPI 7.2%，代表這是輸入性通膨（能源＋弱日圓）造成的被動緊縮，屬於最難處理的政策組合。5年期創史高、30年期逼近史高，說明市場定價的不只是一次升息，而是整條曲線的中性利率上移＋財政風險溢酬。對全球資金面而言，日圓套利交易（carry trade）的資金成本正在系統性重估，這比任何單一央行決策都重要。
🔗 日圓貶值＋能源漲價 → 日本PPI年增7.2%輸入性通膨 → 美日聯手干預匯市＋貝森特施壓 → 日銀9月升息機率升至80% → 10年JGB殖利率2.93%、5年期創史高 → 日圓carry trade資金成本上升 → 日本壽險/銀行海外債券部位（美債、歐債）獲利了結回流 → 美債長端與新興市場信用資產同步承壓

⚡ 矛盾訊號：市場一邊喊日銀9月升息機率80%、殖利率創30年新高，一邊日經指數當天仍收漲0.74%、AI與半導體撐盤；同時Q2 GDP年化1.1%大幅低於預期。升息預期升溫卻股債表現分歧，說明股市定價的是「AI獲利週期」而債市定價的是「財政＋通膨風險」，兩者用的是不同的貼現分母。若日銀真的9月動作且日圓急升，Q2 GDP的疲弱才會被市場認真看待——這時候騙人的是股市，不是債市。

美7月零售銷售意外下滑 — Fed「升息」預期急降，美元指數摔至6月初以來最低

發生什麼事

美國7月零售銷售意外下滑，成為當前循環中第一個明確指向消費動能鬆動的硬數據，市場對聯準會短期升息的押注同步降溫。美元指數應聲下挫至6月初以來最低，主要亞幣全面反彈。高盛同日表示，鑑於美國通膨正在降溫，目前市場對Fed升息的押注「仍然過於激進」。另一方面，8月密西根消費者信心指數三個月來首次下降，受訪者同時對商業環境惡化與通膨上升表達擔憂，其中中東戰火推升的能源與物價是主要來源。市場已將9月升息機率大幅下調，並將焦點轉向即將公布的FOMC會議紀錄；美國10年期公債殖利率隨之走低。這是一個罕見的組合：市場在辯論的是「還會不會升息」，而不是傳統循環末期的「什麼時候降息」。

📐 解讀：本質是「戰爭型通膨」與「消費型衰退」的拉扯，而不是單純的軟著陸敘事。零售銷售下滑＋消費者信心下降＋通膨擔憂上升，這三者同時出現代表滯脹風險（stagflation）正在具體化——需求端在冷、成本端在燒。市場的解讀偏樂觀（升息機率下降＝風險資產可漲），但我認為這是誤讀：如果消費真的走弱，Fed不升息的原因會是成長轉差而非通膨解決，那麼企業獲利預估的下修風險會比利率風險更致命。真正該注意的是，這一輪美元走弱是「基本面走弱型貶值」，不是「風險偏好型貶值」，兩者對新興市場資產的含義完全不同。
🔗 中東戰火推升能源價格 → 美國通膨預期升溫、實質購買力下降 → 7月零售銷售意外下滑、8月消費者信心三個月首降 → Fed升息押注急降、美元指數摔至6月初低點 → 亞幣全面反彈（新台幣單日升1.94角）＋外資回補台韓股市 → 台韓出口企業匯損壓力上升但評價面因利率預期下降而擴張 → 若消費續弱，企業獲利下修將取代利率成為主要風險

歐洲今夏的極端高溫與乾旱已從氣候事件升級為能源與經濟事件。CNBC報導核電廠因冷卻水不足與水溫過高而被迫停機，歐洲的乾旱正演變為能源危機；FT指出歐洲河川水位處於歷史新低、水資源稀缺，運輸、能源與大型科技（資料中心用水）三個領域同時受衝擊。經濟損失已被量化：荷蘭Triodos Bank報告估計熱浪可能造成歐盟成員國GDP損失約1800億歐元，來源包括勞動生產力下降以及能源、運輸、農業多個產業受影響，其中法國可能是受損最重的國家。政策面出現方向轉折：西班牙決定延役阿馬拉斯（Almaraz）核電廠，使原定的核電退場路線恐生變。同一結構性問題在亞洲也浮現，FT報導印度的酷熱夜晚暴露其電力供應缺口。全球運價亦受萊茵河等內陸水道水位過低影響而上漲。

📐 解讀：這是氣候風險第一次以「供給端衝擊」而非「長期外部性」的形式進入總體經濟數據，而且它同時打擊能源供給與能源需求（冷卻用電上升、發電能力下降），是最難處理的一種衝擊。真正的訊號是西班牙延役阿馬拉斯核電廠——當缺水讓核電廠停機、卻同時讓政府決定延長核電壽命，說明各國已經把「可調度電力」（dispatchable power）的稀缺性排在減碳路徑之前。這對投資的含義很清楚：氣候調適（adaptation）而非只是減碳（mitigation），將成為未來十年基礎建設資本支出的主軸，而水資源與可調度電力是其中最稀缺的兩項資產。

壽險公會17日公布最新統計：2026年前7月壽險業保費收入（含非保險合約）合計1兆9326億元、年增26.7%，其中新契約保費9296億元、年增59.3%，續年度保費1兆30億元、年增6.6%。新契約結構出現劇烈變化——傳統型保單賣出3941億元、年增11.6%，投資型保單熱賣5355億元、年增率衝上132%，投資型單月保費更突破千億元。但獲利端同時走弱：台股7月下跌逾6%，市場修正影響壽險業金融資產評價損益，6大壽險7月獲利縮水至僅61.23億元，創今年單月次低。個別公司分歧明顯，南山人壽前7月稅後獲利319.6億元、年增逾110%。

關鍵數據

前7月總保費1兆9326億元（+26.7%）；新契約保費9296億元（+59.3%）；投資型新契約5355億元（+132%）、單月破千億；傳統型3941億元（+11.6%）；6大壽險7月獲利僅61.23億元（今年單月次低）；台股7月跌逾6%；南山人壽前7月獲利319.6億元（+110%）

📐 解讀：投資型保單年增132%與7月獲利僅61億元這兩個數字擺在一起，就是整個台灣壽險業當前處境的縮影。投資型保單的爆量代表壽險業正在把市場風險轉移給保戶（投資型的投資風險由保戶承擔），這在會計與資本適足率上是理性的——尤其在接軌IFRS 17與ICS的壓力下。但它也意味著壽險業的獲利模式正從「賺利差」轉向「賺手續費」，獲利的品質與穩定度會改變。7月獲利只有61億元則暴露另一個真相：即使大力推投資型，壽險自有部位對台股與債市的評價敏感度仍然極高，台股跌6%就能把單月獲利打到今年次低。這代表資產負債管理（ALM）的脆弱性並未因產品結構調整而解決。
🔗 台股7月下跌逾6%＋利率環境波動 → 壽險自有投資部位評價損益轉差 → 6大壽險7月獲利縮水至61.23億元、創今年單月次低 → 同時為降低自身市場風險與因應IFRS 17/ICS資本要求，加速推廣投資型保單 → 投資型新契約保費年增132%、單月破千億 → 壽險獲利模式由利差轉向手續費，市場風險移轉至保戶 → 若市場修正，保戶損失將轉為銷售爭議與監理風險
🔀 如果新台幣穩在31.5-32.0元且台股站穩46K：壽險評價損益回升、投資型保單續熱，全年獲利有機會回到成長軌道，壽險股評價修復；如果新台幣升破31.5元且Fed全年不升息使美日利差收窄：壽險海外部位同時面臨匯兌損失與利差收窄，避險成本上升，投資型保單的手續費收入無法填補利差缺口，屆時增資或發行次順位債的需求會浮現——這對投銀與法金業務反而是承作機會。

🔭 展望

短期（1個月內）：短期（1個月內）：8月台股回穩（外資買超454億元、指數收復部分失土）應有助壽險評價損益改善，但新台幣單日強升1.94角會對海外資產部位造成匯兌壓力，兩者方向相反，8月獲利數字值得細看。

中期（3-6個月）：中期（3-6個月）：關鍵變數有兩個——新台幣升值幅度與避險成本，以及投資型保單的銷售品質。若新台幣持續走強，壽險海外部位（占投資資產大宗）的匯兌損失會壓過股市評價的改善；同時金管會對投資型保單的銷售行為監理若轉嚴，這條成長曲線會放緩。
