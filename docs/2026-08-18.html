全球長債同步崩跌 — 美30年債5.33%創19年新高、日本10年債逼近3%，這次的賣壓來源是「AI發債」

發生什麼事

8月18日美國30年期公債殖利率盤中觸及5.322%，續創2002年以來新高，10年期同步走高；日本10年期公債殖利率逼近3%，是1996年以來最高水準；德、法公債殖利率也在歐股早盤同步揚升，形成全球長端同步賣壓。FT指出這波賣壓有三個疊加來源：一是荷莫茲海峽封鎖推升的能源通膨預期，二是各國財政赤字擴大導致長債供給增加，三是被市場低估的新變數——超大規模雲端業者（hyperscaler）為蓋資料中心而發行的巨額公司債，正在排擠同天期的政府債需求。追蹤20年期以上美債的TLT已摔至2004年以來新低。同時，美國財政部國際資本流動數據顯示中國、日本、英國6月同步減碼美債，中國持有量降至18年新低。有趣的是中國10年期公債殖利率反向下跌至13個月低點，因為內需疲弱把資金推進主權債。Yardeni認為殖利率雖逼近5%但尚未進入恐慌區，不過「債券義勇軍（bond vigilantes）」已經開始蠢動。

📐 解讀：這不是單純的通膨交易，而是「期限溢酬（term premium）重定價」。過去兩年市場習慣把長端殖利率上升解讀成經濟強勁，但這次股債同跌、VIX卻在低點，說明市場在對「誰來吸收這些長債」重新定價，而不是對成長重新定價。真正的新變數是AI資本支出的融資方式已經從自由現金流轉向債券市場——當微軟、Meta、Oracle這類AAA/AA級發行人以數百億美元規模擠進投資級市場，等於在無風險利率之上多開了一個高評級供給水龍頭，直接壓縮政府債的相對吸引力。中國10年債殖利率反向創13個月新低，更凸顯這是「已開發國家財政+AI供給」的問題，不是全球性通膨問題。
🔗 荷莫茲封鎖 → 能源通膨預期升溫 → 市場下修降息路徑 → 長端期限溢酬擴張 → 同時AI資料中心債券供給暴增排擠投資級需求 → 高評級信用利差被迫走闊 → 壽險/退休金的折現率上升、股票相對評價承壓 → 高股息與長天期成長股同時受壓，資金轉向短天期與黃金
🏗️ 結構性 — 結構性為主。財政赤字擴大與AI資本支出債務化都是多年期趨勢，不是庫存循環；只有油價那一層是週期／地緣事件驅動，可能在停火達成後快速回吐。

AI變成一台發債機器 — 資料中心融資正在改寫投資級信用市場的供需

發生什麼事

FT Alphaville以「AI：像一台發債機器」為題指出，超大規模雲端業者的資本支出已經超出自由現金流可以支應的範圍，開始大量轉向債券市場籌資，直接衝擊利率與信用兩個市場。具體案例是輝達為OpenAI在俄亥俄州的資料中心背書1,050億美元（約新台幣3.4兆元）融資、另投入15億美元進入軟銀旗下的資料中心開發商。CNBC同時報導，美國SEC近期針對資料中心債券發出的指引，實質上讓贊助商（sponsor）不必為這些投資背負完整責任，等於替這類融資結構鬆綁。高盛則指出，在實質利率走高加上AI相關供給大增的環境下，投資人正在重新檢視公司信用品質的配置，「高評級公司債未必是最好的交易」。Alphabet也啟動首次澳元計價債券發行，反映AI投資熱潮推動的融資需求已經外溢到非核心貨幣市場。

📐 解讀：這是本輪AI循環最重要、卻最被忽略的結構轉折：AI的資金來源正在從「股東權益」轉向「債權人」。當資本支出靠自由現金流支應時，風險由股東承擔，錯了就是股價修正；一旦轉為債務融資，風險就傳導到信用市場、保險公司與退休金的資產負債表上。這也解釋了為什麼ECB經濟學家會把美國科技股修正稱為「歐元區的金融穩定問題」——因為透過債券持有，歐洲金融機構已經被綁進來了。SEC的指引則是把責任從贊助商身上移開，這在監管上是「風險證券化」的典型前奏。
🔗 AI資本支出超過自由現金流 → 超大規模業者轉向投資級債市募資 → 單季發行量壓過政府債需求 → 長端殖利率與信用利差同步上行 → 壽險/退休金被動持有大量AI相關信用曝險 → 若AI獲利不如預期，虧損不再只落在股東而是傳導到金融體系 → 監管與金融穩定議題浮上檯面（ECB已示警）
🏗️ 結構性 — 結構性。這是AI產業融資模式的典範轉移，不是單季發債旺季；SEC指引屬於制度性變更，會長期改變資料中心專案的風險分配。
⚡ 矛盾訊號：市場一邊喊「AI capex見頂」，一邊卻看到輝達願意用自己的資產負債表擔保1,050億美元幫客戶蓋機房——如果真的需求見頂，供應商不會用自有資本去撐終端需求。反過來說，供應商必須自己出錢才賣得掉，本身就是需求品質下降的訊號。這兩種解讀哪一個對，取決於OpenAI/Anthropic的營收成長能不能持續。
🔀 如果Anthropic、OpenAI的營收年增率維持在3倍以上、且資料中心租金合約能簽到10年以上，則這套「供應商融資」模式會被視為輝達鎖定生態系的高明操作，信用利差維持穩定；如果任一大型模型商在未來12個月內營收成長掉到年增50%以下、或出現重大裁員／IPO延後，則市場會立刻重估GPU作為抵押品的殘值，AI相關投資級債利差可能在數週內擴大80–150個基點，觸發被動基金的連鎖賣壓。

華爾街「恐慌指數」VIX在8月17日跌到2026年以來最低水準，但同一天道瓊下跌超過270點、三大指數連兩日收黑，30年債殖利率創19年新高、布蘭特站上90美元。策略師普遍警告這是「投資人自滿（complacency）」而非真的沒有風險，且期中選舉年的8–10月本來就是季節性最動盪的區間。MoneyDJ引述數據指出，川普支持度已跌到33%、創任內新低，主因正是油價與戰事拖延，這會強化他在期中選舉前做出高風險政策動作的誘因。另一組矛盾數據是：FactSet顯示美股企業獲利率創歷史新高，但持有股票相對債券的超額報酬（ERP）已經歸零。

8月18日台股電子股熄火，加權指數收跌548點、跌破5日線，台積電下挫20元；金融股一度撐盤（富邦金漲逾3%）但擋不住大盤。籌碼面出現明顯轉折：外資賣超119億元，終止連續六個交易日的買超，賣超前幾名為力積電與面板股，另有5檔金融股遭大幅提款；三大法人合計賣超239.3億元。匯市同步走弱，新台幣收31.945元、貶9.3分，終止連四升，主因是台股下挫後外資轉為匯出。台指期在結算前夕轉為逆價差、夜盤跌破45,000點進入季線保衛戰。亞洲同步受創：日經收跌2.54%（半導體拖累、早盤一度跌1,121點），韓國KOSPI收跌1.55%、終止連六紅。導火線明確——美伊談判生變、全球公債殖利率走高的雙重外部衝擊。值得注意的是，同一天有一則反向訊號：0050出現「漲停價」的鉅額配對交易，法人正在棄選股改押指數。

📐 解讀：這一天的下跌不是台股自己的問題，而是外部利率與地緣風險的傳導終點。判斷依據有二：一是日、韓同步重挫且跌幅更大（日經-2.54% vs 台股約-2%），二是外資的賣壓集中在力積電與面板這類「非AI核心」的落後股，台積電只跌20元（約0.5%），代表這是資金撤出而非對AI敘事的否定。0050的鉅額配對與法人「棄選股改押指數」則透露另一個訊號：當個股分化太劇烈、選股勝率下降時，機構會退回指數曝險——這通常出現在循環中後段。

中信金上半年賺395億創新高、淨值破7,000億 — 銀行業在高利率環境的甜蜜點

發生什麼事

中信金法說會揭露上半年獲利395億元、創同期新高，淨值突破7,000億元、較去年底成長6成，資本實力顯著提升；總經理高麗雪表示配息率有望維持在6成至6成5，並以「配息更好」為努力方向，明年配息力可望增加。中信銀上半年放款增額達5,000億元，並主動回應市場關注的「四貸同堂」（同一借款人身上多筆貸款疊加）風險，強調人數與金額均在可控範圍。產業層面，工商時報報導國銀中小企業放款上半年衝破4,000億元、創近十年同期新高，達標率80.53%；純網銀營運轉佳，連線銀行連續7個月獲利、樂天銀行累積虧損大幅收斂。壽險端則有南山人壽7月新契約保費年增414%的爆發性數字。

📐 解讀：這是「高利率有利銀行、不利其他人」最直接的證據。銀行在長端殖利率上行時，資產（放款、債券）收益率重訂價的速度快於負債（存款）成本，淨利差擴大；同時企業因直接融資成本上升（債市殖利率高）而回頭找銀行借款，量價齊揚。中信淨值半年成長6成尤其關鍵——這代表金融資產的未實現損益大幅回沖，也就是說去年的債券部位評價損失正在修復。但要警覺「四貸同堂」被主動提出來說明，通常代表監理機關已在關切；當資產品質的問題被主動溝通時，就是應該開始追蹤的時候。
🔗 全球長端殖利率上行 → 銀行資產端重訂價快於負債端 → 淨利差擴大 → 同時企業發債成本上升而轉向銀行借款（中信銀放款增額5,000億、國銀中小企放款破4,000億創十年新高）→ 量價齊揚推升獲利（中信金上半年395億創新高）→ 淨值因債券部位評價回沖而成長6成 → 資本充足率改善 → 配息能力提升（配息率6~6.5成）→ 金融股成為高利率環境下的防禦性配置（當日金融股撐盤即為證明）
🏗️ 結構性 — 週期性為主。淨利差擴大直接繫於利率環境，一旦進入降息循環就會反轉；但「企業從直接融資轉向間接融資」以及中小企業放款政策目標是較長期的結構因素。
⚡ 矛盾訊號：獲利創新高、淨值成長6成的同時，卻要主動說明「四貸同堂風險可控」——這是一個典型的矛盾訊號。放款增額5,000億元代表積極擴張，而擴張期的資產品質問題通常要2–3年後才會浮現。另一個矛盾：中小企業放款創十年同期新高，但同期英美的數據都顯示中小企業因成本壓力在縮減經營（英國職缺創五年低），台灣的中小企業真的比較好嗎，還是放款成長來自政策目標而非需求？
🔀 如果高利率環境維持到2027年上半年、且台灣經濟成長率確實達到9~10%，銀行股將是最確定的受惠者，中信金配息率有機會挑戰7成、股價評價（股價淨值比）可望從目前水準再提升10%–15%；如果荷莫茲重啟帶動全球殖利率快速回落、聯準會在年底前降息2碼以上，則淨利差會在2027年開始收斂，屆時放款快速擴張期埋下的資產品質問題會與利差收窄同時出現，形成雙重壓力。
