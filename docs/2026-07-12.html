美伊荷莫茲海峽衝突再起 — 油價週漲逾7%，供給面通膨重新定義降息路徑

發生什麼事

美國與伊朗本週再度互射飛彈與無人機，爭點是荷莫茲海峽（全球約20%原油、逾25%液化天然氣運量的咽喉）通行權：川普宣稱海峽對商船開放，德黑蘭則稱「另行通知前」封鎖，並攻擊巴林、科威特、卡達、約旦、阿曼等五個鄰國。美國財政部撤銷原本給伊朗石油銷售、原訂展延至8月21日的豁免，海峽威脅等級被上調至「嚴重（severe）」。布蘭特原油本週累漲逾7%，Eni執行長警告若中東衝突持續油價恐破每桶100美元，Kalshi預測市場對「大選日汽油價格高於3.5美元」的機率跳升至75%。伊朗報紙甚至列出含川普、盧比歐、梅洛尼在內的13人「刺殺名單」，地緣風險溢價明顯回升。

📐 解讀：這一波是基本面（實體供給中斷風險）驅動，不是純情緒。市場過去一年把降息當成基準情境，但荷莫茲若真斷供，這是一個典型的『供給面通膨衝擊』——央行無法用升息解決供給問題，卻又不能在通膨上行時降息，等於把貨幣政策逼進兩難。我傾向認為只要海峽維持『間歇性通行』，油價會在高位震盪而非單邊噴出。
🔗 荷莫茲斷供風險 → 油價與運費（VLCC/LNG保費）跳升 → 進口國輸入性通膨上行 → 央行降息延後甚至轉鷹 → 長天期公債殖利率與高收益債利差走闊 → 風險性資產評價收斂
🏗️ 結構性 — 衝突本身是週期性事件，但『能源航道武器化』與航運改道北方路線是結構性風險溢價，兩者疊加。
⚡ 矛盾訊號：矛盾訊號：IEA同一週說2020年來全球石油需求將首度年減（需求偏空），油價卻因供給風險大漲——這代表當前油價是被『供給恐慌』而非『需求強勁』推動，一旦停火油價回吐速度會很快。
🔀 如果未來兩週達成新停火或海峽恢復穩定通行，布蘭特可能自高點回落10-15%、風險資產反彈；如果伊朗實質封鎖並攻擊使用美軍航道的油輪，布蘭特恐測試100美元、美國10年期殖利率再上行20-30個基點、亞股承壓。

發生什麼事

利率敘事正在從『何時降息』轉向『可能要升息』。台灣主計總處6月CPI年增衝破2.6%，投顧估央行9月理監事會升息機率大增；南韓央行本週市場預期升息1碼（0.25個百分點）；英格蘭銀行首席經濟學家更直言，成長放緩但通膨壓力揮之不去，今年利率『可能需要調升』。這與過去12個月市場一面倒押注全球同步降息的共識相反，背後推手正是能源價格（荷莫茲衝突）與服務性通膨的僵固。台灣本地更疊加『股市、房市太吸金』的資金行情，讓央行的選擇性信用管制難以退場。

📐 解讀：市場的『降息大合唱』正在破裂，取而代之的是各國央行依本地通膨/資產泡沫狀況分頭行動的『政策分歧』。台灣的特殊性在於：CPI破2.6%＋股房雙熱，央行升息不只是為壓通膨，更是為抑制資產過熱——這對台股的資金動能是實質逆風。
🔗 油價與服務通膨僵固 → CPI年增破2.6% → 央行升息機率上升＋信用管制延續 → 房貸/資金成本上行 → 股房資金動能收斂 → 高本益比/高槓桿族群評價回落
🏗️ 結構性 — 偏週期性（通膨末段的政策反覆），但『全球央行不再同步』是後疫情時代的結構性新常態。
🔀 如果台灣7-8月CPI回落至2%以下，央行9月按兵不動、資金行情延續；如果CPI續高於2.5%且房價再漲，央行升息半碼（0.125個百分點）並加碼信用管制，營建與高殖利率題材承壓。

Apollo以57億英鎊反超Castlelake搶下easyJet — 私募巨頭『贏者全拿』的縮影

發生什麼事

美國私募巨頭Apollo以約57億英鎊（約77億美元）的收購價，在最後一刻反超Castlelake，拿下英國廉航easyJet，消息激勵股價單日跳漲13%，easyJet董事會稱此案為股東帶來『更優結果』。FT分析Apollo的獲利劇本是『把easyJet變成Ryanair』——透過提高附加收費、削減成本來拉升利潤率。同一週Apollo還以30億歐元的融資交易買下拜耳（Bayer）避孕藥事業的股權，協助拜耳在Roundup除草劑訴訟後修補資產負債表。背景是FT報導『大型私募基金募資越來越集中』：資金流向少數贏家，恐催生一批募不到新資金的『殭屍基金』。

📐 解讀：這是私募產業『兩極化』的具體案例：一邊是Apollo這種頭部玩家同時operating（easyJet營運改造）與providing capital（拜耳結構融資）通吃，一邊是中小型GP募資枯竭。對想進投資專案/基建投資的人，這說明『能提供解決方案（不只是出錢）』的資本才有議價權。
🔗 利率高位＋公開市場估值分化 → LP資金向頭部GP集中 → 頭部GP用結構融資＋營運改造搶標的（easyJet、拜耳）→ 中小GP募資枯竭成殭屍基金 → 私募產業整併加速
🏗️ 結構性 — 結構性：私募從『純財務槓桿』走向『營運改造＋結構性融資』的能力競賽，是產業長期分水嶺。
⚡ 矛盾訊號：矛盾訊號：市場擔心廉航在消費疲軟下承壓，Apollo卻願付溢價——賭的是『營運改造的利潤空間』大於『景氣週期風險』。
🔀 如果Apollo成功把easyJet附加收費/成本結構改造到接近Ryanair，內部報酬率可觀、複製到其他廉航；如果歐洲消費續弱＋油價高企侵蝕航空獲利，改造難度上升、退場時點延後。

🔭 展望

短期（1個月內）：短期（1個月內）：easyJet併購案細節與其他PE對歐洲消費資產的出價是觀察窗。

中期（3-6個月）：中期（3-6個月）：頭部PE的『營運型收購』與結構性融資（如拜耳案）將成常態，觀察募資是否持續向少數GP集中。

💬 口說版：「Apollo這週做了兩件事很能代表私募現在的樣子：一是用57億英鎊反超對手搶下easyJet，打算把它改造成Ryanair那種靠附加收費賺錢的模式；二是用30億歐元的結構融資買下拜耳避孕藥事業。這說明頭部私募已經不是單純出錢，而是同時做營運改造跟結構性融資——這種能提供整套解決方案的資本才有議價權。如果我面試中信投資專案或開發資本，我會強調評估一個案子不只看財務槓桿，更要看投後管理跟營運改善的空間。」
