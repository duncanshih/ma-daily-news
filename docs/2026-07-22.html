日圓貶破163、近40年首見 — 日銀傳轉鷹、不排除加快升息

發生什麼事

日圓兌美元7月21日盤中貶破163大關，為近40年（1986年以來）首見，22日續在163附近徘徊。日本官員警告必要時將進場干預外匯，但口頭喊話未能有效支撐匯價。日本銀行態度傳出轉變，為因應通膨加劇不排除加快升息節奏，消息一度帶動日圓升值0.3%，但很快又貶回163之下狹幅波動。日本政府同日公布2026上半年貿易逆差逾1兆日圓，弱勢日圓推升進口成本、卻未能顯著改善出口帳。

📐 解讀：這是基本面（美日利差＋能源進口惡化）與政策落後（BOJ升息慢於通膨）交織的結構性貶值，不是單純情緒。口頭干預邊際效果遞減，顯示市場在測試日本央行的容忍上限；真正的轉折點是BOJ是否用實際升息、而非嘴巴，來守住匯價。
🔗 日圓貶破163 → 進口能源與原物料成本上升、輸入型通膨 → BOJ被迫加快升息 → 日債殖利率上行、日圓套利交易（carry trade）平倉 → 全球風險資產（含台股外資部位）面臨資金回抽壓力
🏗️ 結構性 — 偏結構性：美日長期利差＋日本能源近乎全進口＋人口與生產力瓶頸，非單一季度可逆轉；但升息預期若兌現可帶來週期性反彈。
⚡ 矛盾訊號：官方一邊喊『必要時進場』暗示不樂見貶值，一邊遲遲不升息維持超寬鬆，言行矛盾正是市場敢於持續放空日圓的底氣。
🔀 若BOJ在下次會議升息1碼（至0.75%）並釋放連續升息訊號，日圓有機會反彈至158–160、套利平倉衝擊有限；若BOJ再度按兵不動、僅靠口頭與零星實彈干預，日圓恐測試165–168，屆時一旦快速升息去平倉將放大全球波動。

長期（1年以上）：長期（1年以上）：日本告別零利率、正常化貨幣政策，將重塑全球套利資金版圖，過去廉價日圓資金外溢的環境將逐步收斂。

川普威脅炸伊朗橋樑與電廠、油價衝破95美元 — 荷莫茲風險溢價再起

發生什麼事

美國國務卿魯比歐坦承荷莫茲海峽談判陷入膠著、指伊朗『無意達成協議』，川普隨即威脅若伊朗再攻擊船隻將轟炸伊朗橋樑與發電廠。布倫特原油應聲漲破95美元，歐股逆勢收高（能源與國防股走強）。高盛警告若荷莫茲維持『斷供』狀態，布倫特恐跳升至120美元。IEA同步發布警訊，強調『沒有自滿空間』並點名成品油（柴油、航空燃油）供給偏緊，而非僅原油端。

📐 解讀：市場正把地緣事件從『一次性衝擊』重新定價為『可能延續的供給溢價』。這輪與2022不同的是成品油與煉能瓶頸更明顯，代表傳導到CPI的速度會更快、也更黏。是週期性事件疊加結構性煉能不足的組合。
🔗 荷莫茲斷供風險 → 原油與成品油（柴油/航油）齊漲 → 運輸與製造成本上升 → 各國CPI上行 → Fed／ECB延後降息、維持高利率 → 高評價成長股與高收債估值承壓、避險資金流入美元與黃金
🏗️ 結構性 — 地緣衝突本身是週期性事件，但全球煉能投資不足、成品油緩衝薄，是結構性弱點，讓每次衝擊的價格彈性放大。
⚡ 矛盾訊號：胡塞喊話願停止攻擊、卻同時對沙烏地宣布海運封鎖；市場一邊喊『TACO（川普總會退縮）日子不遠』、一邊放空部位升到16年最高，多空訊號極度分歧。
🔀 若10天停火斡旋成局、荷莫茲維持通航，布倫特有望回落至85–88、風險溢價收斂；若伊朗實質封鎖或美軍空襲擴大，布倫特上看110–120，全球通膨預期重新上修、降息劇本延後半年。

短期（1個月內）：短期（1個月內）：布倫特90–100高檔震盪，隨停火談判進度大幅跳動；成品油裂解價差是領先指標。

中期（3-6個月）：中期（3–6個月）：若無實質斷供，油價回落至80–90；但煉能瓶頸使柴油、航油價格易漲難跌。

長期（1年以上）：長期（1年以上）：中東供給不確定性常態化，將加速美國、中東（如ADNOC 62億美元天然氣案）與替代管線（伊拉克—敘利亞）的產能與路線分散布局。

🔄 川普關稅再加碼（持續追蹤）：加拿大50%、學名藥2028年100%、2029年200%

發生什麼事

川普宣布對加拿大商品課徵50%關稅，加國總理卡尼稱正評估『所有選項』，貿易緊張顯著升級。另在社群媒體宣布自2028年8月對輸美學名藥課100%關稅、2029年8月再倍增至200%，設兩年緩衝以逼迫製藥回流美國。美國貿易代表並稱最快7/23公布對部分國家課10%或12.5%關稅；台灣經貿辦表示台美溝通朝正面發展、可能維持10%。

關鍵數據

加拿大關稅50%；學名藥關稅100%（2028）→200%（2029）；台灣可能維持10%；新關稅最快7/23公布。

📐 解讀：關稅工具從即時衝擊轉為『預告式、分階段』，本質是產業回流的長期政策訊號而非單純貿易報復。對藥業與供應鏈是結構性重定位，市場短期會先反映『在美設廠者受惠、未設廠者受害』的分化。
🔗 分階段高關稅預告 → 企業提前赴美設廠（如美時、保瑞）→ 供應鏈重組與資本支出上升 → 短期成本轉嫁、藥價與物價上行 → 通膨黏著、聯準會政策更難鬆手
🔀 若台灣確定維持10%、且低於日韓，台廠出口相對優勢擴大；若最終被課12.5%以上，電子與傳產出口毛利將受壓、需觀察轉嫁能力。

🔭 展望

短期（1個月內）：短期（1個月內）：7/23關稅清單公布前後,相關個股與匯率波動加大；台灣10%稅率能否確立是關鍵。

中期（3-6個月）：中期（3–6個月）：學名藥兩年緩衝期使產業啟動赴美布局，在美有產能者評價領先。

💬 口說版：「川普這波關稅特色是『預告式、分階段』——學名藥2028先課100%、2029再翻倍到200%，中間留兩年逼企業赴美設廠。我會強調這是產業回流的長期訊號，不是一次性報復，市場會先分化成『在美有產能的受惠、沒有的受害』；對台灣來說，最快7/23公布、我們可能維持10%，如果確實低於日韓，就是出口相對優勢，這種稅率差怎麼影響台廠毛利與轉嫁能力，正是投資評估要抓的重點。」

Prologis對Segro開出140億英鎊『最終報價』 — 歐洲物流地產整併升溫

發生什麼事

倫敦上市工業／物流不動產集團Segro董事會表態，若美國最大物流REIT龍頭Prologis提出140億英鎊（約新台幣5,600億元）的『最佳且最終』收購，董事會將予以支持；此前Prologis出價135億英鎊遭拒。這是繼英國多起被收購案後，跨大西洋買家對『被低估』英國資產的又一次出手。同日另有阿波羅（Apollo）57億英鎊收購easyJet的交易，因歐盟檢視航空業所有權規則生變、股價下挫。

📐 解讀：美系私募與REIT正利用英鎊資產估值折價＋AI／電商驅動的倉儲需求結構性成長，發動跨境整併。物流地產是少數同時具『實體資產防禦性＋AI資料中心與電商需求成長性』的類別，本質是結構性成長而非週期性反彈。
🔗 英國資產估值折價 → 美系REIT／私募跨境併購 → 物流倉儲資產證券化與租金重定價 → AI資料中心與電商倉儲需求拉抬estimated NOI → 帶動歐洲不動產類股與REIT估值修復
🏗️ 結構性 — 結構性：電商滲透率與AI資料中心用地需求長期上行；但併購溢價高低仍受利率週期左右。
⚡ 矛盾訊號：一邊是物流地產搶親、一邊是中國房企萬科巨額虧損、房產危機外溢，同屬不動產、東西方景氣冷熱天差地別。
🔀 若Prologis 140億英鎊成交，將定錨歐洲物流地產估值、引發同業重估與後續併購；若因反壟斷或利率上行破局，Segro股價恐回吐併購溢價、類股短線承壓。

🔭 展望

短期（1個月內）：短期（1個月內）：Segro股價緊貼140億英鎊隱含價、消息面主導；關注英國反壟斷態度。

中期（3-6個月）：中期（3–6個月）：若成交，歐洲物流REIT估值中樞上移，觸發同業併購與資產重估。

中國車市銷量較高峰暴跌20%；2025年曾創2,370萬輛歷史新高；恐為2021年來最差一年。

🔗 中國車市需求暴跌20% → 整車廠減產與價格戰 → 車用晶片與電池庫存去化 → 全球車用半導體需求分化（中國弱、車用晶片卻傳漲價）→ 供應鏈區域與客戶結構重組

台股大漲592點、外資終止連13賣轉買超173億 — 券商上半年大賺1440億

發生什麼事

受美股、韓股同漲激勵，台股7月22日在外資終止連13賣、轉為買超173.4億元帶動下開高收高，大漲592.91點、收44,825.78點，連二漲，成交量擴增至1.02兆元，呈『價漲量增』有利格局。法人預期近期大漲小回、朝月線約45,360點邁進。AI熱潮推升今年上半年台股大漲17,162點、創同期最大漲點，投資人湧入使全體證券商上半年稅後純益達1,440.9億元、年增3.24倍；6月股市成交量創新高，券商經紀手續費大賺逾250億元。

📐 解讀：外資由賣轉買是情緒與美股連動的短線修復，但1.02兆元的量能與券商暴賺，反映的是AI主導的結構性資金行情。真正要分辨的是：這是外資資金回流、還是僅美股帶動的短打——央行強調『外資買超不等於資金回流』正是關鍵警訊。
🔗 美股韓股同漲 → 外資終止連13賣、轉買超173億 → 台股價漲量增（1.02兆）攻月線 → 成交量創高、券商手續費與獲利跳增（上半年純益年增3.24倍）→ 證券股基本面受惠、但需驗證資金回流的持續性
🏗️ 結構性 — 結構性（AI資金行情）＋週期性（外資短線隨美股波動）並存，量能是否延續是分水嶺。
⚡ 矛盾訊號：台股大漲592點、外資買超，但新台幣同日逼近32.5元、股匯脫鉤，顯示『外資買超』未必等於『資金淨流入』，多空訊號矛盾。
🔀 若外資買超延續、量能守穩兆元之上，台股有望站上並突破月線45,360；若僅為美股帶動的一日行情、外資再轉賣，指數恐在44,000–45,000反覆震盪、量能萎縮。

🔭 展望

短期（1個月內）：短期（1個月內）：45,360月線是關鍵壓力，價漲量增能否延續是重點；留意外資買賣超與美股臉色。

中期（3-6個月）：中期（3–6個月）：AI供應鏈第二季財報與評價壓縮後的支撐是主軸；量能與外資動向決定續航。

長期（1年以上）：長期（1年以上）：台股與AI資本支出循環高度綁定，AI capex的結構性成長是長線主軸。

📡 持續追蹤：
  • 外資買賣超與是否連續買超
  • 台股成交量能否守穩兆元
  • 月線45,360壓力與站上與否

股匯脫鉤、新台幣逼近32.5元靠央行尾盤強力阻貶 — 外資匯出壓力沉重

發生什麼事

美股走揚激勵台股22日延續反彈、盤中站回45,000點，新台幣兌美元早盤同步升破32.3元，但外資熱錢匯出猛烈、加上中東局勢升溫推升美元避險需求，匯價由升轉貶、盤中一度逼近32.5元關卡，尾盤央行強力阻貶、將貶幅拉回，僅小貶收32.375元。台北金融市場股匯再度脫鉤——台股大漲592.91點、匯價卻承壓，關鍵在外資匯出的美元買壓龐大。

📐 解讀：股漲匯貶的脫鉤，本質是『外資賣匯（獲利了結／匯出）大於買股』，加上地緣避險推升美元。這是資金流向的真實訊號：帳面買超未必等於淨流入，央行只能靠尾盤阻貶維持匯價穩定，屬週期性資金流與地緣避險的疊加。
🔗 中東地緣升溫＋美元避險 → 外資匯出、賣匯壓力大於買股 → 新台幣逼近32.5元、股匯脫鉤 → 央行尾盤強力阻貶 → 匯價僅小貶、但外匯存底與阻貶成本上升
🏗️ 結構性 — 週期性：隨美元強弱與地緣避險波動；但外資對台股AI部位的獲利了結節奏是結構性變數。
⚡ 矛盾訊號：台股大漲、外資帳面買超173億，匯市卻是賣匯壓力主導、匯價逼近32.5，『買股』與『買匯』方向相反，凸顯資金流真相與帳面數字的落差。
🔀 若地緣降溫、美元回softening，新台幣有望回升至32.0–32.3、股匯重新連動；若中東再升溫、美元續強，新台幣恐測試32.5以上，央行阻貶成本與外匯存底消耗加大。

🔭 展望

短期（1個月內）：短期（1個月內）：32.3–32.5區間震盪，央行阻貶力道與地緣避險是主變數。

中期（3-6個月）：中期（3–6個月）：美元走勢與外資對AI部位的獲利了結節奏決定新台幣中期方向。

💬 口說版：「22日台股大漲592點、外資帳面買超173億，新台幣卻逼近32.5、靠央行尾盤強力阻貶才小貶收32.375，這種股匯脫鉤我會解讀成外資賣匯匯出的壓力大於買股，加上中東避險推升美元。重點是：帳面買超未必等於資金淨流入，這也呼應央行說的『外資買超不等於資金回流』。對國泰CIM管理外匯部位，我會盯央行阻貶成本跟外匯存底消耗，還有美元跟地緣這兩個主變數怎麼決定新台幣中期方向。」

🔄 壽險逢低加碼AI科技股、避險成本優於預期 — 除權息旺季挹注經常性收益

發生什麼事

台股近期波動劇烈，多家壽險公司採『資本利得與股利收入雙軌並進』布局，逢低加碼具長期成長趨勢的AI科技股、並適時獲利了結。7、8月上市櫃進入除權息旺季，股息收入將大幅挹注本季經常性收益與獲利。MoneyDJ另指出，避險成本優於預期，壽險實質經常收益率受惠。富邦人壽同期透過新加坡子公司重返境外債市，完成3.5億美元、收益率5.95%發債，投資人認購突破19億美元、超額認購逾5倍。

關鍵數據

富邦人壽發3.5億美元境外次債、收益率5.95%、超額認購逾5倍；7–8月除權息旺季挹注經常性收益；避險成本優於預期。

📐 解讀：壽險『雙軌並進』反映在高波動與新台幣貶值環境下，同時追求資本利得與股利、並靠避險成本改善來守住經常性收益。避險成本優於預期是關鍵利多——它直接改善壽險的實質經常收益率，是被市場低估的預期差。
🔗 新台幣貶值＋避險成本優於預期 → 壽險實質經常收益率改善 → 逢低加碼AI股（資本利得）＋除權息股利收入 → 雙軌挹注本季經常性收益與獲利 → 壽險與金控獲利動能受惠
🔀 若避險成本維持低檔、新台幣貶勢趨穩，壽險實質經常收益率續優、金控獲利受惠；若匯率大幅波動推升避險成本，實質收益率改善幅度將收斂。
