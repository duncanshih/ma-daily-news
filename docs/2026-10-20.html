總經 / 地緣政治

美國通膨3.7%、Fed升息尾段拉長 — 市場賭「本月不動」，官員卻說「還有一次」

深度解析

發生什麼事

美國9月CPI年增3.7%，PPI與進口物價也高於預期，進口物價年增創逾4年最大漲幅，社會安全福利也因此上調。富蘭克林投顧指出，市場評估Fed本月（下週）維持利率不變的機率已升至8成以上，Fed主席華許（Warsh）對後續行動保持保留態度。紐約Fed總裁Williams表示2026年內可能還需再升息一次，但2027年未必需要繼續升息，與交易員預期不一致；克里夫蘭Fed總裁Hammack則警告需更高利率避免「通膨心理」生根。星展則預估至2027年Fed可能再升息2碼。週二美債殖利率小幅走低，市場等待房市數據與下週利率決議。

解讀

這是一個「供給面通膨＋鷹派但猶豫的Fed」組合：通膨主因是伊朗戰爭帶來的能源與柴油衝擊，升息壓不下油價，卻會壓垮房市與高槓桿AI信用。市場賭本月不動是對的，但低估了Fed在油價110美元下「再升一次」的機率，利率路徑風險偏向上方。

傳導鏈

油價破110美元 → 柴油、運輸成本上升 → CPI年增3.7%、進口物價創4年高 → Fed維持高利率並保留再升息選項 → 美元利差優勢延續 → 新興市場貨幣（新台幣、印尼盾）承壓、資金回流美元資產

結構性

偏週期但帶結構成分：能源衝擊屬週期性供給衝擊，但美國財政赤字與「去全球化」關稅推升的核心通膨黏性屬結構性，2%通膨難以在2027年前回來。

矛盾訊號

交易員押注2027年仍有升息，Williams卻說2027年可能不用升；同時預測市場認為通膨「今年已見頂」，但核心通膨降至2.2%的機率極低——市場同時在賭「見頂」與「黏著」。

分叉情境

如果油價在11月中前回落至95美元以下、10月CPI年增降至3.4%以下，Fed可能在12月停在原地，美債10年期殖利率回落15-25bp；如果Brent維持110美元以上、10月CPI再升至3.9%以上，12月升息1碼的機率將升破50%，美元指數再走強1-2%。

展望

短期 · 1M
1個月內：下週FOMC大概率按兵不動（市場機率逾80%），但聲明維持升息偏向；美債殖利率在數據公布間區間震盪，新台幣在32.5-32.9元間偏弱。
中期 · 3–6M
3-6個月：關鍵變數是油價與柴油供給（IEA預估緊俏延續至2027年）；若油價不回落，Fed可能再升1-2碼（星展預估至2027年共2碼），高收債與AI相關公司債利差持續承壓。
長期 · 1Y+
1年以上：「高利率更久」成為資產配置基準情境，股債負相關減弱，壽險與退休基金需提高對抗通膨資產（抗通膨債、基建、實物資產）的配置比重。

持續追蹤

下週FOMC聲明與點陣圖措辭10月CPI／核心PCE美國10年期公債殖利率與2s10s利差WTI與柴油裂解價差

面試角度

國泰CIM會問：Fed可能再升息一次，壽險海外債券部位要拉長還是縮短存續期間？避險成本怎麼算？元大法金可能問：美元利差擴大對台灣企業外幣借款成本與匯率避險需求的影響。

口說版

「我認為這波通膨主要是油價推動的供給面通膨，Fed升息壓不下油價，但會先傷到房市和高槓桿的AI信用，所以我判斷Fed本月不動、但年底前再升一碼的機率被市場低估。如果在國泰CIM，我會維持中性偏短的美債存續期間，等油價回落到95美元以下再拉長，同時留意美元利差對新台幣與避險成本的影響。」

持續追蹤中

發生什麼事

FT報導，與大型科技公司相關的信用違約交換（CDS）交易量暴增，投資人積極買保護以防AI熱潮反轉。標普全球表示，科技巨頭與AI相關的潛在負債可能高於目前已知水準，但暫無必要調整評等；HSBC對CoreWeave給予「減碼」評級，認為結構性疑慮將帶來更多「價值毀損」。股市週一反彈、那斯達克漲逾1%，但債市投資人仍要求CoreWeave與Oracle更高殖利率，Oracle公司債已逼近垃圾級。摩根大通則表示全球多數銀行對CoreWeave曝險有限。

關鍵數據

CoreWeave 2031年到期債殖利率近16%、CDS約1,000bp；Oracle債逼近非投資級；那斯達克100上週創去年貿易戰以來最大週跌幅

解讀

股市「買低」、信用市場「不買單」是典型的週期晚段背離：信用投資人看的是現金流能否支應債務，而非成長故事。債市先行的訊號比股市反彈更可信。

傳導鏈

AI資本支出靠舉債支撐 → Neocloud（CoreWeave）與Oracle債券利差擴大 → CDS避險需求暴增 → 資料中心融資成本上升、案件被重新定價 → 上游伺服器／記憶體訂單能見度受質疑 → 亞洲科技股（台、韓、日）估值下修

分叉情境

如果本週雲端業者財報上調capex且Oracle評等維持BBB-，CoreWeave CDS可回落至800bp左右；如果Oracle遭降評，AI相關信用利差恐再擴大100-200bp，亞洲科技股再跌5-10%。

展望

短期 · 1M
1個月內：本週科技財報為關鍵，若超大規模雲端業者維持capex指引，股市可延續反彈，但CoreWeave利差難以回到800bp以下。
中期 · 3–6M
3-6個月：若Oracle遭降至非投資級，被動型投資級債基金被迫出場，將引發第二波賣壓；資料中心專案融資條件趨嚴。

口說版

「我會把這次AI調整看成「信用先行」的訊號：股市已經在買低，但CoreWeave的CDS還在1,000bp附近、Oracle逼近垃圾級，代表債權人不相信現金流。若在中信MA投資專案評估資料中心案，我會把融資成本敏感度和承租方信用品質放到比IRR更前面的位置。」

關鍵數據

OAT 10年期4.94%；法德利差>150bp（14年新高）；上週末示威人數逾50萬

傳導鏈

社會暴動常態化 → 財政改革政治上不可行 → OAT利差擴大至150bp以上 → 法國銀行與保險公司持債評價損失 → 歐洲產險再保費率上調 → 歐元走弱、資金轉向美元與亞洲投資級債

不動產 / 私募

全球房市同步降溫 — 美國房貸7.4%、英國每天3,000筆降價、台灣千萬房貸成新常態

深度解析

發生什麼事

美國房貸利率飆至7.4%，建商信心指數跌至14年半新低。英國每天約有3,000筆房產下修開價，降價件數為15年來最多。台灣方面，聯徵中心數據顯示今年第二季新增房貸人數降至3.8萬人，連續六季低於4萬人（高峰為2024年Q2的6.5萬人），但平均房貸金額達1,081.1萬元、連續五季站上千萬元，平均房貸利率約2.43%，為金融海嘯以來相對高點。財政部統計青安3.0上路第二個月（9月）受理3,632戶、306.69億元，較8月減少約27%，為扣除春節月份後今年最低。

解讀

三地的共同驅動力是「利率」而非「失業」：需求被資金成本壓抑、但屋主沒有被迫拋售，所以呈現「量縮價撐」而非崩跌。台灣「人數降、單筆金額升」說明市場只剩高所得與換屋族撐盤，首購族被擠出，這是結構性負擔能力問題。

傳導鏈

Fed維持高利率 → 美國房貸7.4%、全球長端利率上行 → 購屋負擔率惡化、交易量萎縮 → 建商推案放緩、土建融需求下降 → 銀行不動產放款成長趨緩、營建相關授信風險上升 → 建材、家電、裝修等下游消費轉弱

結構性

週期為主：交易量萎縮主要由利率週期驅動，一旦降息即可回升；但台灣房價所得比與「千萬房貸常態化」反映結構性負擔問題，不會隨利率下降而消失。

矛盾訊號

台灣經濟成長率預估高達11.6%、外銷訂單創新高，房市交易量卻連續六季萎縮——AI財富效應集中在科技業與股市，未擴散到一般首購族；同時銀行資金趨緊、央行信用管制仍在，政策面壓抑了強勁基本面。

分叉情境

如果Fed在2027年上半年轉向、台灣央行同步放寬第七波信用管制，台灣新增房貸人數可望回到4.5萬人以上、交易量回升10-15%；如果台灣通膨維持2%以上、央行轉向升息半碼，房貸利率升至2.6%以上，新增房貸人數可能跌破3.5萬人，中南部重劃區價格首先修正5-10%。

展望

短期 · 1M
1個月內：青安受理戶數續在3,500-4,000戶區間，第四季交易量季減；美國10月新屋開工維持疲弱。
中期 · 3–6M
3-6個月：關鍵變數是台灣央行12月理監事會是否升息或調整信用管制；建商以小坪數（35坪以下占69%）與讓利促銷去化餘屋。
長期 · 1Y+
1年以上：房市從「全民資產」走向「高所得族群資產」，租賃住宅、社會住宅與包租代管成為不動產投資新主軸，REITs與長租公寓的資產配置價值上升。

持續追蹤

台灣央行12月理監事會與信用管制聯徵中心季度新增房貸人數美國30年期房貸利率青安貸款月受理戶數

口說版

「我認為現在全球房市是「量縮價撐」，驅動力是利率而不是失業，所以不會出現拋售潮。台灣的關鍵是新增房貸人數連六季低於4萬、但平均房貸破千萬，代表首購族被擠出；如果在中信做不動產投資，我會優先看租賃型與收益型資產，而非依賴價差的住宅開發。」

分叉情境

中國三巨頭下單逾350億美元輝達降規晶片 — 需求真實存在，但供給只給5-10%

深度解析

發生什麼事

據知情人士透露，字節跳動、阿里巴巴與騰訊已訂購超過300萬張輝達RTX PRO 5500繪圖處理器，總值逾350億美元（約新台幣1.14兆元）。這款GPU效能較低、符合美國出口管制規定，顯示中國企業在禁令下仍急需算力。輝達已告知客戶，中國需求遠超原定產能，無法保證完全供貨，市場估計實際交貨可能只有5-10%。同時，美國國土安全部禁止聯邦民間機構IT系統使用DeepSeek相關技術；中國記憶體廠長鑫存儲（CXMT）雖公布獲利轉盈，股價仍跌近8%。

解讀

這筆訂單本身是「AI需求見頂」論的反證：在美國股債市場質疑AI回報的同時，中國最大買家仍願意為降規晶片排隊。但5-10%的交貨率意味著它更像「搶產能的期權」，對輝達營收的實質貢獻有限，反而凸顯先進封裝與晶圓產能才是真正瓶頸。

傳導鏈

美國出口管制 → 中國業者只能買降規GPU → 超額下單搶產能 → 輝達需向台積電、封測與板卡供應鏈追加投片 → 台灣伺服器、PCB、散熱供應鏈訂單能見度延長 → 但美方若再收緊管制，訂單可能瞬間取消

結構性

結構性：中美科技脫鉤與出口管制是長期政策，中國需求只能透過「降規版本＋自研晶片」雙軌滿足，這種分裂市場會持續數年。

矛盾訊號

美國信用市場在擔心AI capex泡沫（CoreWeave CDS約1,000bp），中國買家卻超額下單350億美元；一邊說需求過熱、一邊說供給不足——差別在於「誰付錢」：中國巨頭用自有現金流，美國Neocloud靠舉債。

分叉情境

如果美國在11月川習會前維持現行管制，輝達可逐步交貨並把中國營收占比維持在低雙位數；如果美方在期中選舉後收緊至RTX PRO系列，350億美元訂單可能大部分取消，台灣相關板卡與伺服器組裝廠第一季營收恐下修5-10%。

展望

短期 · 1M
1個月內：輝達財報前市場聚焦中國出貨指引；台積電CoWoS與先進製程產能仍滿載。
中期 · 3–6M
3-6個月：中國業者加速導入華為昇騰等國產晶片作為替代；美國對AI模型（DeepSeek）的限制可能從政府機關擴大到關鍵基礎設施。
長期 · 1Y+
1年以上：全球AI供應鏈形成「美系高階＋中系自主」雙生態，台灣業者需在合規與市場占有率間做選擇，出口管制合規成為財務盡職調查的固定項目。

持續追蹤

美國商務部對RTX PRO系列的出口規範輝達財報中的中國營收占比台積電CoWoS產能擴充進度11月川習會談結果

傳導鏈

台灣10年期公債得標利率破2%、2008年來首見 — 11.6%成長率終於反映到利率

深度解析

發生什麼事

台灣10年期公債標售得標利率站上2%，為2008年以來首見，反映AI對經濟的強勁拉動與未來通膨隱憂，進一步推升市場的升息預期。星展維持台灣2026年與2027年GDP成長率預測分別為11.6%與5.6%，CPI分別為2.0%與2.1%，並指出第三季GDP成長率應維持約12%（Q2為12.9%、Q1為15.4%），2%通膨可能成為新常態。經濟部公布9月外銷訂單1,142.1億美元、連兩個月破千億，前9月累計8,192億美元，已超越去年全年7,437億美元，全年破1.1兆美元機率相當高。星展也預估Fed至2027年可能再升息2碼。

解讀

台灣長期處在「高成長、低利率」的異常組合，10年期破2%是利率向基本面回歸的開始，而非一次性波動。對壽險業而言這是好消息（新錢收益率上升），但對持有大量長天期債券的機構與房市則是評價壓力。

傳導鏈

AI出口推升GDP成長至11.6% → 薪資與服務業價格上升、CPI黏在2% → 市場預期央行升息、10年期公債得標利率破2% → 銀行存放款利率與房貸利率上調 → 壽險業新錢投資收益改善、但既有債券部位評價損失 → 房市與高槓桿企業融資成本上升

結構性

結構性為主：AI帶來的產業結構轉型使台灣潛在成長率上移，2%通膨成為新常態，長期低利率環境（2008年以來）可能正式結束。

矛盾訊號

長端利率上升代表市場預期升息，但同時外資連10賣、新台幣創18個月新低，資本外流理應壓低債市需求、推升殖利率——利率上升究竟是「成長樂觀」還是「資金外逃」所致，兩股力量同時存在。

分叉情境

如果台灣央行12月升息半碼、且10月CPI維持2%以上，10年期公債殖利率可能上看2.2-2.3%；如果AI出口在明年第一季放緩、外銷訂單年增率降至個位數，央行可能按兵不動，10年期回落至1.8-1.9%。

展望

短期 · 1M
1個月內：10年期殖利率在1.95-2.1%區間；市場聚焦11月CPI與央行官員發言，金融股中壽險相對受惠、銀行利差改善但授信成長放緩。
中期 · 3–6M
3-6個月：12月央行理監事會為關鍵，若升息半碼，房貸利率可能升至2.6%，房市交易量續縮；外銷訂單在2027年基期墊高下成長放緩。
長期 · 1Y+
1年以上：台灣利率結構正常化，壽險業可增加新台幣債券配置、降低海外債與匯率避險負擔，有利IFRS 17與ICS接軌後的資本適足管理。

持續追蹤

台灣10年期公債殖利率央行12月理監事會決議10月CPI與核心CPI10月外銷訂單

面試角度

國泰CIM必問：台灣10年債破2%，壽險資產配置要如何調整？要不要增加新台幣債券比重？中信MA可能問：利率上升對不動產投資案的折現率與估值有什麼影響？

口說版

持續追蹤中

發生什麼事

外資週二再賣超台股795.4億元、連續10個交易日賣超，主要減碼ETF並連10日調節台積電累計13.23萬張；外資賣超前十名中ETF占6檔。加權指數跌529.15點（-1.13%）收46,292.93點，成交值降至7,587億元，回測季線。新台幣盤中最低32.672元，收32.617元、貶1.72角，連四黑並創18個月新低，央行尾盤進場調節才收斂貶幅。投信則逆勢買超183億元。

關鍵數據

外資10月累計賣超7,416億元、今年逾2.11兆元；新台幣32.617元；台積電收2,405元（-0.62%）

解讀

外資賣ETF而非個股，顯示這是「資產配置層級」的減碼（降低台灣權重、獲利了結與匯率避險），而不是對個別公司基本面的否定；投信與內資承接讓指數跌幅有限，但匯率成為主要壓力釋放管道。

傳導鏈

AI信用疑慮＋美元利差 → 外資降低台股權重、賣ETF與台積電 → 資金匯出推升美元需求 → 新台幣貶至32.6元 → 壽險避險成本下降、出口商匯兌受惠 → 進口通膨上升，強化央行升息壓力

分叉情境

如果本週美股科技財報優於預期，外資賣超可望縮小至每日200億元以下、新台幣回到32.3元；如果CoreWeave等信用事件擴大，外資可能續賣並推升新台幣至33元，台股下探44,000點。

展望

短期 · 1M
1個月內：新台幣在32.5-32.9元間偏弱，央行持續阻升／阻貶雙向調節；台股在季線附近（約46,000點）攻防。
中期 · 3–6M
3-6個月：若美國科技財報穩住、AI信用利差收斂，外資有機會回補；否則年度賣超可能擴大至2.5兆元。
