貝森特長債回購反噬 — 30年美債殖利率破5.3%、國債突破40兆美元，市場改買黃金與比特幣

發生什麼事

美國財政部長貝森特（Scott Bessent）8月9日宣布把10-30年期公債的流動性支持回購規模至少加倍，單次操作金額由20億美元提高至至少40億美元，9月9日啟動，20日再表態規模可能超過40億美元、並直言30年債流動性不佳。市場反應與意圖完全相反：30年期美債殖利率本週一度突破5.3%，創2007年以來新高，長天期殖利率在回購消息後續漲，所謂「Bessent Bid」在一週內失效。同一週美國聯邦債務正式突破40兆美元，較2017年約20兆水準十年翻倍，光是利息支出目前一年已超過1兆美元。市場的通膨損益兩平率（breakeven）升抵兩個多月來最高，顯示投資人把財政部干預解讀為「財政主導」訊號而非技術性流動性操作。資金轉向硬資產：比特幣單週上漲22%、突破7.6萬美元，創三年多來最佳週線表現，黃金同步反彈、美元指數走弱。橋水基金創辦人達里歐（Ray Dalio）21日直接把這次回購定調為債務危機逼近的訊號，建議減碼債券、加碼黃金與少量比特幣；摩根大通的James Sullivan則形容這是「用信用卡繳房貸」，只是把問題往後遞延。川普21日則稱他並未指示貝森特動作，還讚其有「債券直覺」。

📐 解讀：這不是情緒面問題，是基本面的定價權移轉。財政部回購長債本質上是把發債結構往短端推（用短債換長債），在通膨仍有黏性、Fed 7月紀要甚至討論升息的環境下，市場合理推論這是為了壓低政府利息成本而非為了市場功能——一旦干預被讀成「財政主導貨幣政策」，期限溢酬（term premium）就會擴張而不是收斂。真正的訊號不在殖利率水準，而在殖利率上升的同時美元走弱、黃金與比特幣同步噴出：這是典型的主權信用折價組合，而非單純的利率上升。
🔗 財政部加碼回購長債 → 市場解讀為財政主導、通膨損益兩平率走升 → 期限溢酬擴張、30年殖利率破5.3% → 美元走弱＋黃金/比特幣「貶值交易」湧入 → 全球長天期公債殖利率同步走高（英國Gilt、日本超長債）→ 美國30年房貸利率卡在6.7%、企業投資級與高收益債發行成本墊高 → 壽險與退休基金資產負債兩端同時受衝擊（負債折現率上升有利、既有債券部位評價受損）
🏗️ 結構性 — 結構性。判斷依據是債務存量本身：40兆美元、利息支出年逾1兆美元，這個數字不會隨景氣循環回落，而回購操作只改變存量的期限分布、不改變存量規模。週期性的部分只有短期的殖利率超漲。
⚡ 矛盾訊號：貝森特說「我知道一些債券市場不知道的事」並宣稱回購是為了改善30年債流動性；但同一週真正的流動性指標（買賣價差、拍賣尾差）並未惡化到需要干預的程度，而殖利率反而上行。另一組矛盾：全球公債殖利率齊漲時，中國公債殖利率卻維持低檔逆勢抗跌，市場一邊喊「主權債風險」、一邊把資金停泊在信評更低的中國國債，說明這波賣壓賣的是「財政紀律」而非「主權信用」本身。
🔀 如果9月9日回購正式啟動後30年殖利率仍站上5.3%以上，且8月核心PCE年增率高於3.0%，則市場會把回購定調為失敗的財政干預，美元指數有機會再跌3-5%、黃金挑戰前高、台幣等亞幣受惠續升；如果核心PCE回落至2.8%以下且Fed在9月會議明確排除升息，則長端殖利率可望回落至5.0%附近，貶值交易獲利了結，比特幣從7.6萬美元回吐15-20%、黃金回檔，資金重回久期較長的投資級債。

美加談判破局 — 50%關稅對200億美元加拿大商品生效，卡尼揚言「一對一等價」報復

發生什麼事

美國與加拿大的新一輪貿易談判於8月21日破裂，雙方互指對方搞破壞，且未安排後續談判時程。美東時間8月22日凌晨0時起，美方對價值200億美元的加拿大商品加徵高達50%關稅，鎖定鋼鋁、汽車零組件等關鍵產業。加拿大總理卡尼（Mark Carney）拒絕接受他形容為「不公平」的協議，公開表示將「一對一等價」（dollar for dollar）對等報復。華府高層特使則批評加方錯失機會。加拿大是美國第二大貿易夥伴，僅次於墨西哥，雙邊年貿易額逾7,000億美元，200億美元約占加拿大對美出口的低個位數百分比，但集中在少數產業。渥太華同步加速「去美化」布局，包括推動省級解除美國酒類禁令以換取談判空間、並擴大對歐盟與亞太的出口通路。

📐 解讀：50%是懲罰性稅率而非談判籌碼稅率——談判籌碼通常落在10-25%，50%的設計目的是讓特定產業直接失去價格競爭力。但選擇性打200億美元（而非全面課徵）說明白宮仍在控制對美國自身通膨的外溢，這與同一週川普宣布30萬噸進口牛絞肉90天免關稅是同一套邏輯：對外強硬、對內壓通膨。真正的訊號是「未安排後續談判」——這代表短期內沒有回到談判桌的機制，市場要為長期化定價。
🔗 美對加50%關稅生效 → 加拿大等值報復、北美供應鏈成本上升 → 汽車與鋼鋁業者調整產能配置（部分回流美國、部分轉出北美）→ 美國車價與建材價格上行、CPI商品項受壓 → 通膨黏性延長、Fed降息空間壓縮 → 長端殖利率維持高檔、美元與加幣波動放大 → 台灣汽車零組件與扣件出口商在北美的訂單重新洗牌
🏗️ 結構性 — 結構性。判斷依據是USMCA架構本身正在被單邊關稅侵蝕，且雙方都已啟動供應鏈分散（加拿大轉向歐亞、美國推回流），這種產能配置決定一旦做出就有5-10年的沉沒成本，不會隨政治週期逆轉。
⚡ 矛盾訊號：白宮一邊對加拿大課50%關稅，一邊對進口牛絞肉開放30萬噸90天免稅，且美國牧場主人公開抗議這是「背叛」。同一個政府同時在做保護主義與反通膨兩件互相矛盾的事，說明關稅政策的真正約束條件是國內物價與期中選舉，而非貿易平衡本身——這也意味著若通膨數據惡化，關稅有被打折的空間。
🔀 如果加拿大真的執行等值報復且範圍涵蓋能源（加拿大是美國最大原油進口來源，日供逾400萬桶），則美國中西部煉廠成本上升、汽油價格再加碼，Q4美國CPI商品項可能多推升0.2-0.3個百分點；如果加拿大只做象徵性報復並在90天內回到談判桌，則市場會把這視為又一次「TACO交易」（關稅宣布後打折），加幣與加股在初期下跌後3個月內收復失土。

📐 解讀：這不是房市回溫，是政策紅利的期末結算。房貸金額暴增而交易量沒動，說明增量來自「已成交但尚未撥款」的遞延交屋潮＋青安補貼截止效應，本質上是把未來的需求提前到7月實現。真正該警惕的是雙貸族創高與專家點名的「股市榮景成推力」——房貸增貸周轉金拿去投資股市，等於用不動產做抵押品加槓桿買金融資產，這是房市與股市風險互相傳染的管道，也是台灣銀行業目前最容易被低估的相關性風險。

🔄 台灣券商掀籌資潮 — 凱基證通過213億元聯貸，八家銀行聯手支應融資融券需求（持續追蹤）

發生什麼事

凱基金控子公司凱基證券8月21日董事會決議通過不超過213億元的聯合貸款案，契約期3年，用於支應融資融券及不限用途款項借貸（不限用途借款）等業務資金需求。參貸行陣容以公股銀行為主，包含第一銀行、臺灣銀行、兆豐銀行、華南銀行、彰化銀行、合作金庫銀行、臺灣企銀，以及純網銀樂天銀行。背景是台股交投熱絡導致券商資金水位拉響警報，帶動整體證券業籌資潮。同期市場另一個訊號是台股融資餘額新增約500億元的「聰明錢」進場卡位籌碼大換手的潛力股，以及台股複委託成交額熱絡（但7月已見退燒跡象）。

關鍵數據

凱基證聯貸額度上限213億元、期限3年、參貸行8家；台股新增融資約500億元；7月複委託金額已見退燒

📐 解讀：券商在成交量縮到一個月低點的當下反而擴大籌資，這是典型的逆向訊號——資金水位的準備是為了下一波交易熱潮，而不是反映當前的量能。更值得注意的是資金用途：融資融券與不限用途借貸都是槓桿業務，這與前面提到的雙貸族42.3萬人創高、房貸增貸投資股市是同一個主題的不同切面——台灣的家計部門與券商都在為股市加槓桿做準備。這是繁榮的訊號，也是脆弱性的來源。
🔗 台股交投熱絡＋散戶槓桿需求上升 → 券商融資融券與不限用途借貸業務資金水位吃緊 → 券商向銀行聯貸籌資（凱基證213億元）→ 銀行對證券業的曝險上升 → 若台股回檔且融資追繳出現，券商信用風險上升、銀行連帶承壓 → 與雙貸族（房貸增貸炒股）形成同一條槓桿鏈 → 房市、股市、銀行體系的風險相關性同步升高
🔀 如果台股在Q4站上46,000點以上且成交量回升至9,000億元，則券商的融資融券與經紀業務收入同步成長，凱基證這筆213億元銀彈可望創造可觀的利息利差收益；如果台股回檔測試44,000點且融資追繳大量出現，則券商的授信品質與銀行對證券業的曝險會同時受檢驗，凱基金這類券商佔比高的金控獲利波動將明顯放大。
