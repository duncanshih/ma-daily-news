總經 / 地緣政治

中國3月工業利潤年增15.8% — AI/晶片榮景與輸入性通膨壓力同步發酵

深度解析

發生什麼事

中國國家統計局公布3月工業利潤年增15.8%，明顯高於市場預估，主要由AI伺服器與半導體製造商帶動，雲端運算、HBM記憶體相關產線持續滿載。但同時間，自伊朗戰爭推升的進口原油成本（布蘭特已突破108美元）開始傳導至下游石化、化工與航運業，部分依賴進口原料的中小製造商毛利率被壓縮。北京尚未宣布大規模刺激，僅靠AI產業鏈獨撐景氣。

解讀

這份數據是「結構性熱度」與「週期性壓力」並存的典型樣本，AI鏈把整體獲利數字撐高，但內需消費與傳統製造仍在去化庫存階段。市場若把15.8%當成中國經濟全面復甦訊號就會誤讀；本質上是極不均衡的K型復甦，關鍵不是總額而是分布。

傳導鏈

AI伺服器訂單擴張 → 大陸DRAM/HBM製造商滿載 → 工業利潤大增 → 但油價上行壓縮石化/化工毛利 → 中小企業實質獲利惡化 → 內需消費回溫被延後 → PBoC需在通膨與成長間二選一

結構性

結構：AI/晶片利潤是長期結構性紅利；週期：油價推升的成本壓力屬短期外生衝擊，但若Hormuz拖到Q4將轉為結構性。

矛盾訊號

市場上同時有兩種說法：一派認為中國工業已從谷底反轉、適合做多A股；另一派指出工業利潤集中在3-5家AI龍頭、底層數據（中小企業景氣指數）仍偏弱，總量數據在誤導投資人。

分叉情境

如果布蘭特油價Q2平均維持在95-105美元，且Hormuz於8月底前部分解封 → 中國Q2工業利潤年增可望維持10%以上、PBoC不需降準；如果油價Q2跨入110-120美元區間且Hormuz持續封閉 → 中小製造商裁員潮起、北京將被迫於7月底前釋出至少3000億人民幣專項再貸款支持非AI產業。

展望

短期 · 1M
短期（1個月內）：4月工業利潤年增率可能回落至8-12%區間，因油價傳導全面顯現；A股科技股與週期股將出現明顯分化，人民幣兌美元在7.18-7.25區間震盪。
中期 · 3–6M
中期（3-6個月）：若AI訂單能見度延續至2026Q4，深成指相對上證綜指將維持10-15%超額報酬；但若全球Mag-7資本支出見頂訊號於Q3顯現，中國AI鏈將同步回檔20-30%。
長期 · 1Y+
長期（1年以上）：中國經濟轉向「AI單腳走路」是脆弱結構，2027年若AI capex週期反轉、且房地產仍未築底，將出現第二次去槓桿衝擊；長期投資邏輯應放在AI硬體+綠能基建的雙軌而非單押AI。

中國中小企業PMI（看是否跌破49）布蘭特油價是否守住100美元PBoC公開市場操作量（是否轉為大量淨投放）深圳/上海二手房成交量月變化HBM3e/HBM4出貨指引（SK海力士、三星）

深度解析

發生什麼事

本週將有Meta、Apple、Amazon、Microsoft、Alphabet 5家科技巨頭公佈財報，市場期權市場顯示call單量普遍高於put（除Alphabet），多單情緒明確。但同時Meta上週宣布裁員10%（約2萬人）、Microsoft史上首次提供員工買斷方案。Nvidia市值上週首破5兆美元、Intel單日漲24%（自1987年以來最佳）。CNBC訪問30位CEO，最大共同憂慮是『AI、戰爭、通膨已成新基線』。

解讀

市場以期權結構押多Mag-7財報，反映的是『AI capex故事還沒結束』的共識，但Meta裁員與Microsoft買斷其實是對沖訊號——大廠開始把AI生產力紅利兌現為人事成本下降。本質上這是『股東報酬從營收成長轉向利潤率擴張』的拐點，財報數字漂亮但勞動市場將承壓。

傳導鏈

Mag-7資本支出持續高位 → AI晶片/雲端基建供應鏈受惠 → 同時AI agent取代知識工作 → 大廠人事費用下降、毛利率擴張 → 短期EPS驚喜、股價上漲 → 但消費端薪資成長放緩、白領失業率上行 → 6-12個月後拖累科技股自身終端需求

結構性

結構：AI對白領工作的取代是不可逆的長期趨勢；週期：本季財報的call/put多單情緒是短期定位、不可外推。

矛盾訊號

華爾街多單押Mag-7財報亮眼，但Cramer同時警告『所有資金都流向AI是個問題』、Carter Worth指醫療股圖形『更多痛苦在前』；Bank of England副行長明說股市『太高、會跌』；BBC更追蹤到伊朗戰前後的可疑內線交易模式。一邊期權看多、一邊監管/技術派看空。

分叉情境

如果5家Mag-7有4家以上capex指引上調 → S&P 500未來4週上看7000點、Nvidia續攻至120美元、半導體權值股推升台股突破4萬2；如果Apple與Alphabet capex指引同時下調或Meta廣告營收年增率跌破18% → Mag-7週內回檔8-12%、台積電將下測2150元、外資將連續賣超台股逾2000億。

展望

短期 · 1M
短期（1個月內）：本週財報後波動率將先升後降，VIX有機會自18跳上25再回測；費半（SOX）4週內波動區間6500-7200。
中期 · 3–6M
中期（3-6個月）：若capex指引上調，Q3記憶體/CoWoS/光電供應鏈將湧現第二波營收動能、台廠AI伺服器代工Q3營收年增續維持30-40%；但勞動市場數據將開始顯現AI替代效應，美國白領失業率將自3.6%上行至4.2-4.5%。
長期 · 1Y+
長期（1年以上）：AI capex單一週期高峰可能落在2027上半年，若沒有殺手級應用接棒（除了coding agent），2028會迎來首次AI資本支出衰退；長期持有應集中在電力/水/土地等實體瓶頸資產，而非單純晶片。

持續追蹤

Meta廣告營收年增率（門檻18%）Microsoft Azure年增率（門檻30%）Apple中國區營收年增（門檻+5%）Nvidia下季資料中心營收指引美國白領失業率（門檻4.0%）

面試角度

國泰CIM：『若Mag-7財報後VIX跳上25，你會調整投組Beta還是維持？』中信MA：『AI agent取代知識工作對私募股權投資組合中SaaS被投公司的估值有什麼衝擊？』元大投行法金：『大型科技公司ECM/併購窗口在Mag-7財報週後是否會打開？』富邦證券投行：『AI概念股IPO接下來6個月排程怎麼影響承銷費結構？』

解讀

中國最後堡壘萬科Q1巨額虧損 — 房地產危機擴散到國有體系，國家是否出手成最大問號

深度解析

發生什麼事

WSJ報導，中國最大、最具國家背景的地產商之一萬科（Vanke）公布Q1巨額虧損，連這家原本被視為相對穩健的『國家隊』成員都無法倖免。萬科的問題從現金流惡化、債券價格已跌至面額70%，到上下游供應商拖欠款項擴大。市場質疑中國房地產危機是否已蔓延至國有體制，深圳地方國資2024年底注資後仍未阻止下行。

解讀

如果連萬科都倒下，意味著中國地產去槓桿已從民營（恆大、碧桂園）燒到半官方體系，這不再是單一公司財務問題、而是整個央地財政與地方國企體系的信用重新定價事件。中國真正的『雷曼時刻』分水嶺在於萬科是否獲得中央層級支援。

傳導鏈

萬科虧損擴大 → 萬科債券殖利率上行 → 同類國資地產商（保利、招商蛇口）信用利差跟漲 → 銀行體系AT1債承壓 → 地方土地出讓金枯竭 → 地方政府財政惡化 → 基建投資進一步放緩 → 鐵礦砂/銅/鋁需求下修

結構性

結構：中國房地產佔GDP權重從30%降至20%是不可逆的長期結構性調整；週期：萬科Q1帳面虧損是調整過程中的階段性事件、但會放大週期下行幅度。

分叉情境

如果中央在5/1勞動節後宣布3000-5000億人民幣國家隊收儲 → 萬科債價回升、A股地產指數一週內反彈15-20%；如果北京僅由地方國資出面、中央保持距離 → 萬科債價將跌至50%面額以下、中國房地產股全面再下殺、人民幣兌美元跌破7.30。

展望

短期 · 1M
短期（1個月內）：萬科美元債殖利率將維持在18-25%區間、體現高違約風險定價；A股房地產板塊本週可能出現5-8%急跌。
中期 · 3–6M
中期（3-6個月）：若中央接手收儲，市場將短期反彈但結構性問題未解；若放任市場自行出清，將迎來第三波二線城市房價急跌（年降幅可能擴大至15-20%）。
長期 · 1Y+
長期（1年以上）：中國房地產佔GDP權重將從目前約20%降至12-15%（日本90年代後類比）；對應的銀行業ROA將永久性下降40-60bp；外資對中國股債的『可投資』評等將下修，至少需3-5年重建信心。

持續追蹤

萬科美元債殖利率（門檻25%）中國居民每月新增房貸（門檻3500億人民幣）70城新房價格指數年降幅（門檻-7%）央行PSL投放量（看是否啟動收儲）保利、招商蛇口股價變動

面試角度

中信MA投資專案：『若被指派評估一個中港不動產基金的投資案，萬科事件如何納入折現率假設？』開發資本基礎建設：『中國地產去槓桿對亞洲基建專案融資成本傳導有多大？』國泰CIM：『中國地產美元債目前殖利率20%，是價值機會還是價值陷阱？』

X-energy小型核反應爐IPO飆27% — AI資料中心電力需求點燃核能新一輪

持續追蹤中

發生什麼事

上週X-energy掛牌首日上漲27%，市值達46億美元；公司主打小型模組化反應爐（SMR）並已與Amazon、Google簽訂供電預備合約，主訴求是解決AI資料中心未來5年新增60-80GW電力缺口。NRC已開始審查其Xe-100設計、預計2030年商業運轉。

關鍵數據

X-energy IPO首日+27%、市值46億美元；AI資料中心電力需求2030年估100-120GW（vs目前約40GW）；SMR單機容量80MW、佔地約20公頃（傳統核電1/10）。

解讀

AI capex熱潮的下一站不只是晶片、是『電力』。SMR比天然氣電廠單位電價低、但建置週期長（5-7年）、屬於長線基礎建設機會。但需注意：NRC審查若延遲將直接打掉商業時程。

傳導鏈

AI資料中心電力需求暴增 → 電網瓶頸顯現 → 大型科技公司簽SMR預備合約 → SMR新創估值跳升 → 鈾價結構性走高 → 鈾礦商Cameco、Kazatomprom長多

分叉情境

如果X-energy 2026下半年通過NRC設計認證 → 估值再上漲50%、Amazon/Google加碼採購；如果認證延遲超過12個月 → 估值將大幅修正30-40%。

展望

短期 · 1M
短期（1個月內）：SMR概念股（X-energy、NuScale、Oklo）繼續高波動、區間+/-20%。
中期 · 3–6M
中期（3-6個月）：鈾現貨價格將自目前115美元/磅突破130美元、鈾股齊揚。

口說版

「X-energy IPO首日大漲27%是AI capex故事的第二章——電力。如果應徵開發資本基礎建設投資，SMR是未來3-5年最具alpha的基建子題、但要區分『有客戶簽約』與『純概念』兩類；只買有Amazon/Google已下供電預備合約的標的、純概念類即使便宜也別碰，因為認證風險極大。」

台股盤中觸及4萬點、TSMC 2330元創新高，但外資反手倒貨511億 — 拉積盤後的第一個壓力測試

深度解析

發生什麼事

台股加權指數4/27盤中觸及40,000點歷史關卡，台積電盤中達2330元創新高、本益比約26倍（法人稱仍合理）。但盤後資料顯示外資反手賣超511億元、賣超前三全部是ETF（00981A、0050、006208）、台積電被賣超1.8萬張。新台幣連2升收31.467元、午盤一度強升1.07角至31.409元。3月景氣燈號連4紅、AI需求挹注出口表現。

解讀

這是『拉積盤』的典型訊號——指數靠台積電獨撐推上40K，但ETF同步被外資減碼，意味著外資減持的是廣度型部位（被動式投組）、且對指數高位採風險中性立場。台股短期『高指數、空成交』的結構性問題突顯。

傳導鏈

AI訂單持續 → 台積電2/3奈米營收滿載 → 台積電股價推升大盤 → 但外資ETF減碼反映對全市場估值高位的擔憂 → 大盤指數高位但成交額萎縮 → 隱含波動率（VIX台版）將上行 → 個股分化加劇

結構性

結構：台積電在全球先進製程的市佔結構性領先（2/3奈米>90%）；週期：4萬點關卡是技術面+心理面的週期性高點，外資定位調整屬於戰術性。

矛盾訊號

經濟日報投票顯示近半投資人選擇進場追高、散戶情緒高昂，但外資同步倒貨511億；同時間穩懋、信驊爆出近1.3億元大額違約交割（多頭市場震撼彈）。散戶積極vs外資減碼+違約交割同步出現，是常見的階段性頂部訊號。

分叉情境

如果Mag-7財報後台積電獲ADR帶動上攻、4月底守穩2300元 → 大盤可挑戰40,500點、外資將回補500-800億元；如果Mag-7有任一家下修capex指引、台積電跌破2200元 → 大盤一週內可能下測38,500-39,000點、外資再賣超千億。

展望

短期 · 1M
短期（1個月內）：大盤39,000-40,500區間震盪、台積電2200-2400區間；新台幣31.20-31.70；外資週均賣超400-700億元。
中期 · 3–6M
中期（3-6個月）：若Mag-7資本支出指引維持、CoWoS擴產順利 → Q3台積電月營收年增率仍可維持35-40%；本益比有望維持25-28倍區間。
長期 · 1Y+
長期（1年以上）：台股結構性升級（台積電市值占比升至45%、半導體占比60%）使指數越來越像『SOX(費半)代理』，散戶面臨『單一檔台積電決定全部部位風險』的集中度問題、配置策略應引入產業ETF分散。

持續追蹤

外資累積買賣超（5日均線）台積電ADR與台股價差（門檻+3%）新台幣兌美元（門檻31.0元）投信買超科技權值持股變化違約交割金額（門檻單日2億）

面試角度

國泰CIM：『若你是台股投組經理人，TSMC占大盤45%的集中度風險如何管理？』中信MA：『散戶情緒高昂+外資減碼的頂部訊號出現時，你會調整哪些配置？』元大投行法金：『新台幣升破31元對台廠ECM定價、籌資窗口的影響？』富邦證券投行：『大盤4萬點下，IPO新案承銷溢價空間有多少？』

口說版

「台股盤中觸及4萬點、台積電2330元歷史新高，但外資同步賣超511億、ETF被倒貨，這就是『拉積盤』的標準頂部訊號。如果應徵國泰CIM，做投組要問三個問題——台積電的權重相對benchmark是overweight還是underweight？對沖工具用台指期還是個股call？以及散戶融資餘額（目前約3000億）是否觸頂？我對4萬點的看法是：技術面突破有意義、但成交結構的分化警告短期回測不可少。」

台積電2奈米洩密案宣判 — 東京威力科創（TEL）台灣遭罰1.5億、主嫌判10年有期徒刑

深度解析

發生什麼事

智慧財產法院4/27一審宣判台積電2奈米製程洩密案：前員工陳姓研發人員判10年有期徒刑、為近年來營業秘密法中最重判決之一；同時將機密資訊提供給競爭對手的設備商台灣東京威力科創（TEL）遭判罰金新台幣1.5億元。TEL總部緊急發聲明稱『將與客戶強化營業秘密及機密資訊保護與共享』、並撤換中國籍涉案高管。台積電強調『絕對從嚴處理、零容忍』。

解讀

這是台灣科技保護主義的指標性判決——首次將設備商納入懲處對象，意味著未來台廠對外資設備供應商的IP合規要求將大幅升級。對全球半導體供應鏈的訊號是『台廠不只防範員工、也要防範供應商』。同時東京威力科創在中國市場的政治風險也升高（已撤換中國籍高管），中美設備商進入中國的彈性將下降。

傳導鏈

TSMC洩密案重判 → 台廠對設備商的合規條款升級 → 全球設備商在台分公司加強內控 → 中國籍高管在敏感職位被排除 → 中國半導體設備本土替代壓力增加 → SMIC等中國晶圓廠被迫加速國產化 → 中微公司、北方華創訂單上行

結構性

結構：台灣對先進製程營業秘密的法律保護升級是長期、可外推到全球供應鏈；週期：個別法人懲處屬一次性事件。

矛盾訊號

TEL在台被判1.5億罰、但TEL股價（東京）上週反而上漲4%，市場認為金額相對其營收（台廠約佔TEL全球40%）為小、且事件已『法律一刀切』、不確定性消除。多空訊號顯示市場已price in最壞情境。

分叉情境

如果上訴後最終確定罰金維持1.5億、TEL在台業務照常 → 對全球半導體供應鏈影響有限、TSMC設備採購維持原計畫；如果二審加重罰、且TEL被列入TSMC敏感供應商黑名單 → ASML、TEL在台分潤的市佔可能被Lam Research、KLA分食，全球設備商版圖洗牌。

展望

短期 · 1M
短期（1個月內）：TEL台灣分公司可能進行內部組織重整、人事換血；台廠半導體設備供應商合規條款全面升級。
中期 · 3–6M
中期（3-6個月）：類似訴訟可能再現2-3起（過去24個月已有3起員工跳槽國外晶圓廠的案例）。
長期 · 1Y+
長期（1年以上）：台灣將成為全球營業秘密法律保護最嚴格的科技重鎮，吸引更多歐美機構在台設立先進製程研發中心；TSMC本土供應鏈忠誠度進一步加深。

持續追蹤

TEL股價（東京）TSMC對外資設備商採購比例變化其他類似洩密訴訟案件數中國半導體設備自主率（中微+北方華創市佔）ASML對中國二手機台政策

面試角度

中信MA投資專案：『台積電供應鏈重組對亞洲半導體設備商的M&A機會在哪裡？』國泰CIM：『TEL股票若大跌是逢低布局還是該避開？』開發資本：『台灣營業秘密法律強化對製造業海外投資結構（特別是台商赴美/赴日）的影響？』富邦證券投行：『台廠半導體公司因合規升級可能擴大資本支出，ECM需求增加多少？』

口說版

「台積電2奈米洩密案首次將設備商TEL納入懲處1.5億、主嫌判10年，這是台灣科技保護主義的指標性判決。如果應徵中信MA投資專案，這意味著未來台積電供應鏈的M&A機會將集中在『台美雙重合規架構』類標的、台廠合規IP管理SaaS（如群信、敦泰旗下子公司）會出現估值溢酬；同時這也是台灣相對韓國的策略性優勢——當韓國對營業秘密訴訟仍寬鬆，全球客戶會將敏感製程訂單向台轉移。」

旺宏Q1終結連10季虧損、董座吳敏求：NAND/eMMC缺口非常大、Flash下半年還會漲

持續追蹤中

發生什麼事

旺宏4/27法說會公布Q1 EPS 0.9元、終結連10季虧損；董座吳敏求指『NAND、eMMC缺口非常大』、預期下半年Flash記憶體價格續揚；NOR與SLC NAND將是兩大主力漲價產品；公司重啟12吋廠產能擴張計畫。

關鍵數據

Q1 EPS 0.9元（vs去年同期-1.2元）、毛利率42%（年增18個百分點）；NOR Flash報價Q2較Q1再漲8-12%、SLC NAND Q2漲10-15%。

解讀

旺宏是台灣記憶體產業的『落後復甦』指標——SK海力士Q1已展現獲利+400%、旺宏現在才終結虧損、代表中低階記憶體（NOR、SLC NAND）的供需平衡比HBM/DDR5晚3-6個月才轉緊。但反過來說，旺宏的營運槓桿巨大、若Q3 ASP續揚，全年EPS有望挑戰5元。

傳導鏈

AI伺服器需求 → 主流DRAM/HBM/eMMC供給吃緊 → 中低階NOR/SLC NAND因產能挪用而跟著缺貨 → 旺宏報價提升 → 毛利率擴張 → EPS上修

分叉情境

如果Apple/Tesla對NOR Flash需求Q3突破歷史高點（受AI on edge應用驅動） → 旺宏全年EPS上看5元、股價突破85元；如果AI on edge應用Q3落後預期 → 旺宏EPS僅3元水準、股價回測55元。

展望

短期 · 1M
短期（1個月內）：旺宏股價有機會挑戰75元（目前約62元）、本益比修正至14-16倍。
中期 · 3–6M
中期（3-6個月）：若Q3 NOR、SLC NAND漲價如預期、全年EPS可達3.5-4.5元、市場將重新給予『記憶體景氣循環復甦』溢酬。

口說版

「旺宏Q1終結連10季虧損加上董座明確指引『NAND/eMMC缺口非常大』，這是台灣記憶體景氣『落後復甦』訊號；如果應徵國泰CIM做台股投組，旺宏就是典型的高Beta、高槓桿復甦股，季度Flash報價(DRAMeXchange)是最重要的leading indicator；操作策略上不要追高，逢回到月線+5%以內加碼勝率較高。」
