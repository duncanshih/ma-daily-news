貝森特加倍長債回購 — 美式殖利率曲線控制的試水溫

發生什麼事

美國財政部19日宣布將長天期公債回購規模至少加倍，直接鎖定殖利率曲線最敏感的長端。此舉的背景是美國聯邦政府債務同日正式突破40兆美元、10年內翻超過一倍，30年期公債殖利率創下近20年（一說19年）新高。消息公布後，30年期殖利率應聲回落，美元指數跌破99關卡、觸及三個月低點，現貨黃金一度突破每盎司4,500美元，比特幣重返7萬美元、空頭24小時爆倉逾30億美元。財長貝森特今年已多次直接介入市場（從協同壓抑日圓到擴大回購），被彭博形容為數十年來對金融市場干預最積極的美國財長。經濟學家警告，財政部主動管理長端殖利率，實質上侵入了原屬聯準會的政策領域，對即將由華許（Warsh）主導的Fed構成獨立性壓力。

📐 解讀：這不是技術性的流動性管理，而是財政部在做「美式殖利率曲線控制」——當赤字大到市場不願以現價吸收長債時，發債者只好自己下場當買家。市場的反應已經給出答案：殖利率壓下去了，但美元、黃金、比特幣同步走強，反映的是貨幣貶值交易（debasement trade）。本質上這是把利率風險轉換成匯率風險，而不是消滅風險。
🔗 財政部加倍長債回購 → 30年期殖利率回落、期限溢酬暫時收斂 → 美元指數跌破99、實質利率下行 → 黃金（4,500美元）與比特幣（7萬美元）等非主權資產走強、亞幣同步升值（新台幣收31.925元） → 以美元計價的進口原物料變貴、輸入性通膨升溫 → Fed更難降息（7月紀要已在討論升息） → 長端殖利率再度上行，回購效果被抵銷
🏗️ 結構性 — 結構性。40兆美元債務存量、每年破兆美元的利息支出，疊加AI與國防資本支出同時擴張，這是財政主導（fiscal dominance）的長期格局，不是一次性的市場失序。
⚡ 矛盾訊號：財政部把這定調為例行流動性管理，但花旗等投行直接視為壓低融資成本的政策工具，並據此喊出黃金「強烈看多」；同一天Fed公布的7月會議紀要卻顯示支持升息的官員人數增加。財政部在鬆、央行在緊，兩個政策部門對通膨的判讀正好相反。
🔀 如果回購規模持續加倍且Fed在9月按兵不動，30年期殖利率有機會從近20年高點回落30-50個基點，美元指數下探96-97，黃金測試4,700-4,800美元；如果8-9月CPI因布蘭特原油站上90美元而重回3.5%以上，Fed被迫轉鷹甚至暗示升息，回購將被證明只是治標，30年期殖利率再創新高，屆時股債匯三殺的風險最高。

全球長天期公債殖利率同步飆高 — 期限溢酬的一次全球重定價

發生什麼事

美、英、德、日四國長天期公債利率同步竄升至多年高點，BBC點名油價、AI資本支出與通膨是三大推手。德國7月PPI年增3.0%，為3年多來最快漲幅，主因中間商品與能源成本上揚，顯示德國再度面臨通膨壓力。日本7月出現6,345億日圓貿易赤字、連續第3個月赤字，且規模較去年同期擴大至4倍，中東局勢推升原油成本是主因。美國方面，40兆美元債務與破兆的年度利息支出，讓投資人要求更高的期限溢酬。NPR則直接提醒散戶：債券市場正在對美國經濟發出警訊。這不是單一國家的財政問題，而是全球債市同時在對「高通膨＋高財政赤字＋高資本支出」的新組合重新定價。

📐 解讀：市場正在拆掉過去15年「長債＝避險資產」的假設。當通膨的不確定性上升，長債與股票的相關性由負轉正，長債不再是股票的對沖工具，投資人就必須要求更高的補償，這就是期限溢酬擴張的本質。這是基本面的重定價，不是情緒性恐慌——所以它不會因為一次央行喊話就結束。
🔗 布蘭特原油站上90美元＋AI資料中心電力需求 → 各國PPI／CPI再度上行（德國7月PPI +3.0%、日本貿易赤字擴大4倍） → 通膨預期的不確定性升高 → 長債期限溢酬擴張 → 各國政府融資成本上升、財政空間收窄 → 政府被迫縮減支出或加稅 → 內需放緩、企業折現率上升 → 成長股與長天期實體資產（基建、不動產）評價同步受壓
🏗️ 結構性 — 結構性為主。能源轉型與AI基建都是長達10年的資本支出週期，會持續佔用實體資源與資金；疊加人口老化下的社福支出剛性，赤字無法靠景氣回升自然消化。
⚡ 矛盾訊號：全球長債殖利率同步飆升，唯獨中國公債殖利率維持低檔，CNBC因此指出中國債券的分散配置價值正在上升。同一個宏觀環境，一邊是通膨與赤字推升殖利率，一邊是通縮壓抑殖利率——這代表全球債市已經不是同一個週期，配置上不能再用單一「全球債券」的思維。
🔀 如果布蘭特原油在9月底前回落至80美元以下，德國PPI與日本進口成本壓力同步緩解，10年期德債與30年期日債殖利率有機會回落20-30個基點，全球股市評價壓力解除；如果布蘭特因荷莫茲海峽持續封鎖而站上100美元，歐洲與日本將同時面臨輸入性通膨加貿易赤字，日本央行被迫加速升息，日圓套利交易（carry trade）平倉會是全球風險資產最大的單一風險事件。

短期（1個月內）：短期（1個月內）：在美國財政部回購與各國財政部調整發行結構的短暫支撐下，長端殖利率高檔震盪；但只要月度CPI／PPI持續高於央行目標，任何回落都只是技術性的。

中期（3-6個月）：中期（3-6個月）：日本是最脆弱的一環——連3個月貿易赤字、規模擴大至4倍，日圓貶值與輸入性通膨形成正回饋，日銀升息機率上升，30年期日債殖利率有機會再上行30-50個基點。

恒大許家印判無期徒刑 — 中國房地產出清從財務重組進入司法問責

發生什麼事
