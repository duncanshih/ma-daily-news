總經 / 地緣政治

噩夢週後的反彈與政策裂痕 — 那指期貨+3%、輝達盤前+10%，貝森特公開警告Fed「過度緊縮是嚴重錯誤」

深度解析

發生什麼事

經歷那斯達克單週下跌10%（2020年新冠以來最差）、標普500單週下跌8.61%、歐股單週下跌約6%（2025年3月以來最大）後，週一美股期貨大幅反彈：道瓊期貨+761點（+1.58%）、標普期貨+2.24%、那斯達克100期貨+3%，輝達盤前上漲近10%、Anthropic與Sandisk同步走強，VIX上週一度突破40、創2025年4月以來最高。美債殖利率同步跳升，部分回吐上週末的避險買盤，市場等待紐約Fed總裁Williams講話。政策面出現罕見分歧：財長貝森特公開警告Fed若在股市暴跌時持續收緊「將是嚴重政策錯誤、甚至威脅金融體系穩定」，但Fed理事庫克同日表示遏制通膨擴散「愈發緊迫」，延後行動只會被迫更快升到更高。摩根資產管理則指出，在AI相關舉債潮消退前，主權債殖利率難以大幅回落；華爾街仍偏好押注Fed守住抗通膨承諾的殖利率曲線趨平交易。

解讀

這是典型的「超賣反彈 + 政策口水戰」組合。上週的跌勢主要是CTA與融資部位的機械式去槓桿，VIX破40、台股融資單日減10%都是部位出清訊號，因此週一反彈是部位面而非基本面。真正的新訊息是貝森特與庫克的公開對撞：財政部需要股市穩定來支撐IPO窗口與財富效應，Fed需要用鷹派語言壓住通膨預期。這種分歧本身會提高12月FOMC的尾部風險——若Fed為了捍衛獨立性而照升，市場會把它解讀為「Fed不在乎股市」；若Fed暫停，又會被解讀為「屈服於政治壓力」，兩種結果都不利於波動率回落。

傳導鏈

上週去槓桿賣壓出清（融資、CTA） → VIX破40觸發逆向買盤、期貨反彈3% → 美債殖利率回升、黃金自月跌幅反彈 → 貝森特介入施壓Fed、庫克反向強調升息緊迫 → 市場對12月升息定價在50-70%間劇烈擺盪 → 美元與亞幣波動放大 → 台韓外資流向短線跟著Fed預期而非基本面擺動

結構性

週期（部位去槓桿後的技術性反彈），但「財政部對Fed公開施壓」若成為常態，會結構性提高美債期限溢價

矛盾訊號

貝森特說Fed過度緊縮是錯誤，庫克說延後升息才是錯誤；市場同時相信「VIX破40是底部訊號」與「Fed 12月還會升息」。另一個矛盾：摩根資產管理說AI舉債潮壓住債市，但AI資本支出放緩本身會減少發債供給——債市到底該漲還是跌，取決於AI capex是「放緩」還是「崩塌」。

分叉情境

如果Williams本週講話轉向「金融條件已顯著緊縮」且12月升息定價跌破40%，標普可在一週內收復7,100-7,200、VIX回落至22以下；如果Fed官員維持鷹派、12/4非農仍高於15萬，反彈將在7,000-7,100遇壓，並在12/10 CPI前重新測試6,850-6,900，VIX重回30以上

深度解析

發生什麼事

工商時報統計，過去12個月台灣「雙貸族」（同時背房貸與信貸）信貸金額增加1,044億元、人數突破43萬人創歷史新高；中央社引述房仲指出，今年前3季全國建物買賣移轉棟數減少，但抵押權設定棟數卻逆勢增加，推測民眾透過房屋增貸取得資金投入股市是主因之一。台股在不到2個月內從近5萬點（10/6高點49,968）下探3萬5千餘點，借錢投資的風險浮現，房仲憂心若信心無法回穩，房市盤整期將被拉長。同日央行公布10月全體貨幣機構對民間部門債權達49兆9,591億元、逼近50兆元創新高，顯示整體槓桿仍在擴張。供給端則出現兩個訊號：富旺董事長林宗毅表示，換屋族第二戶貸款成數提升至七成後，Q4賞屋人潮與詢問度明顯升溫；台灣金聯與彰化銀行簽署「續建資金承諾」、成為第三家結盟公股銀，為建商資金缺口建立續建安全網以防爛尾樓。美國方面，CNBC指出9月房貸利率急升已把原本就冷的房市推入「深凍」，買賣雙方與整體經濟同受衝擊。

解讀

「抵押權設定增加但買賣移轉減少」是最乾淨的借房炒股證據——不是買房的人在增貸，是已經有房的人在拿房子換現金進股市。43萬雙貸族中若有三成是2026年才加槓桿、進場均價在45,000點以上，這群人現在同時面臨股票浮虧30%與房貸利率即將上升（央行估兩季各升半碼）的雙重壓力，第一個斷點會是信貸的循環額度到期而非房貸違約。這代表房市的調整路徑不是「價格崩跌」而是「成交量凍結＋議價空間擴大」——與美國目前的「深凍」狀態是同一種病理，只是病因不同（美國是利率太高買不起，台灣是資金被套在股市不敢買）。

傳導鏈

台股自高點跌28%、融資維持率逼近追繳線 → 雙貸族須補繳保證金或賣股認賠 → 信貸循環額度到期時無法展延、房屋增貸空間被央行限貸令封死 → 被迫出售持有的第二屋或投資型住宅 → 中古屋賣壓增加、議價空間從5%擴大到8-10% → 新成屋因建商財務壓力（續建資金承諾機制啟動代表銀行已在防爛尾）而降價促銷 → 房價指數Q1-Q2 2027年修正3-5%、成交量年減15-20%

結構性

週期（槓桿去化），但「以房養股」的槓桿結構在台灣是2024-2026年的新現象，去化過程將比2016年的純房市修正更劇烈

矛盾訊號

富旺說Q4賞屋人潮升溫（第二戶貸款成數鬆綁）、宏璟/國建/達麗前三季獲利創高，但雙貸族與抵押權設定數據顯示資金正從房市流向股市而非反向；建商看到的是「政策鬆綁帶來的詢問度」，銀行看到的是「需要續建資金承諾才敢放款」。另一個矛盾：央行說民間債權近50兆創新高（放款很鬆），銀行公會說「台灣已無廉價資金」（放款很緊）。

分叉情境

如果台股在12月守住35,000點且央行12月僅升半碼，雙貸族壓力止於「停止加碼」、房市進入6-9個月的量縮盤整、價格持平至-3%；如果台股再探33,000以下且融資維持率追繳潮在12月中爆發，雙貸族被迫處分資產的賣壓將在2027年Q1顯現，六都中古屋價格修正5-8%、新成屋降價促銷案比例從目前的不到一成升至三成以上

解讀

混合資本的興起代表私募股權的「估值僵局」仍未解：GP不願以低於帳面的價格出售、LP不願再出資，所以用優先股／結構性債務把估值爭議「延後」到下一輪。這跟接續基金「賣給自己」是同一個邏輯——都是用金融工程取代真實的價格發現。「大型IPO小流通量」則是公開市場版本的同一現象：用稀缺性撐住首日定價。這三件事合在一起，顯示私募資產的真實清算價值仍低於帳面10-20%，而上週美股修正會讓這個折價進一步擴大。中國重啟美國PE往來是值得注意的逆向訊號：當西方LP縮手時，人民幣資金成為GP的新金主，但地緣風險會讓這類資金在CFIUS審查下受限。

深度解析

發生什麼事

CrowdStrike週一宣布以全股票方式收購Zscaler，交易對Zscaler估值約439億美元，為資安產業史上最大併購；上週四報導傳出洽購時Zscaler股價已跳漲18%。FT指出，交易發生在全球企業與政府正面對一波科技當機與網路攻擊之際：美國最大原油出口樞紐的港口每天回報數千次駭侵嘗試、航運公司正與資料外洩搏鬥；Visa、萬事達卡與摩根大通的客戶資料因第三方供應商遭駭外洩（n0n勒索組織宣稱犯案）；FBI的國家犯罪資訊中心資料庫傳出第二次遭入侵；美國國家情報總監Clayton警告，隨著企業與政府汰換老舊系統，民眾應預期感恩節期間將有更多當機與服務中斷（此前FAA、Microsoft 365與部分銀行交易已先後中斷）。此交易延續上週的資安整併潮：Palo Alto以45億美元買Applied Compute、Intuit以36.8億美元賤賣Mailchimp給Bending Spoons。台灣端，數發部長林宜敬表示政府網路每日抵禦約280萬次攻擊，並正在切斷智慧城市「不必要的連線」。

解讀

這是一筆「用高估值股票買高估值股票」的防禦性併購：CrowdStrike選擇全股票而非現金，一方面是自身股價在資安需求爆發期仍處高檔（相對AI硬體股抗跌），另一方面是避免在信用利差走寬時舉債。戰略邏輯是「端點（CrowdStrike）＋網路/零信任（Zscaler）」的平台整合，對抗微軟與Palo Alto的全棧方案。更深層的訊號是：當AI基建股在修正時，資本正流向「AI時代的保險」——資安是少數需求與AI滲透率正相關、但估值與AI capex週期負相關的產業。對投行而言，這類全股票交易的關鍵風險是換股比例在波動市場中的重新談判，以及反壟斷審查（兩家合計在零信任市場的份額）。

傳導鏈

連環科技當機與國安級駭侵（FBI、港口、Visa/JPM） → 企業與政府資安預算從IT預算的8-10%升至12-15% → 資安龍頭估值抗跌、成為AI修正期的資金避風港 → CrowdStrike以高估值股票為貨幣完成439億美元併購 → 產業進入「平台化」整併，中型資安公司（Zscaler、Okta、SentinelOne等）成為被併標的 → 資安IPO與併購成為2027年投行費用的主要來源之一 → 台灣資安服務商（中保科、資通等）與零信任解決方案商受惠於政府「切斷不必要連線」政策

解讀

COP31的失敗不是意外而是「多邊共識機制的正式失靈」：當美國退出、中國把氣候當作地緣槓桿、產油國把化石燃料退場視為生存威脅時，需要全體一致的UNFCCC程序必然破局。但同週英歐ETS接軌說明氣候治理並未消失，而是從「全球共識」轉向「俱樂部模式」——有共同碳價的經濟體互免碳關稅、對外築牆。這對台灣是結構性風險：台灣碳費（每噸300元）遠低於歐盟ETS（約70歐元），若「碳俱樂部」擴大（英歐、接下來可能是日韓、加拿大），台灣出口將面臨多重CBAM。對投資而言，COP破局短期利多化石燃料與傳統能源基建（政策風險降低），但中長期反而加速「碳俱樂部內部」的綠色資本支出，因為CBAM讓碳價可以被轉嫁。

深度解析

發生什麼事

行政院長卓榮泰23日下午邀集金融業、科技業及工商產業公協會代表召開財經會議。銀行公會理事長（兆豐金董事長）董瑞斌表示，隨AI與資通訊產業資金需求大增，銀行面臨流動性覆蓋比率（LCR）挑戰、必須提高資金成本吸收存款，未來放款利率將跟著提高，「台灣不缺資金，但已經沒有廉價的資金」，科技業或可承受、但中小企業與傳統產業恐受較大衝擊，與會銀行承諾不抽銀根；央行同日公布10月全體貨幣機構對民間部門債權達49兆9,591億元創新高。產業端則一片樂觀：台灣半導體產業協會理事長侯永清（台積電資深副總）預估半導體產值從2025年約6.5兆元成長至2026年9兆1,900億元、年增逾40%，「未見客戶調整訂單或出貨」、先進製程持續供不應求；SEMI台灣總裁曹世綸稱台灣半導體供應鏈到2028-2029年仍供不應求、目前無主要業者下修短期AI展望；電電公會理事長（鴻海董事長）劉揚偉提出「四個相信」，稱AI訂單能見度延伸至2029年底、台灣供應鏈占AI逾9成；宏碁董事長陳俊聖稱2027年COMPUTEX展位一位難求。經濟部長龔明鑫估今年全年經濟成長率超過12%。金融配套：財政部研擬擴大「金融支持措施」適用對象（貿易融資利息減碼、輸出保險費減免），公股銀對中小微企業放款餘額逾6兆元；壽險公會理事長陳慧遊呼籲業者發揮30兆資金「壓艙石」角色並爭取調降台股風險係數；金管會主委彭金隆宣布27日開會全面檢討處置股機制、評估股市震盪對企業籌資的影響；業界並盼檢討擴大國安基金規模與啟動時機。

解讀

這場會議最有價值的訊息不是產業界的樂觀喊話（那是救市會議的例行台詞），而是董瑞斌說出的「沒有廉價資金」——這是台灣銀行體系15年來第一次承認資金成本結構性上升。背後機制是：AI製造業的巨額資本支出（台積電、鴻海、廣達的建廠與設備）吸走了銀行放款額度，民間債權近50兆創新高，LCR逼近監理下限，銀行必須用更高利率搶存款，而這個成本最終會轉嫁給議價能力最弱的傳產與中小企業。這形成了台灣版的「擠出效應」：AI產業的榮景正在推高非AI產業的資金成本。產業界「訂單到2029年」與外資「連8週賣超3兆」的矛盾，本質是「數量 vs. 價格」的分歧——訂單數量確實滿載，但市場在重估這些訂單的利潤率（伺服器加價45%代表成本轉嫁戰已開打）與終端需求的可持續性。經長「GDP成長破12%」是驚人數字，但它幾乎全由AI出口貢獻，內需與傳產的實質成長可能低於2%，這正是董瑞斌警告的結構。

央行23日公布10月金融情況：被視為「散戶風向球」的證券劃撥存款餘額降至4兆1,963億元、較9月大減5,018億元，寫下史上最大單月減額（9月曾月增1,269億至4兆6,981億的歷史高點）；但上市櫃融資餘額卻逆勢攀升至8,454億元續創新高，呈現「存款縮水、融資增加」的兩樣情，顯示散戶是「用槓桿換現金」而非離場。M1B年增率降至7.08%、M2降至7.11%。匯市方面，新台幣23日早盤一度貶至32.999元、距33元僅一步，午後隨台股翻紅、出口商拋匯而轉升，終場收32.895元、升4.1分、連3升，成交量30.58億美元，但匯銀人士認為恐慌未退、本週仍可能貶破33元。主計總處公布10月失業率3.35%、連2月下滑、為26年同月最低，勞參率59.63%創37年同月最高。另外，上市櫃21檔11/24起列入處置股（含健策、聯亞、漢測等千金股），11檔因淨值低於票面暫停融資券。

關鍵數據

證券劃撥存款4兆1,963億（月減5,018億，史上最大）；融資餘額8,454億（新高）；M1B年增7.08%、M2年增7.11%；新台幣32.895（連3升）；10月失業率3.35%、勞參率59.63%

解讀

「劃撥存款減5,018億、融資卻創新高」是這次股災最危險的散戶行為特徵：10月散戶把帳戶現金抽走（可能是獲利了結或轉去還信貸），但同時把持股改用融資撐著——等於把自有資金的部位換成槓桿部位。11/20融資單日減491億的30年最大退潮，就是這個結構在11月被強制拆解的結果。10月數據是「暴風前的槓桿堆積」，11月數據（12月下旬公布）才會顯示散戶真正的受傷程度。勞動市場數據（失業率26年同月最低、勞參率37年最高）則顯示實體經濟仍熱，與金融市場的恐慌脫鉤——這給了央行12月升半碼的底氣，但也意味著「股災→失業→消費」的傳導目前尚未發生。新台幣在33元前的拉鋸是外資匯出與出口商拋匯的對決，央行「守32字頭」的意志明確。

傳導鏈

10月散戶抽走5,018億現金但融資增至8,454億 → 11月股災觸發融資維持率追繳、單日減491億 → 融資維持率降至120%延緩第二波追繳 → 散戶信心（劃撥存款）12月下旬公布的11月數據將再減3,000-5,000億 → 消費動能受財富效應影響在2027年Q1放緩（百貨周年慶已見買氣停滯） → 但勞動市場強勁（失業率3.35%）緩衝衝擊 → 央行在「金融穩定 vs. 通膨」間選擇12月升半碼的機率仍高 → 新台幣在升息預期與外資匯出間於32.5-33.2拉鋸

分叉情境

如果11月劃撥存款減幅低於3,000億且融資餘額止穩在8,000億附近，代表散戶已完成去槓桿、12月反彈有散戶回流支撐；如果11月劃撥存款減幅超過5,000億（連兩月創紀錄），散戶將進入「賣股還債」階段，2027年Q1消費與房市同步降溫，央行被迫在12月按兵不動

展望

短期 · 1M
短期：新台幣32.7-33.2區間，33元是央行防線、外資若續賣超每日200億以上將測試；12月下旬公布的11月證券劃撥存款預估再減3,000-5,000億、融資餘額降至7,500-8,000億
中期 · 3–6M
中期（3-6個月）：散戶信心修復至少需要一季，劃撥存款回到4.5兆以上要到2027年Q2；央行12月若升半碼、重貼現率升至2.125%，新台幣在2027年Q1因利差收斂回升至32.3-32.5；零售消費年增率從目前約3%降至1-2%

口說版

「10月央行數據揭露了這次股災最危險的散戶行為：證券劃撥存款單月減5,018億創史上最大，但融資餘額卻創新高到8,454億——散戶是把自有資金抽走、改用槓桿撐部位，等於主動把安全部位換成風險部位，11月融資單日減491億的30年最大退潮就是這個結構被強制拆解的結果。我認為真正的傷害要看12月下旬公布的11月數據。另一方面，失業率3.35%創26年同月最低、勞參率創37年最高，實體經濟仍熱，股災到消費的傳導還沒發生，這給央行12月升半碼的底氣。從國泰CIM外匯部位的角度，新台幣33元是央行防線，我會在32.9-33.0區間做多新台幣，賭央行守關加上升息預期。」
