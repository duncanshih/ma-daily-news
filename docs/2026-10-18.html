🌍 總經 / 地緣政治

英國央行示警避險基金推升債市崩跌風險 — 「AI避險買債」與「財政赤字賣債」正在拉扯殖利率

發生什麼事

英國央行副總裁警告，避險基金在公債市場的槓桿操作（如現貨與期貨的基差交易）可能放大一次全球債市衝擊，因為一旦保證金追繳，部位會被迫同步拆解。同時，歐洲央行總裁Lagarde表示近期全球債市賣壓（法國受創最重）推高融資成本，反而有助壓低通膨。背景是美國2026財年赤字逼近2兆美元、年增12%，IMF總裁喬治艾娃直言財長貝森特靠成長解決40兆美元債務「不夠快」，需要財政整頓。但本週情勢出現反轉：AI科技股重挫讓資金湧入美債，FT指出這一波避險買盤中止了延續數月的公債賣壓。

📐 解讀：債市本週的上漲是「避險需求」而非「基本面改善」：赤字、3.7%的CPI與Fed鷹派發言都沒變，只是AI股的恐慌暫時壓過財政恐慌。真正的風險在於市場結構——當避險基金槓桿部位集中，殖利率的方向一旦反轉，波動會被非線性放大，類似2020年3月與2022年英國LDI危機。
🔗 美國赤字近2兆美元 → 公債供給持續增加 → 避險基金承接並以基差交易加槓桿 → 殖利率急升觸發保證金追繳 → 被迫拋售公債、流動性斷層 → 全球長端利率飆升、壽險與退休基金資產評價受壓 → 央行被迫介入購債
🏗️ 結構性 — 結構性：財政赤字常態化與公債市場由非銀行機構主導是長期變化；本週的避險買盤則是週期性、情緒性的短期現象。
⚡ 矛盾訊號：Lagarde認為債市賣壓會降溫通膨（等同幫央行緊縮），但Fed的Hammack仍主張需要更高利率以防「通膨心態」生根；同一個殖利率上升，被一方視為政策工具、另一方視為金融穩定威脅。
🔀 如果AI股在11月財報季止穩、資金流回股市，美10年債殖利率可能重回5%以上並測試5.2%，基差交易拆倉風險上升；如果AI股持續下修且期中選舉後財政整頓訊號出現，殖利率可能回落至4.5%-4.7%區間，壽險業持有的長債評價回升。

🔭 展望

短期（1個月內）：1個月內：殖利率在AI避險與財政供給間拉扯，10年債預估4.6%-5.1%區間震盪，關注11月初美國財政部季度再融資公告（QRA）的發債規模。

中期（3-6個月）：3-6個月：若Fed於12月再升息一次，短端上行、長端受避險壓抑，殖利率曲線可能趨平；各國監管機關可能提高基差交易保證金要求。

長期（1年以上）：1年以上：公債「無風險」地位被財政紀律侵蝕，期限溢價（term premium）中樞上移50-100個基點，成為所有資產估值的新底線。

📡 持續追蹤：
  • 美國10年期公債殖利率與期限溢價
  • CFTC公債期貨槓桿基金空單部位
  • 美國財政部11月季度再融資規模
  • MOVE債市波動率指數

🔄 川普豁免對俄新制裁換柴油供給（持續追蹤）

發生什麼事

川普正式豁免9月簽署之《葛蘭姆法案》所要求的對俄新制裁與關稅，FT指出這是在與莫斯科達成柴油釋出協議後給普丁的「緩刑」。澤倫斯基批評此舉「錯誤」，共和黨內也有議員公開反對。CNBC估算，俄羅斯柴油協議的量不到美國兩週需求，分析師認為對油價的實質壓抑有限，但對烏克蘭的談判籌碼與西方制裁信用傷害更大。

關鍵數據

柴油協議量＜美國2週需求；期中選舉距今不到3週；IEA同步釋出逾2,000萬桶柴油

📐 解讀：這是選舉驅動的能源外交：以制裁信用換取短期油價觀感。供給量有限代表價格效果多為心理面，但它傳遞了「制裁可被交易」的訊號，會削弱未來對伊朗、俄羅斯影子船隊的施壓效果。
🔗 期中選舉前油價壓力 → 豁免對俄制裁換柴油 → 俄羅斯能源出口收入與議價力上升 → 烏克蘭加強打擊俄煉油廠 → 東歐能源設施風險升高 → 柴油價差（crack spread）維持高檔
🔀 如果選後川普恢復制裁，柴油供給預期再收緊，柴油價差可能擴大10%-15%；如果豁免延長並擴及影子船隊，俄伊石油出口回升，布蘭特可能回落至95-100美元。

🔭 展望

短期（1個月內）：1個月內：選前美國柴油零售價可能小幅回落，但烏軍對聖彼得堡等能源設施的無人機攻擊使俄羅斯實際出口量存在不確定性。

中期（3-6個月）：3-6個月：若選後政策轉向，制裁可能重新啟動；歐洲對俄資產（比利時凍結資產）處置議題升溫。

💬 口說版：「川普用對俄制裁換來的柴油不到美國兩週需求，價格效果有限，但它讓市場看到制裁是可以交易的。對開發資本這類投資能源基建的機構，我會把『政策可逆性』納入風險溢價，而不是只看當下油價。」

🔄 Fed升息路徑：CPI 3.7%、Williams與Hammack鷹鴿分歧（持續追蹤）

發生什麼事

美國9月CPI年增3.7%、高於預期，主要由汽車燃料推升，社會安全福利將隨之調升。紐約Fed總裁Williams預期2026年再升息一次、2027年不需再升，與交易員預期不一致；克里夫蘭Fed總裁Hammack則認為可能需要更高利率防止「通膨心態」生根。預測市場認為通膨今年可能已見頂，但核心通膨難降至2.2%。

關鍵數據

9月CPI年增3.7%；Fed預期2026年再升息1次；預測市場：核心通膨年底難降至2.2%

📐 解讀：通膨的主因是能源供給衝擊而非需求過熱，升息對油價無效，卻會傷害信用市場；Fed內部分歧反映「打供給型通膨」的兩難。AI股重挫導致金融條件自然收緊，可能讓Fed少升一次。
🔗 荷姆茲攻擊推升油價 → 汽油柴油上漲推高CPI至3.7% → Fed鷹派升息預期 → 美元與台美利差擴大 → 外資匯出亞洲、新台幣週貶1.45% → 台灣央行面臨跟升壓力
🔀 如果10月CPI續升至3.9%以上，Fed可能12月升息一碼並暗示2027年仍有空間；如果AI股修正擴大、信用利差擴張超過100個基點，Fed可能以金融穩定為由暫停升息。

🔭 展望

短期（1個月內）：1個月內：10月底FOMC前市場聚焦能源價格，若布蘭特維持105美元以上，12月升息機率維持高檔。

中期（3-6個月）：3-6個月：若油價回落至95美元以下，CPI可能於2027年第一季降至3%左右，Fed有空間暫停。

💬 口說版：「這波3.7%的通膨主要來自油價這種供給衝擊，升息壓不了油價，卻會傷到已經很緊的AI信用市場，所以我認為Fed內部分歧會持續。對國泰CIM的債券部位來說，短端升息、長端被避險壓住，曲線趨平是比較可能的情境。」

🏢 不動產 / 私募

壽險業砸重金卡位養生宅 — 凱基人壽百億標下信義區地上權，保險資金轉向銀髮實體資產

發生什麼事

中央社報導，壽險業為打造新營運動能，積極布局「銀髮樂齡」住宅商機。台灣人壽布局最廣，已在台南、台中與高雄籌設健康宅；凱基人壽今年砸下百億元，標下台北市信義區陸保廠C區基地地上權，正式進軍康養住宅市場。同時自由財經系列報導指出，全台近9成縣市住宅已陷入高齡化，台北市「人老屋也老」的雙老問題最嚴重，過去12年台北市淨遷出人數相當於一個嘉義市人口。另據經濟日報，壽險業也針對失智風險規劃保單共管人機制。

📐 解讀：這不是單純的不動產投資，而是壽險業的「負債端與資產端整合」：保戶老化帶來長照與居住需求，壽險公司把保費投入能產生穩定租金的康養資產，同時延伸服務鏈。地上權模式降低土地取得成本，但也意味著資產沒有土地增值、只靠營運現金流，營運能力決定成敗。
🔗 人口老化與雙老問題 → 銀髮居住與照護需求上升 → 壽險業以地上權取得都會區基地 → 長天期、穩定租金收益配對長期保單負債 → 改善ALM存續期間缺口、降低對海外債券依賴 → 營建、物業管理、醫療照護產業鏈受益
🏗️ 結構性 — 結構性：台灣2025年已進入超高齡社會，銀髮需求是不可逆的人口趨勢，與房市週期關聯低。
⚡ 矛盾訊號：政策面打炒房使全台房貸負擔率降至41.46%、房市降溫，但壽險業反而加碼不動產；差別在於壽險業買的是「營運型收益資產」而非「價差型住宅」，兩者並不矛盾，卻常被混為一談。
🔀 如果康養宅入住率能在營運第3年達到80%以上、租金收益率維持3%-4%，將與壽險業的負債成本相當，可望複製到其他都會區；如果入住率低於60%或照護人力不足（餐飲零售業已出現斷崖式缺工），地上權租金與營運成本將侵蝕報酬，可能拖累IFRS 17下的合約服務邊際（CSM）。

🔭 展望

短期（1個月內）：1個月內：觀察其他壽險業者是否跟進參與國有地地上權標案，以及金管會對壽險不動產投資收益率門檻的態度。

中期（3-6個月）：3-6個月：預期更多公有地地上權、BOT案釋出，壽險業與醫療集團、建商的合資模式將成為主流。

長期（1年以上）：1年以上：康養住宅可能發展為REITs或私募基金化的獨立資產類別，提供壽險業退場與再投資管道。

📡 持續追蹤：
  • 公有地地上權標案得標權利金與年租
  • 壽險業不動產投資收益率
  • 高齡人口比率與長照需求
  • 照護人力缺口數據
💡 面試角度：中信MA投資專案會問：康養宅專案的IRR怎麼估？入住率與營運成本的敏感度分析要怎麼做？開發資本會問：這類具社會基礎建設性質的資產，與傳統基建的現金流特性有何異同？國泰CIM會問：從ALM角度，這類資產適合配置多少比重？
💬 口說版：「凱基人壽百億標下信義區地上權、台灣人壽在三都布局健康宅，我認為本質是壽險業用長天期營運型資產去配對老化保戶的負債。地上權沒有土地增值，報酬完全取決於入住率與營運能力，所以如果我在中信做這類專案評估，會把入住率與照護人力成本當成最關鍵的敏感度變數。」

🔗 資料中心IPO受挫 → 私募基金與基建基金退場受阻 → 新案融資利差擴大 → 開發商延緩新建案 → 電力設備與營建訂單放緩 → 能源股（BE、GEV）承壓
