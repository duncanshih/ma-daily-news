貝森特擴大公債回購護盤失利 — 40兆美債時代，財政部只能用信用卡繳房貸

發生什麼事

美國財政部8月19日宣布，未來一季將把10年期、20年期與30年期公債的回購規模「至少擴大一倍」至40億美元，試圖壓抑急升的長天期殖利率。消息當天債息回落、美股三大指數收高，但效果僅維持不到24小時：週四10年期指標公債殖利率反彈逾5個基點至4.704%，30年期殖利率則已站上近20年最高水準。背景是美國聯邦政府債務8月18日正式突破40兆美元，較2017年整整翻倍，光是利息支出一年就超過1兆美元；以債務占GDP計算，美國約125.8%，全球仍有8國高於美國，日本以204%居首。貝森特週四表示可能進一步擴大回購規模，並在川普指示下與白宮預算管理局長沃特協作，這種「財政部下場護盤」的做法引發市場對政策干預常態化的疑慮。摩根大通的James Sullivan直言，這等於「用信用卡繳房貸」，只是把問題往後推。資金轉向避險資產：金價自7月底每盎司4,000美元附近的底部一路走高，比特幣本週漲近20%、可望創三年多來最佳單週表現，美元指數本週估跌近1%。

📐 解讀：這不是技術性流動性操作，而是財政主導（fiscal dominance）的預演——當財政部而非央行下場管理殖利率曲線，市場定價的就不再只是通膨與成長，而是「政策可信度」本身。40億美元的回購規模，相對於32兆美元的可交易公債市場根本是杯水車薪（不到0.0125%），真正的訊號價值在於：財政部承認5%的長端殖利率是它不能接受的水準。市場立刻做出的反應——賣美元、買黃金與比特幣——是教科書式的「不信任投票」：投資人不是在賭通膨，而是在賭美元計價資產的長期實質報酬率被政治因素侵蝕。
🔗 美債破40兆＋利息支出超1兆美元 → 長端供給預期上修、期限溢酬走升 → 30年殖利率創20年高 → 財政部擴大回購護盤（40億美元） → 市場判定「財政主導」風險上升 → 賣美元、買黃金／比特幣 → 美元走弱推升非美貨幣（新台幣、韓元） → 台灣壽險業避險成本與海外債部位評價同步波動
🏗️ 結構性 — 結構性。40兆美元債務與每年逾1兆美元利息支出是不可逆的存量問題，回購只影響存續期分布而非總量；判斷依據是即使在回購加碼下殖利率仍走升，代表市場定價的是財政軌跡而非流動性摩擦。
⚡ 矛盾訊號：貝森特一方面說「美國預算赤字很有可能已經見頂」，另一方面又要靠擴大回購來壓抑殖利率——如果赤字真的見頂，債市不需要護盤。同時，債券投資人拋售長債的同時，貨幣市場基金規模仍在替股市提供「火箭燃料」，代表資金不是離開美元資產，而是集體縮短存續期。這種「短端滿手現金、長端無人接盤」的組合，才是真正的訊號。
🔀 如果9月財政部再度加碼回購（例如提高到每月80-100億美元）而30年殖利率仍站上5.0%，代表干預失效，美元指數可能再跌3-5%、金價挑戰每盎司4,500美元，新台幣有機會升破31.0元；如果聯準會9月釋出鴿派訊號、同時伊朗局勢降溫使油價回落至每桶80美元以下，長端殖利率有望回落至4.3-4.5%區間，美元反彈、黃金與比特幣的避險溢價將快速消風。

日本7月通膨創今年新高、日銀9月升息壓力升溫 — 但日圓干預反而「加持」了套利交易

發生什麼事

日本7月總體通膨率升至今年最高水準，核心CPI（排除生鮮食品但含能源）年增1.8%，與市場預期一致，主要推力來自伊朗戰爭推升的能源價格。這份數據把日本央行推到9月會議升息的風口上。弔詭的是，日本先前那次歷史性的日圓干預（與美方聯手）並沒有讓日圓走強：CNBC引述交易員指出，干預反而「加持」（turbo-charged）了套利交易——因為官方進場提供了更好的賣出價位與更低的短期波動率，等於替carry trade投資人補貼了進場成本。日本國內資金面同步出現變化：日本散戶持續減碼日股，賣超金額創4個月新高，日經指數週五跌0.3%、險守66,000點，靠半導體股撐盤。

📐 解讀：這是典型的「政策工具反向作用」案例。匯率干預只有在改變利差預期時才有效，如果央行沒有同步升息，干預只是替空頭提供流動性。核心CPI 1.8%仍低於2%目標，日銀其實沒有非升不可的壓力，但能源輸入型通膨若持續，實質薪資會被侵蝕、內需轉弱，反而讓日銀陷入「升息打壓需求 vs. 不升息日圓續貶」的兩難。我判斷日銀9月升息的機率過半，但幅度會很保守（15-25個基點），且會強調不是升息循環的開始。
🔗 伊朗戰爭推升能源價格 → 日本輸入型通膨、7月核心CPI升至1.8% → 日銀9月升息壓力上升 → 但干預未改變利差、日圓仍弱 → 套利交易（借日圓買高息資產）規模擴大 → 全球風險資產獲得廉價資金支撐 → 一旦日銀真的升息或美債殖利率急跌，carry trade平倉將同步衝擊美股、韓股與台股 → 台灣外資賣壓與新台幣波動放大
🏗️ 結構性 — 週期性為主但夾帶結構轉折。能源價格是週期變數，但日本從「零利率永久化」轉向正常化是三十年一次的結構性轉折，判斷依據是核心CPI已連續維持在1.5%以上、且日銀已進入實質升息討論而非僅口頭指引。
⚡ 矛盾訊號：官方說法是干預為了「捍衛日圓」，但市場實際結果是carry trade規模變大、日圓更弱——這是最典型的訊號衝突。另一個矛盾：日經站在66,000點高檔，但日本散戶卻連續賣超、金額創4個月新高，代表撐盤的是外資與企業回購，不是本地資金信心。
🔀 如果日銀9月升息25個基點且同步縮減購債，日圓有機會從目前水準升值3-5%，carry trade平倉將使那斯達克與台股在兩週內出現5-8%的回檔；如果日銀因為核心CPI仍低於2%而按兵不動、且油價續漲至每桶95美元以上，日圓可能再貶3%，套利資金持續外流反而短線利多亞股，但累積的平倉風險會遞延到年底。

📐 解讀：這三則消息拼起來是一條完整的政策線：台灣正在把「壽險業的資金過剩」與「公共建設的資金缺口」接在一起，而AI算力中心被納入公建標的是關鍵轉折——它把資料中心從「科技業的資本支出」重新定義成「具公共利益的基礎設施資產」。這在投資邏輯上非常重要：一旦被歸類為公建，壽險資金可以用更長的期限、更低的報酬率門檻進場，資產的估值基準會從「科技業EV/EBITDA」轉向「基建的現金流折現與資本化率」。REIT修法則是打通退場機制的最後一哩路——沒有流動的次級市場，長期資金不敢進場。

發生什麼事

英國氣象局8月21日預測，今年的聖嬰現象（El Niño）將是逾百年來最強，海面溫度恐攀升至「前所未聞」的水準。實體衝擊已經出現在三條戰線上：第一，巴拿馬運河管理局宣布將減少每日通行船舶數量，這是該運河史上第二次採取此措施，原因是聖嬰造成的降雨不足導致水位下降。第二，歐洲今夏持續籠罩致命熱浪，歐洲氣候監測機構資料顯示，自6月中旬到8月中旬已有8,000萬居民身處超過攝氏40度的環境，多數地區過去不曾遇過如此酷熱的天氣；先前歐洲的乾旱已迫使部分核電廠降載甚至停機（羅馬尼亞已著手將其唯一運轉中的反應爐與電網解聯）。第三，CNBC報導全球糧食供給今年冬天正醞釀一場「完美風暴」，小麥價格跳升，市場憂慮作物收成與農民明年的播種能力。FT則另有專文指出，氣候風險正開始「層層擴散」（cascade）進入美國經濟。

📐 解讀：這是一個很好的「非金融事件變成金融變數」的教材。聖嬰現象本身是氣象，但它同時打擊了三個關鍵基礎設施：航運通道（巴拿馬運河）、電力供給（歐洲核電降載）與糧食生產（小麥）。這三者恰好都是通膨的上游。我判斷市場目前嚴重低估了氣候變數對2027年通膨路徑的影響——當央行還在辯論貨幣政策時，供給面已經被氣候鎖住了。更關鍵的是：這類供給衝擊是升息無法解決的，升息壓不下小麥價格，只會在壓抑需求的同時傷害成長，這正是滯脹的定義。

🏗️ 結構性 — 結構性。判斷依據是這已是中國對台使用經貿工具的常態化模式（從石斑魚、鳳梨到關鍵材料），且台灣的反應也是結構性的（成立聯盟、推動在地化到原料源頭），雙方都在做長期布局而非短期反應。
⚡ 矛盾訊號：台積電與崇越說影響不大，但SEMI在同一天成立材料聯盟、35家公司響應、還把「關鍵原物料供應韌性」列為四大任務之首——如果真的影響不大，不需要這麼大的動員。這個矛盾的解釋是：對今年的營運影響確實不大，但對五年後的供應鏈架構影響很大，兩者講的是不同的時間尺度。第二個矛盾更有意思：黃義從說AI材料供應滿足度「不到一半」，這是缺料的警訊，但他同時說這是「黃金窗口」——同一個事實，一邊是風險一邊是機會，取決於你是買方還是賣方。
🔀 如果中國把灰色手段升級為正式的出口管制清單（如同先前對鎵、鍺的做法），高純度石英的現貨價可能在一季內上漲30-50%，台灣的材料在地化投資將加速，環球晶、崇越等具備非中國料源的廠商可望取得結構性的訂單移轉；如果這只是階段性的施壓手段、在數週內恢復正常清關，材料價格衝擊有限，但SEMI材料聯盟的成立仍會讓台灣材料在地化的長期趨勢持續，只是投資節奏放緩。

發生什麼事

上海航交所8月21日公布的出口貨櫃運價指數（SCFI）連續第四週上漲，上漲54.39點至3,409.63點、週漲幅1.62%，漲勢主要由美東線續漲1.38%帶動，東南亞線大漲8.49%，但歐洲線與地中海線分別續跌3.08%與6.65%，航線間分化明顯。貨代業者透露，船公司已陸續開出9月參考價，地中海航運（MSC）9月上旬美西線FAK持平、美東線喊漲約500美元/FEU。台股航運股同步噴出：萬海應證交所要求提前公布7月自結損益，單月營收186.40億元、年增50.13%，歸屬母公司淨利60.84億元、EPS 2.17元，年增19.97%；股價鎖上124.5元漲停，六個交易日暴漲41%。長榮7月營收480.79億元、月增22.82%、年增43.07%，創近23個月新高。外資持續加碼長榮、萬海與陽明，買超張數自7千張至3.7萬張不等，陽明更成為當日上市成交量第一的個股。萬海指出，巴拿馬運河水位連續下降、全球港口壅塞，是運價維持高檔的支撐。

📐 解讀：這一則跟energy版塊的聖嬰現象是同一條傳導鏈的兩端：巴拿馬運河因水位下降限航 → 船舶繞道或塞港 → 有效運力減少 → 運價上漲。所以要判斷航運股還能漲多久，不要看運價，要看巴拿馬運河的水位與通行配額。我要提醒一個關鍵風險：SCFI的漲勢正在窄化——美東線漲、東南亞線大漲，但歐洲線跌3.08%、地中海線跌6.65%，這不是全面性的運價多頭，而是特定航線的供給瓶頸。萬海六天漲41%、被列入注意股，短線的價格已經跑在基本面前面。
