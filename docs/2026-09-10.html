美國8月PPI月增0.4%、年增率跳至5.4% — 油價把「通膨已死」的敘事重新殺回來

發生什麼事

美國勞工部10日公布8月生產者物價指數（PPI）月增0.4%，符合道瓊調查的市場共識，但明顯高於7月上修後的月增0.1%，是三個月來最大增幅；年增率由7月水準跳升至5.4%。推升主因是能源價格：美伊戰事使布蘭特原油本周站上105美元、西德州突破100美元，直接灌進最終需求的能源分項。同日公布的上周初領失業金為20.6萬人，較前周減少1,000人、略高於分析師預期的20.5萬人，四周移動平均同步降至20.6萬人，勞動市場並未鬆動到可以抵銷通膨壓力。數據公布後10年期美債殖利率升破4.9%，創2023年11月以來新高，道瓊開盤跌195點（-0.4%）、標普500跌0.6%、那斯達克跌0.9%。市場對Fed下周升息1碼的押注升至約60%，但「新債王」岡拉克公開表示他個人傾向認為Fed不會動，並警告若真的按兵不動，長天期公債殖利率恐再度攀升、加劇這波歷史性的債券拋售。

📐 解讀：這是基本面而非情緒面的重定價。PPI月增0.4%本身「符合預期」，市場真正在反應的是年增率的斜率與來源：能源驅動的成本推升型通膨，是央行工具最難處理的一種——升息壓不下荷莫茲海峽的船，卻會同時壓垮需求。真正的訊號是殖利率曲線的長端在跑，而不是短端，代表市場定價的不是「Fed會升幾碼」，而是「Fed的可信度與財政赤字的期限溢價」。這已經從貨幣政策問題變成資產配置問題。
🔗 美伊衝突推升油價（Brent 105美元）→ 能源分項灌進PPI（月增0.4%、年增5.4%）→ 市場上修Fed升息機率至60% → 10年期美債殖利率破4.9%、期限溢價擴張 → 折現率上升壓縮成長股評價（那斯達克-0.9%）+ 房貸利率創一年多新高 → 高收益債利差走闊、槓桿收購（LBO）融資成本上升 → 私募基金退出窗口再度收窄
🏗️ 結構性 — 混合：能源價格衝擊本身是週期性的（戰事結束即回落），但財政赤字造成的期限溢價擴張是結構性的——即使油價回到70美元，美國長端殖利率也回不到2021年的水準。判斷依據是美中10年期利差已擴至317個基點的紀錄新高，這不是油價能解釋的。
⚡ 矛盾訊號：市場押注升息機率60%，但岡拉克從2年期美債的定價讀出Fed不會動；同時紐約Fed主席威廉斯把殖利率飆升解讀成「強勁的經濟前景」，而非通膨失控——同一組殖利率數字，被讀成三種完全不同的故事。另一個矛盾：初領失業金20.6萬人顯示勞動市場穩健，但成屋銷售與消費數據卻在轉弱，「C型經濟」的說法正在浮現。
🔀 如果Fed下周升息1碼且聲明偏鷹：10年期殖利率可能先衝上5.0-5.1%再回落，美元指數走強2-3%，新台幣測試31.8-32.0，台股外資賣壓延續2-4週；如果Fed按兵不動：短端殖利率下滑但長端因可信度受質疑而續揚，10年期恐上探5.2%，曲線陡峭化（bear steepening），這對壽險業的評價損失與銀行的AFS部位傷害反而更大。

發生什麼事

歐洲央行10日一如市場預期升息1碼，存款機制利率由2.25%調升至2.5%，再融資利率與邊際貸款利率分別升至2.65%與2.9%，是今年來第二度升息（7月例會曾按兵不動）。ECB同時上修經濟成長與通膨預測，並在聲明中明確使用「upside risk（上行風險）」形容通膨前景。拉加德在記者會表示，歐元區經濟韌性可望延續至第三季，短期成長展望好轉，動能來自AI投資與出口增加；但她同時警告，能源價格上漲將「逐步推高核心通膨」，能源維持高檔的時間愈長，推升通膨率的機率愈高。關於未來利率路徑，拉加德說例會並未討論方向，管委會重申逐次會議（meeting-by-meeting）依數據決定。歐元同日挑戰1.1700，而德國10年期公債發行殖利率已創2009年以來新高，英國10年期殖利率盤中升8個基點至5.348%、創2007年來新高。

📐 解讀：這是一次「被迫的升息」而非「有信心的升息」。ECB上修成長又上修通膨，表面上是好消息組合，實際上是承認自己被能源價格綁架：AI投資撐起的成長，掩蓋不了輸入型通膨的第二輪效應。拉加德刻意不給前瞻指引，就是保留在中東局勢反轉時快速收手的彈性。真正值得注意的是，這是全球「同步升息模式」的第三塊拼圖——日銀、英國、歐洲同時在緊縮，而這在2021年以後從未同時發生過。

美國8月成屋銷售再降 — 供給創十年新高、房價卻還在漲，房貸利率把市場凍住了

發生什麼事

美國8月成屋銷售再度下滑，儘管待售房屋供給已達十年以上最高水準，房價卻仍持續上漲——這是典型的「量縮價僵」格局。主因是房貸利率：30年期固定房貸利率升至一年多以來最高，隨油價上漲、通膨預期升溫，連5/1年期機動利率（ARM）都突破7%，讓過去用ARM降低初期月付的購屋族失去最後一條退路。房貸利率與10年期公債殖利率高度連動，而後者當日已破4.9%。同時，極端氣候正在從另一端擠壓持有成本：美國房屋保險費創下歷史新高，屋主的實質總持有成本（月付＋稅＋保險）持續墊高，市場開始討論洪水與野火高風險區的房屋是否該有「災害折價」。

📐 解讀：這不是需求崩潰，而是「鎖定效應（lock-in effect）」的極致版本——手上有3%房貸的屋主不願賣，想買的人負擔不起7%，成交量被兩端夾死。供給創十年新高卻壓不下價格，說明這批供給多半是新建案與被迫出售者，不是真正的存量釋出。真正的結構性變化是保險：當保費開始反映氣候風險，房價的「地理溢價」會第一次出現負值區域，這是美國房市過去三十年沒發生過的事。
🔗 油價破100美元 → 通膨預期上行、10年期美債殖利率破4.9% → 30年期房貸利率創一年多新高、5/1 ARM破7% → 購屋負擔能力惡化、成交量下滑 → 但存量屋主因低利房貸鎖定而不賣、供給釋出有限 → 房價僵持不跌 → 同時氣候風險推升房屋保險費至歷史新高 → 總持有成本上升 → 高風險地區開始出現「災害折價」，房價分化取代齊漲齊跌
🏗️ 結構性 — 利率造成的量縮是週期性的（利率回落即解凍），但氣候保險成本重定價是結構性的——保費一旦上去，不會因為利率下降而回來。
⚡ 矛盾訊號：供給創十年新高，理論上該壓價，但價格續漲；同時市場一邊擔心房市泡沫，Yahoo Finance卻同步刊出「2026年房市大概不會崩」的分析。矛盾的解法是：這是流動性危機（成交量），不是償債能力危機（違約率），跟2008年本質不同。
