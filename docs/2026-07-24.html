總經 / 地緣政治

川普對60國重啟關稅牆、以「強迫勞動」為由 — 台灣10%稅率反成相對贏家

深度解析

發生什麼事

隨著先前暫緩的全球對等關稅到期，川普政府對約60個貿易夥伴課徵新一輪關稅，並以「強迫勞動」作為法律正當性，加拿大遭課50%、泰國與新加坡各12.5%，歐盟、菲律賓等紛紛駁斥指控「毫無根據」。台灣在301調查下稅率確定為10%，優於日本、韓國，紡織與塑化業者普遍視為「相對好消息」，但工商界仍憂「川普變數」導致下單決策無所適從。美國最高法院近期推翻部分關稅政策，大法官強調「最高院非川普的橡皮圖章」，替關稅的法律基礎埋下不確定性。

解讀

這波關稅本質是「以貿易工具遂行地緣與價值觀外交」，強迫勞動的框架讓關稅從經濟議題升級為政治議題，也讓談判空間變小。對台灣而言，10%的相對優勢是短期利多，但真正的風險在於供應鏈客戶的『下單觀望』——不確定性本身就是需求的殺手。

傳導鏈

美國課徵關稅 → 進口成本轉嫁至美國消費者（通膨上行）→ 各國出口商壓縮利潤或轉單 → 台灣10%相對優勢吸引轉單 → 但客戶因政策反覆而遞延拉貨 → 台廠短期接單能見度下降

結構性

結構性。這是全球貿易秩序從『多邊規則』轉向『雙邊實力』的長期轉變，不是景氣循環，關稅牆一旦建立很難完全拆除。

矛盾訊號

市場一方面說台灣10%是利多、族群股價該漲；另一方面台股當天卻重挫千點——顯示關稅利多被『全球資金因油價與殖利率上行而撤退』的宏觀逆風完全蓋過。

分叉情境

如果最高院最終認定關稅授權違憲、且維持在2026下半年判決，則關稅可能部分回吐、台幣與出口股獲得喘息；如果關稅牆長期化（工商時報所稱『美301關稅牆長期化』），則SCFI等運價將結構性走高、供應鏈被迫加速美國在地化，資本支出負擔上升。

短期 · 1M
短期（1個月內）：台灣10%的相對優勢讓紡織、塑化、部分電子零組件出口維持接單，但受美國消費旺季前的『下單觀望』拖累，8月出口年增率可能較7月放緩2-4個百分點。
中期 · 3–6M
中期（3-6個月）：關稅談判進入細節攻防，若台美能就半導體、AI伺服器達成豁免或優惠，將是台股電子權值股的重要催化劑；反之疊加課稅風險升高。
長期 · 1Y+
長期（1年以上）：全球供應鏈『去風險化』與美國在地化為結構性趨勢，台廠赴美設廠（神達、緯創等已在加州費利蒙布局AI伺服器聚落）將成常態，資本支出與毛利率承壓，但貼近終端客戶也墊高議價地位。

美國最高院對關稅授權的最終判決時點台美301後續談判是否納入半導體/AI伺服器豁免8月台灣出口訂單年增率SCFI運價指數走勢

油價破$100引爆全球債市拋售 — 10年期美債殖利率創2025年1月新高、Fed升息機率反轉

深度解析

發生什麼事

布蘭特原油單週上漲約10%、盤中突破每桶100美元（5月以來首見），重新點燃通膨疑慮。美國10年期公債殖利率升至2025年1月以來最高，全球債市同步遭拋售。CNBC報導Fed升息（而非降息）的機率明顯上升，達拉斯聯準銀行總裁Logan公開呼籲利率應『適度』走高。原本市場定價的降息路徑在數週內幾乎翻盤，摩根大通Jamie Dimon直言市場低估風險、他在目前價位不會買股票或美債。金價在4,000美元附近震盪，安全資產與通膨對沖需求同時發酵。

解讀

這是典型的『供給面通膨衝擊』重演——油價上行不是需求過熱，而是地緣供給中斷，這種通膨最棘手，因為Fed無法用升息壓制供給。市場最大的預期差在於：多數投資人年初還在交易『降息』，如今被迫重新定價『不降甚至升息』，殖利率的重定價才是這波股災的真正引擎，油價只是導火線。

傳導鏈

地緣衝突推升油價破$100 → 運輸與生產成本上行、CPI預期升溫 → 10年期美債殖利率跳升至2025年1月高點 → 全球債市拋售、無風險利率抬升 → 高本益比科技股與新興市場股評價下修 → 外資撤離台韓、台股崩1195點、新台幣貶值

結構性

週期性衝擊疊加結構性風險。油價本身是週期（地緣事件驅動），但『財政赤字+去全球化+關稅通膨』讓長天期殖利率的結構性中樞上移，即使油價回落，殖利率也難回到過去低點。

矛盾訊號

Yahoo Finance一篇稱『大家擔心的油價噴出從沒真正出現』、FT也說『在利率大戲中，油價只是配角』；但債市與台股的反應顯示油價確實是壓垮駱駝的最後一根稻草——矛盾點在於油價是『觸發器』還是『主因』，我判斷主因是殖利率重定價，油價是催化劑。

分叉情境

如果油價守在$95-105、且地緣不再惡化，則10年期殖利率可能在高檔盤整、Fed維持觀望，股市有機會技術性反彈；如果油價衝上$120（CNBC情境）、荷莫茲海峽進一步受阻，則殖利率可能再上行20-40個基點、Fed被迫升息一碼，股債雙殺、新興市場資金外流加劇。

展望

短期 · 1M
短期（1個月內）：10年期美債殖利率在地緣未緩和前料維持高檔震盪，若油價站穩$100之上，Fed 9月會議按兵不動、甚至釋出鷹派訊號的機率上升；台股與新台幣續受外資撤離壓力。
中期 · 3–6M
中期（3-6個月）：關鍵在油價能否回落至$90以下、以及美國通膨數據是否被油價二次傳導。若通膨黏著，Fed全年降息預期將被完全抹除，成長股評價持續承壓。
長期 · 1Y+
長期（1年以上）：財政赤字、去全球化與能源轉型使長天期利率中樞結構性上移，『無風險利率長期偏高』將是資產配置的新常態，債券的股票替代效應（FT稱持股相對持債的超額報酬已消失）值得長期追蹤。

不動產 / 私募

台灣6月房貸餘額衝11.8兆創新高、青安2.0末班車助攻 — 但建築貸款首度轉負成長

深度解析

發生什麼事

台灣6月房貸餘額爆出近一年最大增量、總額衝上11.8兆元創歷史新高，主因青安（青年安心成家）2.0優惠房貸『末班車』效應，購屋族趕在優惠退場前進場。與此同時，反映建商推案動能的建築貸款（土建融）卻轉為負成長，是本波房市週期的重要轉折訊號——需求端仍靠政策撐、但供給端（建商）已在收手。

解讀

這是房市『需求末升段、供給先反轉』的典型分歧訊號。房貸餘額創高是政策催出來的『遞延需求前置』，不代表基本面轉強；而建築貸款轉負才是領先指標，暗示建商對後市轉趨保守，未來1-2年推案量與新屋供給可能下滑。

傳導鏈

青安2.0優惠將退場 → 購屋族提前進場搶末班車 → 房貸餘額短期衝高至11.8兆 → 但建商預期需求後繼無力、放緩推案 → 建築貸款轉負成長 → 未來1-2年新屋供給下滑、營建類股接單能見度下降

週期性

週期性轉折訊號。青安末班車是一次性的政策脈衝，建築貸款轉負則反映建商對『央行信用管制+利率高檔』的週期性因應，房市正從擴張末期進入盤整。

矛盾訊號

房貸餘額創新高（看似房市熱）vs. 建築貸款轉負（建商看空）——這組矛盾訊號說明『成交熱是政策催出的假象』，真正的方向要看供給端的建商行為。

分叉情境

如果央行維持信用管制、且利率因油價通膨而續高，則房市在青安退場後量縮價盤整、營建股評價承壓；如果通膨受控、央行2026下半年鬆綁管制，則遞延需求可能再度釋放、支撐蛋黃區價格。

展望

短期 · 1M
短期（1個月內）：青安2.0退場前的搶進效應延續，7月房貸餘額可能再創高，但這是最後一波脈衝。
中期 · 3–6M
中期（3-6個月）：建築貸款轉負的領先訊號將逐步反映到成交量，房市進入『價穩量縮』，營建類股股價修正。
長期 · 1Y+
長期（1年以上）：在高利率與信用管制的結構下，房市從『全面上漲』轉為『區域分化』，蛋黃區抗跌、蛋白區承壓，對不動產私募與REITs的標的選擇更講究。

持續追蹤

建築貸款餘額後續是否持續負成長青安2.0退場後單月房貸增量央行對房市信用管制的鬆緊六都成交量與價格分化

深度解析

發生什麼事

台股單日重挫1,195.97點（-2.67%）、收43,654點，為史上第9大跌點、跌破季線，台積電收2,350元（-2.28%、跌55元）。外資單日賣超609億元、終止連4買，並反手大買緯創、中鋼，三大法人狂掃緯創4.35萬張。新台幣貶9.2分收32.358元、週線連5黑，反映外資匯出壓力。亞股同步崩跌，日經下跌2.73%（1,811點）、韓股KOSPI暴跌逾6%並觸發熔斷。全週台股仍上漲983點，上市公司總市值142.5兆元，呈現『先盛後衰』格局。金管會稱反映國際情勢、將持續關注波動。

解讀

這是一場『進口的股災』——導火線不在台灣基本面，而是油價破百、美債殖利率上行、AI capex疑慮三重外部逆風下的外資去槓桿。外資賣權值（力積電、台積電）卻買緯創、中鋼，說明這不是無差別逃命，而是『調節高評價、轉進落後補漲與AI伺服器』的結構性換股，值得留意。

傳導鏈

油價破$100+美債殖利率上行+AI capex疑慮 → 全球風險偏好下降、外資去槓桿 → 賣超台韓等高beta市場609億 → 新台幣貶至32.358、匯出壓力 → 台股失守季線、跌1195點 → 但外資同步買緯創/中鋼、換股而非全面撤離

結構性

週期性回檔。台股基本面（記憶體超級循環、AI供應鏈訂單）未變，這波是外部宏觀逆風驅動的週期性去槓桿，非結構性轉空，但失守季線的技術面轉弱需觀察量能。

矛盾訊號

單日崩1195點（看似轉空）vs. 全週仍漲983點、外資賣權值卻買緯創/中鋼（結構性換股）——矛盾訊號顯示這不是全面看空，而是『高評價殺、AI伺服器補』的內部輪動。

分叉情境

如果油價回落、殖利率鬆動，台股在季線附近止穩、AI供應鏈領軍反彈，44K是多空分水嶺；如果油價衝$120、外資續匯出，台股可能再測前低、新台幣貶破32.5元。

長期（1年以上）：台股與全球AI資本支出週期高度連動，AI變現進度與地緣風險將是決定指數中樞的兩大結構變數。
