總經 / 地緣政治

美伊衝突第9夜、荷莫茲油運風險 — 布蘭特觸90美元後回落，通膨陰影壓上ECB與Fed

深度解析

發生什麼事

美軍對伊朗目標展開連續第9晚空襲，兩名美軍在約旦遭伊朗飛彈攻擊身亡，伊朗革命衛隊揚言若美方持續「侵略」將不讓任何一滴油或天然氣經荷莫茲海峽通過。布蘭特原油週一盤中一度突破90美元、創6月以來新高，但在伊朗外交部表示已接獲中間人轉交提案、可基於國家利益與美方重啟談判後，油價回吐漲幅、跌破90美元。美國汽油全國均價重返每加侖4美元，高於一年前的3.14美元；伊朗里亞爾匯率跌至歷史新低。美國10年期公債殖利率上行逾1個基點至4.558%。市場同時在權衡：週稍晚召開政策會議的歐洲央行（ECB）官員正評估是否因油價再起而升息。

解讀

這波油價是地緣政治溢價（供給恐懼）而非需求拉動，本質是『尾部風險定價』而非基本面轉強——證據是伊朗一釋出談判訊號，油價當日就由紅翻黑。真正的殺傷力不在油價絕對水位，而在它同時卡住Fed與ECB的降息路徑，把『停滯性通膨』的舊劇本重新推回央行決策桌上。

傳導鏈

荷莫茲油運中斷疑慮 → 布蘭特衝90美元、美汽油回4美元 → 頭條CPI下行趨勢中斷（6月已回落至3.5%） → Fed（Logan已喊話升息）與ECB延後／逆轉降息 → 公債殖利率上行、實質利率走高 → 高評價科技股與高收債同步承壓 → 資金撤離新興亞股（台、韓）

結構性

週期性衝擊為主（戰事一停、溢價就消），但若荷莫茲運輸被實質封鎖，將轉為結構性供給斷點；判斷依據是週一油價對談判訊號的高敏感度，顯示市場仍視其為可逆事件。

矛盾訊號

矛盾訊號：一邊是美軍第9夜空襲、汽油破4美元的『戰事升溫』敘事；另一邊是伊朗鬆口談判、週日仍有逾800萬桶原油在軍事護航下通過荷莫茲的『實際油流未斷』事實。市場在『恐懼』與『數據』間拉扯，油價高波動正反映這種訊號打架。

分叉情境

情境X（談判破局、荷莫茲實質封鎖）：布蘭特恐測試100美元以上，ECB本週按兵、Fed全年不降息，美10年期殖利率上探4.8%，全球風險資產再殺一段；情境Y（4週內達成停火）：溢價快速消風、布蘭特回落至75-80美元區間，降息預期重回，殖利率回落、科技股獲估值修復空間。

展望

短期 · 1M
短期（1個月內）：油價在80-95美元寬幅高波動，取決於談判進度；美10年期殖利率在4.4%-4.8%箱型，ECB本週大機率按兵不動並在聲明中強調『油價不確定性』。
中期 · 3–6M
中期（3-6個月）：若戰事降溫，通膨隨基期與油價回落，Fed有望在Q4啟動小幅降息（Logan仍偏鷹是主要變數）；能源類股與防禦性資產相對抗跌。
長期 · 1Y+
長期（1年以上）：荷莫茲反覆的地緣風險，將促使亞洲能源進口國（含台灣）加速能源來源多元化與戰略儲備，並推升繞道管線、LNG長約與再生能源的結構性投資。

持續追蹤

布蘭特原油90美元關卡與伊朗談判進展本週ECB利率決議與聲明用字美國10年期公債殖利率4.558%後續走向美國汽油均價與頭條CPI下期數據

面試角度

國泰CIM會關注：油價驅動的殖利率曲線變化對債券部位與資產配置的含義（『你會怎麼在戰事溢價與降息預期間調整存續期間？』）；開發資本可能問：油價與利率雙升對基建投資案IRR假設與折現率的衝擊；中信投資專案角度：地緣風險如何反映到跨產業投資案的風險定價與情境分析。

口說版

「這波油價我會定位成『地緣政治溢價』而非需求復甦——證據是伊朗一鬆口談判，布蘭特當天就從90美元以上翻黑。但對投資決策真正的重點不是油價本身，而是它同時卡住Fed和ECB的降息路徑，把停滯性通膨的劇本推回檯面。如果我在做債券配置，我會傾向縮短存續期間、保留現金部位，等本週ECB和油價方向明朗，因為現在市場在『戰事恐懼』和『每天仍有800萬桶通過荷莫茲』的實際數據之間拉扯，波動會很大。」

持續追蹤中

發生什麼事

在上週全球AI科技股重挫後，中國國有基金宣布買進約90億美元股票護盤，穩定市場信心。同時第二季GDP年增4.3%，為2022年底以來最慢，內需與民間投資疲弱，主要靠出口（部分受惠AI相關需求）支撐；中國車市今年恐創2021年來最差、銷售年減20%（2025年為2370萬輛的歷史高點）。

關鍵數據

國家隊護盤約90億美元；Q2 GDP +4.3%（2022年底以來最慢）；車市銷售年減20%。

解讀

『國家隊』出手是政策底而非市場底——它反映的是官方對信心崩解的容忍度到極限，而非基本面反轉。GDP『出口強、內需弱』的結構，暴露中國成長引擎過度依賴外需與AI單一題材，一旦外部關稅或AI資本支出降溫，緩衝就消失。

傳導鏈

AI科技股全球回檔 → A股／港股急殺 → 國家隊護盤90億美元 → 短線止穩但內需（車市-20%）未改善 → 通縮壓力延續 → 人民幣與亞幣連動承壓 → 台股外資也在同一波亞股撤退中被賣超

分叉情境

如果Q3推出大規模消費／財政刺激且房市止穩，港股AI與內需股有補漲空間；如果僅靠國家隊護盤而無實質刺激，資金將續流向高股息與防禦性標的（陸股已現『股息才是最熱門下注』現象）。

展望

短期 · 1M
短期：護盤可暫緩恐慌，但在Q2 GDP走弱下反彈力道有限，指數易陷區間震盪。
中期 · 3–6M
中期：關鍵看財政刺激是否加碼與房市（萬科巨虧顯示地產危機外溢）止穩，否則通縮與內需疲弱仍將壓抑估值。

口說版

「中國國家隊砸90億美元護盤，我會解讀成『政策底』而不是『市場底』——它告訴你官方對信心崩盤的容忍度到頂了，但沒告訴你基本面反轉。真正的警訊是Q2 GDP只有4.3%、還是靠出口和AI單一題材撐著，內需連車市都年減20%。對中信這種要做跨產業投資評估的職位，我會把中國的『出口強、內需弱』結構當成一個系統性風險變數，尤其影響任何有中國市場曝險的投資案的營收假設。」

台灣『青安3.0』8月上路：排富（所得<200萬）排老（年齡<50）— 六月搶末班車撥貸創逾一年新高

深度解析

發生什麼事

財政部公布，新版『青安3.0』將於8月起上路，新增排富（個人年所得需低於200萬元）與排老（年齡需小於50歲）條款，並對育有未成年子女的婚育家庭最高貸款額度可望提高至1500萬元。因新制限縮，6月出現『搶末班車』潮：8大公股銀行受理4718戶、月增7.94%，撥貸戶數達4552戶、月增28.26%，撥貸金額373.63億元，雙雙創去年4月以來最佳。住商機構分析，符合新制的買盤多集中中南部；台北市甚至逾半數買方不符合青安3.0資格，雙北、新竹恐淪『首購孤島』。

解讀

這是一次『需求前置＋結構篩選』的政策操作——排富排老短期製造搶購潮（6月數據衝高），中長期則是把補貼從高房價都會區導向中南部與婚育家庭。本質是政府在『打炒房』與『助首購』之間重新校準，等於行政手段替房市降溫、也讓雙北首購族被排擠。

傳導鏈

青安3.0排富排老公布 → 6月搶末班車、撥貸月增28% → 8月新制上路後都會區合格買盤驟減 → 雙北／新竹首購需求遞延或轉租 → 中南部及婚育宅（總價1000-1500萬）交易相對熱 → 影響公股銀行房貸放款結構與建商區域布局

結構性

結構性政策轉向（補貼對象重分配），疊加短期週期性搶購；判斷依據是排富排老是制度性門檻、非一次性優惠。

矛盾訊號

矛盾訊號：政策名義上『助首購』，實際上讓房價最高的雙北首購族逾半數被排除在外，形成『幫得到的地方不缺、缺的地方幫不到』的錯配。

分叉情境

如果8月新制嚴格執行，Q3雙北首購成交量與房貸放款下滑、中南部撥貸占比上升；如果後續放寬所得或年齡門檻，都會區買盤回補、搶末班車效應反轉。

展望

短期 · 1M
短期（1個月內）：8月新制上路前後，房貸撥貸量先高後低，公股銀新增房貸戶數波動。
中期 · 3–6M
中期（3-6個月）：都會區首購成交量與房貸成長放緩，中南部及1000-1500萬婚育宅相對抗跌。
長期 · 1Y+
長期（1年以上）：補貼結構性導向中南部與婚育家庭，牽動建商區域推案策略與公股銀房貸資產組合。

持續追蹤

8月青安3.0撥貸戶數／金額變化雙北 vs 中南部房貸放款占比公股銀房貸逾放比與淨利差婚育宅（總價1000-1500萬）成交量

面試角度

中信投資專案／不動產角度可能問：政策性房貸的排富排老，如何改變不動產投資與REITs的區域配置邏輯？開發資本角度：這對住宅開發案的去化速度與IRR假設有何影響？富邦證券角度：對建商客戶的籌資與推案時程規劃有何連動。

口說版

「青安3.0我會用『需求前置加結構篩選』來拆——排富排老短期製造了6月撥貸月增28%的搶末班車潮，但真正的重點是它把補貼從高房價的雙北，導向中南部和婚育家庭，結果台北反而有超過一半首購族不符合資格。對做不動產投資評估的職位，我會提醒這是一個區域配置訊號：資金和交易熱度會往中南部和總價1000到1500萬的婚育宅移動，建商的推案策略和公股銀的房貸資產結構都會跟著調整。」

全球AI／半導體去槓桿式回檔 — 費半跌入技術熊市、台股寫史上最大單日跌點、韓股單日崩4.46%觸發今年第20次熔斷

深度解析

發生什麼事

深度解析

發生什麼事

根據中國海關7月20日公布資料，6月中國對日本的鎵（gallium）、鏑（dysprosium）、鋱（terbium）、釔（yttrium）等具戰略重要性的稀土金屬出口量掛零，加劇中日外交爭議與原物料供給危機；近幾個月這些關鍵礦物出口一直受中國嚴格管控。與此同時，中國的氦氣出口禁令也切斷了俄羅斯氦氣輸歐路線、威脅歐洲供應（疊加卡達產能中斷壓力）。這使『能源與關鍵礦物武器化』從原油、天然氣延燒到半導體與國防不可或缺的稀土與工業氣體。

解讀

這是地緣經濟從『油氣戰』升級為『關鍵礦物戰』的訊號——稀土（鎵、鏑用於半導體、磁材、國防）與氦氣（半導體製程、MRI）是供給高度集中、需求剛性且難以短期替代的『卡脖子』環節。中國把出口管制當外交槓桿，本質是把供應鏈依賴轉化為地緣籌碼，逼使日、歐、美加速去中化與替代來源布局。

傳導鏈

中日外交爭議 → 中國對日稀土出口掛零＋氦氣禁令 → 日／歐半導體、磁材、國防原料供給緊張 → 價格上行＋交期拉長 → 下游被迫尋找替代來源／建立戰略庫存 → 供應鏈去中化與友岸外包加速 → 相關替代供應商（澳、非中稀土）與回收技術受惠
