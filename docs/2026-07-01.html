總經 / 地緣政治

聯準會利率路徑生變 — Warsh拒鬆口、市場罕見押注7月「升息」、SCOTUS力保Fed獨立性

深度解析

發生什麼事

新任聯準會主席Kevin Warsh週三於葡萄牙Sintra的ECB央行論壇與各國央行首長同台，明確拒絕暗示7月FOMC決策方向。與此同時，聯邦基金利率期貨市場出現此前難以想像的轉折：交易員開始加碼押注Fed最快7月可能「升息」，利率交換目前定價反映約9%的7月升息機率，反映通膨僵固與財政赤字擴張下的重定價。基本面訊號矛盾：6月ADP民間就業僅增9.8萬人、低於市場預期，顯示勞動市場降溫；但美國企業6月裁員人數月減53%、創2025年12月以來最低，勞動需求並未崩解。政治面，美國最高法院(SCOTUS)裁定阻止川普開除聯準會理事Lisa Cook，短期保住Fed人事獨立性，但市場已開始為「Fed被政治化」情境定價，10年期公債殖利率同步走高。

解讀

這不是單純的降息或升息辯論，本質是市場對『Fed反應函數(reaction function)』信任度的重新定價。當央行獨立性受政治侵蝕、財政持續擴張，長端殖利率會透過期限溢酬(term premium)上行，即使短端政策利率不動。9%的升息機率不是主流預期，而是尾部風險被重新標價的訊號。

傳導鏈

Fed獨立性疑慮 → 期限溢酬上行 → 10年期殖利率走高 → 成長股折現率上升、長天期資產(REITs/公用事業/高評級債)承壓 → 資金轉向短天期與實體資產 → 黃金因實質利率上行短線受壓但避險需求墊底

結構性

結構性。央行獨立性受政治侵蝕與結構性財政赤字是長期主題，不是單一循環波動；判斷依據是期限溢酬而非政策利率主導長端。

矛盾訊號

市場矛盾：ADP就業降溫(指向降息)vs.聯邦基金期貨押注升息(指向通膨僵固)；同一組數據下，殖利率曲線的短端與長端訊號背離，反映市場對Fed『先控通膨還是先保成長』無共識。

分叉情境

若7月核心PCE年增回落至2.5%以下且就業續弱，則Fed維持觀望、10年殖利率回落至4.2%以下、成長股反彈；若通膨僵固在3%附近且財政赤字續擴，則長端殖利率上探4.8-5.0%、高評級信用利差走闊、股市評價收縮。

展望

短期 · 1M
短期(1個月內)：7月FOMC大機率按兵不動(不升不降)，市場焦點轉向點陣圖與Warsh記者會措辭；10年期殖利率區間4.3-4.7%，任何『政治化』言論都會放大波動。
中期 · 3–6M
中期(3-6個月)：若財政赤字/GDP續破6%，期限溢酬將主導長端；即使短端不動，30年期殖利率恐挑戰5%，壓縮全球風險資產評價。
長期 · 1Y+
長期(1年以上)：Fed獨立性是否被實質侵蝕將決定美元儲備地位與美債避險屬性；若市場確認Fed政治化，全球央行加速去美元化配置(黃金、其他主權債)，這是結構性格局轉變。

持續追蹤

7月FOMC聲明與點陣圖聯邦基金期貨隱含升息/降息機率10年與30年期公債殖利率及期限溢酬核心PCE與ADP/非農就業SCOTUS對Fed人事後續裁決

面試角度

國泰CIM會關注：這對債券殖利率曲線與存續期(duration)配置的含義——若期限溢酬主導長端，投資組合該縮短存續期還是加碼實體資產？中信MA投資專案角度：Fed政治化如何改變無風險利率假設、進而影響所有DCF估值的折現率？富邦投行組角度：長端殖利率上行如何壓抑IPO/SPO評價窗口？

口說版

「我認為現在市場定價的核心不是降不降息，而是對Fed反應函數的信任重定價。聯邦基金期貨罕見出現約9%的7月升息押注，加上SCOTUS要擋下川普開除理事，反映的是央行獨立性溢酬正被重新標價。以國泰CIM的投資組合視角，這意味著長端殖利率可能由期限溢酬而非政策利率主導，我會傾向縮短存續期、增加對利率不敏感的實體資產部位來對沖這個結構性風險。」

來源CNBCCNBC (Treasury yields/Warsh)BBC (SCOTUS blocks firing of Lisa Cook)

黃金創13年最慘單季 — 實質利率上行+散戶熱潮退燒，資金輪動的訊號

深度解析

發生什麼事

黃金週三續跌，收在本季度以來的低點，完成2013年以來最糟的單季表現。FT指出，散戶買金熱潮(retail frenzy)明顯退燒，是本季金價下挫的關鍵推手之一；世界黃金協會(WGC)則表示，金價後市方向將由『利率』與『地緣政治情勢』兩大變數決定。金價回落與前述美債殖利率走高互為表裡：實質利率上行提高持有無息黃金的機會成本。台灣媒體同步報導，資金正從黃金流向其他兩類資產(股票與部分計息資產)，顯示這是一次資產輪動而非單純避險退潮。

解讀

黃金這波回落主要是『實質利率』驅動的週期性修正，而非黃金長多結構的破壞。散戶熱潮退燒代表投機部位出清，反而讓後續由央行購金與地緣避險支撐的基本盤更乾淨。我判斷這是評價修正，不是趨勢反轉。

傳導鏈

美債殖利率上行 → 實質利率(TIPS殖利率)走高 → 持有無息黃金機會成本上升 → 散戶/ETF獲利了結 → 金價單季重挫 → 資金輪動至股票與計息資產 → 若地緣風險再起則避險需求回補

結構性

週期性修正為主、結構性支撐仍在；判斷依據是驅動因子為實質利率(週期)，但央行去美元化購金(結構)並未逆轉。

分叉情境

若10年期實質利率升破2.2%且地緣情勢緩和(美伊達協議)，則金價續探前低、季線續空；若Fed政治化疑慮升溫或中東再生變數，則央行與避險買盤回補、金價快速V轉。

展望

短期 · 1M
短期(1個月內)：金價區間震盪偏弱，方向取決於7月FOMC與美伊談判；若實質利率續升，短線仍有壓。
中期 · 3–6M
中期(3-6個月)：央行購金(尤其新興市場去美元化)提供結構性下檔支撐，散戶出清後的籌碼面更健康，回檔即買盤浮現。

口說版

「黃金創13年最慘單季，很多人問是不是長多結束，我的判斷是不是——這波主要是實質利率上行加散戶熱潮退燒的週期性修正，但央行去美元化的結構性購金並沒有逆轉。以投資組合角度，我會把這種回檔視為調整黃金配置權重的機會，而不是清倉訊號，因為它同時是利率風險與地緣風險的雙重對沖工具。」

來源CNBC (gold worst quarter in 13 years)FT (gold heads for worst quarter in more than a decade)

日圓貶至40年低點、日本砸740億美元干預無效 — 亞幣競貶與利差模型失靈(持續追蹤)

持續追蹤中

發生什麼事

日本累計投入約740億美元干預匯市支撐日圓，但分析師直言：真正的對手是Fed，只要美日利差維持高檔、美元就有支撐，單靠干預難以逆轉貶勢。瑞穗更警告日圓跌至歷史低點已『顛覆市場假設』，傳統美日利差模型出現失靈。韓元同步跌向2009年以來低點、外資拋售韓股。新台幣則隨亞幣走弱、終止連2升，收在31.874元。

關鍵數據

日本干預金額約740億美元；韓元逼近2009年低點；新台幣收31.874元、貶5.4分。

解讀

亞幣全盤走弱的根源是美日/美亞利差結構，而非各國基本面惡化。干預只能『減速』不能『轉向』，這是典型的央行對抗市場結構的無效戰。日圓利差模型失靈則暗示套利交易(carry trade)的定價錨正在鬆動，尾部風險升高。

傳導鏈

Fed維持高利率 → 美日/美亞利差擴大 → 套利資金賣亞幣買美元 → 日圓/韓元/新台幣走弱 → 進口通膨升溫、亞洲央行兩難 → 干預消耗外匯存底但難逆轉 → 若carry trade平倉則亞幣急升、全球波動放大

分叉情境

若Fed維持利率不動而BOJ按兵，則日圓破165、亞幣續貶；若BOJ意外升息或Fed鴿轉，則carry trade平倉、日圓單週升值逾5%、拖累日股與全球風險資產。

展望

短期 · 1M
短期(1個月內)：亞幣偏弱格局延續，日圓在160-165、新台幣在31.5-32.2區間；干預只造成短線急拉、不改趨勢。
中期 · 3–6M
中期(3-6個月)：關鍵在Fed是否轉向與BOJ是否升息收斂利差；若美日利差收窄，carry trade平倉恐引發亞幣同步急升與股市波動。

口說版

「日本砸了740億美元干預日圓還是壓不住貶勢，這說明一件事：匯率的主導權在利差、不在干預。以國泰CIM的外匯與資產配置角度，我會關注的不是日圓現在多低，而是美日利差一旦收斂、套利交易平倉的尾部風險——那會同時衝擊亞幣、日股和全球波動率，是投資組合避險時最該預留的情境。」

不動產 / 私募

中國萬科(Vanke)公告巨額虧損 — 地產危機蔓延至最後堡壘，國家是否出手成關鍵

深度解析

發生什麼事

WSJ報導，中國龍頭房地產開發商萬科(Vanke)公告巨額虧損，作為過去被視為財務相對穩健、有深圳國資背景的『行業標竿』，其失血引發市場對地產危機是否進一步擴散、以及中國政府是否會介入紓困的疑問。萬科的問題不同於恒大/碧桂園等民企違約，它牽動的是『連國企背景的優等生都撐不住』的訊號，衝擊市場對地產底部的信心。

解讀

萬科爆雷的意義不在單一公司，而在它打破了『國資背書=安全』的市場假設。這代表中國地產去槓桿仍未見底，且風險正從民企擴散到準國企。是否救、怎麼救，將決定市場對中國系統性風險的定價。

傳導鏈

萬科虧損 → 國資背書信仰破滅 → 投資人對中資地產債重定價、利差走闊 → 銀行對開發商授信收縮 → 土地財政收入續降、地方政府融資平台(LGFV)壓力升 → 中國內需與大宗商品(鋼、銅)需求疲弱 → 拖累全球工業金屬與新興市場情緒

結構性

結構性。中國地產是長期去槓桿與人口/城鎮化見頂的結構問題，不是短期庫存循環；判斷依據是連國資標竿都失血，代表商業模式(高週轉+高槓桿)已系統性失效。

矛盾訊號

市場矛盾：官方持續釋出『穩地產』政策訊號(指向底部)vs.龍頭企業實際財報持續惡化(指向危機未止)；政策底與市場底出現時間差。

分叉情境

若中國政府對萬科實質注資或債務重組，則地產債利差收斂、市場認定政策底浮現；若放任市場化出清，則中資高收益地產債再殺一波、人民幣與陸股承壓、大宗商品需求下修。

展望

短期 · 1M
短期(1個月內)：市場緊盯深圳國資與中央是否表態；任何紓困訊號都會引發地產股債急彈，但持續性存疑。
中期 · 3–6M
中期(3-6個月)：地產去槓桿續行，成交量與房價落底時間拉長；土地財政缺口將透過地方化債與特別國債填補。
長期 · 1Y+
長期(1年以上)：中國經濟成長引擎由地產基建轉向製造業/科技(如電動車、綠能出口)，這是格局的永久性移轉；地產占GDP比重將結構性下降。

持續追蹤

萬科債務重組/國資注資進展中資高收益地產債利差中國70城房價與商品房成交量地方政府土地出讓金收入人民幣匯率與陸股情緒

面試角度

中信MA投資專案角度：評估中資不動產相關曝險時，這筆虧損如何改變違約機率與回收率假設？這是不動產/私募投資風險定價的絕佳案例。開發資本基礎建設投資角度：中國地產去槓桿如何外溢到大宗商品與新興市場基建需求？國泰CIM角度：中資地產債在固定收益組合中的信用風險該如何重定價？

口說版

「萬科爆雷最值得注意的不是虧多少，而是它打破了『國資背書等於安全』的市場信仰。以中信投資專案評估不動產風險的角度，這代表過去用國企背景來調降違約機率的假設要全面重估。它的傳導鏈會從地產債利差走闊，一路傳到地方土地財政、大宗商品需求，最後外溢到新興市場情緒，是一個典型跨資產、跨區域的風險定價題目。」

來源WSJ (Leading China property developer reports huge loss)

KKR切入英歐退休金買斷市場 — 私募資本吃下長天期負債與實體資產(持續追蹤)

持續追蹤中

發生什麼事

FT報導，私募巨頭KKR計劃進軍英國與歐洲的退休金買斷(pension buyout)市場，把企業確定給付制(DB)退休金負債連同其資產一併承接。這延續私募資本『從企業手中買下長天期負債+穩定現金流資產』的策略，與其在保險(如Global Atlantic)、基礎設施、私募信貸的布局一脈相承。同日另有KKR與SK集團合作、掌控南韓13億美元再生能源平台以供應AI資料中心電力的消息，顯示私募資本正同時卡位『負債端』與『實體資產端』。

關鍵數據

KKR南韓再生能源平台規模13億美元；退休金買斷承接企業DB負債(規模視個案，英歐市場潛在數千億英鎊)。

解讀

私募資本的本質戰略是『用永久性/長天期資本，去承接被銀行與企業因監管或去風險而丟出來的長天期資產與負債』。退休金買斷、保險、基建、私募信貸其實是同一套邏輯：賺取流動性溢酬與資產負債匹配的利差。這是金融中介去銀行化(disintermediation)的結構性主題。

傳導鏈

銀行受資本監管退出長天期資產 → 企業想甩開DB退休金負債 → 私募資本以永久資本承接負債+資產 → 賺取流動性溢酬與利差 → 私募信貸/保險/基建AUM膨脹 → 系統性風險從受監管銀行移轉到較不透明的私募領域

分叉情境

若利率維持高檔且信用環境穩定，則私募資本持續擴張、蠶食銀行與保險傳統地盤；若信用循環反轉(私募信貸違約升溫)，則不透明的私募估值與流動性錯配風險曝光、AUM成長急煞。

AI帶動的『排擠效應』從記憶體蔓延至被動元件。經濟日報報導，被動元件龍頭國巨股價漲破千元，華新科、禾伸堂、信昌電、立隆電等近3個月股價至少翻倍，外資法人大幅上修國巨展望。MoneyDJ指AI訂單排擠效應使MLCC缺貨風險升溫，日月光也因AI熱與成本考量、傳先進封裝再度漲價;日月光股價首登700元、外資喊上835元。設備廠亦因供需與原料成本『漲價有底氣』。

關鍵數據

國巨股價破1000元;華新科/禾伸堂等近3個月漲幅逾100%;日月光股價登700元、外資目標835元。

解讀

AI的排擠效應正沿供應鏈層層外溢：從HBM/DRAM →被動元件(MLCC)→先進封裝，形成『AI缺料漲價鏈』。這代表AI紅利不再只集中於晶圓與記憶體，而是擴散到過去被視為成熟/低毛利的零組件，帶動整條供應鏈的漲價與評價重估。但漲勢已大、需留意基期與訂單能見度。

傳導鏈

AI伺服器需求 → 高階被動元件/MLCC需求激增 → 產能排擠消費級料件 → MLCC缺貨、被動元件漲價 → 國巨等台廠股價翻倍、外資上修 → 先進封裝(日月光)跟漲 → 整條AI缺料鏈評價重估 → 若AI capex降溫則漲價鏈由末端先回檔

分叉情境

若AI伺服器拉貨續強且產能開出緩慢，則被動元件/先進封裝漲價延續至2027、台廠獲利續上修;若AI capex放緩或消費電子續弱，則漲價鏈由被動元件等末端先反轉、股價領先回檔。

展望

短期 · 1M
短期(1個月內)：被動元件與先進封裝漲價與缺貨題材延續，但股價漲多、波動加大;留意訂單能見度與Q3拉貨。
中期 · 3–6M
中期(3-6個月)：AI缺料鏈的漲價能否延續取決於AI capex與產能開出時程;高階料件(車用/AI用)相對抗跌，消費級承壓。
