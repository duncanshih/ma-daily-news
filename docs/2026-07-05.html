總經 / 地緣政治

聯準會集體轉鷹——多位官員明示今年恐升息，逆轉市場降息預期

深度解析

發生什麼事

美國聯準會近期釋出一連串偏鷹訊號。明尼亞波利斯聯準銀行總裁Kashkari直言預期今年就會升息一次，理由是經濟仍在承受通膨飆升的衝擊；克里夫蘭聯準銀行總裁Hammack對CNBC表示『通膨太高、而且過去五年一直太高』，並警告AI資本支出熱潮本身可能推升通膨，升息或有其必要。同一時間，美國6月非農就業明顯放緩，弱數據一度讓美元跌至兩週低點、COMEX黃金單日上漲1.5%。市場因此陷入『鷹派官員談升息 vs 弱就業暗示降息』的訊號打架。這與過去一年市場一面倒押注寬鬆的敘事出現重大分歧。

解讀

這是基本面訊號、不是情緒面雜訊。聯準會的焦慮點已經從『成長』轉向『AI驅動的結構性通膨』——資料中心用電、晶片與資本財需求正在製造一種需求拉動型的物價壓力，這不是傳統貨幣政策容易處理的。我的判斷是：市場對『2026下半年降息』的定價過度樂觀，殖利率曲線長端上行風險被低估。

傳導鏈

AI資本支出爆發 → 電力/晶片/資本財需求拉動物價 → 核心通膨黏著在目標之上 → 聯準會延後降息甚至升息 → 美債長端殖利率上行 → 高估值成長股折現率承壓 → 新興市場資金回流美元資產

結構性

結構性為主：AI推升的通膨屬供需結構重塑，不是單純庫存週期，故政策反轉的持續性高

矛盾訊號

同一週內『聯準會官員談升息』與『美元因升息預期消退而走弱、市場押注降息』兩種說法並存——關鍵在於區分『政策利率路徑』與『美元短期資金流』，前者看通膨、後者看避險與利差交易平倉

分叉情境

若7月核心PCE年增率仍站在3%以上且就業回穩，聯準會9月升息1碼機率將被重新定價、10年期美債殖利率上探4.8%-5.0%；若就業連兩月走弱、失業率破4.5%，則升息論調收回、曲線轉為牛陡、風險性資產反彈

展望

短期 · 1M
短期（1個月內）：聯準會官員鷹派放話延續，10年期美債殖利率在4.5%-4.9%區間震盪，美元指數守穩、但受弱就業牽制上行有限
中期 · 3–6M
中期（3-6個月）：關鍵變數是AI capex是否見頂。若capex續強、通膨黏著，全年恐由『不降息』轉為『升息1碼』；反之若capex放緩，年底前仍有一次降息空間
長期 · 1Y+
長期（1年以上）：AI時代的中性利率（r*）可能被結構性墊高，市場需適應『比疫情前更高的常態利率』，這將永久性壓縮長天期資產的估值天花板

持續追蹤

核心PCE與trimmed mean通膨月變動10年期與2年期美債殖利率利差非農就業與失業率聯準會官員談話與點陣圖AI資料中心用電成長率

面試角度

國泰CIM會關注：若聯準會由降息轉升息，債券部位的存續期間（duration）該如何調整、殖利率曲線策略怎麼做？開發資本面試可能問：長端利率墊高對基建投資案的WACC與IRR假設有什麼衝擊、折現率該用多少？

口說版

「我認為市場對聯準會降息的定價太樂觀了。Kashkari已經明講今年可能升息、Hammack點名AI資本支出本身會推升通膨，這代表通膨的性質從週期性轉成結構性。如果我在國泰CIM負責債券部位，我會傾向縮短存續期間、避開長天期公債，因為10年期殖利率有機會上探接近5%；同時這也意味著對開發資本這類基建投資，折現率假設要往上調，IRR的安全邊際得抓得更保守。」

日圓歷史性貶值——高盛轉更空、示警乾預也擋不住，亞幣連動承壓

深度解析

發生什麼事

高盛對日圓轉為更加看空，直言即使日本央行（BOJ）出手乾預，日圓仍可能進一步走弱，並以『AI與能源供給缺口將支撐美元』為由看多美元。台灣國銀觀察日本升息預期降溫、壓抑日圓，短線需留意BOJ乾預風險。日圓的持續貶值已外溢到整個亞洲：日經225一度因獲利了結重挫824點，但TOPIX仍創歷史新高；同一時間新台幣貶破32元大關。日圓走弱也直接催化了台灣資金湧入日本房市的趨勢。

解讀

日圓的問題本質是『利差』：美日名目利率差維持在高檔，套利交易（carry trade）動能不減，光靠口頭或實質乾預只能製造短期反彈、無法逆轉趨勢。我的判斷是，除非BOJ真正啟動連續升息、或聯準會轉向大幅降息把利差收斂，否則日圓弱勢是結構性的，任何乾預都是逢高沽日圓的機會。

傳導鏈

美日利差維持高檔 → 套利交易持續做空日圓 → 日圓貶值 → 進口通膨壓迫BOJ表態升息 → 升息預期降溫又反手壓日圓 → 亞幣競貶、資金流向美元與海外資產 → 台灣資金外流買日本房產

結構性

結構性：源於長期的利差與人口/債務結構，非短期波動

矛盾訊號

『日本升息預期升溫應撐日圓』vs『升息預期反而降溫、日圓再貶』——訊號矛盾點在於BOJ在通膨與龐大政府債務利息負擔間投鼠忌器，升息空間受限，市場已看穿這點

分叉情境

若BOJ在下次會議意外升息並釋出鷹派前瞻指引，美元兌日圓可能自高檔快速回落5-8日圓、觸發carry trade平倉；若BOJ維持按兵不動，美元兌日圓有機會挑戰更高整數關卡、亞幣競貶壓力續增

展望

短期 · 1M
短期（1個月內）：日圓在乾預與套利拉鋸下高檔震盪，任何乾預帶來的反彈都偏短命
中期 · 3–6M
中期（3-6個月）：關鍵變數是聯準會是否升息（放大利差）與BOJ升息決心，兩者一升一按將延續日圓弱勢

口說版

「日圓的核心是利差，不是乾預。高盛連BOJ出手都不看好，因為只要美日名目利差維持高檔，套利交易就會一直做空日圓。對做外匯與資產配置的國泰CIM來說，我會把乾預造成的日圓反彈當成逢高沽出的機會；而且日圓弱勢有個延伸交易——台灣資金正大舉買進東京房產，這是匯率、地緣、財富效應三重驅動的結構性資金流。」

美股估值警訊——Grantham稱『美國史上最貴市場』、Burry首度放空卡特彼勒

深度解析

發生什麼事

價值投資大師Jeremy Grantham直言AI推升的估值讓美股成為『美國史上最貴的市場』。以《大賣空》聞名的Michael Burry在卡特彼勒（Caterpillar）於2026年AI行情中股價近乎翻倍後，生涯首度放空這檔股票，稱『它就這樣跳出來抓住我的目光』。與此同時出現耐人尋味的分歧：小型股迎來35年來（自1991年）最強的上半年、AI題材外溢；但『七雄』（Magnificent 7）6月表現疲弱、年初至今轉為負報酬。華爾街雖喊下半年『很牛』，卻同時提醒不要蜂擁追買特定族群。國際清算銀行（BIS）也警告公債高漲疊加AI投資過熱，令全球經濟脆弱。

解讀

這是典型的『多頭末段輪動』訊號：資金從擁擠的權值AI股，外溢到落後的小型股與景氣循環股（如卡特彼勒），拉高整體指數但也拉高了尾部風險。我的判斷是——市場正處在『擴張末期到高峰』的過渡帶，估值已透支未來多年成長，Burry放空卡特彼勒正是在賭『AI基建需求被過度外推到重機械』的預期差。

傳導鏈

AI權值股估值過高 → 資金外溢至落後的小型股與循環股 → 卡特彼勒等重機械股翻倍 → 估值脫離基本面 → 空方（Burry）進場 → 一旦AI capex放緩，外溢邏輯瓦解 → 循環股與小型股回吐領跌

週期性

週期性為主：屬牛市末段的資金輪動與估值擴張，週期定位偏向擴張末期／接近高峰

矛盾訊號

『小型股35年最強上半年、下半年很牛』vs『史上最貴市場、大師放空、七雄轉負』——多空論述同時存在，反映市場對AI景氣『續航』與『見頂』的定價尚未收斂

分叉情境

若Q2 AI大廠財報（三星、台積電、Meta）續強且資本支出上修，輪動行情延續、小型股與循環股再漲一波；若任一龍頭下修capex指引，估值最貴的族群首當其衝、卡特彼勒這類外溢受惠股回檔20%以上，Burry的空單獲利

展望

短期 · 1M
短期（1個月內）：財報季主導方向，指數在AI大廠財報前後波動加大，資金持續在權值與小型股間輪動
中期 · 3–6M
中期（3-6個月）：若通膨黏著＋聯準會轉鷹，高估值成長股折現率承壓，市場恐由『估值擴張』轉為『看獲利兌現』
長期 · 1Y+
長期（1年以上）：AI是否真能兌現生產力紅利決定這輪估值是泡沫還是重定價；BIS的警告提醒，公債水位偏高使系統對利率與獲利失望的容錯空間變小

持續追蹤

七雄與小型股（Russell 2000）相對強弱卡特彼勒等循環股估值AI大廠capex指引美股股債風險溢酬（ERP）BIS/IMF對系統性風險的示警

面試角度

中信投資專案角度：在『史上最貴市場』做大型投資案評估，估值假設與退出倍數（exit multiple）該如何抓才不會買在高點？富邦證券投行組會問：估值過高時IPO/SPO的定價與時機窗口如何拿捏，發行人與投資人的利益怎麼平衡？

口說版

「我會用『多頭末段輪動』來讀現在的美股。Grantham說這是史上最貴的市場、Burry生涯首度放空卡特彼勒，同時小型股卻創35年最強上半年——這種多空並存正是牛市末段的特徵，資金從擁擠的AI權值股外溢到落後族群。如果我在中信做投資專案評估，我會特別警惕退出倍數的假設，因為現在的高估值已經把未來好幾年的成長折現進來，安全邊際很薄；一旦AI大廠capex指引下修，估值最貴、靠外溢邏輯撐起來的族群會最先修正。」

台灣富豪搶進日本房市——成東京都心新建公寓最大境外買家

深度解析

發生什麼事

台灣富裕人士正大舉進軍日本房市，成為東京都心新建公寓最大的境外買家。據日本國土交通省統計，東京市中心新公寓的境外買家中，台灣人佔比居首。背後有三大驅動：一是台灣半導體帶來的財富效應（護國群山造富），二是日圓走弱大幅降低以台幣計價的購入成本，三是兩岸地緣政治風險促使高資產族群分散資產配置。這股趨勢與日圓的結構性貶值互為因果，形成一條清楚的跨境資金流。

關鍵數據

台灣人為東京都心新建公寓最大境外買家；台幣近期貶破32元、日圓同步走弱放大匯率誘因

解讀

這不是單純的投機買房，而是『財富效應＋匯率套利＋地緣避險』三重結構性力量疊加的資產配置行為。我的判斷是，只要日圓弱勢與兩岸風險不變，這股資金流具高度黏著性，且會從住宅外溢到日本商用不動產與REITs。

傳導鏈

台灣半導體造富 → 高資產族群現金部位增加 → 日圓貶值降低海外購入成本 → 兩岸地緣風險推升分散資產需求 → 台灣資金湧入東京房市 → 進一步支撐日本都心房價、外溢至商用不動產

結構性

結構性：財富效應與地緣風險屬長期趨勢，非短期波動；唯匯率因素含週期成分

分叉情境

若日圓續貶且兩岸風險升溫，台灣資金將從住宅擴散到日本商用不動產與物流資產；若日圓大幅反彈（升值5-8日圓），以台幣計價的報酬率被侵蝕，投機性買盤退場、剩下自用與長線配置買盤

展望

短期 · 1M
短期（1個月內）：日圓維持弱勢，台灣買盤延續，聚焦東京、大阪都心新案
中期 · 3–6M
中期（3-6個月）：若日圓因BOJ升息反彈，短線購入成本上升可能小幅降溫買氣，但地緣與財富效應仍撐需求

口說版

「台灣富豪成為東京新建公寓最大境外買家，這是一個很好的跨資產案例——它同時反映了半導體財富效應、日圓貶值的匯率套利、以及兩岸地緣避險三股力量。如果我在中信做不動產投資專案，我會把它看成一條可延伸的資金流：從住宅外溢到日本商用不動產和REITs，而風險點就是日圓，一旦BOJ升息讓日圓大幅反彈，以台幣計價的報酬率會被侵蝕，投機買盤就會退。」

中國房市危機蔓延——龍頭萬科（Vanke）爆巨額虧損

持續追蹤中

發生什麼事

《華爾街日報》報導，中國指標性房企萬科（Vanke）公布巨額虧損，凸顯房地產危機正持續擴散。萬科向來被視為財務相對穩健的『優等生』，如今也難逃衝擊，市場再度質疑危機是否會進一步蔓延、以及中國官方是否將出手救援。

關鍵數據

萬科（Vanke）公布巨額虧損；市場關注中國政府是否介入紓困

解讀

當連財務最穩健的龍頭都爆虧，代表這波房市調整已從『個別高槓桿房企違約』演變為『行業系統性去化』。我的判斷是，中國房市仍在L型底部的長尾階段，官方政策底已到但市場底未到。

傳導鏈

萬科等龍頭爆虧 → 市場對房企信用重新定價 → 銀行對開發商放款更保守 → 土地出讓與新開工續縮 → 地方政府土地財政承壓 → 拖累中國內需與大宗商品需求

分叉情境

若中國政府擴大收儲與注資，龍頭房企信用風險暫緩、A/H股地產股反彈；若官方按兵不動，違約與虧損擴散，恐波及上游鋼鐵、水泥與大宗商品需求

展望

短期 · 1M

台股挑戰47K、新台幣卻貶破32元——股匯不同調，外資獲利了結撞上股利匯出旺季

深度解析

發生什麼事

台股與新台幣走勢明顯背離。台股早盤一度重返47,000點之上、由台積電領軍、記憶體股助陣，市場並喊出挑戰50K；但新台幣匯率貶勢明確，因熱錢持續流出，盤中摜破32元整數大關、最低觸及32.047元、重貶約1.17角，為睽違3個月再見『32字頭』。匯銀人士指出，台股上方有壓、外資獲利了結並匯出，加上7、8月適逢企業股利匯出旺季，共同壓抑匯價。三大銀行對美元後市看法分歧。券商並因股票質押額度吃緊發出風險通知。

解讀

股匯不同調的本質是『本土資金撐盤、外資調節匯出』的資金結構分歧。我的判斷是，這反映外資對台股高檔（近47K）的獲利了結需求，疊加季節性股利匯出，短期匯率弱勢難免；但只要台股AI基本面不變、本土資金＋財富效應續撐，股市未必跟著匯率走弱。關鍵在外資是『調節』還是『轉空』。

傳導鏈

台股攻高至47K → 外資獲利了結 → 資金匯出換美元 → 疊加7-8月股利匯出旺季 → 新台幣需求減、供給增 → 匯價貶破32元 → 若外資由調節轉為趨勢性匯出，股匯恐同步走弱

結構性

週期性為主：季節性股利匯出＋高檔獲利了結；但半導體財富效應與資金行情屬結構性支撐

矛盾訊號

『台股攻47K、挑戰50K』（股市強）vs『新台幣貶破32元、外資匯出』（匯市弱）——股匯不同調的訊號矛盾，關鍵在辨別外資是短期匯率避險/獲利了結，還是對台股基本面轉空

分叉情境

若外資僅為股利匯出與匯率調節、AI財報季（台積電法說）續強，股匯將回歸同調、台股挑戰50K；若外資轉為趨勢性賣超並匯出，股匯同步走弱、新台幣貶勢延續、指數回測月線支撐

展望

短期 · 1M
短期（1個月內）：7-8月股利匯出旺季壓抑新台幣，匯價在32元附近震盪偏貶，台股在財報季高波動
中期 · 3–6M
中期（3-6個月）：若AI基本面延續、外資回補，股匯有望重回同調；反之聯準會轉鷹＋美元走強，亞幣續貶
長期 · 1Y+
長期（1年以上）：半導體財富效應與AI資本行情是台股結構性支撐，但需留意資金過度集中AI權值股的系統性風險

持續追蹤

新台幣匯率與外資買賣超/匯出台股在47K-50K的量能與外資動向台積電法說會（財報季）股票質押維持率與券商風險通知三大銀行美元/新台幣預測

國泰CIM會問：股匯不同調時，你如何判斷外資是調節還是轉空、資產配置該如何因應匯率風險？富邦證券投行組角度：新台幣貶值對企業海外籌資（如赴美IPO）與匯兌損益有何影響？

口說版

「台股攻上47K要挑戰50K，新台幣卻貶破32元，這種股匯不同調，本質是本土資金撐盤、外資獲利了結匯出的資金結構分歧。我會關鍵去分辨：外資到底是調節還是轉空？現在看起來偏向前者——是高檔獲利了結加上7、8月股利匯出旺季的季節性因素。如果我在國泰CIM做資產配置，我會在匯率避險上多做一點，但不會因為匯率弱就看空台股，因為只要AI財報季台積電法說撐住、本土資金和財富效應還在，股市未必跟著匯率走。」

發生什麼事

金管會公布金融三業最新獲利，受惠資本市場暢旺、交投熱絡，2026年前5月合計稅前淨利達7,569.3億元、年增5,241.55億元或2.25倍，續創同期新高。其中銀行業3,279.3億元（年增35.8%）、保險業2,725億元、證券投信業1,565億元，全數改寫同期新高。市場預期全年獲利有望再度叩關兆元、配息空間擴大，唯壽險發股息仍要闖三道關卡。整體看，台股熱絡讓市場資金緊俏、銀行搶活存戶，八大銀行全年總存款拚近雙位數成長。

關鍵數據

解讀

金融三業獲利爆發是『台股資金行情＋交投熱絡』的直接受惠者，本質是市場行情驅動的週期性獲利，非結構性ROE提升。我的判斷是，這波獲利高度連動台股多頭，若下半年股市高檔震盪加大，證券與投資收益的成長動能將放緩；但銀行的存放款與財管業務相對穩健，是防禦性較強的一塊。

結構性

週期性為主：獲利高度連動台股多頭與交投熱度，非結構性ROE改善

分叉情境

若下半年台股續強、交投熱絡，金融三業全年獲利叩關兆元、金控配息加碼；若股市回檔、資本利得縮水，保險與證券獲利成長趨緩、獲利成長由『高基期』轉『個位數』
