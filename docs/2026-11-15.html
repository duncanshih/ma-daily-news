總經 / 地緣政治

東協馬尼拉峰會：南海準則談判交棒新加坡、高市早苗倡「亞洲版IEA」 — 能源安全成為亞太外交的新貨幣

深度解析

發生什麼事

東南亞國家協會（ASEAN）峰會15日在馬尼拉登場，輪值主席國菲律賓坦承無法在任內完成南海行為準則（COC）談判，僅促成各方就約8成內容達成共識，將交棒給2027年主席國新加坡繼續推進。半島電視台指出，美國與以色列對伊朗的戰爭造成的能源斷鏈，是這個高度依賴進口能源的區域集團本屆峰會的核心議題。日本首相高市早苗擬於17日在馬尼拉舉行的亞洲零排放共同體（AZEC）領袖會議上，倡議成立「亞洲版國際能源總署（IEA）」，由日本收費替東南亞國家儲備石油，作為危機時期合作調度石油的架構。同日菲律賓與澳洲在峰會場邊簽署新國防協議，簡化聯合軍事行動協調程序以「強化嚇阻」中國在南海的軍事擴張；加拿大總理卡尼也在馬尼拉表示與川普的貿易談判「取得進展但尚未達成協議」。此外，美國空軍兩架F-15EX戰機15日抵達沖繩嘉手納基地，是這型戰機首度常態性部署於美國之外。

解讀

這是基本面而非情緒面：近9個月的美伊戰爭與荷莫茲海峽斷航，讓亞洲進口國第一次認真把「石油戰略儲備」當成區域公共財來談，日本提議的「亞洲版IEA」本質上是把日本過剩的儲油基礎設施商業化、同時換取區域影響力。COC談判失敗則顯示中國在南海的議價力沒有因美國介入而下降，菲澳國防協議與F-15EX常駐都是「美國分心中東、盟友自行補位」的訊號。

傳導鏈

荷莫茲斷航9個月 → 亞洲進口國庫存見底、現貨溢價 → 日本提議收費代儲石油（亞洲版IEA）→ 儲油槽、LNG接收站、海運保險需求結構性上升 → 區域能源基建成為新一輪政府主導的資本支出 → 台灣中油、台塑化的儲備政策與民間儲槽投資面臨重新定價

結構性

結構：能源安全從「市場效率」轉向「韌性」的定價邏輯一旦建立，即使伊朗停火也不會回到戰前的低庫存模式，這與2022年歐洲天然氣危機後LNG長約比例永久性上升的路徑相同。

矛盾訊號

IEA同日說全球油市已轉為供過於求、布蘭特跌破90美元，但亞洲國家卻在峰會上把能源斷鏈列為頭號議題。價格訊號說「危機過去了」，政策訊號說「我們不再相信市場會在危機時供油」。兩者都對：價格反映當下流量，政策反映對下一次斷航的恐懼。

分叉情境

如果高市提案在AZEC會議獲得至少5個東協國家簽署意向書（17日可驗證），則日本商社（三菱、三井）與儲油基建相關標的中期受益，亞洲LNG長約比例可能從目前約65%升至70%以上；如果提案僅停留在倡議層次且美伊在APEC前達成停火，則區域能源基建溢價會隨布蘭特回落至80-85美元而消退，資金回流AI硬體。

展望

短期 · 1M
短期（1個月內）：17日AZEC會議與APEC深圳峰會是兩個觀察點；若亞洲版IEA有具體簽署國，布蘭特在85-95美元區間的地緣溢價下限會被政策需求托住，難以跌破80美元。
中期 · 3–6M
中期（3-6個月）：新加坡接手COC談判後2027上半年難有突破，南海軍事化持續；亞洲儲油與LNG接收站的政府主導投資案（含台灣第三、四接收站進度）會成為基建基金的新標的，預估亞太能源基建年化報酬要求從8-10%上修到10-12%以反映地緣風險。
長期 · 1Y+
長期（1年以上）：亞洲能源安全架構若成形，等於在IEA之外建立一個以日本為中心的區域儲備體系，中國被排除在外會強化「兩套能源供應鏈」格局，對台灣意義是能源進口來源多元化從政策口號變成有國際框架可依附的實務。

持續追蹤

面試角度

開發資本基礎建設投資面試可能問：如果亞洲版IEA成形，台灣的儲油槽、LNG接收站專案的IRR假設要怎麼調？答案方向是「政府需求保證提高現金流確定性、可降低風險溢價1-2個百分點，但地緣風險讓資金成本上升」兩者相抵。國泰CIM會關注：能源安全溢價對亞幣與日圓的影響——日本若收費代儲，等於多了一筆服務出口收入，長期對日圓是小幅正面。

「我會把馬尼拉東協峰會看成「能源安全從市場議題變成外交議題」的轉折點。IEA說油市已經供過於求、布蘭特跌破90美元，但同一天東協把能源斷鏈列為頭號議題、日本提議收費替東南亞儲油，這個落差說明亞洲進口國已經不再相信市場會在危機時供油。從基建投資的角度，這代表儲油與LNG接收站的政府主導需求會上升，專案現金流確定性提高，但要用更高的地緣風險溢價來折現，兩者相抵後我認為亞太能源基建的合理報酬要求會從8-10%上修到10-12%。」

解讀

發生什麼事

APEC峰會本周在深圳登場，白宮13日宣布川普提議與普丁、習近平舉行歷史性「三邊無核化」會談，CSIS核子專家威廉姆斯撰文指出川普自1980年代就對核裁軍抱有熱情，但實務上困難重重；幾乎同時，外媒引述商業衛星影像指中國正快速擴充四川峨眉山附近的離心機鈾濃縮設施，暗示北京可能已結束近40年暫停生產武器級高濃縮鈾的狀態。貿易面上，中美官員在川習會前討論關稅與農產品貿易，北京重申美方須先落實600億美元關稅削減協議，才是增加採購美國農產品的前提。FT專文指出深圳APEC將展示中國「按自己條件重塑全球秩序」的野心。另一方面，加拿大總理卡尼14日稱與川普的貿易談判「有實質進展但尚未達成協議」，並強調加拿大不會退出北約。

關鍵數據

中方要求落實600億美元關稅削減協議；川普提議美中俄三邊無核化會談；中國峨眉山鈾濃縮廠疑結束近40年停產

解讀

川普的「三邊無核化」是典型的議題捆綁：用一個大到不可能短期達成的目標，為APEC川習會製造「大國談判」氛圍，實際可交割的只有農產品採購與關稅執行。但鈾濃縮廠的衛星證據讓這個提案在開場前就被打臉。對市場而言，真正重要的是600億美元關稅協議是否在深圳簽署執行時程，這決定台灣對美出口的轉單效應能延續多久。

傳導鏈

APEC川習會 → 若600億關稅削減協議落實 → 中國恢復採購美國黃豆/玉米 → 美國農產品價格回升、通膨壓力小幅增加 → Fed升息理由更充分；同時中國對美出口關稅下降 → 台灣與東南亞的轉單效應邊際減弱 → 台灣10月出口年增58.9%的高基期難以維持

分叉情境

如果深圳簽署600億美元關稅協議執行時程且中國承諾年採購300億美元以上農產品，則美中「交易式緩和」延續到明年Q1，台灣轉單效應放緩、新台幣出口旺季支撐減弱；如果峨眉山鈾濃縮議題被美方公開提出且川普退出三邊會談，則地緣風險溢價回升、黃金重返4,000美元以上。

展望

短期 · 1M
短期（1個月內）：深圳APEC若產出關稅協議執行時程與農產品採購數字（市場預期年採購300-400億美元），則人民幣在6.60-6.65偏強、亞股短線受惠；若僅有「無核化」等口號式聲明，則視為談判失敗，人民幣回測6.70。
中期 · 3–6M
中期（3-6個月）：民主黨1月接掌國會後，對中強硬的立法（晶片出口規則、Megaspeed實體清單）會與川普的交易式外交形成府會拉扯，美中關係的波動率上升而非方向改變。

矛盾訊號

家族辦公室把60%資產放進流動性差的另類資產，同時FT警告對沖基金「熱錢」風控失靈、Trump Media面臨10億美元債務危機——資金一方面厭惡流動性風險，一方面卻湧向更不流動的資產。解釋是：他們厭惡的不是不流動，而是「被迫在錯的時間賣」，私募資產的估值不會每天被市場打臉。

深度解析

發生什麼事

伊朗革命衛隊（IRGC）15日宣稱為報復美國「敵對行動」，向巴林一處空軍基地的美軍雷達設施發射6架無人機；巴林國防軍表示空防系統攔截了「數起伊朗空中攻擊」，並發布兩次潛在威脅警報，是今年9月以來首次。伊朗稱對「與美國合作的國家」發動攻擊在國際法上是正當的，巴林則指控伊朗攻擊其領土是為了「與美國算帳」。這是在美伊近9個月戰爭能否達成協議仍充滿不確定性之際發生：川普上周稱「我們已經掌握了他們的海峽」、不需要協議，國務卿Rubio稱談判「毫無成果」、伊朗的要求「離譜」，財長Bessent因領導「經濟驅逐行動」成為伊朗威脅目標而被移至軍事基地辦公。供給面卻在反方向：IEA月報指俄羅斯10月原油產量回升至每日873萬桶、波灣出口恢復，全球供給已超過需求、油市轉為供過於求，但警告重建被戰爭耗盡的庫存「需要數月」。布蘭特上周一度跌破90美元（8月以來首次），美國汽油跌破每加侖4美元（7月以來首次），柴油14日跌破每加侖6美元創2個月新低。美國家庭取暖油價格仍比去年冬天高59%，緬因州非營利組織稱正在「壓垮民眾」。

解讀

這是地緣政治與供給基本面的罕見分叉：軍事上戰爭沒有結束（巴林襲擊、Bessent躲進軍營、Rubio說談判沒成果），但原油流量上已經「正常化」（俄羅斯增產、波灣出口恢復）。市場選擇相信流量而非炮火，布蘭特跌破90是在交易「戰爭持續但不影響供給」的情境。我認為這個定價太樂觀：巴林襲擊是伊朗在展示它仍有能力打擊波灣產油國的基礎設施，而IEA說庫存重建需要數月——意味著任何一次成功的基建攻擊都會讓價格反彈15-20%，因為沒有庫存緩衝。

週期中的結構：價格回落是週期性的（供給恢復、季節性需求轉弱），但「無庫存緩衝」是這場戰爭留下的結構性脆弱，會讓油價在未來12個月的波動率比戰前高出一倍。

分叉情境

深度解析

發生什麼事

緯創資通宣布投入129億元購置廠房與機械設備、擴大台南AI伺服器相關產能，台南市長黃偉哲稱市府將協助（南科沙崙「雙引擎」）。工商時報報導台積電先進製程進駐高雄帶動北高雄從傳統工業區轉型，市府都市計畫檢討與產業用地開發新增楠梓、橋頭兩科學園區及白埔、聖森路西側產業園區，合計提供562公頃產業腹地，預估帶動1.4兆元年產值、2.5萬個就業機會，範圍涵蓋晶圓製造、先進封裝到材料設備。PCB方面，TPCA統計上半年台灣PCB海內外產值5,247億元、年增23.9%，全年有望衝上1.1兆元，金像電、華通擴產搶市；PCB設備上半年產值460.8億、年增27.8%，群翊、亞泰金屬等六大廠產能全滿載、關鍵設備一機難求交期延長；材料端PTFE被視為取代玻纖布的下一代材料，台虹、台郡搶進輝達供應鏈。日月光投控前三季營收6,088.87億元、年增逾30%創同期新高，路竹千億先進封裝基地已啟用。

關鍵數據

緯創129億台南擴產；高雄562公頃產業用地、1.4兆年產值、2.5萬就業；PCB全年產值看1.1兆（上半年+23.9%）；PCB設備上半年+27.8%；日月光前三季營收6,088.87億（+30%）

解讀

這些資本支出的共同特徵是「在股市崩跌的同一周宣布」——緯創129億、高雄562公頃都是在台股跌12,131點之後，說明實體經濟的投資決策週期（18-36個月）與股市的定價週期（1-3個月）完全脫鉤。對基建與不動產投資者這是明確的訊號：南科、高雄的工業用地與廠辦需求是「已簽約的需求」，不會因輝達事件消失。但要注意PCB設備「一機難求、交期延長」是循環高點的典型現象，2027年設備交付後若需求不如預期，產能過剩的壓力會先出現在設備與材料端。

傳導鏈

AI伺服器訂單（2027年已敲定）→ 緯創/鴻海/廣達擴產（緯創129億台南）→ 南科、高雄工業用地需求上升（562公頃）→ PCB、CCL、載板擴產（全年1.1兆）→ PCB設備滿載、交期延長 → 2027年設備交付、產能釋出 → 若AI需求持續則材料端（PTFE、玻纖布）缺口擴大；若見頂則設備端先過剩、工業地產租金承壓

分叉情境

如果雲端巨頭2027年capex維持且輝達17日法說guidance穩定，則緯創129億投資在2027下半年貢獻營收、高雄562公頃在3年內去化70%以上、PCB產值2027年挑戰1.3兆；如果AI capex見頂訊號在明年Q1確認（巨頭下修capex超過15%），則PCB設備廠訂單在Q2出現取消、南科高雄工業地產租金漲幅從雙位數降到個位數、壽險業自地委建案的租金假設需下修。

展望

短期 · 1M
短期（1個月內）：經濟部外銷訂單（估1,125-1,159億美元創高）與上市櫃Q3財報全數出爐（16日）是驗證點；高雄產業用地的開發時程與公告地價是基建投資者的進場參考。
中期 · 3–6M
中期（3-6個月）：PCB設備交期若從目前約9-12個月縮短到6個月以下，代表擴產高峰已過；南科與高雄廠辦租金若年漲幅超過10%，壽險資金（國泰人壽自地委建倉儲模式）會加速進場。

「台股跌12,131點的同一周，緯創宣布129億加碼台南、高雄為台積電新增562公頃產業用地估1.4兆年產值，這說明實體投資的18到36個月決策週期與股市1到3個月的定價週期完全脫鉤。對開發資本基礎建設投資來說，南科與高雄的工業用地是已簽約的需求、不會因輝達事件消失，是進場的好時機；但我會提醒一個週期訊號：PCB設備一機難求、交期延長到9到12個月是循環高點的典型現象，2027年設備交付後若需求不如預期，產能過剩會先出現在設備與材料端。所以配置上我會偏向土地與廠辦這類「需求確定、供給受限」的資產，而非設備製造商。」

台灣IPO與籌資管線：鈺祥通過上市審議規劃2027Q1掛牌、宏于電機16日申購（承銷價208元 vs. 市價293元）、正達3,500萬美元參與美國SPAC私募、耐能赴美IPO — 震盪市中的資本市場活動（持續追蹤）

持續追蹤中

發生什麼事

台灣資本市場在震盪中維持籌資活動：先進製程微污染防治（AMC）濾網廠鈺祥（7909）獲證交所上市審議委員會通過IPO申請、待董事會核議，規劃2027年第1季掛牌，明年迎40周年。智慧電力與能源系統整合廠宏于電機（7869）16日啟動上櫃前公開申購，承銷價每股208元，以13日收盤293元計算中籤潛在獲利約8.5萬元（溢價約41%）。正達砸3,500萬美元參與美國SPAC IX Acquisition的私募案（PIPE），加速推進無人機（UAV）市場布局。AI晶片新創耐能進入赴美IPO關鍵階段。海外方面，Anthropic本周上市、阿里T-Head赴港上市、輝達投資的新雲Nscale更新招股書顯示虧損擴大、美國國防科技新創Anduril盼兩年內IPO挑戰洛馬雷神。富邦金控董事長蔡明興15日獲頒台大名譽博士，致詞回顧富邦人壽初期「資本額差點虧光」靠調整商品與銀保通路翻身。

關鍵數據

鈺祥2027Q1掛牌；宏于電機承銷價208元、市價293元（溢價41%）；正達3,500萬美元PIPE；耐能赴美IPO；Nscale虧損擴大

解讀

宏于電機承銷價與市價41%的落差是台灣IPO市場「定價保護」的典型現象——詢圈制度與承銷商的保守定價讓一級市場投資人幾乎穩賺，代價是發行公司少募了約30%的資金，這是台灣投行與美國投行最大的結構差異。正達選擇參與美國SPAC的PIPE而非在台灣籌資，顯示台灣中小型科技公司對海外資本的需求；耐能選擇赴美而非台灣IPO，則是AI新創「估值在美國」的現實。對投行來說，震盪市中IPO沒有停擺是好訊號，但Nscale虧損擴大與Anthropic定價下修提醒：窗口是開的，但估值要讓步。

傳導鏈

台股震盪但未凍結 → 中小型IPO（鈺祥、宏于）照常推進、承銷價保守 → 一級市場投資人獲得41%保護溢價 → 申購熱度維持、資金留在台灣IPO市場 → 但AI新創（耐能）與需要大額資金者（正達）轉向美國 → 台灣投行在「大案流失、小案承做」的結構下，業務轉向海外籌資顧問（如協助PIPE、ADR）→ 富邦投行的國內外籌資能力成為差異化關鍵

分叉情境

如果Anthropic首周站穩且台股守住42,000，則年底前台灣IPO申請件數維持月均8-10件、耐能美國IPO在Q1完成且估值超過30億美元；如果Anthropic破發且台股回測40,000形成第二隻腳，則鈺祥等案可能延後到2027Q2、承銷價折價擴大到50%以上、正達式的海外PIPE成為中小型科技公司的替代籌資路徑。

展望

短期 · 1M
短期（1個月內）：宏于電機申購中籤率與掛牌首日表現是震盪市IPO熱度的指標；Anthropic掛牌首周若穩，耐能的美國IPO時程可能提前到明年Q1。
中期 · 3–6M
中期（3-6個月）：鈺祥2027Q1掛牌、耐能赴美、T-Head赴港，三個市場的AI供應鏈IPO同時進行，台灣投行能否在耐能這類案件中取得共同承銷或台灣存託憑證（TDR）角色，是對富邦、元大投行能力的考驗。
