總經 / 地緣政治

Fed升息共識成形 — 施密德稱通膨「朝錯誤方向發展」、Waller開放12月升2碼、10月PPI年增6.5%近四年高，金價跌破3,900美元

深度解析

發生什麼事

堪薩斯城聯準銀行總裁施密德（Jeff Schmid）週日在夏威夷信用合作社會議上表示，通膨「令人不安地超出2%目標，且正朝著錯誤的方向發展」，聯準會「有工具也有責任」應對已經過熱的物價壓力。這是繼Fed理事Waller上周表態「傾向12月升息、視數據可支持升2碼」、芝加哥聯準銀行總裁Goolsbee形容10月CPI「borderline disturbing」之後，第三位鷹派官員公開發言。10月PPI年增6.5%，創近四年新高，顯示上游成本壓力仍在堆積；FT統計上周是美債自「解放日」以來最差一周，10年期殖利率一度回到5.145%。市場反應直接反映在貴金屬：黃金現貨週一亞洲盤重挫52美元、最低回測每盎司3,832.8美元，接連跌破4,000與3,900美元整數關卡，臺銀指出若本周美國零售銷售與FOMC會議紀要偏鷹，金價恐下探3,800美元尋求支撐。Fed同時宣布政策程序調整：2027年10月會議將不進行利率投票，明年只有7次投票會議。

解讀

這不是情緒面而是基本面：PPI 6.5%意味著CPI還有上行壓力尚未完全傳導，Fed官員集體轉鷹是在替12月升息鋪路，爭論焦點已經從「升不升」轉為「升1碼還是2碼」。黃金作為避險資產卻在股市崩跌日下跌，說明實質利率上行的力量壓過避險需求，這是典型的「升息週期初期」資產行為。對台灣而言最關鍵的是美台利差擴大，央行12月被迫跟進升息的機率上升。

傳導鏈

PPI 6.5%上游成本堆積 → Fed官員集體轉鷹、12月升息1-2碼定價 → 美債10年期殖利率站上5%、美元指數走強 → 實質利率上行壓垮黃金（跌破3,900）與高估值科技股 → 台美利差擴大、外資匯出壓力、新台幣逼近33元 → 央行12月升息機率升高 → 台灣房貸、企業融資成本上升

結構性

週期性：這是2022年以來第二輪升息週期的起點，但背後的結構性因素是伊朗戰爭推升能源成本與關稅導致的輸入性通膨，使通膨比上一輪更黏著。

矛盾訊號

Fed說通膨過熱要升息，但日本Q3 GDP意外萎縮、中國10月數據全面miss、美國成屋銷售創16年新低——需求端已在走弱。市場在賭「停滯性通膨」而非「過熱」，這解釋了為何升息預期升溫但股市崩跌而非輪動。

分叉情境

如果11/19 FOMC會議紀要顯示多數委員支持升2碼、且本周零售銷售年增超過4%，則10年期美債殖利率將挑戰5.3%、金價下探3,700-3,800美元、台股外資續賣；如果零售銷售轉弱、會議紀要顯示委員對升息幅度分歧，則殖利率回落至4.9%以下、金價反彈至3,950-4,050美元區間。

發生什麼事

解讀

亞洲三大經濟體同時出現需求疲弱訊號，而美國Fed卻在談升息——這是典型的「美國通膨、亞洲通縮」分化格局。日本的問題是能源輸入型通膨吃掉實質所得，中國的問題是內需結構性不足，兩者都會壓縮對台灣的進口需求。台灣AI出口一枝獨秀，但傳統產業（中鋼今日遭外資賣超3.5萬張）正在承受亞洲需求走弱的壓力。

傳導鏈

伊朗戰爭油價高檔 → 日本能源補貼到期、家庭實質所得下滑 → Q3 GDP萎縮、日銀升息兩難、日圓貶破160 → 日本對台灣機械設備、石化進口需求下降 → 中國內需同步走弱、鐵礦石採購壓價 → 台灣傳產（鋼鐵、石化、工具機）出口承壓 → 台股「AI獨強、傳產獨弱」的K型分化加劇

結構性

結構性為主：日本高齡化與能源進口依賴、中國房地產去槓桿與內需不足都是長期問題，能源補貼到期只是觸發點。

分叉情境

如果日本Q4 GDP再度負成長形成技術性衰退、日圓續貶至165，則日銀將被迫在12月升息以守匯，亞洲股市再跌5-8%；如果中國在APEC後推出超過1兆人民幣的消費刺激、11月零售銷售回升至4%以上，則亞洲需求回穩、台灣傳產出口在2027Q1觸底。

FT報導，陷入財務困境的香港地產商新世界發展（New World Development）宣布32億美元供股計畫，新股發行價較市價折價80%，消息公布後股價單日暴跌40%。新世界是鄭氏家族旗下的香港老牌藍籌，近年因大規模商業地產開發（如11 SKIES、K11）累積龐大債務，這次供股是為削減負債的最後手段。同日WSJ報導中國龍頭開發商萬科公布鉅額虧損，市場質疑這家曾被視為「最穩健」的國企背景地產商是否也需要國家出手。美國方面，NAR數據顯示10月成屋銷售年減8.8%、創16年新低，NPR形容為「punch in the gut」。歐洲則是另一種信用壓力：S&P報告指出歐洲銀行越來越依賴合成風險轉移（SRT）來提升報酬與放貸能力，增加了「強迫去槓桿」的曝險；華爾街銀行則準備以面額90-95%出售數十億美元的X（前Twitter）貸款。

解讀

新世界的80%折價供股是一個標誌性事件：這代表香港商業地產的資產價值已經無法支撐債務，股東權益被大幅稀釋以換取生存。這不是週期性修正，而是香港作為「中國離岸資本門戶」地位弱化後的結構性重估。萬科的鉅虧則說明中國地產危機已從民企蔓延到國企背景公司，政府「保交樓不保房企」的底線正在被測試。美國成屋銷售16年新低則是高利率鎖定效應（lock-in effect）的極致，與Fed再升息形成惡性循環。

傳導鏈

香港商業地產租金下滑、估值縮水 → 新世界債務覆蓋率不足、被迫80%折價供股 → 股價崩40%、港股地產板塊重估 → 香港銀行（匯豐、中銀香港）商業地產貸款撥備增加 → 台灣壽險業持有的港股與港元商業不動產評價承壓 → 私募不動產基金在亞洲的退出窗口關閉、IRR假設下修

結構性

結構性：香港地產的問題是中國資本流入消退與辦公需求永久性下降的結果，而非利率週期；萬科與美國成屋則是週期性因素（高利率）疊加結構性因素（中國人口、美國供給不足）。

矛盾訊號

Brookfield與KKR正在爭搶7億美元的波灣眼鏡連鎖Eyewa，私募資本在中東「交易荒」後重啟出手；但同一批私募機構在香港與中國地產卻是賣方。訊號衝突說明私募資本的偏好正從「不動產」轉向「有現金流的實體消費資產」。

分叉情境

如果新世界供股順利完成且香港甲級辦公室空置率在2027Q1前回落到15%以下，則港股地產板塊觸底、台灣壽險港股部位評價損失止穩；如果供股認購不足、鄭氏家族需要額外注資，則香港可能出現第一家藍籌地產商重組，連帶衝擊香港銀行股與台灣金融業的港資曝險。

深度解析

發生什麼事

工商時報引述彭博分析，台灣迎來近40年最強勁的經濟成長之一，AI熱潮帶動出口暢旺，經常帳盈餘高居全球第四，照理應推升新台幣，但新台幣卻逼近2016年以來最低水準。這場「台灣匯率悖論」的關鍵在於企業賺進的大量美元沒有換回新台幣，而是持續留在海外投資擴產；外資今年又創紀錄賣出台股，使AI榮景的美元收入無法轉化為升值動能。經濟日報專欄直指「台幣該強不強？既詭異又瘋狂」，貶向10年來最弱水位與正常外匯法則背道而馳。16日股匯雙殺，新台幣盤中一度貶逾1角、最低觸及32.969元逼近33元關卡，但央行盤中持續實彈穩匯、尾盤直接沒收近1角貶幅，終場收32.886元、僅貶4.8分，成交17.22億美元；匯銀主管認為央行穩匯決心很強，短線守住32.8元價位。中央社報導外資大舉賣超台股卻不急於匯出、甚至反手匯入。央行同日公布10月國銀人民幣存款餘額1,067.49億元、連2月下滑，官員提醒關注Fed升息預期是否帶動資金轉向美元。央行總裁楊金龍則表示12月是否升息需考量通膨與放款熱度等3重點，台灣CPI年增率持續高於2%警戒線。經濟部公布前10月對外投資699.16億美元、年增105.14%，主要是台積電增資海外子公司500億美元。

解讀

彭博點出的「悖論」其實是台灣經濟結構轉變的結果：AI出口的美元收入屬於台積電等少數企業，它們把美元留在海外（亞利桑那、日本、德國擴廠，前10月對外投資699億美元翻倍），這些錢永遠不會回來換台幣。同時壽險業的海外部位與外資賣股，形成「出口賺美元、資本流出美元」的雙重結構。央行的實彈護盤只能平滑波動、無法扭轉方向。但16日外資「賣股不匯出」是個關鍵訊號：外資在等待更好的進場點而非撤離，這意味著台幣的貶值壓力有底。12月央行升息與否將是台幣方向的決定點——升息縮小台美利差可支撐台幣，但會壓抑已經被6%崩跌嚇壞的股市。

結構性

結構性：台灣企業「賺美元、留海外」的模式是全球化布局的必然，不會因為週期逆轉；但Fed升息造成的利差擴大是週期性的。

矛盾訊號

經常帳盈餘全球第四、僑外投資創高（208.99億美元）、但台幣逼近10年最弱——資本流動的方向與經常帳背道而馳。另一個矛盾：外資賣超701億卻不匯出、反手匯入，說明「賣股」與「看空台幣」是兩回事。

分叉情境

如果央行12月升息半碼且Fed只升1碼，台美利差縮小、台幣在32.3-32.8區間回穩；如果央行按兵不動而Fed升2碼，台幣貶破33元、央行干預成本上升、進口物價推升CPI至2.5%以上，形成「貶值-通膨-被迫升息」的惡性循環。
